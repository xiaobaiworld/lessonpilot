# Changelog

## 2026-08-25

- 新增 v1 节点扩展标准：以后增加课程节点必须明确类型、显示、学生动作、返回值、完成规则、本地记录、
  后端职责、版本兼容和验收路径。
- 明确普通节点复用草稿、真实预览、课程发布和课程包接口；只有确有服务端职责时才新增节点专用 API。

## 2026-08-24

- 学生端小人旁新增紧凑的“原视频 / 课程”模式切换。
- 原视频模式不显示课程节点；课程模式恢复节点提示和互动。
- 2 秒重点提示改为更易读的窗口，标题只显示“重点提示”，视频会先暂停，点击“确认并继续”后才恢复播放。
- 示例课程补充 4 道练习路线和简短激励语“加油”。
- 发布候选版本：legacy 插件 `0.9.2`，v1 插件 `1.0.1`。
- V1 `1.0.2` 恢复原有 KnownMap 图标、学生助手小人、书包课程入口和播放控制。
- V1 重点提示支持重新播放时再次弹出，提示按钮统一为“确认并继续”。
- V1 `1.0.3` 将重点提示改为 C 方案的结构化摘要布局；旧版长正文会自动转换为“先理解、再练习、最后巩固”，并保留旧格式回退。
