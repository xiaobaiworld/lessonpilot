# Changelog

## 2026-08-26（依赖安全告警清理）

- Vite 升级到 `6.4.3`，TypeScript ESLint 升级到 `8.68.0`，AJV 升级到 `8.20.0`；
- 移除无官方修复版本的 Quill，改用受安全清洗器保护的原生富文本编辑器；
- 根工程与 v1 workspace 的官方 npm audit 均为 0 vulnerabilities。

## 2026-08-26（契约遗留问题收口）

- 插件存储 Schema 与实际 `StorageRoot` 结构对齐，并增加契约回归测试；
- 后端和插件补齐封闭字段、链接协议、资源类型与视频海报引用校验；
- 手工验收脚本改用当前节点 `anchor` 字段，文档明确区分 B 站播放视频与节点媒体。

## 2026-08-26

- 接受初期发布约定 `D-V1-013`：本机测试后提交 GitHub，用 `web-prod/<时间-commit>` 与 `deploy/releases/*.json` 版本化，再拷本机构建产物到阿里云；唯一入口 `tools/release.sh`。
- 学生插件版本升至 `1.0.10`；互动窗支持大小/样式预设、结构化富页面和练习题本机表单。
- 教师端所有互动节点共用结构化富页面编辑器；保存为 `RichPageDocument`，题型数据与窗口提示分离，不保留普通正文回退或 HTML 真源。
- 课程包升级为 v3：节点媒体通过不可变 `assetId` 引用并由顶层资源清单描述；B 站播放视频仍只保留在课节 `videoRef`。
- 节点类型下拉菜单复用上级交互节点的图标和颜色，并移除重点标注编辑器中的 C 方案结构化提示字段与说明文案。
- 学生插件安全渲染重点标注富文本，只允许有限排版标签、安全链接协议和颜色值，不执行课程内容中的脚本或事件属性。

## 2026-08-25

- 学生插件版本升至 `1.0.9`；内置示例课程前两个互动节点调整为第 1 秒和第 10 秒触发。
- 学生插件版本升至 `1.0.8`；互动节点弹出时暂停正在播放的视频，关闭节点后恢复播放；原本已暂停的视频保持暂停。
- 教师课节编辑器接入参考页的横向可视化时间轴：支持课程内课节切换、长视频五分钟时间段导航、上下交错节点摘要、字幕上下文和节点属性弹窗。
- 修正教师编辑器的无草稿课节加载：课程下拉框现在显示课节名称；时间段支持 5、10、30 分钟切换，并同步更新 `1 / N` 范围、导航和可见竖向刻度线。
- 顶部编辑区按参考图重排为两行：第一行是交互节点按钮，第二行依次显示课程名称、课节下拉框和彩色时间段分页控制。
- 当前测试课程的后台标题已改为创建时使用的“英语面试表达：把答案说得具体”；编辑器加载中使用明确的读取状态，不再显示错误的占位课程名。
- 四种节点的图标统一由共享图标真源渲染，点击放置、拖放、移动、编辑、删除和草稿保存继续使用 v1 现有节点协议。
- 已验证：根目录 135 个测试、v1 236 个测试、后端 16 个测试、类型检查、构建、文档/端点/模块/契约门禁全部通过。
- 删除旧学生插件 `src/`；学生插件版本升至 `1.0.6`。
- 发布与本机构建只使用 `v1/extension/`。
