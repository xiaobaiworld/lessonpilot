# 教师课程编辑器参考样式对齐计划

状态：提议中，尚未进入实现

更新时间：2026-08-25

## 1. 背景与问题

当前 v1 教师课节编辑页已经支持：

- 读取和保存课节草稿；
- 创建四种互动节点；
- 导入 SRT/VTT 字幕；
- 按字幕最后结束时间生成时间轴；
- 在时间轴上点击创建重点标注；
- 在页面下方逐张编辑节点表单；
- 测试预览。

但当前编辑方式与 `forsale.html` 中已经确认过的产品形态不一致。当前页面是：

```text
顶部添加按钮
-> 简化时间轴
-> 字幕导入和字幕列表
-> 纵向节点表单卡片
```

目标页面应是：

```text
课程/课节上下文
-> 交互节点组件栏
-> 横向可视化时间轴
-> 上下交错的节点摘要卡片
-> 选中节点附近的字幕上下文
-> 节点属性编辑弹窗
```

这不是一次单纯的颜色、边框或图标调整，而是把 `forsale.html` 中的编辑逻辑迁移到当前
v1 教师工作台，同时继续使用当前 v1 的后端草稿、发布和授权协议。

## 2. 本轮目标

把教师课节编辑器改造成与 `forsale.html` 同一套信息结构和交互语言的真实编辑器。

本轮完成后，教师应当能够：

1. 从四种节点组件中选择一个节点类型；
2. 点击或拖放到时间轴的指定时刻；
3. 在时间轴上看到节点图标、节点摘要和上下连接线；
4. 选择节点后看到该节点附近的字幕上下文；
5. 打开节点属性弹窗，填写、修改或删除节点；
6. 移动已有节点并自动更新其时间与字幕关联；
7. 取消未完成的新建或编辑而不污染草稿；
8. 保存草稿、刷新后恢复草稿，并继续现有发布流程。

## 3. 约束与非目标

### 3.1 本轮必须保持不变的边界

- 后端继续使用当前 v1 的教师认证和权限边界。
- 草稿接口继续使用：
  `GET /api/v1/teacher/lessons/{lesson_id}/draft`；
  `PUT /api/v1/teacher/lessons/{lesson_id}/draft`。
- 节点仍使用当前 `ScriptNode` 结构。
- 四种节点的后端组合不变：
  - `attention + notice`
  - `practice + choice`
  - `practice + blank`
  - `practice + free_text`
- 字幕仍只在教师浏览器内解析，不上传后端。
- 不新增数据库表、HTTP 端点或外部依赖。
- 不把销售页中的静态示例节点直接当成真实课程数据。
- 不把截图中的课程标题、字幕正文、节点数量或时间点写死到正式编辑器。

### 3.2 本轮明确不做

- 新增节点类型；
- AI 自动生成或改写节点；
- 播放器内嵌、播放头实时同步或自动读取 B 站当前播放时间；
- 多课节同时编辑；
- 撤销/重做历史；
- 自动保存；
- 多人协作和冲突合并；
- 将字幕持久化到服务器；
- 重新设计课程发布包或学生端运行时；
- 把 `forsale.html` 的销售文案、营销区块或静态示例课程搬进教师工作台。

## 4. 目标页面结构

### 4.1 顶部工作区操作

保留当前工作台必要操作，并统一到参考页的紧凑布局：

- 返回课程；
- 当前课程和课节标题；
- 当前课程下的课节菜单或下拉选择器；
- 草稿状态；
- 测试预览；
- 保存草稿；
- 当前页面已有的退出登录入口。

课节选择器规则：

1. 课程编辑器必须以“课程”为工作区，而不是只把单个课节当成孤立页面。
2. 顶部显示当前课程名称和当前课节名称。
3. 同一课程有多节时，课节名称以菜单或下拉选择器展示。
4. 选择其它课节后，先处理当前课节的未保存状态，再切换到目标课节。
5. 切换课节只改变当前编辑上下文，不改变课程身份、教师身份或其它课节草稿。
6. 当前课节的节点数量、字幕、时长、选中节点和 dirty 状态不能错误带到其它课节。
7. 只有当前课节的草稿保存成功后，才允许把它显示为已保存。

发布课程和创建授权码仍属于课程页的现有流程，本轮不把它们重新设计成新的后端动作。
如果编辑页需要提供快捷入口，只能复用已有 API 和现有课程页行为。

### 4.2 课程分段与长视频导航

一个课程可以包含多节；单个课节也可能对应一段很长、内部已经按主题分节的视频。
编辑器需要同时表达这两种层级：

```text
课程
-> 课节 1 / 课节 2 / 课节 3
-> 当前课节的视频章节或时间段
-> 当前时间段内的字幕、节点和编辑状态
```

分段规则：

1. 课节是课程内容的正式编辑单位，课节名称来自课程数据，不从字幕正文猜测。
2. 长视频可以按主题章节或连续时间段拆分为多个可导航时间段。
3. 时间段必须有稳定的显示名称、开始时间和结束时间。
4. 时间段导航显示在课程/课节标题下方或时间轴上方，与 `forsale.html` 中的段落选择逻辑保持一致。
5. 当前时间段显示“第几段 / 共几段”以及对应的时间范围。
6. 上一段和下一段按钮在边界处禁用，不循环跳转。
7. 选择时间段后，时间轴显示该段范围，同时保留整节视频的时间语义。
8. 节点时间仍保存为当前课节视频的绝对秒数，不因切换显示分段而改写。
9. 位于当前时间段外的节点不删除；可以降低强调度或显示在段落边界之外，但不能丢失。
10. 字幕上下文、节点摘要和当前选中状态随时间段切换更新。
11. 原参考页面和正式教师编辑器使用同一套分段数据表达，不能一边显示章节、一边把章节写成静态文案。
12. 如果当前后端还没有分段数据结构，第一阶段可以先采用前端明确传入的章节配置，但必须标记为临时数据源；不得通过猜测字幕标题冒充正式章节。

长视频的显示目标：

- 课程页显示课程下的多个课节；
- 课节编辑页显示当前课节的多个视频时间段；
- 每个时间段显示名称、序号、时间范围和节点数量；
- 时间轴能够切换“当前分段视图”和“整节视频视图”的显示范围；
- 原参考页面中对应的课程编辑展示也显示相同的课节/分段层级。

### 4.3 节点组件栏

时间轴上方显示四个组件按钮：

| 当前节点 | 显示名称 | 视觉表达 | 后端结构 |
| --- | --- | --- | --- |
| `notice` | 重点标注 | 铅笔图标，金色系 | `attention + notice` |
| `choice` | 选择题 | 勾选列表图标，红棕色系 | `practice + choice` |
| `blank` | 填空题 | 文本空位图标，灰棕色系 | `practice + blank` |
| `free_text` | 问答题 | 对话气泡图标，墨绿色系 | `practice + free_text` |

组件栏规则：

1. 每个组件必须显示稳定 SVG 图标、名称和可访问名称。
2. 点击组件后进入“待放置”状态。
3. 待放置状态必须在组件按钮和时间轴上有明确反馈。
4. 再次点击当前组件或按 `Escape` 取消待放置状态。
5. `Enter` 或 `Space` 可以选择组件。
6. 拖动组件进入时间轴时显示可放置位置。
7. 点击放置和拖放放置必须进入同一个节点创建函数，不得维护两套节点构造逻辑。
8. 没有选择组件时，单独点击时间轴不创建节点，避免误插入重点标注。

### 4.4 图标共享真源

四种节点图标必须只定义一次，所有使用位置引用同一份图标真源：

```text
图标注册表 / SVG symbol 真源
-> 节点组件栏
-> 时间轴 marker
-> 节点摘要或属性弹窗中的类型标识
-> 参考页面的对应展示
```

图标维护规则：

1. 每种节点只拥有一个稳定的 `iconId`。
2. SVG path 或 symbol 只在共享资源中定义一次。
3. 组件栏、时间轴、节点卡片和参考页面不能各自复制一份 SVG。
4. 图标颜色由节点类型的共享视觉 token 控制，不把颜色硬编码到多个组件。
5. 图标资源应由共享前端模块导出，教师页和其它页面只传入 `iconId`。
6. 新增或替换图标时只修改图标真源和必要的 token，不逐个搜索页面复制粘贴。
7. 测试需要检查四种节点的 `iconId` 唯一且所有渲染入口使用同一映射。
8. 不使用 emoji、字体字形或依赖平台差异的符号替代正式节点图标。

### 4.5 横向时间轴

时间轴是编辑器的主工作区，而不是字幕列表的附属装饰。

时间轴包含：

- 开始边界胶囊；
- 结束边界胶囊；
- 课程时长和刻度；
- 一条共享的水平主轴；
- 节点图标层；
- 节点摘要卡片层；
- 放置位置反馈；
- 空状态；
- 当前节点选中状态。

布局规则：

1. 主轴、刻度、节点图标和开始/结束边界使用同一套左右安全边距。
2. “开始”位于有效轴线左端，“结束”位于有效轴线右端。
3. 课程总时长只表达时间范围，不替代“结束”语义。
4. 节点图标中心必须落在同一条主轴上。
5. 节点摘要卡片在主轴上方和下方交错排列。
6. 摘要卡片通过竖直连接线连接到对应节点图标。
7. 相邻节点过近时，通过轨道分配和最小间距减少文字重叠。
8. 超出字幕时长的已有节点不能静默消失，应显示为异常状态并允许修正。
9. 没有字幕时显示明确空状态，不伪造课程时长。
10. 小屏保持时间轴的最小可读宽度，只允许时间轴局部横向滚动，不让整个页面横向溢出。

### 4.6 节点 marker 与摘要

节点 marker 使用与组件栏相同的稳定图标：

- 重点标注：铅笔；
- 选择题：勾选列表；
- 填空题：横线/空位；
- 问答题：对话框与问号。

节点摘要文本来源按以下优先级取值：

1. `display.title`；
2. 节点类型默认名称。

marker 交互规则：

1. 单击 marker：选中节点、更新字幕上下文并滚动/聚焦到节点状态。
2. 双击 marker：打开节点属性弹窗。
3. 键盘聚焦后按 `Enter`：打开节点属性弹窗。
4. 选中节点后按 `Delete`：进入删除确认。
5. 拖动 marker：进入移动预览状态。
6. 拖动距离不足点击阈值时按选择处理，不改变时间。
7. 松开后将坐标转换成合法秒数，更新 `timeSeconds` 和最近字幕 `captionId`。
8. 移动后按时间重新排序，但不改变节点 ID、类型和内容。

### 4.7 字幕上下文栏

字幕栏展示当前选中节点附近的字幕，而不是继续作为主编辑列表。

规则：

1. 中心句由节点现有 `captionId` 优先确定；缺失时取最接近节点时间的字幕。
2. 中心句高亮显示。
3. 同时显示中心句前后有限范围的上下文。
4. 字幕文本使用安全文本节点渲染，不执行字幕中的 HTML。
5. 选择无字幕节点时显示“暂无对应字幕”的明确状态。
6. 导入字幕失败时保留之前已经成功导入的字幕。
7. 更换字幕后，重新计算课程时长，并重新绑定节点的最近字幕引用。
8. 字幕文件名和句数可以显示，但字幕正文不得写入日志或后端。

为了支持上下文栏，字幕数据需要由当前 `SubtitlePicker` 的局部状态提升到课节编辑器状态；
这只是前端状态组织变化，不改变“字幕不上传”的边界。

### 4.8 节点属性弹窗

创建节点后立即打开属性弹窗；编辑已有节点时也使用同一个弹窗。

公共字段：

- 触发时间；
- 节点类型；
- 节点标题。

按类型显示字段：

- 重点标注：正文；
- 选择题：题目、选项、正确答案、解析；
- 填空题：题目、可接受答案、解析；
- 问答题：问题、参考答案/反馈。

弹窗规则：

1. 新节点只存在于弹窗草稿中，点击“取消”不会进入 `nodes`。
2. 编辑已有节点时先复制节点，取消不会修改原节点。
3. 保存前执行前端最小校验；最终合法性仍以服务端 schema 为准。
4. 节点类型改变时按目标类型默认值补齐字段，并清理旧类型无效字段。
5. 保存时保留稳定节点 ID。
6. 删除需要明确确认。
7. 有未保存修改时取消、关闭或切换节点需要确认放弃。
8. 打开弹窗后焦点进入标题或第一个可编辑字段。
9. 关闭后焦点返回来源组件或 marker。
10. 弹窗内容较长时内部滚动，不能遮挡页面的主要保存操作。

## 5. 状态模型

编辑器需要明确维护以下状态：

```text
course
lessons
selectedLessonId
segments
selectedSegmentId
nodes
captions
durationSeconds
selectedNodeId
armedNodeKind
dialogDraft
dialogMode
dirty
busy
error
notice
```

状态不变量：

1. `lessons` 中的课节 ID 唯一。
2. `selectedLessonId` 必须属于当前课程。
3. `segments` 必须属于当前课节，`selectedSegmentId` 不能跨课节复用。
4. `nodes` 中节点 ID 唯一。
5. `timeSeconds` 不为负数。
6. 有字幕时，非空 `captionId` 必须指向当前字幕集合。
7. 节点在发送给后端前按 `timeSeconds`、ID 升序排序。
8. 同一字幕可以关联多个节点。
9. 新建弹窗取消不会增加节点。
10. 编辑弹窗取消不会改变原节点。
11. 保存失败不清空或替换当前课节的编辑内容。
12. 只有当前课节保存成功后才清除该课节的 `dirty` 状态。
13. 切换课节前必须处理当前课节未保存的修改。
14. 页面离开前，存在未保存修改时必须给出浏览器离开提示。

## 6. 数据流与接口边界

### 6.1 读取

```text
课节 URL
-> TeacherAPI.getCourse / 当前课节上下文
-> TeacherAPI.getDraft
-> 编辑器 nodes 状态
-> 课节/时间段选择器
-> 时间轴 marker/摘要
```

字幕流：

```text
教师选择 SRT/VTT
-> 浏览器 parseSubtitle
-> captions 状态
-> durationSeconds
-> 节点字幕关联
-> 时间轴和字幕上下文
```

课程和分段流：

```text
课程详情
-> 课节菜单
-> 当前课节
-> 当前课节的章节/时间段配置
-> 时间轴显示范围
-> 节点和字幕上下文
```

### 6.2 新建与编辑

```text
组件选择或拖放
-> 坐标转换为秒数
-> 找最近字幕
-> createNode(kind, seconds)
-> 打开属性弹窗
-> 弹窗保存
-> nodes 状态
-> dirty
```

### 6.3 保存

```text
nodes
-> 前端最小校验
-> 按时间排序
-> TeacherAPI.saveDraft
-> 后端整份 schema 校验
-> 返回标准 ScriptDraft
-> 替换本地 nodes
-> 清除 dirty
```

保存失败时保留编辑器本地状态，并显示稳定错误信息；不因为服务端拒绝整份草稿而回滚
用户已经填写的其它节点。

## 7. 实施阶段

### 阶段 0：设计确认

交付：

- 本计划由用户确认；
- 明确本轮包含完整编辑器交互，但不改变后端协议；
- 明确 `forsale.html` 只作为视觉和交互参考，不作为静态数据来源。

验证：

- 计划无未决的主要交互歧义；
- 当前 v1 API 和四种节点结构已列入边界。

### 阶段 1：建立编辑器纯逻辑

范围：

- 节点注册表统一四种组件的图标、颜色、默认值和字段定义；
- 时间轴模型补齐百分比、刻度、边界、最近字幕和上下轨道分配；
- 增加组件点击/拖放共用的创建流程；
- 增加 marker 移动和最近字幕更新逻辑；
- 增加类型切换时字段清理逻辑。

验证：

- 节点注册、默认值和 schema 组合测试；
- 时间坐标换算测试；
- 相邻节点轨道分配测试；
- 最近字幕和超出时长测试；
- 节点移动不丢失内容测试。

### 阶段 2：迁移时间轴页面骨架

范围：

- 替换当前简化 `Timeline` 的 DOM 结构；
- 加入课程课节选择器；
- 加入当前课节的长视频分段导航和时间范围显示；
- 加入组件栏、主轴、开始/结束边界、marker、摘要卡片和连接线；
- 将字幕数据提升到 `LessonPage` 或专用编辑器状态；
- 删除纵向节点卡片作为主编辑入口，但保留节点数据编辑能力；
- 保持当前顶部登录、返回、保存和错误状态。

验证：

- 四种节点视觉状态全部存在；
- 多课节切换不会串用节点或字幕状态；
- 长视频分段、当前段序号和时间范围可见；
- 节点位置和时间刻度共用同一坐标系统；
- 空状态、导入字幕状态和异常状态可见；
- 桌面和小屏没有整体横向溢出。

### 阶段 3：接入字幕上下文和属性弹窗

范围：

- 选中节点后显示附近字幕；
- 新建、编辑、取消、删除和关闭确认；
- 节点字段按类型显示；
- 表单校验和后端错误回显；
- 焦点管理和键盘操作。

验证：

- 新建取消不产生节点；
- 编辑取消不改变原节点；
- 删除确认有效；
- 选择、填空、问答和重点标注的字段分别正确；
- 错误保存不丢本地输入。

### 阶段 4：接回草稿和现有课程闭环

- 保持课程页发布、授权码和教师会话行为；

验证：

- 已有草稿刷新后节点、时间和类型不变；
- 保存成功后 dirty 状态清除；
- 保存失败后输入保留；
- 教师不能访问管理员能力。

- 多个临近节点仍可辨识；
