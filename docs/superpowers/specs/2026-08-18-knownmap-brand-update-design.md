# KnownMap 品牌更新与 Logo 设计

状态：已确认方向，待实施前用户审阅  
日期：2026-08-18  
范围：项目品牌文字、网页展示、Chrome 扩展图标、favicon 与相关文档

## 目标

将项目当前对外品牌从 `LessonPilot` 统一迁移为 `KnownMap`，域名统一使用 `knownmap.com`。品牌名称不再把产品锁定在课程或视频，而是保留向知识平台、内容理解和学习路径扩展的空间。

本次只做品牌识别与文档同步，不改变课程契约、消息协议、来源白名单、数据模型或第一阶段功能边界。

## 已确认设计

### Logo 概念

采用“地图窗口”圆形图标：

- 深墨绿圆形底，作为稳定的品牌容器；
- 浅灰绿地图外轮廓，表达一个可进入、可展开的知识空间；
- 内部一条纸白色折线路径，表达内容、理解与下一步发现；
- 两个节点使用暖金色与陶土色，表达路径上的关键停靠点；
- 两条内部竖向折页线保留，但弱化为同一种低强度纸白色，不能抢过主路径；
- 竖线必须收在地图轮廓内部，不得穿透外边界；
- 不使用额外的字母、渐变、阴影装饰或第三种路径颜色。

最终几何以“地图外轮廓 + 一条内部路径 + 两个节点 + 两条弱化同色竖线”为准。此前没有竖线、竖线异色、竖线虚线和未收口边界的视觉稿均为探索稿，不得直接生成正式资源。

### 颜色

| 角色 | 色值 | 说明 |
| --- | --- | --- |
| 圆形底 | `#103B2B` | 深墨绿，沿用项目主品牌深色 |
| 地图外轮廓 | `#CFE4D8` | 浅灰绿，退到第二视觉层 |
| 主路径 | `#FFFDF8` | 纸白色，保持最清晰 |
| 弱化竖线 | `#FFFDF8`，约 48% 不透明度 | 与主路径同色，但降低存在感 |
| 节点一 | `#D9A51E` | 暖金色 |
| 节点二 | `#A9654E` | 陶土色 |

主 Logo 不新增蓝紫、霓虹或高饱和渐变。已有页面的节点色和纸张体系可继续复用。

### 尺寸

同一 SVG 几何导出为：

- `16 × 16`：favicon 与最小浏览器资源；
- `24 × 24`：浏览器小图标；
- `48 × 48`：Chrome 扩展图标；
- `128 × 128`：扩展清单与完整应用图标。

正式资源必须使用同一几何和同一配色，不为小尺寸另画一套图形。导出后验证四个尺寸仍能识别圆形、地图轮廓、路径和两个节点。

## 品牌文字规则

- 产品名：`KnownMap`
- 域名：`knownmap.com`
- 句首和标题使用 `KnownMap`；纯域名、URL、代码标识使用小写 `knownmap.com`
- 旧名 `LessonPilot` 只在历史记录、迁移说明、旧协议标识、历史归档和测试兼容边界中保留
- 不改动内部协议和 CSS/DOM 标识中的 `lessonpilot`，除非该标识是用户可见品牌文字或本次替换明确要求的资源入口
- 对外页面的页眉、标题、描述、销售文案、扩展 manifest 名称和图标 alt/aria 文本统一使用 KnownMap

## 资源落点

- `src/assets/icon-16.png`
- `src/assets/icon-48.png`
- `src/assets/icon-128.png`
- 新增网页 favicon 或品牌 SVG 源文件时，源文件必须只有一份；PNG 为导出物
- `src/manifest.json` 的用户可见扩展名称改为 `KnownMap`
- `teacher-web/index.html`、`teacher-web/forsales.html`、`teacher-web/workspace.html`、`teacher-web/editor.html` 中的用户可见品牌改为 KnownMap
- README、当前权威文档、销售页设计文档和相关测试中的用户可见品牌同步更新

## 非目标

- 不改动 GitHub 仓库名、GitHub Pages origin、路径白名单、协议 channel、存储键和 JavaScript 全局命名空间；
- 不把远期品牌迁移包装成已完成的平台能力；
- 不新增账号、域名解析、后端、隐私政策或商标法律结论；
- 不批量改写历史归档中的旧产品名。

## 验收

1. `rg` 搜索当前代码、当前入口文档和用户可见页面时，旧品牌只保留在明确的历史、协议兼容或内部标识上下文。
2. 四个 PNG 图标由同一精修几何导出，尺寸和透明背景正确。
3. 页面页眉、标题、meta description、manifest 名称和 favicon 使用 KnownMap。
4. 自动化测试通过；涉及旧品牌断言的测试按新的用户可见文案更新，协议和内部标识断言保持不变。
5. 在桌面和移动视口检查销售页与工作台页无溢出、遮挡或品牌资源加载错误。
