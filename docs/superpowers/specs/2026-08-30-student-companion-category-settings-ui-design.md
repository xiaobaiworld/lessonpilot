# 学习伙伴类别设置页设计

## 背景

插件 v1.1.0 已经具备独立设置页，但当前页面把角色预览、状态切换、声音试听和上传说明全部铺开，体量过大，不像插件设置。已确认的产品模型是：用户选择一个陪伴角色，图片与声音状态属于角色包内部资源，不要求用户逐项管理。

## 目标

1. 将设置页收敛为紧凑、可爱的“选择你的学习伙伴”页面。
2. 第一版只开放“神秘猫精灵”；其他角色作为后续版本预留。
3. 当前角色用一张真实大图和 6 张真实状态缩略图表达角色包完整性。
4. 鼠标悬停缩略图时显示对应状态的真实大图。
5. 页面通过角色包资源接口读取图片，不把图片路径或某一只猫写死在 UI 中。

## 页面设计

- 顶部：KnownMap 品牌、设置页标题和版本号。
- 当前伙伴卡：显示“神秘猫精灵”、真实 idle 大图、陪伴文案和 6 个独立状态缩略图。
- 状态缩略图：等待、开始注意、提示、答对、答错、完成庆祝；每个图标独立显示，悬停时弹出对应真实大图。
- 角色卡：
  - 神秘猫精灵：第一版可选。
  - 元气狗狗伙伴：显示“下一版本完成”。
  - 奇趣森林伙伴：显示“下一版本完成”。
  - 未知世界伙伴：显示“下一版本完成”；其中“个性设定”和“自己上传”也显示为下一版本能力。
- 底部提示：使用“选对伙伴，让你的学习事半功倍。”，不再解释内部状态资源，也不再显示“选择一个即可”或未来扩展说明。

## 资源与数据流

设置页只发送白名单 `companionAsset` 消息，并以 `packId` 和状态名请求资源。页面初始化后读取 `cat-v1` 的六个状态，idle 作为当前大图，其余状态按状态名填入缩略图。将来切换到新角色时，只替换 `packId` 和角色元数据，UI 结构不变。

## 非目标

- 本次不开放狗狗、其他动物或未知世界伙伴的选择。
- 本次不开放自定义头像上传、个性设定或角色包编辑。
- 本次不改变节点生命周期、声音播放时机或课程判分逻辑。

## 验收标准

- 设置页没有状态按钮列表、声音试听列表和上传规则大卡片。
- 真实猫咪大图和 6 个真实状态缩略图来自 background 资源接口。
- 悬停任意缩略图可见对应状态的大图预览。
- 第二、第三、第四角色卡均显示“下一版本完成”，且不可选择。
- 原有扩展测试、类型检查、构建和打包检查通过。
