# 学生插件课程库、课程升级与设置设计

状态：已确认，依据 2026-08-28 第十二版视觉草稿；进入开发计划阶段。

视觉资产：[`../assets/2026-08-28-course-library-sync-layout.html`](../assets/2026-08-28-course-library-sync-layout.html)

## 1. 产品目标

学生插件首页要能管理多门课程，同时让学生清楚地区分三件事：领取新课程、升级已有课程、打开并继续学习课程。课程列表不能因为课程增加而无限变长，插件设置要能控制首页入口和同步行为。

## 2. 已确认的交互规则

### 2.1 课程列表

- “全部课程”就是学生本机已经安装的课程总列表。
- “需要升级”是已安装课程中服务端存在更新版本的课程。
- 每个列表区最多直接显示 3 门课程。
- 列表总数不超过 3 门时，显示全部课程，不显示更多入口。
- 列表总数超过 3 门时，只显示 3 门，下方显示“更多课程”或“打开更多待升级课程”。
- 更多列表按每页 10 门分页。
- 课程卡片可直接打开；卡片内保留明确的“打开课程”按钮。
- 课程升级动作统一使用“升级”，不再使用“同步”。

### 2.2 更新提示

- 更新提示是小型浮窗，不占课程列表的固定位置。
- 文案为“有 X 门课程可以升级，当前学习不会被打断”。
- 浮窗使用低饱和淡红色，只做状态提示，不把升级按钮染成红色。
- 小箭头用于收起浮窗，叉号用于关闭本次浮窗。
- 关闭提示不等于拒绝升级，课程仍可从“需要升级”区域手工升级。

### 2.3 升级模式

设置提供三种模式：

1. 自动升级：发现新版本后，在安全时机自动替换；当前课节正在学习时延后。
2. 提示升级：发现新版本后提示学生，学生确认后替换。
3. 手动升级：只有学生点击“检查更新”或课程卡片“升级”时才检查。

默认模式为“提示升级”，自动检查默认开启。自动检查发生在打开插件首页或进入已安装课程对应的 B 站页面时；不能在当前课节会话中热切换课程内容。

### 2.4 升级后的学习记录

- 相同课节、相同节点且节点内容没有变化：保留完成状态和历史作答。
- 相同课节、相同节点但内容发生变化：清除完成状态，保留历史作答。
- 新增节点：未完成。
- 删除节点：不再显示，历史作答保留在本机。
- 课程升级失败：继续使用旧课程，不产生新旧内容混合状态。

节点身份由 `lessonId + node.id` 确定。节点内容比较时排除 `id`、学生学习状态和 `captionId`，比较标题、互动类型、正文、互动数据、触发时间、效果和展示提示。教师编辑器已经在编辑、移动和切换题型时保留节点 `id`；删除后重新创建的节点会得到新身份，不猜测为旧节点。

## 3. 首页组成

首页自上而下包含：

1. 标准 KnownMap 图标与 K/M 彩色字标；真实实现复用 `v1/site/assets/knownmap-icon.png` 和 `v1/extension/assets/icon-48.png`。
2. 可收起/关闭的升级浮窗。
3. “领取新课程”入口，默认显示，进入授权码输入窗口。
4. “需要升级”课程区。
5. “全部课程”课程区。
6. “为你推荐”区域，默认显示。
7. 设置入口。

“领取新课程”和“为你推荐”分别由设置页的开关控制。关闭只隐藏首页入口，不删除课程、授权来源或学习记录。

## 4. 设置页

设置页分为：

- 学生入口：显示未登录/已登录状态，提供学生登录入口；登录不阻挡授权码领取和本机课程学习。
- 首页显示：控制“领取新课程”和“为你推荐”，默认开启。
- 课程升级：选择自动升级、提示升级、手动升级，控制自动检查和手工检查。
- 页面陪伴：小人 Logo 选项、默认快捷键和快捷键修改入口。
- 更多功能：为记事本、学习日志、课程推荐等后续功能预留入口。

设置是插件本地偏好，不进入课程包，不影响服务端授权资格。

## 5. 范围边界

本次第一实施单元实现课程库分页、课程升级、学习记录迁移、首页显示设置、授权码入口和标准品牌资源复用。

学生账户登录和真实课程推荐属于独立后端域。当前仓库没有学生账户、会话、跨设备学习记录或推荐目录数据模型，因此先保留设置入口和页面结构，账户认证接口、账户与本机身份绑定、推荐数据接口分别在冻结对应后端契约后实施。不得用静态示例课程冒充真实推荐结果。
