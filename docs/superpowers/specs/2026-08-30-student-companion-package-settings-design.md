# 学生插件学习伙伴角色包设置设计

## 目标

修正学生插件 `1.2.0` 中“插件设置 → 学习伙伴 → 设置”的体验：学习伙伴页面保持 KnownMap 插件的紧凑尺寸、蓝色操作色和品牌栏，并提供清楚的返回路径。页面以“角色包”为单位展示图片状态与声音，而不是把头像、状态和音效拆成互不相干的设置。

## 入口与返回

1. 学生从插件首页右上角进入“插件设置”。
2. 在“学习伙伴”设置行点击“设置”，在同一 popup 内进入“学习伙伴”第三层视图；不再新建浏览器标签页。
3. 学习伙伴页左上角“返回”回到插件设置；右上角“关闭”关闭当前插件 popup。
4. popup 保持 380px 基线宽度，内容区可滚动，避免为角色包设置打开全屏或宽版页面。

## 视觉规则

- 使用当前 popup 的浅灰底、白色卡片、`#00aeec` 操作色、KnownMap 品牌栏和圆角密度。
- 顶部显示当前已选角色的大头像、名称“神秘猫精灵”、简短陪伴文案和“已选择”状态。
- 不沿用旧独立设置页的大面积浅绿底、720px 宽卡片、全页面留白或不同的按钮体系。

## 角色包选择

页面显示四个角色类别卡片：

| 类别 | 当前状态 | 页面内容 |
| --- | --- | --- |
| 神秘猫精灵 | 已开放、已选择 | 真实主头像、六种状态图和整组声音 |
| 元气伙伴 | 下一版本完成 | 名称、热情鼓励的基础描述、状态标签 |
| 森林伙伴 | 下一版本完成 | 名称、轻松好奇的基础描述、状态标签 |
| 未知伙伴 | 下一版本完成 | 名称、空灵专属的基础描述、状态标签 |

未开放类别不允许选择、不显示虚构状态图或虚构音效，也不影响当前猫咪包。

## 猫咪包状态和声音

1. 选择神秘猫精灵后，显示现有六个独立状态缩略图：`idle`、`focus`、`prompt`、`correct`、`wrong`、`complete`。
2. 状态缩略图继续使用内置角色包真实资源；悬停显示对应大图。
3. 状态下方显示“神秘猫精灵声音组”。声音和状态由角色包预先绑定，用户不能把答对、答错或庆祝声音互换到其他状态。
4. 当前声音组提供五条可试听项：开始注意、提示与等待、答对反馈、答错反馈、完成庆祝。每条显示名称、来源说明、时长和试听按钮。
5. 声音设置采用“整组开关 + 单条试听”：整组关闭后，学习时不播放任何猫咪声音；单条按钮仅用于设置页试听，不改变状态绑定关系。

## 数据与实现边界

- 继续复用 `assets/companion/cat/v1/manifest.json` 和现有 `companionAsset` 白名单消息读取真实图片/声音。
- 继续复用 `companionSound` / `setCompanionSound` 保存整组声音开关，不新增伪造音频或远程资源。
- 学习伙伴第三层由 popup 渲染，现有 `settings/index.html` 不再作为从 popup 进入的目标；它可作为旧 options_page 兼容入口，并显示同一紧凑角色包页面或重定向到同等内容。
- 本次只改插件界面与既有声音设定链路；不新增伙伴包、不实现自定义头像、不实现逐条音效禁用，也不改变学习节点触发逻辑。

## 资源压缩与交付

当前猫咪包的六张 PNG 与五段 WAV 约为 2.12 MB，不适合直接作为后续多个角色包的体积基线。本次发布前按以下规则生成运行时资源：

1. 六张 512×512、透明背景的状态图转换为 WebP；保持原有画布尺寸，采用以肉眼无明显差异为验收标准的有损压缩。
2. 五段运行时声音转换为单声道 Ogg/Opus；保持已确认的时长、淡入淡出和响度处理，不重新剪辑声音内容。
3. 原始 PNG/WAV 是制作源文件，只保存在设计源资源目录，不复制到 extension 的发布资源目录；插件清单和白名单只引用 WebP/Ogg 文件。
4. 首版猫咪包的发布体积目标为 0.5–0.8 MB；若压缩结果超出目标，优先进一步调整编码质量与码率，而非降低状态图分辨率或删减声音。
5. 每个未来角色包沿用同一规则，并在资源清单中记录文件体积、格式和总包体积；单个角色包以 0.8 MB 为上限，超过上限须在发布前明确评审。
6. 压缩后的文件须逐一验证：状态图可由白名单加载并带透明背景；五段音频可试听且时长与清单一致；扩展构建产物中不包含同名 PNG/WAV 运行时副本。

## 验收标准

1. 点击“学习伙伴 → 设置”后不新开标签页，仍在同一插件 popup 内。
2. 页面颜色、宽度、顶部品牌栏和按钮风格与插件设置一致。
3. 左上角能回到“插件设置”，右上角能关闭 popup。
4. 四类伙伴卡片可见；仅神秘猫精灵可选，其他三类明确显示“下一版本完成”。
5. 猫咪包展示六种真实状态图，缩略图悬停能显示对应大图。
6. 五段猫咪声音可单独试听；整组开关能控制学习中的声音播放。
7. 因为本次会改变 popup 代码和设置资源引用，实施时按当前版本规则将插件从 `1.2.0` 递增一个小功能版本。
8. 发布的猫咪角色包使用 WebP/Ogg 压缩资源，整体体积不超过 0.8 MB；原始 PNG/WAV 不进入插件构建产物。
