# 本地插件测试流程

## 固定测试目录

本机加载的插件目录固定为：

`/Users/bai/Downloads/knownmapplugin (1)`

以后测试新版本时，直接覆盖这个目录里的插件文件，不更换目录，也不重新安装扩展。

## 测试步骤

1. 修改代码并生成新的插件版本。
2. 运行 `tools/refresh-local-plugin.sh`，它会构建生产目标并清空同步固定目录；不能只做覆盖复制，否则旧版未被 manifest 引用的文件也会残留。
3. 打开 Chrome 的扩展管理页。
4. 在 KnownMap 卡片上点击“刷新”。
5. 回到 B 站视频页面并刷新页面。
6. 播放到对应节点，检查本次改动。

## 版本规则

- 每次本地候选版本都必须使用新的版本号。
- 本次候选版本：`1.0.5`。
- 版本号写入固定目录的 `manifest.json`。
- 同一个目录只代表当前正在测试的候选版本。
- 通过测试后，才同步到 GitHub，再发布到阿里云。
