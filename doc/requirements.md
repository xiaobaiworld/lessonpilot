# LessonPilot 第一阶段需求

版本：2.0

更新时间：2026-08-15

状态：当前实现权威。旧 W0 / D0 / D1 合并需求已归档，不再作为开发指令。

## 1. 当前目标

LessonPilot 第一阶段只验证一条真实闭环：

> 一位已经拥有 B 站录播课的英语老师，愿意提供课程链接，在人工协助下准备字幕，亲手配置课程互动，并在自己电脑的 B 站原页面通过插件完成真实预览。

第一阶段不是成熟 SaaS，也不是完整销售产品。它要取得四个行为证据：

1. 老师看完销售页后愿意提供一条真实课程；
2. 老师愿意在指导下使用工作台配置至少一个节点；
3. 工作台保存的配置能可靠进入老师本机插件；
4. 插件能在 B 站原页面完成暂停、互动、反馈和继续播放。

设计背景、方案比较和范围理由见：

- `doc/stage-one-validation-loop-design.md`
- `doc/DECISIONS.md`

## 2. 目标用户与交付方式

### 2.1 购买者与配置者

第一批用户是已经拥有付费或半付费 B 站录播课程的英语老师或小型培训团队。他们希望增加课程差异化、练习和反馈，但不重新录制整套课程。

### 2.2 学习者

学习者在 PC Chrome 中打开老师指定的 B 站原视频，并使用老师协助安装的 LessonPilot 已解压插件。

### 2.3 礼宾式交付

第一阶段允许人工协助：

- 老师提供标准 B 站 BV 视频 URL；
- 老师提供 SRT/VTT 字幕，或 LessonPilot 提供者之后通过其它工具取得；
- LessonPilot 提供者人工确认字幕和视频时间轴匹配；
- 首次安装插件、导入字幕和配置节点可以远程或现场协助；
- 不承诺老师发送链接后立即自动生成课程。

## 3. 正式用户流程

```text
老师打开公网销售首页
  -> 回复并提供 B 站视频 URL
  -> 提供或等待人工取得字幕
  -> 人工确认字幕与视频匹配
  -> 老师打开公网教师工作台
  -> 输入 URL 并导入字幕
  -> 选择字幕时间点并配置节点
  -> 保存到本机插件
  -> 打开对应 B 站原页面
  -> 视频到点自动暂停
  -> 学生确认或作答
  -> 显示反馈并继续播放
```

第一次接触和实际体验可以分成两次。销售页的有效信号是老师愿意提供真实课程；产品试用的有效信号是老师愿意安装插件、配置节点并完成学生体验。

## 4. 页面与部署需求

### WEB-01 默认销售首页

- `teacher-web/index.html` 是默认入口；
- 当前 `teacher-web/forsales.html` 的销售内容迁入该入口；
- 页面可以展示真实产品形态，但本身保持静态；
- 主要行动是“申请改造一节真实课程”；
- 次要行动是“进入教师工作台”；
- 不得把老师语音、AI 评价、正式报告、账号或规模化发布描述为已可用。

### WEB-02 教师工作台

- `teacher-web/workspace.html` 是第一阶段真实工作台；
- 沿用现有工作台示例的主要信息结构和视觉语言；
- 增加课程 URL、字幕导入、真实时间线、节点编辑、保存和预览；
- 不重新设计与当前目标无关的后台模块。

### WEB-03 兼容入口

- `teacher-web/forsales.html` 迁移后跳转到默认销售首页；
- `teacher-web/editor.html` 停止扩展；
- 旧编辑器的必要能力迁入 `workspace.html` 并回归通过后，才另行决定删除。

### WEB-04 公网地址

- 第一阶段默认部署到 `https://xiaobaiworld.github.io/lessonpilot/`；
- 当前 GitHub Pages 尚未启用，启用和真实访问验证是开发门禁；
- 本地开发仍从仓库根运行 `python3 -m http.server 4173`；
- 生产或本地 origin 变化时，必须同步更新插件白名单和部署文档。

### WEB-05 响应式边界

- 销售首页和工作台在桌面及 375px 宽度下不得横向溢出或遮挡关键内容；
- 实际插件预览只支持 PC Chrome；移动宽度只验证页面可阅读，不承诺移动端插件体验。

## 5. 课程输入与工作台需求

### COURSE-01 视频 URL

- 只接受当前浏览器可访问的标准 `https://www.bilibili.com/video/BV.../` URL；
- 从路径提取 BVID，拒绝缺少 BVID、非标准视频页和非 B 站来源；
- 第一阶段不自动验证课程所有权、付费权限或字幕是否对应视频。

### COURSE-02 字幕导入

- 接受 `.srt` 和 `.vtt`；
- 字幕只在浏览器本地解析，不上传；
- 拒绝空文件、不支持格式、无法解析的时间戳、结束早于开始和非递增时间线；
- 导入后显示文件名、字幕段数和“需要人工确认与视频匹配”的提示；
- 完整字幕保留在工作台草稿中，不发送给插件。

### COURSE-03 单课程限制

- 工作台和插件只保留一门当前课程；
- 当前课程已有字幕或节点时，更换 URL 必须弹出确认；
- 用户取消时不得改变任何当前数据；
- 用户确认后，先通过消息桥清除插件旧课程并收到成功响应，再清空工作台旧草稿；
- 清除失败时保留旧课程并显示可重试错误，不得假装切换成功。

### COURSE-04 时间线与节点管理

- 时间线来源是已导入字幕，不是跨源播放器进度；
- 老师可在字幕段落上新增、编辑和删除节点；
- 节点按 `trigger.timeSeconds` 升序排列；
- 同一时间允许多个节点，但运行时按排序后的稳定节点 ID 依次处理；
- 保存前必须校验所有节点；任一节点非法时整体拒绝保存。

## 6. 第一阶段节点需求

第一阶段只支持四种封闭节点。字段权威见 `doc/data-spec.md`；展示原则继续遵守 `doc/node-content-standard.md` 和 `doc/learning-window-standard.md` 的对应子集。

### NODE-01 重点标注

- `family: attention`、`interaction: notice`；
- 老师配置标题、正文和可选重点词；
- 到点暂停，窗口完整展示内容；
- 学生确认或跳过后继续播放；
- 画面高亮只是增强，失败不影响节点完成。

### NODE-02 选择题

- `family: practice`、`interaction: choice`；
- 题目非空，至少两个非空选项，选项 ID 唯一；
- 必须指定一个存在的正确选项；
- 提交后显示正确/错误状态和老师预设解释；
- 允许重试、跳过和继续。

### NODE-03 填空题

- `family: practice`、`interaction: blank`；
- 题目非空，至少一个可接受答案；
- 比较时固定执行 `trim` 和英文 `casefold`；
- 提交后显示正确/错误状态和老师预设解释；
- 允许重试、跳过和继续。

### NODE-04 问答题

- `family: followup`、`interaction: free_text`；
- 提示非空，提交答案不能为空；
- 保存学生原始回答；
- 显示老师预设的参考反馈；
- 不判断对错，不调用 AI，不生成个性化评价或追问；
- 允许修改、跳过和继续。

### NODE-05 通用边界

- 一个节点只属于当前课程、当前视频和一个时间点；
- 每个节点必须能结束并返回播放；
- 节点内容在学习窗口内自足；
- 配置不得携带自定义 HTML、CSS、JavaScript 或外部跳转；
- 第一阶段拒绝其它 family、interaction 和不合法组合。

## 7. 网页与插件消息桥

### BRIDGE-01 传输路径

```text
workspace.html
  -> window.postMessage(request)
  -> 白名单 workspace content script
  -> chrome.runtime.sendMessage
  -> background service worker
  -> chrome.storage.local
```

该路径不要求网页知道开发者模式扩展 ID。

### BRIDGE-02 信任边界

- 内容脚本只注入本地工作台和已确认的 GitHub Pages 工作台路径；
- 必须校验 `event.source === window`、`event.origin`、页面路径、协议版本、操作枚举、`requestId` 和 payload schema；
- 页面发送前校验，内容脚本和后台再次校验；
- 校验失败默认拒绝；
- 响应必须携带同一 `requestId`；
- 消息内容和日志不得包含完整字幕或未脱敏学生答案。

### BRIDGE-03 固定操作

第一阶段只开放：

- `PING`
- `GET_CURRENT_COURSE`
- `SAVE_CURRENT_COURSE`
- `CLEAR_CURRENT_COURSE`
- `START_PREVIEW_SESSION`

操作和错误码见 `doc/data-spec.md`。未知操作必须拒绝。

### BRIDGE-04 保存语义

- `SAVE_CURRENT_COURSE` 发送完整课程配置并替换旧配置；
- 后台 schema 校验和 `chrome.storage.local.set` 都成功后才返回成功；
- 页面只有收到成功响应后才能显示“已保存”；
- 超时、插件未安装、版本不兼容或存储失败都显示明确错误和重试入口。

## 8. 插件与学生运行时

### RUNTIME-01 课程识别

- 插件读取唯一当前课程；
- 只有当前页面 BVID 与课程 `videoRef.videoId` 精确一致时启动；
- 其它 B 站视频不得显示课程窗口、记录行为或报告错误。

### RUNTIME-02 节点状态机

```text
pending -> active -> completed | skipped
```

- 到达触发时间时暂停视频并打开唯一学习窗口；
- 同一预览会话中已完成或跳过节点不重复触发；
- seek 跨过多个节点时，先触发排序后的最早 pending 节点；
- 同一时间的多个节点按稳定节点 ID 依次触发；
- 完成或跳过当前节点后处理队列，再继续播放；
- 刷新页面创建新预览会话。

### RUNTIME-03 生命周期

- B 站 SPA 进入匹配课程时只挂载一个运行时；
- 离开或切换到不匹配视频时，卸载学习窗口、播放器监听、计时器、字幕遮挡和其它注入 UI；
- 找不到播放器时显示可恢复的“课程暂时无法启动”，不得无限创建观察器或伪造成功；
- 页面重新出现播放器时允许有限重试并避免重复绑定。

### RUNTIME-04 本地会话

- `START_PREVIEW_SESSION` 创建新的本地预览会话；
- 预览会话绑定当前 `courseId` 和课程 `updatedAt`，不另建版本历史；
- 节点状态和答案只保存在老师本机插件；
- 新预览会话替换旧 active session；
- 第一阶段不生成老师报告、不上传、不跨设备同步。

### RUNTIME-05 插件交付

- 老师使用 PC Chrome 开发者模式加载仓库 `src/` 的已解压插件；
- 首次安装和更新允许人工协助；
- 保存新配置不要求重新加载或重新安装插件；
- Chrome 应用商店发布不属于第一阶段。

## 9. 错误与用户可见状态

至少定义并处理：

- 无效视频 URL；
- 字幕格式或时间线错误；
- 字幕与视频匹配尚未人工确认；
- 节点字段或组合非法；
- 插件未安装或桥接内容脚本未连接；
- 协议版本不兼容、未知操作、payload 非法或消息超时；
- 插件本地存储失败；
- 当前 BVID 不匹配；
- B 站播放器缺失或 DOM 变化；
- SPA 切换后的重复挂载或残留 UI。

用户错误显示在工作台或学习窗口的固定状态区。详细调试信息可以进脱敏控制台日志，但不得向用户展示堆栈、内部路径或敏感内容。

## 10. 数据、隐私与安全

- B 站 URL、字幕和老师节点内容视为外部输入，必须先校验；
- 字幕和工作台草稿保存在网页本地；
- 当前课程、预览会话和答案保存在 `chrome.storage.local`；
- 不使用后端、账号、cookie、token、密钥或远程数据库；
- 不采集与当前课程无关的 B 站浏览历史；
- 原始学生回答不进入通用日志；
- 页面只发送节点配置，不发送完整字幕；
- 任何未来远程同步都必须重新进行隐私和安全设计，不能沿用本地 Demo 假设。

## 11. 非功能要求

- 配置校验、消息协议、节点状态机和答案判断必须是可单元测试的纯逻辑；
- 工作台与运行时不得共享近似但不同的 schema；
- 所有动态字幕、题目、选项和答案使用 `textContent` 或等价安全渲染；
- 核心操作有明确成功、失败和重试状态；
- 不引入构建工具、框架、后端或第三方运行时依赖，除非另立决策；
- 现有 B 站选择器集中在播放器适配模块，不泄漏进节点逻辑。

## 12. 第一阶段非目标

- AI 评价、AI 追问和 AI 报告；
- 老师补充音频、语音输入和发音评价；
- 账号、权限、支付、班级和机构；
- 自动抓取、识别或生成字幕；
- 正式老师报告、多学生汇总和远程遥测；
- 多课程管理、历史版本、发布和云端同步；
- 手机端插件体验；
- YouTube 或其它视频平台；
- Chrome 应用商店正式发布；
- 重点标注、选择题、填空题、问答题以外的节点；
- 通用聊天、习题本、书签、学习计划和其它学生工具；
- 完整 SaaS 后台和公开营销推广片。

## 13. 第一阶段验收

第一阶段只有以下全部通过才算完成：

1. GitHub Pages 销售首页和工作台可从公网访问；
2. 两页在桌面和 375px 宽度下无关键遮挡或横向溢出；
3. 标准 B 站 BV URL 和真实 SRT/VTT 可导入为时间线；
4. 四种节点都能新增、编辑、删除和校验；
5. 页面经白名单桥保存，失败时不显示假成功；
6. 保存后无需重装或重载插件即可预览；
7. 插件只在配置对应的 B 站原页面启动；
8. 四种节点按时暂停并完成确认/作答、反馈、跳过和继续；
9. 状态机、seek 跨节点和同时间节点队列行为符合需求；
10. 更换 URL 的确认、清除和失败保留行为符合 COURSE-03；
11. B 站 SPA 离开课程后无残留窗口、监听器或定时器；
12. 自动化测试覆盖数据 schema、字幕解析、协议、状态机和三种题型规则；
13. 人工验收从公网工作台到真实 B 站原页面完整跑通；
14. 销售页展示能力与真实结果一致；
15. `README.md`、`doc/INDEX.md`、`doc/DECISIONS.md`、数据文档、计划和 changelog 已同步。
