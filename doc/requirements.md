# KnownMap 第一阶段需求总览

版本：3.0

更新时间：2026-08-15

状态：历史第一阶段需求入口。销售页和原型 Demo 已归档；当前实施需求以 `doc/requirements/teacher-platform-local-stage.md` 为准。

## 1. 第一阶段要验证什么

KnownMap 当前只验证一条真实闭环：

> 一位已经拥有 B 站录播课的英语老师，愿意提供课程链接，在人工协助下准备字幕，亲手配置课程互动，并在自己电脑的 B 站原页面通过插件完成真实预览。

需要取得四个行为证据：

1. 老师看完销售页后愿意提供一条真实课程；
2. 老师愿意在指导下使用工作台配置至少一个节点；
3. 工作台保存的配置能可靠进入老师本机插件；
4. 插件能在 B 站原页面完成暂停、互动、反馈和继续播放。

第一阶段不是成熟 SaaS，也不是对完整商业模式的最终证明。字幕取得、时间轴核对、插件安装和首次配置允许人工协助。

## 2. 目标用户与使用边界

- 购买者和配置者：已有付费或半付费 B 站录播课程的英语老师或小型培训团队；
- 学习者：在 PC Chrome 打开老师指定的 B 站原视频，并使用已解压插件；
- 当前平台：只支持 B 站原页面，不支持网页播放器、手机端或 YouTube；
- 当前数据范围：只管理一门当前课程，所有数据只保存在网页或插件本地；
- 当前节点：重点标注、选择题、填空题、问答题；
- 当前交付：可以远程或现场协助，不承诺老师提供链接后立即自动生成课程。

## 3. 完整用户流程

```text
老师打开公网销售首页
  -> 回复并提供 B 站视频 URL
  -> 提供字幕或等待人工取得字幕
  -> 人工确认字幕与视频匹配
  -> 老师打开公网教师工作台
  -> 输入 URL、导入字幕并配置节点
  -> 保存到本机插件
  -> 打开对应 B 站原页面
  -> 视频到点自动暂停
  -> 学生确认或作答
  -> 显示反馈并继续播放
```

第一次接触和实际试用可以分成两次。销售有效信号是老师愿意提供真实课程；产品有效信号是老师愿意安装插件、配置节点并完成学生体验。

## 5. 共同产品规则

- 工作台和插件只保留一门当前课程；
- 完整字幕只留在工作台本地，不发送给插件；
- 所有节点到点自动暂停，并且能够完成或跳过后返回播放；
- 问答题只保存原始回答并显示老师预设反馈，不判断对错、不调用 AI；
- 页面、内容脚本和插件后台分别校验外部输入，失败默认拒绝；
- 保存、清除和创建预览会话必须返回真实结果，不能显示假成功；
- 动态字幕、题目、选项和回答使用安全 DOM API 渲染；
- 不引入构建工具、框架、后端或第三方运行时依赖，除非另立决策。

字段、存储键、消息结构和错误码以 `doc/data-spec.md` 为准。

## 6. 第一阶段共同非目标

- AI 评价、AI 追问、AI 报告和 AI 生成题目；
- 老师补充音频、语音输入和发音评价；
- 账号、权限、支付、班级、机构和正式老师报告；
- 自动抓取、识别或生成字幕；
- 多课程、历史版本、发布、云同步和远程遥测；
- 手机端、YouTube 和其它视频平台；
- Chrome 应用商店正式发布；
- 四种当前节点以外的节点类型；
- 通用聊天、习题本、书签、学习计划和完整 SaaS 后台；
- 公开营销推广片。

## 7. 第一阶段最终完成定义

只有以下条件全部成立，第一阶段才算完成：

1. 公网销售首页和教师工作台可访问，展示能力与真实结果一致；
2. 老师能导入一条真实 B 站 URL 和匹配字幕，创建四种节点；
3. 工作台经安全消息桥把有效课程保存到本机插件，失败时不假成功；
4. 插件只在匹配 BVID 上启动，并完成暂停、互动、反馈、跳过和继续；
5. seek、刷新和 B 站 SPA 切换后没有重复触发或残留运行时；
6. 自动化测试与真实 Chrome 人工验收均通过；
7. README、索引、决策、数据规范、计划和 changelog 与实现一致；
8. 邀请真实老师开始试用，不再以补充第二阶段功能代替市场验证。
