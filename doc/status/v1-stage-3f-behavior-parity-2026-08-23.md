# 阶段 3F — 新旧页面行为对照

日期：2026-08-23

执行计划要求：`3F 每个旧页面只有在新应用通过自动化和真实浏览器对照后才停止发布。`

对照对象是旧页面用测试固定下来的行为承诺，不是逐像素比外观。

## 管理端（`teacher-web/admin.html` → `v1/web/admin`）

旧页面的承诺来自 `tests/admin-page.test.js` 五项断言。

| 旧承诺 | v1 是否满足 | 依据 |
| --- | --- | --- |
| 保留原有入口链接并暴露完整账号管理状态 | 部分 | v1 只做教师账号管理；销售站与服务状态入口不再从管理页跳转，见下方"有意的差异" |
| 宽表格不撑宽移动端页面 | 是 | `.table-wrap` 用 `overflow-x: auto`，横向滚动限制在容器内，取值直接来自 `admin.html` 的 `<style>` |
| API 客户端使用隔离的带凭据端点 | 是 | 只调 `/api/v1/admin/*`，Cookie 由后端按管理员专用 cookie 名下发，与教师会话互不通用 |
| 拒绝过期响应并串行化凭据操作 | 是 | `TeacherListPage` 用请求代次丢弃在途响应；临时密码在屏时 `locked` 禁用新建与重置 |
| 临时凭据只留在内存，且安全渲染不可信数据 | 是 | 密码只存 `useState`，关闭即清；教师名称由 React 文本节点渲染，不拼 HTML |

真实浏览器验证（本机真实后端，非 mock）：

- 登录 → 教师列表（含已发布课程数）→ 新建教师 → 一次性密码 → 复制 → 关闭后
  密码不在 DOM 中 → 列表自动刷新 → 重置密码 → 退出 → 刷新仍为未登录；
- 凭据面板打开时「新建教师」与全部「重置密码」按钮均为 `disabled`，关闭后恢复。

### 有意的差异

- **不再从管理页跳转销售站与服务状态。** 旧 `admin.html` 把三个入口并列在一页，
  是因为它同时充当落地页。v1 管理端只承担账号管理，销售站入口保持在
  `forsales.html` 自身，不随框架迁移改写（执行计划 3F 明确要求）。
- **未提供停用/恢复按钮。** `api.ts` 留有方法，但后端对应端点尚未确认实现；
  点了会报错的按钮比没有按钮更糟，因此界面暂不暴露。

## 教师端（`teacher-web/editor.html` → `v1/web/teacher`）

旧页面已知的两处缺陷在 v1 中不复现：

| 旧缺陷 | v1 行为 |
| --- | --- |
| `app.js` 读 `state.course.lesson`，与后端 `CourseDetail.lessons[]` 漂移（重构计划第 2 节记录） | 按 `lessons[]` 渲染，且在组件内按 `sort_order` 显式排序 |
| 固定 BVID、固定 513 秒、内置字幕，只操作第一门课程的第一个课节 | 课程与课节都需显式选择；BVID 由老师粘贴链接得到；时长不再由前端假定 |

真实浏览器验证：

- 登录 → 课程列表（空状态与多课程）→ 新建课程 → 添加课节（粘贴 B 站链接自动
  取出 BVID）→ 导入 177 句真实字幕 → 从某句插入节点 → 填写并保存草稿 →
  发布 → 创建授权码 → 关闭后授权码不在 DOM 中；
- 刷新与浏览器后退都落回同一课程／课节（位置在 URL 上）；
- 保存前的本地空字段检查会指名节点序号、时刻、类型和缺失项。

### 尚未迁入

- **横向时间轴与拖放定位。** 旧 `visual-node-editor.js` 的可视化轨道未迁入；
  v1 用字幕列表定位节点，时刻也可手填 `mm:ss`。
  `v1/web/shared/src/editor/TimelineModel.ts` 已就位并有测试，等待 UI 落地。
- **学生端效果预览。** 旧页面该区域已在早前决策中降级为静态示意图
  （`doc/lessons.md` 2026-08-14 条），v1 不再保留这个区域，真实效果通过
  插件在 B 站原页面查看。

## 结论

两个应用的行为承诺已覆盖，可以进入切换准备。

切换本身属于阶段 6（`发布、安全、恢复与旧入口隔离`）：现有 `tools/web-release.sh`
从 git archive 复制已跟踪文件，而 v1 是 Vite 构建产物，发布路径需要改造。
在那之前旧入口继续对外服务，v1 只在本机运行。

销售页 `forsales.html` 与试用表单在整个过程中保持原样。
