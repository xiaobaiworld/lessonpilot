## D-001 学生宿主使用 B 站原页面加插件

- 日期：2026-08-14
- 状态：已接受，技术路径部分已验证，完整产品闭环待验证
- 问题：B 站跨源 iframe 无法由普通网页稳定读取播放时间并暂停，定时互动无法成立。
- 事实：插件 content script 已证明能在指定 B 站页面定位视频、暂停、seek、监听时间、卸载 UI 和遮挡字幕；当前只是 spike。
- 方案：网页学生页、代理/托管视频、B 站原页面插件。
- 决定：第一阶段学生宿主只用 PC Chrome 的 B 站原页面加插件。
- 放弃：网页学生页不能兑现定时互动；代理或托管不符合当前资源和内容边界。
- 假设：第一批老师和学生愿意接受人工安装已解压插件。
- 重开条件：真实老师普遍拒绝安装，或平台提供稳定官方播放器控制 API。
- 影响：`student-web/` 已删除；所有学生运行时进入 `src/` 插件。

## D-002 第一阶段采用礼宾式真实闭环

- 日期：2026-08-15
- 状态：已接受，替代旧 D0/D1 作为当前实施目标
- 问题：等待完整教师端、学生端和报告后再接触老师，会继续用开发替代市场证据；只发销售页又无法承接“我想试试”。
- 方案 A：完成完整产品后销售；方案 B：销售页 + 人工准备 + 最小真实闭环；方案 C：只发销售页。
- 决定：采用方案 B。老师可以亲手操作，但字幕取得、安装和首次配置允许人工协助。
- 放弃：A 范围和周期过大；C 没有真实产品体验承接兴趣。
- 假设：一个真实课程、四种基础节点和本地预览足以验证使用意愿。
- 重开条件：第一批老师要求完全自助才能试用，或四种节点仍不足以表达真实教学意图。
- 影响：旧 W0/D0/D1 需求和计划归档；当前需求只描述第一阶段。
- Supersedes：2026-08-11 至 2026-08-14 文档中的 D0/D1 当前排期。

## D-003 销售首页和真实工作台分开，但复用现有产品形态

- 日期：2026-08-15
- 状态：已接受
- 问题：`teacher-web/index.html` 作为默认入口却显示工作台示例，页面语义不正确；项目同时维护销售页、示例页和旧编辑器三种近似形态。
- 方案：保留三页；让 index 直接成为工作台；让 index 成为销售首页并新增 workspace。
- 决定：`teacher-web/index.html` 是销售首页；`teacher-web/workspace.html` 是真实工作台；`forsales.html` 做兼容跳转；旧 `editor.html` 停止扩展并在迁移回归后决定删除。
- 理由：默认 URL 自然承担首次销售，真实工作台有稳定语义，同时沿用已确认的工作台产品形态。
- 重开条件：部署平台要求不同路由，或真实用户需要登录后默认进入工作台。

## D-004 第一阶段只管理一门当前课程

- 日期：2026-08-15
- 状态：已接受
- 问题：多课程列表、版本和发布会扩大范围，但老师仍需要用自己的课程试用。
- 决定：网页草稿和插件都只保留一门当前课程。更换 URL 时警告；清除插件成功后才清空网页旧草稿。
- 放弃：多课程管理、版本历史和云端课程库。
- 假设：第一阶段一次只服务一位老师的一节课。
- 重开条件：同一位试用老师必须在一次测试中反复切换两门以上课程。

## D-005 第一阶段支持四种节点，问答题不使用 AI

- 日期：2026-08-15
- 状态：已接受
- 问题：只做选择题不能展示已确认的主要产品形态；AI 自由回答会引入后端、成本和质量风险。
- 决定：支持重点标注、选择题、填空题和问答题。问答题只保存原始回答并展示老师预设反馈，不判断对错、不调用 AI。
- 放弃：老师音频、排序、匹配、语音、AI 评价和追问。
- 假设：四种节点的本地确定性实现可以在第一阶段快速形成闭环。
- 重开条件：真实课程无法用这四种节点表达，或老师把 AI 评价视为试用前提。

## D-006 公网工作台通过白名单内容脚本连接本机插件

- 日期：2026-08-15
- 状态：已接受，待真实公网验证
- 问题：网页直接外部消息需要知道稳定扩展 ID，开发者模式安装会增加配置；同时配置桥必须限制来源和操作。
- 方案：网页直接 `chrome.runtime.sendMessage(extensionId)`；把编辑器做进插件；`window.postMessage` 到白名单内容脚本。
- 决定：工作台发版本化 `window.postMessage`，只在工作台路径注入的内容脚本校验后转发到后台。网页、内容脚本和后台都执行 schema 校验。
- 放弃：直接依赖扩展 ID；把完整教师端塞入插件。
- 安全边界：校验 source、origin、path、channel、协议、requestId、操作和 payload；失败默认拒绝；不传完整字幕。
- 重开条件：Chrome 平台限制该桥，或正式上架后稳定扩展 ID 能明显简化架构。
