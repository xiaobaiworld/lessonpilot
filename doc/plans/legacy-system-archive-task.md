# 旧系统集中归档任务

日期：2026-08-24

状态：执行中

## 目标

仓库只继续开发和发布 V1。旧前端、旧 Chrome 插件、旧专用测试、旧组装工具和旧
GitHub Pages 工作流集中放入 `archive/legacy-v0.9.1/`，不再参与默认测试、构建和发布。

归档不是删除。出现问题时，通过本任务对应的 Git 提交整体回退，不从归档目录直接启动
半套旧系统。

## 已确认边界

- 根目录 `backend/` 虽然沿用历史路径，但当前承载生产 V1 API、迁移和测试，保留原位；
- `v1/` 是当前管理员端、教师端和学生插件；
- 销售页、学生使用说明、飞书试用入口和共享视觉样式仍在生产使用，迁入 `v1/`；
- 根目录 `link.html` 是当前导航页，保留原位；
- 旧 `teacher-web/` 与旧插件 `src/` 进入归档；
- 只验证旧系统的测试、`tools/assemble-workspace.js` 和旧 GitHub Pages 工作流进入归档。

## 验收

1. 根目录不再存在 `teacher-web/` 和旧插件 `src/`；
2. `archive/legacy-v0.9.1/README.md` 记录内容、冻结提交和整体回退方法；
3. V1 构建不引用归档目录，生产发布只打包 V1 应用、V1 插件和当前静态站点；
4. `/`、`/teacher-web/forsales.html`、`/teacher-web/student-guide.html`、
   `/admin.html` 和 `/teacher-web/editor.html` 的公网路径保持兼容；
5. 根测试、V1 测试、后端测试、Lint、类型检查、构建和发布候选验证通过；
6. 不修改生产数据，不执行生产部署。

## 回退

本任务形成单一结构变更提交。出现问题时优先对该提交执行 `git revert <commit>`，恢复旧目录、
旧测试入口和旧发布来源。生产仍使用已验证的不可变 release，不依赖工作区归档目录直接恢复。
