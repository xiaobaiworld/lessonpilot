# 学生插件使用说明页开发计划

版本：`0.1.3`

状态：执行中

更新时间：2026-08-24

## 1. 目标与依据

把销售页中的“学生插件下载”改为“学生使用步骤”，进入独立说明页，帮助学生按图完成固定 ZIP 下载、解压和 Chrome 手动安装，并能返回销售页。

需求依据：`FR-LIB-014`、`SCOPE-05`、`SCN-STU-01`。

既有决策：`D-V1-004`。本功能只解释既有固定 ZIP 手动分发流程，不改变插件包、下载地址、授权、更新或生产发布策略。

设计依据：`doc/design/v1/07-product-interaction-state.md` 第 6.0 节。

## 2. 范围

### 本轮完成

- 修改 `teacher-web/forsales.html` 的学生入口文案和目标地址；
- 新建 `teacher-web/student-guide.html`；
- 新建不含个人信息的安装说明截图；
- 把新页面和截图加入 Web 发布白名单、精确提交构建和生产探针；
- 增加自动化测试，覆盖导航、内容、可访问性和发布产物；
- 同步需求、设计、追踪矩阵、`next.md` 和 `changelog.md`；
- 提交并推送到 GitHub。

### 本轮不做

- 不发布到 `knownmap.com`，除非产品负责人另行明确要求；
- 不改变插件 ZIP 内容、版本或下载地址；
- 不新增 Chrome Web Store、自动安装、自动升级或移动端支持；
- 不读取学生本机课程或要求学生登录。

## 3. 验收标准

1. 销售页只出现“学生使用步骤”入口，点击进入 `/teacher-web/student-guide.html`；
2. 新页面有“返回销售页”入口，直接访问时也能正常使用；
3. 页面完整说明下载、解压、扩展管理页、开发者模式和加载已解压扩展；
4. 页面至少包含解压与 Chrome 安装两类截图，图片均有准确替代文本；
5. 固定 ZIP 链接仍为 `/downloads/student-plugin/knownmapplugin.zip`；
6. 页面风格与销售页色彩、字体、卡片和按钮视觉一致，窄屏可读；
7. `sales-static-v1`、`teacher-platform-v1` 和 `v1-apps` 发布产物均包含新页面与截图；
8. 根测试、相关构建、文档检查、秘密扫描和 GitHub CI 全部通过。
