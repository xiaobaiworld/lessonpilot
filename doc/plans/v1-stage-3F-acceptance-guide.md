# KnownMap v1 阶段 3F — 人工验收脚本

**目标**：逐步验证管理员应用和教师应用的完整功能

**预计时间**：30-45 分钟

**环境**：本地开发环境

---

## 第一步：启动应用

### 1.1 启动后端 FastAPI 服务

```bash
cd backend
uv run python -m app.main
```

**预期输出**：
```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

### 1.2 启动管理员应用

在另一个终端：
```bash
cd v1/web
npm install  # 首次运行
npm run dev  # 启动开发服务器
```

**预期输出**：
```
  VITE v5.0.0  ready in 123 ms

  ➜  local:   http://localhost:5173/admin/
  ➜  press h to show help
```

### 1.3 启动教师应用

在第三个终端：
```bash
cd v1/web/teacher
npm run dev
```

**预期输出**：
```
  ➜  local:   http://localhost:5174/
```

## 第二步：管理员应用验收

### 2.1 管理员登录

**步骤**：
1. 打开浏览器，访问 `http://localhost:5173/admin/`
2. 在邮箱字段输入：`admin@example.com`
3. 在密码字段输入：（查看后端日志中的初始密码）
4. 点击"登录"按钮

**验收标准**：
- [ ] 页面显示"超级管理员登录"标题
- [ ] 邮箱和密码输入框可用
- [ ] 登录按钮正常显示
- [ ] 若登录成功 → 进入教师列表页面（跳到 2.2）
- [ ] 若登录失败 → 显示错误提示并可重试

**如果登录失败**：
```bash
# 检查后端是否有管理员
cd backend
uv run python -c "
from app.db import get_db
from app.models.admin import AdminAccount
db = next(get_db())
admin = db.query(AdminAccount).first()
if admin:
    print(f'Admin exists: {admin.email}')
else:
    print('No admin found - need to seed')
"
```

## 第五步：错误处理与网络验证

### 5.1 验证 API 错误处理

**步骤**：
1. 打开浏览器开发者工具 → Network 选项卡
2. 在管理员或教师应用中执行操作（登录、查询等）
3. 查看网络请求

**验证标准**：
- [ ] 每个请求都有 `X-Request-ID` 头（用于追踪）
- [ ] 请求体和响应体都是有效的 JSON
- [ ] 成功请求返回 200
- [ ] 失败请求返回对应错误码（400/401/500 等）

**检查 Request Header**：
```
GET /api/v1/teacher/courses HTTP/1.1
Host: localhost:8000
Authorization: Bearer eyJ...
X-Request-ID: 1692777600000-a1b2c3d4
Content-Type: application/json
```

### 5.2 测试网络错误恢复（可选）

**步骤**（仅在有网络工具时）：

**验证标准**：
