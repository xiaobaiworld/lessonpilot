# KnownMap v1 测试计划

文档版本：`1.0.0`

状态：已建立，待随 v1 实现执行；本计划只定义测试证据和门禁，不改变已接受需求与设计

需求真源：[`../requirements/v1/README.md`](../requirements/v1/README.md)

设计真源：[`../design/v1/README.md`](../design/v1/README.md)

## 1. 测试目标

证明 v1 能在不越权、不泄露秘密、不上传学生学习数据和不破坏最后有效数据的前提下，完成以下真实闭环：

```text
管理员接入教师
  -> 教师创建课程/课节/节点
  -> 真实预览并发布课程版本
  -> 创建并交付授权码
  -> 学生输入授权码并确认安装
  -> B 站匹配视频运行互动
  -> 本机保存状态
  -> 失败恢复、更新、回退和重复交付
```

代码通过、测试数量多、页面能打开或旧版本曾经演示成功，都不能单独证明 v1 完成。每条稳定需求最终必须能
追踪到设计、代码、自动化/人工证据、环境、版本和发布记录。

## 2. 证据等级

| 等级 | 适合证明 | 最低证据 |
| --- | --- | --- |
| 单元 | 纯规则、Schema、状态机、摘要、映射和错误分类 | 可重复测试输入/输出 |
| 集成 | SQLite 事务、FastAPI、文件、插件存储和模块协作 | 真实组件 + 隔离数据 |
| 契约 | OpenAPI、课程包、插件消息和文件版本 | 新旧版本、未知字段/版本、拒绝结果 |
| 浏览器 | 教师 Web、插件 popup/content、B 站页面和页面生命周期 | 指定桌面 Chrome、步骤、截图/日志和结果 |
| 运维 | 构建、发布、健康、备份、恢复和回退 | 精确提交、产物摘要、环境、记录和对账 |
| 真实闭环 | 真实老师、真实学生、真实课程和重复交付 | 匿名化人工记录，不把演示数据冒充真实证据 |

自动化优先覆盖业务规则、权限、完整性、幂等、原子性和错误契约；真实浏览器、公网、B 站、发布、备份恢复和
升级顺序必须保留可重复手工证据。没有真实证据的范围标为“未验证”。

## 3. 测试数据与环境

### 3.1 匿名夹具

建立一套稳定、无真实个人信息的 v1 夹具：

- 两个教师工作空间、一个管理员和两个学生本机身份；
- 一门包含多个有序课节的课程，允许两个课节复用同一视频，也允许重复脚本内容；
- 至少两个课程发布版本；
- 课程级、课节级和节点级授权，另有失效、终止和范围为空的来源；
- 四类基线节点、合法/畸形视频引用、合法/损坏课程包、有效/冲突/未知版本的本机存储；
- 虚构 SRT/VTT、导入文件、请求标识和授权码；不使用真实密码、联系方式、学生回答或生产数据库。

### 3.2 环境分层

| 环境 | 用途 | 数据规则 |
| --- | --- | --- |
| 本地单元/集成 | 快速开发和失败回归 | 临时 SQLite、匿名夹具、无外部真实账号 |
| 隔离迁移副本 | Schema/初始化/拒绝旧数据 | 只读旧样例 + 匿名代表数据，执行后清理 |
| 浏览器验收环境 | 教师 Web、插件、B 站真实边界 | 指定桌面 Chrome，专用测试账号和课程 |
| 发布候选环境 | 精确产物、健康、公开表单和回退 | 与生产配置隔离，测试申请必须可识别和清理 |
| 小规模真实交付 | D-V1-005 闭环 | 真实老师/学生，记录最小必要证据，不上传学生数据 |

## 4. 测试矩阵

### 4.1 身份、工作空间和数据归属

- 管理员、教师、无会话和失效会话的登录、恢复、退出、停用和重置；
- 两个教师交叉读取、保存、发布、授权、导入和导出，所有跨空间操作拒绝且不泄露正文；
- 客户端伪造角色、教师 ID、工作空间 ID 和课程 ID；
- 账号/会话失败不删除已确认课程和草稿。

关联：`FR-AUTH-*`、`FR-WS-*`、`SEC-ACCESS-*`、`INT-WEB-*`。

### 4.2 课程、课节、节点和发布

- 一门课程多课节、显式顺序、同内容课节和同视频多课节保存；
- 视频引用不完整、来源不支持、字幕解析失败、节点类型/时间非法；
- 草稿保存、修订冲突、失败保留和刷新恢复；
- 课程级原子发布、发布前权利确认、重复发布幂等、旧发布不可变；
- 发布包保留课程/课节/节点身份和顺序，不合并重复内容、不生成跨版本混合包。

关联：`FR-COURSE-*`、`FR-AUTHOR-*`、`FR-PUBLISH-*`、`DATA-CONTENT-*`、`DATA-PUBLISH-*`。

### 4.3 授权、兑换和课程库

- 授权码原文只在创建结果显示一次；数据库、日志、查询和包中无原文/摘要；
- 领取窗口与授权项有效期独立；课程、课节和节点范围正确裁剪；
- 无效、过期、终止、无发布内容和跨空间授权不返回正文；
- 同一机器重复提交、请求重试、响应超时和并发兑换不产生重复关系；
- 多来源按并集计算，单个来源失效不清空其它来源；
- 课程包独立校验、学生确认、临时区、原子安装、同课程原子更新和其它课程不受影响；
- 更新不热切换当前会话；已安装课程不因在线资格失效被远程删除。

关联：`FR-GRANT-*`、`FR-LIB-*`、`INT-PACKAGE-*`、`SEC-SECRET-*`、`SEC-TRUST-003`。

### 4.4 学生运行时和本机状态

- 无匹配视频静默；单匹配自动加载；多课节匹配由学生选择并由会话锁定；
- B 站单页切换、播放器重建、全屏变化、刷新和 seek 不重复触发或静默换课；
- 播放事实、窗口交互、正式尝试、节点结果和进度分别记录；错误答案/关闭窗口不伪装为完成；
- 学习状态只写本机；弱网、离线、损坏存储和空间不足保留最后可确认状态；
- 预览不写入学生课程库、学习状态或服务端学生数据。

关联：`FR-RUNTIME-*`、`FR-LEARN-*`、`DATA-LOCAL-*`、`SEC-PRIV-001`、`INT-BILI-*`。

### 4.5 契约、输入和安全

- OpenAPI、课程包、插件消息、字幕和教师文件的版本/字段/大小/引用校验；
- 未知主版本、未知操作、空响应、旧上下文响应、脚本化文本、路径字段、超大文件和损坏包安全拒绝；
- 密码、会话、授权码、本机证明、部署密钥不出现在日志、导出、包、仓库或页面；
- 本机学习数据、回答、进度和完整字幕不通过领取、预览、运行时或支持接口上传；
- 公开表单无登录可访问，未授权人员不能读取申请，提交结果未知不显示成功。

关联：`INT-*`、`SEC-*`、`DEV-DEP-*`、`DEV-LOG-*`。

### 4.6 发布、备份、恢复和干净初始化

- 精确提交、依赖锁、配置检查、产物摘要和契约版本一致；
- 候选发布、健康检查、公开入口、切换中断和版本回退；
- 服务端空库初始化、迁移脚本拒绝旧数据、旧插件/旧存储隔离且不被 v1 覆盖；
- 代表性副本备份、隔离恢复、对象/归属对账和中断恢复；
- 故障停止风险写入、保留恢复点、执行回退并验证核心闭环。

关联：`OPS-*`、`MIG-*`、`D-V1-012`、`ACC-GATE-*`。

## 5. 自动化执行基线

当前仓库已有自动化基线，重构期间只把它当作现状回归参考；新增 v1 测试应按目标契约重新组织：

```bash
node --test tests/*.test.js
cd backend && uv run pytest
```

后端测试也应在可用时运行覆盖率报告，但不设置没有真实基线的统一数字。每个失败修复先添加能复现问题的测试，
再修改实现；测试名称应包含稳定需求/设计编号或在追踪矩阵中明确映射。

## 6. 浏览器与真实闭环脚本

### 6.1 教师人工脚本

1. 以专用管理员创建一名教师和唯一工作空间；
2. 教师创建包含重复内容/同视频课节的课程，导入匿名字幕并制作四类节点；
3. 保存、刷新、制造一次修订冲突，确认未保存输入和服务端版本分别可见；
4. 启动真实预览，确认节点触发、窗口关闭、播放器恢复和预览不写学生数据；
5. 发布课程，创建课程级和部分范围授权，核对授权码只显示一次；
6. 记录 Chrome、插件、服务、代码提交、时间、输入夹具和实际结果。

### 6.2 学生人工脚本

1. 在指定桌面 Chrome 安装固定插件包，初始化新的本机身份；
2. 输入有效授权码，核对课程名称、课节/节点范围、发布版本和本机影响；
3. 取消一次安装，确认课程库未改变；再次确认，核对原子安装；
4. 打开匹配 B 站视频，验证单匹配、多课节选择、节点暂停/反馈/继续和本机状态；
5. 刷新、断网、关闭页面、删除候选或损坏本机记录，确认最后有效状态保留；
6. 发布新版本，在线检查更新，确认版本/范围/状态迁移摘要后更新；
7. 终止/到期来源，确认已安装课程仍可用、更新和重新下载受限；
8. 记录版本、屏幕、日志关联、期望/实际和未验证边界。

### 6.3 D-V1-005 真实门禁

发布候选必须有：至少一位真实老师使用真实课程完成制作、保存和发布；至少一位真实学生领取、运行并完成互动；
另一门课程或另一位老师重复成功；本机重启恢复、授权更新、失败恢复和回滚通过；全过程不需要开发者改代码或
直接改生产数据。市场价值只记录真实反馈，不预设样本量或完成率数字。

## 7. 证据记录格式

每个测试/人工记录至少包含：

- 稳定需求/设计/决策编号；
- 代码提交、产物摘要、环境、浏览器/插件/服务版本和日期；
- 前置数据、步骤、预期、实际、失败点和恢复动作；
- 证据文件路径（日志、截图、输出或对账表）；
- 未覆盖边界、敏感数据检查和最终状态：待验证/已验证/阻塞/不适用。

推荐目录：`tests/manual/v1/<date>-<flow>.md`。真实用户记录使用匿名标识，不保存授权码、密码、联系方式、
学生回答、完整课程正文或学习状态原文。

## 8. 发布门禁

1. 需求级矩阵中所有适用 P0 项达到“已验证”；
2. `D-V1-012` 的干净初始化、旧数据拒绝和不覆盖测试通过；
3. 自动化测试、契约检查、秘密扫描和依赖检查通过；
4. 真实 Chrome/B 站、公开表单、备份恢复和发布回退证据齐全；
5. 失败、未验证、已知风险和回退入口已记录；
6. 发布记录固定提交、产物、环境、恢复点和发布后探针。

任何 P0 待验证、阻塞、证据过期或结果不可重复，都阻止 v1 发布。

## 9. 维护规则

需求、决策、契约、数据模型、代码、依赖、宿主环境或迁移源变化时，重新评估受影响证据；不因测试名称、页面
外观或版本号未变而自动继承结论。新的安全/数据事故先写失败复现和 lessons，再补回归测试。
