# LessonPilot 第一阶段真实验证闭环设计

版本：1.1

日期：2026-08-15

状态：已确认，作为需求与开发计划整理的范围依据

当前功能权威见 `doc/requirements.md`，数据与消息字段权威见 `doc/data-spec.md`，方案变更与重开条件见 `doc/DECISIONS.md`。

## 1. 阶段目标

第一阶段不是交付成熟平台，而是用一条真实、可操作的闭环验证以下四件事：

1. 老师看完销售页后，愿意提供一条真实 B 站课程；
2. 老师愿意在指导下亲手配置课程互动；
3. 教师工作台保存的配置能够进入老师本机插件；
4. 插件能够在 B 站原页面完成一次真实学习过程。

第一阶段采用礼宾式交付。老师可以自己操作工作台，但字幕取得、时间轴核对、插件安装和首次课程准备允许由 LessonPilot 提供者人工协助。第一阶段不以无人协助、自助注册或规模化交付为完成条件。

## 2. 完整用户流程

第一轮接触和实际体验允许分开进行，不能承诺老师提供链接后立即生成课程。

```text
老师看到公网销售页
  -> 回复并提供 B 站视频链接
  -> 老师提供字幕，或 LessonPilot 提供者随后通过其它工具取得字幕
  -> 人工确认字幕时间轴与视频匹配
  -> 老师打开公网教师工作台
  -> 输入课程链接并导入字幕
  -> 在字幕时间点配置互动节点
  -> 保存并发送到老师本机插件
  -> 打开 B 站原页面
  -> 视频到点自动暂停
  -> 展示重点标注或题目
  -> 学生确认或作答
  -> 展示反馈并继续播放
```

第一次接触的有效商业信号仍然是老师愿意提供一节真实课程。实际试用的有效产品信号是老师愿意安装插件、亲手配置至少一个节点，并完成对应的学生体验。

## 3. 页面结构与职责

### 3.1 默认销售首页

`teacher-web/index.html` 是网站默认入口，由当前 `teacher-web/forsales.html` 的销售内容迁入。

职责：

- 让目标老师识别自己的录播课问题；
- 解释旧课如何增加互动练习、反馈和学习证据；
- 使用真实产品形态展示第一阶段能够兑现的结果；
- 以“申请改造一节真实课程”为主要行动；
- 为已经准备好课程的老师提供进入教师工作台的次要入口。

销售页保持静态即可，不承担课程编辑和学生运行时。销售页不得暗示老师语音、AI 评价、正式报告、账号或规模化发布已经可用。

### 3.2 真实教师工作台

`teacher-web/workspace.html` 是第一阶段真实教师工作台。它沿用当前工作台示例已经确认的产品形态，不重新设计一套主体界面。

第一阶段功能：

1. 输入并校验一个标准 B 站 `https://www.bilibili.com/video/BV.../` 视频 URL；
2. 从 URL 提取 BVID；
3. 导入对应的 SRT 或 VTT 字幕；
4. 在浏览器本地解析字幕并生成真实时间线；
5. 在字幕段落上新增、修改或删除节点；
6. 按触发时间自动排列节点；
7. 校验并保存当前课程配置；
8. 将课程配置发送给插件；
9. 打开对应 B 站原页面开始独立预览会话。

工作台只管理一门当前课程。老师更换视频 URL 且当前课程已有字幕或节点时，必须先确认。确认后清空原课程、字幕、节点和插件中的旧配置；取消则完整保留当前课程。第一阶段不提供课程列表、课程复制、草稿版本或云端保存。

### 3.3 兼容与旧原型

- `teacher-web/forsales.html` 在迁移完成后保留兼容跳转，避免旧链接立即失效；
- `teacher-web/editor.html` 是旧功能原型，不再增加功能；
- `teacher-web/editor.html` 的必要能力迁入 `workspace.html` 并完成回归后，再单独决定删除时间。

## 4. 第一阶段节点范围

第一阶段只支持四种节点，不增加其它题型或内容组件。

### 4.1 重点标注

- 老师配置标题、说明和需要强调的词或短句；
- 到达触发时间后自动暂停；
- 学习窗口必须完整显示重点内容；
- 对 B 站画面的额外高亮只是增强，不是完成条件；
- 学生确认后继续播放。

### 4.2 选择题

- 题目不能为空；
- 至少有两个非空选项；
- 必须指定一个正确答案；
- 老师可以配置正确和错误反馈；
- 学生提交后显示确定性反馈，再继续播放。

### 4.3 填空题

- 题目必须包含明确的填空位置；
- 老师至少配置一个可接受答案；
- 比较答案时忽略首尾空格和英文大小写；
- 学生提交后显示确定性反馈，再继续播放。

### 4.4 问答题

- 学生输入自由回答；
- 插件保存原始回答；
- 提交后显示老师预先配置的参考答案或反馈提示；
- 第一阶段不判断对错，不调用 AI，不生成个性化评价或追问。

所有节点均允许跳过。完成或跳过后继续播放。

## 5. 架构与数据流

第一阶段由三个独立单元组成：

```text
公网静态站
  销售首页 + 教师工作台
        |
        | 精确来源白名单消息桥
        v
老师本机 Chrome 插件
  配置校验 + chrome.storage.local + 学习运行时
        |
        | Content Script
        v
B 站原视频页面
  BVID 识别 + 播放时间监听 + 暂停/继续 + 学习窗口
```

### 5.1 教师工作台

- 字幕文件只在老师浏览器内解析，不上传；
- 工作台只向插件发送课程标识、节点配置和协议元数据，不发送完整字幕文件；
- 保存前进行字段级校验；
- 插件未安装、版本不兼容或消息桥不可用时，页面显示可操作的错误，不伪装保存成功。

### 5.2 消息桥

- 只允许已配置的公网教师工作台精确 origin 和本地开发 origin；
- 协议包含版本、操作类型、`requestId` 和配置载荷；
- 页面发送前校验，插件接收后再次校验；
- 第一阶段只开放保存当前课程、读取当前课程、清空当前课程、创建预览会话和查询连接状态所需的固定操作；
- 课程配置不得包含自定义 HTML、CSS 或 JavaScript。

### 5.3 插件本地存储

- 使用 `chrome.storage.local` 保存唯一当前课程；
- 当前课程至少包含 `VideoRef`、节点数组和可追溯的 `updatedAt`；
- 学生回答与预览会话状态只保存在本机；
- 更换课程时清除旧课程配置和对应会话数据；
- 第一阶段没有账号、后端、跨设备同步、课程发布或多人分发。

### 5.4 插件交付

- 第一阶段由老师在 PC Chrome 开发者模式下加载已解压插件；
- 首次安装和更新允许由 LessonPilot 提供者远程或现场协助；
- 第一阶段不以 Chrome 应用商店审核和发布为前置条件；
- 老师保存新配置后无需重新加载或重新安装插件。

## 6. 学生运行时规则

插件只在当前保存课程对应的 BVID 页面启动课程运行时。其它 B 站视频不得显示课程界面或记录行为。

节点状态机：

```text
pending
  -> active
  -> completed | skipped
```

运行规则：

- 到达节点触发时间时暂停视频并打开唯一学习窗口；
- 同一预览会话中，`completed` 或 `skipped` 节点不重复触发；
- seek 跨过多个节点时，只先触发最早一个 `pending` 节点；
- 完成或跳过当前节点后，再继续处理后续节点；
- 刷新 B 站页面后创建新的预览会话；
- B 站单页跳转离开当前课程时，卸载学习窗口、播放器监听、字幕遮挡和其它注入 UI；
- 找不到播放器时显示课程无法启动状态，不进行无限重试或伪造成功。

## 7. 错误与边界处理

第一阶段必须明确处理：

- 无效或不支持的 B 站视频 URL，包括非标准视频页、缺少 BVID 或当前浏览器无权访问的视频；
- 空字幕、格式错误、时间顺序异常或不支持的字幕扩展名；
- 字幕与视频是否匹配无法自动证明，必须提示人工确认；
- 节点字段缺失、时间非法、选项不足或缺少正确答案；
- 插件未安装、版本不兼容、消息超时或来源不在白名单；
- 保存配置的 BVID 与当前 B 站页面不一致；
- B 站播放器元素暂时不存在或站点 DOM 变化；
- B 站 SPA 进入、离开和切换视频时的重复挂载与残留监听。

第一阶段允许界面和题目配置体验不完善，但不允许假保存、配置丢失后无提示、错误视频触发课程、重复触发已处理节点或把自由回答伪装成 AI 评价。

## 8. 第一阶段非目标

以下功能全部属于第二阶段或以后，不能作为第一阶段实现过程中的顺手扩展：

- AI 评价、AI 追问和 AI 报告；
- 老师补充音频、语音输入和发音评价；
- 账号、权限、支付、班级和机构；
- 自动抓取或生成字幕；
- 正式老师报告和多学生汇总；
- 多课程管理、版本历史和云端同步；
- 手机端；
- YouTube 或其它视频平台；
- Chrome 应用商店正式发布；
- 选择题、填空题、问答题和重点标注以外的节点类型。

## 9. 验收标准

第一阶段只有同时满足以下条件才算完成：

1. 公网销售首页和教师工作台在桌面及 375px 宽度下无关键内容遮挡或横向溢出；
2. 老师能输入任意可访问的标准 B 站 BV 视频 URL，并导入对应的 SRT/VTT 字幕；
3. 四种节点都能新增、编辑、删除和校验；
4. 老师保存后无需重新安装插件即可预览；
5. 插件只在配置对应的 B 站原页面启动，并按节点时间自动暂停；
6. 四种节点分别完成确认或作答、反馈、跳过和继续；
7. 同一会话不会重复触发已完成或已跳过节点；
8. 更换 URL 时明确警告，并在确认后清空原课程和插件旧配置；
9. 自动化测试覆盖课程配置、字幕解析、消息协议、四种节点校验、状态机和三种题型的作答规则；
10. 人工验收从公网工作台保存配置到真实 B 站原页面完整跑通；
11. B 站 SPA 离开课程后没有残留学习窗口、播放器监听或注入 UI；
12. 销售页展示的第一阶段能力与真实运行结果一致，不展示未完成能力为已可用。
