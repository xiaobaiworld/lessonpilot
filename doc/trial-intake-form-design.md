# 飞书真实课程试用表单设计

版本：1.0

更新时间：2026-08-19

状态：已发布并完成匿名访问验收

## 1. 目标与边界

这张表单是销售页私信主 CTA 之外的次要入口，用来确认老师是否愿意拿出一节真实课程进入试用沟通。它不负责自动生成课程、创建账号、上传字幕或承载学生数据。

当前试用只支持老师预先配置的固定时间点和固定互动节点。个性化教学问题只验证未来需求，不能写成当前能力。

## 2. 表单身份与说明

- 标题：`KnownMap 真实课程互动改造申请`
- 说明：`填写约 1 分钟。提交一节真实录播课，申请一次可实际运行的互动改造试用；无需重新录制，首次配置可协助完成。提交后我会联系您。`
- 创建位置：飞书多维表格表单视图
- 草稿管理地址：仅供表单所有者编辑，不得写入销售页
- 公开提交地址：`https://my.feishu.cn/share/base/form/shrcnGpoiVzLw8v5sD5K2TV8sFb`

## 3. 字段定义

| 顺序 | 问题 | 类型 | 必填 | 选项或说明 |
| --- | --- | --- | --- | --- |
| 1 | 怎么称呼您？ | 单行文本 | 是 | 只用于后续联系称呼 |
| 2 | 您的联系方式是？（微信、手机号或邮箱均可） | 单行文本 | 是 | 不强制只留微信 |
| 3 | 如果视频已在 B 站，请粘贴课程链接（选填） | 单行文本 | 否 | 只收标准 B 站视频链接 |
| 4 | 您最想通过互动改造解决哪个教学问题？ | 多行文本 | 是 | 示例：学生只看不练、答疑重复、无法判断是否理解 |
| 5 | 您的课程视频目前是什么情况？ | 单选 | 是 | 已在 B 站 / 准备上传到 B 站 / 需要协助 |
| 6 | 这节课目前有可用字幕吗？ | 单选 | 是 | 有字幕 / 没有字幕 / 不确定 |
| 7 | 如果课程能根据学生的不同回答，调整后续问题和反馈，这项能力对您有多重要？ | 单选 | 否 | 没有它也可以试用 / 有帮助，但不是必要条件 / 非常重要 / 没有这项能力，我不会使用 |
| 8 | 您最希望系统根据学生的哪些差异调整教学？ | 多行文本 | 否 | 未来方向验证，不代表当前试用包含 |

必填字段只服务于判断试用是否可继续和完成后续联系。不得增加公司规模、预算、学生名单、完整字幕或其它与第一轮联系无关的信息。

## 4. 网页模块

`teacher-web/trial-intake.js` 是表单入口的唯一配置真源，集中保存公开 URL、按钮文案、说明文案和挂载规则。`teacher-web/forsales.html` 只保留空挂载点，不复制 URL。

入口规则：

- 只接受 HTTPS 的 `feishu.cn`、`larksuite.com` 及其子域名，并要求路径为公开表单的 `/share/base/form/…`；
- URL 缺失、无法解析或不是允许域名时，整个入口保持隐藏；
- 有效时使用新标签页打开，并设置 `rel="noopener noreferrer"`；
- 按钮固定为 `填写 1 分钟试用信息`；
- 说明固定为 `不方便私信？留下课程情况，我会联系你。`；
- 发布白名单同时包含站点根目录和 `teacher-web/` 兼容目录中的模块文件。

## 5. 数据、权限与响应

- 公开表单必须允许未登录飞书的老师提交；如果飞书产品限制无法满足，入口不得上线；
- 提交结果只由表单所有者或被明确授权的 KnownMap 处理人查看；
- 表单不得收集学生个人信息、账号密码、授权码、完整字幕或课程源文件；
- 页面不保存表单答案，也不把答案发送到 KnownMap 自建后端；
- 提交后的人工响应承诺仅为“我会联系您”，不承诺自动生成课程或固定响应时限。

## 6. 验收与维护

自动化验收：

```bash
node --test tests/trial-intake.test.js tests/sales-page-copy.test.js tests/page-information-architecture.test.js
node --test tests/web-release.test.js
```

人工验收：

1. 使用未登录飞书的浏览器打开公开链接，确认可见且显示提交控件；
2. 检查 8 个问题的文案、顺序、选项和必填状态；
3. 从销售页点击次 CTA，确认新标签页打开公开表单；
4. 需要验证结果通知链路时，再提交带 `KnownMap 验收测试` 标记的数据并在验收后删除，避免把样本当作真实线索。

2026-08-19 发布验收：公开 URL 在无飞书 Cookie 的干净浏览器中返回 HTTP 200；标题、8 个问题、必填标识、全部固定选项和提交按钮均可见，未出现登录前置页。未创建测试线索。

后续更换表单时，只修改 `teacher-web/trial-intake.js` 的 `TRIAL_INTAKE.url`，同步本文件的发布状态和人工验证记录，再运行上述测试。禁止把飞书内部编辑地址写入公开模块。
