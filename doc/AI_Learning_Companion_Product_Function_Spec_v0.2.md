## 1. 文档目标

v0.2 描述 KnownMap 从当前 B 站 Chrome 插件试用形态，继续扩展为教师可以管理课程、授权学生并查看学习数据的产品功能。

目标闭环：

```text
平台定向创建教师账号
→ 教师建立课程和课节
→ 绑定 B 站视频或分 P
→ 创建并发布互动脚本
→ 创建课程或课节授权码
→ 学生领取并下载课程配置
→ 学生在 B 站视频页面学习
→ 插件上传已同步的学习记录
→ 教师查看学生进度和作答结果
```

本文件只确认产品功能、业务规则、边界和验收方向。

本文件不表示：

- 已经存在对应数据库；
- 已经完成教师后台；
- 已经完成账号、授权或学习数据服务；
- 已经确定最终数据库表、API 或技术实现；
- 文档列出的全部功能会在同一个开发阶段一次完成。

后续开发前仍需审计现有代码，再建立数据模型、接口合约、开发计划和测试方案。

## 2. v0.2 相对 v0.1 的关键变化

### 2.1 教师中心功能完成确认

本版本明确了：

- 测试期教师账号由平台定向创建；
- 教师账号包含序号、登录名、昵称、类别、批次和创建时间；
- 测试期一个教师只有一个工作空间；
- 后续一个教师可以拥有或加入多个工作空间；
- 一个工作空间可以管理多个课程；
- 一个课程可以包含一个或多个课节；
- 教师只能查看当前工作空间的数据；
- 教师可以管理课程、授权码、学生和学习数据；
- 教师测试反馈由平台管理员管理，不向教师本人展示；
- 教师助手、开放注册和多工作空间属于后续方向。

### 2.2 授权码不再定义为强制 DRM

授权码控制：

- 课程或课节的领取；
- 课程配置和互动内容的首次下载；
- 后续版本更新资格。

授权码不控制：

- 远程删除学生本地已有课程配置；
- 强制停止学生继续使用本地已有版本；
- 下载 B 站视频本身。

### 2.3 下载内容的定义被澄清

学生下载到本地的是：

- 课程配置；
- 课节信息；
- B 站视频定位信息；
- 已发布互动脚本；
- 运行互动所需的结构化内容；
- 必要的本地学习状态。

学生不会通过 KnownMap 下载 B 站视频文件。视频仍由 B 站提供和播放。

### 2.4 授权码停用不可恢复

教师主动停用或作废授权码后：

- 不能恢复；
- 不能继续产生新的领取和下载；
- 不能继续为该授权来源提供课程更新；
- 需要重新开放时必须创建新的授权码；
- 旧授权码和历史领取记录永久保留。

### 2.5 多授权码权限采用并集

同一学生可以领取多个授权码。最终领取、下载和更新资格由全部有效授权来源合并计算。

## 3. 产品边界

### 3.1 当前产品功能范围

- 平台管理员定向创建教师账号
- 教师账号和测试批次管理
- 教师工作空间
- 课程和课节管理
- B 站视频及分 P 绑定
- 结构化互动脚本
- 草稿、发布和历史版本
- 普通授权码
- 指定 Google 账号的定向授权码
- 课节授权和整课授权
- 多授权码权限合并
- 课程配置下载和更新
- 匿名学生和 Google 登录学生
- 学生自动进入教师学生列表
- 学习进度和作答记录上传
- 教师查看学生和课程学习数据
- 教师后台首页
- 教师和平台管理员操作记录
- 课程配置 JSON 导入导出
- 学习数据 CSV 导出

### 3.2 只做方向预留

- 教师自主注册
- 一个教师拥有或加入多个工作空间
- 教师助手和细粒度权限
- 课程合集
- 教师全部课程通行证
- 外部授权 API
- Webhook
- 外部订单关联
- 更完整的匿名身份合并
- 多设备同步冲突处理
- 教师和学生站内消息
- 教师对学生回答进行人工反馈
- AI 辅助生成练习
- 动态个性化教学

### 3.3 当前明确不做

- 学生向教师付款
- 平台收款
- 分账和提现
- 退款和发票
- 课程价格和优惠系统
- 复杂班级管理
- 多学校和多机构体系
- 手机端
- B 站以外的视频平台
- 完整知识图谱
- AI 自动发布教学内容
- 强制 DRM 或远程删除学生本地课程

## 4. 用户和角色

### 4.1 平台管理员

平台管理员负责：

- 创建测试教师账号；
- 设置教师序号、账号类别和测试批次；
- 停用或恢复教师账号；
- 查看教师总数和测试批次统计；
- 记录教师联系、试用、反馈和跟进情况；
- 查看系统异常和关键操作记录；
- 处理工作空间归属问题。

平台管理员可以看到内部测试字段。教师本人不能看到测试评价、内部反馈摘要或平台跟进记录。

### 4.2 教师所有者

教师可以：

- 登录自己的教师后台；
- 管理当前工作空间；
- 创建、编辑、发布和归档课程；
- 创建和管理课节；
- 绑定 B 站视频；
- 创建、预览和发布互动脚本；
- 创建和终止授权码；
- 查看授权码领取情况；
- 查看自己的学生；
- 查看学习进度和作答结果；
- 导出课程配置和学习数据；
- 查看自己工作空间内的操作记录。

教师不能查看其他工作空间的课程、学生、授权码、学习数据或操作记录。

### 4.3 教师助手

测试期不开放教师助手。

后续教师助手使用独立账号加入工作空间，可以按角色获得课程编辑、学生管理、授权码管理或数据查看权限。

### 4.4 学生

学生可以：

- 使用插件生成临时身份；
- 在允许时匿名领取普通授权码；
- 主动使用 Google 登录；
- 领取一个或多个授权码；
- 下载获得授权的课程配置；
- 在 B 站视频页面运行互动课程；
- 保存本地学习状态；
- 联网后上传学习记录；
- 在有效授权来源存在时获取课程更新。

## 5. 教师账号

### 5.1 测试期账号来源

- 测试期不开放教师自由注册。
- 教师账号由平台管理员定向创建。
- 忘记密码时由平台管理员重置。
- 后续开放注册时，沿用同一教师账号结构。

### 5.2 教师账号字段

每个教师账号至少包含：

- 内部稳定 ID；
- 教师序号；
- 登录名；
- 昵称；
- 账号类别；
- 创建方式；
- 测试批次；
- 创建时间；
- 账号状态；
- 最后登录时间。

教师序号、账号类别和测试批次是独立字段。

### 5.3 教师测试反馈

平台为测试教师维护：

- 当前测试阶段；
- 是否已经联系；
- 是否已经试用；
- 是否已经反馈；
- 每次反馈的时间和内容；
- 跟进状态；
- 最后反馈时间；
- 最后反馈摘要。

反馈记录采用追加方式保留历史，不能只覆盖成最后一次反馈。

### 5.4 教师可修改内容

教师可以：

- 修改昵称；
- 修改登录密码；
- 安全退出登录。

教师不能自行修改：

- 教师序号；
- 账号类别；
- 测试批次；
- 内部反馈记录；
- 工作空间归属。

### 5.5 教师账号停用

平台管理员停用教师账号后：

- 教师不能登录；
- 教师不能编辑或发布课程；
- 工作空间、课程、学生和历史数据继续保留；
- 工作空间暂时停止新的课程领取、下载和更新；
- 学生本地已有版本不受影响。

管理员恢复教师账号时，恢复的是教师和工作空间的运行资格，不等于恢复已经被教师永久停用的授权码。

## 6. 教师工作空间

### 6.1 测试期

- 一个教师账号只有一个工作空间。
- 教师是该工作空间的 Owner。
- 测试期不提供工作空间切换。
- 测试期不允许教师助手加入。

### 6.2 后续方向

- 一个教师账号可以拥有多个工作空间；
- 一个教师账号可以加入其他工作空间；
- 教师登录后可以选择当前工作空间；
- 每个工作空间独立管理自己的数据。

### 6.3 数据归属

以下对象归属于工作空间：

- 课程；
- 课节；
- 视频绑定；
- 互动脚本；
- 学生关系；
- 授权码；
- 领取记录；
- 学习记录；
- 操作日志。

工作空间是业务数据的归属主体，教师账号是工作空间的所有者或成员。

## 7. 课程、课节和视频

### 7.1 层级

```text
教师账号
→ 工作空间
→ 课程
→ 课节
→ B 站视频或分 P
→ 互动脚本版本
→ 互动节点
```

### 7.2 课程

教师可以：

- 创建课程；
- 编辑课程名称和描述；
- 查看课程状态；
- 保存草稿；
- 发布课程；
- 归档课程；
- 查看课程下的学生学习状态；
- 导出课程配置。

一个工作空间可以包含多个课程。

### 7.3 课节

- 一个课程可以包含一个或多个课节。
- 教师可以创建、编辑、排序和归档课节。
- 学习状态既可以按课节查看，也可以汇总到课程。
- 授权可以覆盖单个课节，也可以覆盖整门课程。

### 7.4 B 站视频绑定

教师可以：

- 粘贴 B 站视频链接；
- 识别 BVID；
- 识别分 P 对应的 CID；
- 查看视频标题和基础信息；
- 将视频或分 P 绑定到具体课节；
- 更换视频绑定。

课程运行依赖 B 站视频可访问。教师将视频下架、删除或设为不可访问后，学生本地互动配置仍可能存在，但无法正常完成对应视频课程。

### 7.5 课程归档

课程归档后：

- 不出现在教师正常课程列表；
- 历史课程、学生和学习数据继续保留；
- 暂停新的领取、下载和更新；
- 不强制删除学生本地已有版本；
- 教师可以继续查看历史记录。

归档是课程层面的运行限制，不自动改变每个授权码的历史状态。教师永久停用某个授权码时，仍按授权码不可恢复规则处理。

## 8. 互动脚本和配置文件

### 8.1 结构化配置

教师编辑的课程和互动内容必须保存为结构化配置，使用 JSON 或等价的 JSON 兼容结构。

配置至少能够表达：

- 课程和课节标识；
- B 站视频和分 P 信息；
- 脚本版本；
- 节点唯一编号；
- 触发时间；
- 节点类型；
- 节点内容；
- 知识点；
- 选项和答案结构；
- 正确答案；
- 正确和错误反馈；
- 答对和答错后的行为；
- 节点顺序；
- 创建和更新时间；
- 草稿、已发布和历史状态。

### 8.2 编辑能力

教师可以：

- 在视频时间线上添加节点；
- 修改节点；
- 删除节点；
- 调整顺序；
- 设置触发时间；
- 设置答案和反馈；
- 保存草稿；
- 发布脚本；
- 查看历史版本。

### 8.3 版本

- 草稿修改不会直接影响学生。
- 发布后形成新的不可混淆版本。
- 新领取学生下载最新已发布版本。
- 有有效更新资格的学生可以获取最新版本。
- 学习记录必须保存学生当时使用的脚本版本。

### 8.4 候选节点类型

测试期先保留以下候选类型：

- 重点内容；
- 选择题；
- 填空题；
- 问答题。

这些类型不是最终固定范围。制作真实课程时，如果无法表达实际教学活动，应重新评估节点类型。

测试期问答题：

- 保存学生原始回答；
- 展示教师预设反馈；
- 不自动判断对错；
- 不调用 AI 评分；
- 不自动生成追问。

### 8.5 学生模式预览

教师可以：

- 预览草稿版本；
- 预览当前已发布版本；
- 在 B 站视频页面测试节点触发；
- 检查题目、反馈和播放行为；
- 确认预览使用的版本。

预览数据不计入真实学生统计。教师只能预览自己当前工作空间的课程。

### 8.6 导入和导出

教师可以：

- 导出课程或课节 JSON；
- 下载配置作为备份；
- 导入已有 JSON；
- 在导入时执行格式和版本检查；
- 在覆盖前查看预览并确认。

无效、缺失字段或不兼容配置不能直接覆盖现有课程。

## 9. 学生身份

### 9.1 身份状态

| 状态 | 说明 |
| --- | --- |
| 临时学生 | 插件生成设备身份，尚未登录 |
| 匿名学生 | 已领取授权码，拥有内部学习身份，没有正式登录方式 |
| Google 登录学生 | Google 外部身份绑定内部学习身份 |
| 系统账号学生 | 后续可增加用户名、邮箱或手机号 |

### 9.2 Learning Identity

- 学习记录归属于稳定的内部 Learning Identity。
- 授权码不是学生身份。
- Gmail 地址不是数据库主键。
- 插件设备 ID 不是长期学习身份。
- 外部账号只是登录入口。

### 9.3 匿名领取

普通授权码默认允许匿名领取。

匿名学生领取后：

- 创建或关联 Learning Identity；
- 获得学生序号；
- 自动进入教师学生列表；
- 可以下载课程配置；
- 可以上传学习数据。

### 9.4 Google 登录和合并

匿名学生后续绑定 Google 账号时：

- 不重复创建学生；
- 保留原学生序号；
- 保留授权码领取记录；
- 保留课程版本；
- 保留进度和作答；
- 更新身份状态；
- 教师学生总数不能重复增加。

### 9.5 指定 Google 账号授权

教师可以创建指定 Google 账号的定向授权码。

规则：

- 教师预先填写目标学生 Google 账号；
- 学生必须主动完成 Google 登录；
- 系统验证登录账号后才允许领取；
- 其他账号不能领取；
- 匿名身份不能领取该定向授权码；
- 领取后绑定内部 Learning Identity。

该方式是可选能力，不作为测试期普通授权码的默认限制。

## 10. 授权码系统

### 10.1 授权范围

当前支持：

- 指定课节；
- 整门课程。

后续预留：

- 课程合集；
- 教师当前全部课程；
- 教师当前和未来全部课程。

### 10.2 测试期默认值

普通授权码默认：

- 长期有效；
- 领取人数不限；
- 允许匿名领取；
- 允许有效领取者获取后续版本；
- 不要求教师提前知道学生身份。

教师仍可以按需要配置生效时间、到期时间、人数或指定 Google 账号。

### 10.3 创建字段

教师创建授权码时可以设置：

- 名称或备注；
- 授权课节或课程；
- 普通授权或指定账号授权；
- 是否允许匿名领取；
- 可领取人数；
- 生效时间；
- 到期时间；
- 是否允许获取更新；
- 教师备注。

### 10.4 授权码状态

建议状态：

- Draft；
- Active；
- Exhausted；
- Expired；
- Revoked。

不提供可恢复的 Paused 状态。

### 10.5 领取流程

```text
学生输入授权码
→ 标准化字符和大小写
→ 检查授权码状态和时间
→ 检查领取条件
→ 检查指定账号
→ 创建或返回幂等领取记录
→ 合并全部有效授权范围
→ 下载允许的最新课程配置
```

### 10.6 重复领取

- 同一学生重复输入同一授权码时返回原有领取结果。
- 不重复创建学生。
- 不重复创建领取记录。
- 同一学生可以领取不同授权码。
- 一个授权码可以被一个或多个学生领取。
- 普通测试授权码默认不限制领取人数。

### 10.7 多授权码权限合并

有效资格按并集计算：

```text
授权码 A：课节 1
授权码 B：课节 2
→ 最终拥有课节 1 + 课节 2
```

```text
授权码 A：单个课节
授权码 B：整门课程
→ 最终拥有整门课程
```

规则：

- 权限不能被最后领取的授权码覆盖；
- 多个课节范围可以相加；
- 任一有效来源允许更新时，对应内容可以更新；
- 永久来源存在时，不因另一个限时来源到期而失效；
- 停用一个授权码只移除该授权码贡献的资格；
- 其他有效来源仍然保留；
- 所有来源失效后，停止重新下载和更新。

### 10.8 教师停用授权码

教师主动停用或作废授权码后：

- 操作不可恢复；
- 新学生不能领取；
- 该授权来源不能用于重新下载；
- 该授权来源不能用于获取更新；
- 学生本地已有版本继续保留；
- 学生删除本地版本后，不能再用该授权码重新下载；
- 需要重新开放时必须创建新授权码；
- 旧领取和操作记录永久保留。

如果学生对同一内容仍有其他有效授权来源，则仍按权限并集获得下载或更新资格。

### 10.9 授权码管理页面

教师可以查看：

- 授权码；
- 对应课节或课程；
- 授权方式；
- 创建时间；
- 当前状态；
- 已领取人数；
- 最近领取时间；
- 领取学生；
- 每名学生领取的课程版本；
- 该授权码贡献的授权范围；
- 操作记录。

教师可以：

- 创建；
- 复制；
- 查看；
- 永久停用或作废。

不提供恢复操作。

## 11. 课程下载和更新

### 11.1 下载内容

KnownMap 下载的是课程配置和互动内容，不下载 B 站视频。

下载包至少包含：

- 课程和课节标识；
- 视频定位信息；
- 已发布脚本版本；
- 互动节点；
- 运行所需反馈和行为；
- 必要的版本信息。

### 11.2 本地保留

- 下载后的课程配置可以保存在插件本地。
- 网络不可用时，不依赖服务器的内容仍可运行。
- 授权码失效不会远程删除本地已有版本。
- 产品不承诺对学生本地内容进行强制 DRM。

### 11.3 更新

学生获取更新时：

- 检查当前全部有效授权来源；
- 检查工作空间和课程运行状态；
- 返回允许范围内的最新已发布版本；
- 不自动覆盖尚未确认的本地状态；
- 记录学生实际使用的课程和脚本版本。

### 11.4 视频源停止

教师不再提供课程时，可以将 B 站视频下架、删除或设为不可访问。

KnownMap 不控制 B 站视频的可访问性，也不承诺在视频已下架后继续提供完整课程体验。

## 12. 学习记录

### 12.1 本地优先和上传

插件记录：

- 视频打开；
- 播放、暂停和跳转；
- 节点触发；
- 答案提交；
- 正确或错误结果；
- 回看；
- 课节完成；
- 最后学习时间。

网络失败时可以先缓存在本地，恢复连接后再上传。

### 12.2 数据新鲜度

教师后台只能显示已经上传的数据。

后台必须显示：

- 学生最后上传时间；
- 记录更新时间；
- 是否长期没有同步；
- 当前统计基于已上传数据。

“没有上传”不能直接解释为“没有学习”。

### 12.3 数据一致性

- 每条学习事件需要稳定唯一标识；
- 重复上传不能重复统计；
- 学习记录绑定学生、课程、课节、视频和脚本版本；
- 后端不能信任插件直接提交的 learner_id；
- 身份合并不能丢失授权、进度或作答。

```text

→ Courses

Course

→ Bilibili Video Binding
```

关键约束：

- 多个授权来源必须保留；
- 最终资格由有效来源并集计算；
- 本地已有课程配置与在线下载资格是两个不同概念。

## 18. 安全和一致性要求

- 授权码不得以可直接泄露的明文形式长期保存。
- 授权码比较前需要标准化字符和大小写。
- 领取接口必须幂等。
- 学习事件上传必须防止重复写入。
- 后端从会话推导学生身份，不信任客户端 learner_id。
- 教师只能访问当前工作空间的数据。
- 指定 Google 账号授权必须验证真实登录身份。
- 匿名身份合并必须防止重复学生和重复领取。
- 所有关键操作进入操作日志。
- 授权码永久停用必须有明确确认提示。
- 课程归档、教师账号停用和授权码永久停用必须是三个独立状态。
- 任何状态变化都不能远程删除学生本地已有课程配置。

## 19. 验收方向

### 19.1 教师账号和工作空间

1. 管理员可以创建带序号、类别和批次的教师账号。
2. 测试教师登录后进入唯一工作空间。
3. 教师无法访问其他工作空间。
4. 管理员可以记录教师测试反馈。

### 19.2 课程

1. 教师可以创建多个课程。
2. 一个课程可以有多个课节。
3. 课节可以绑定具体 B 站视频或分 P。
4. 教师可以保存、发布和预览结构化互动脚本。
5. 教师可以导入和导出 JSON 配置。

### 19.3 授权

1. 教师可以创建课节码和整课码。
2. 普通授权码默认长期有效、人数不限并允许匿名领取。
3. 学生可以领取多个授权码。
4. 多个授权码的有效范围按并集合并。
5. 授权码永久停用后不能恢复。
6. 停用后不允许新领取、重新下载或更新。
7. 学生本地已有版本继续保留。
8. 其他有效授权来源存在时，学生仍保留对应资格。

### 19.4 学习数据

1. 学生领取后自动进入教师学生列表。
2. 匿名身份绑定 Google 后不重复创建学生。
3. 插件可以上传进度和作答。
4. 教师可以查看已上传数据及最后同步时间。
5. 重复上传不会重复统计。
6. 教师可以导出基础 CSV。

### 19.5 视频和本地内容

1. KnownMap 下载课程配置和互动内容，不下载 B 站视频。
2. B 站视频不可访问时，课程不能正常完成。
3. 授权或账号状态变化不会远程删除学生本地内容。

## 20. 后续开发要求

后续 Agent 开始实现前必须：

1. 审计当前插件、教师网页和共享课程契约。
2. 列出已实现、部分实现和未实现功能。
3. 识别本文件与现有第一阶段单课程、本地存储设计之间的差距。

6. 按多个授权码权限并集设计，不使用最后写入覆盖。
7. 将授权码永久停用设计为不可恢复操作。
8. 区分教师账号停用、课程归档和授权码永久停用。
9. 不把授权码直接当成学生身份。
10. 不把 Gmail 地址直接当成内部主键。
11. 为迁移、测试、回滚和数据保留编写计划。
12. 任何偏离本文件已确认规则的方案，先记录原因、影响和重新确认结果。
