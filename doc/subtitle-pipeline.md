# 字幕生成与课程时间线方案

更新时间：2026-08-11
状态：方案确认，等待实现字幕导入与本地生成

## 1. 产品判断

KnownMap 不需要先分析视频画面。老师只需要提供视频和带时间戳的字幕，系统就可以把字幕段落转成课程时间线，再在关键段落上编排课堂事件。

```text
视频 / 音频
  -> 本地语音识别（可选）
  -> SRT / VTT / JSON 字幕
  -> 字幕校对与分段
  -> 课程时间线
  -> AI 建议与课堂设计（重点提醒、老师补充、学生练习、点评追问）
```

字幕是 AI 备课与课堂设计的输入，不是一个需要被 AI 自由解读的聊天上下文。画面分析不属于当前范围。

## 2. 开源方案调查

| 项目 | 适合角色 | 已确认能力 | 当前判断 |
|---|---|---|---|
| [OpenAI Whisper](https://github.com/openai/whisper) | 本地语音识别基线 | 从音频生成带时间信息的转写，支持多语言 | 适合第一版离线生成器；速度取决于模型和硬件 |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | 高效本地生成 | Whisper 的更高效实现，适合本地批量转写 | 优先评估为桌面/服务端生成后端 |
| [whisper.cpp](https://github.com/ggerganov/whisper.cpp) | 低依赖本地运行 | C/C++ 实现，适合将识别能力嵌入桌面工具 | 后续需要低安装成本时评估 |
| [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) | 人工校对与格式参考 | 离线字幕编辑器，支持字幕工作流与多种格式 | 不直接嵌入 KnownMap；参考其校对、导出和隐私边界 |

这些项目解决的是“音频 → 带时间戳文字”，不是视频画面理解。这个边界与 KnownMap 的教学产品定位一致。

## 3. 第一版输入与输出

### 输入

- 视频文件：只作为本地预览载体；
- `.srt` / `.vtt` 字幕；
- 后续可选：本地 Whisper 生成的识别结果；
- 不上传视频，不要求远程视频分析。

### 输出

```js
{
  id: 'caption-03',
  start: 35,
  end: 51,
  text: 'A strong answer needs a specific example.',
  language: 'en',
  confidence: null,
  events: []
}
```

导入后必须允许老师校对文字、合并/拆分字幕段落、调整时间点，再审核 AI 建议并形成课堂设计。

## 4. 时间线事件

字幕段落是统一锚点，课堂设计是挂在段落上的可配置教学意图；运行时再将其映射为具体动作：

- `attention`：短暂视觉强调，包含强度、关键词和冷却时间；
- `voice`：老师录音或音频文件，播放时降低视频原声；
- `activity`：选择题、填空题、自由回答；
- `ai`：受限教学模板，输入字段、评价维度和输出结构均由老师配置。

学生姓名只作为学生主动输入的昵称变量使用，不建立账号，也不默认收集个人资料。

## 5. 实施顺序

1. SRT/VTT 解析与时间线展示；
2. 字幕校对、合并、拆分和保存；
3. 注意力爆发事件；
4. 老师语音录制、上传和播放；
5. 把现有三个固定互动节点迁移为时间线事件；
6. 最后接入受控 AI 模板。

AI 不做通用聊天框。每个模板都必须明确输入、评价维度、输出结构、长度限制和失败状态。
