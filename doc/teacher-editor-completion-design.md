# 教师编辑器收尾体验设计

版本：0.1

更新时间：2026-08-20

状态：已实现并验证

关联需求：`doc/requirements/teacher-platform-local-stage.md`

## 1. 问题与目标

当前编辑器把固定课程的最低时长写成了 `222` 秒，导致没有导入字幕时显示 `03:42`，并让结束标记指向错误的课程终点。顶部操作在长页面滚动后不可见；授权码区域也只能展示本次刚创建的明文，刷新后无法说明课程已经创建过多少授权码。

本轮目标：

- 固定课程始终以规范中的 `513` 秒（`08:33`）作为时间轴下限；
- 时间轴开始、结束边界与节点百分比使用同一条有效轴线；
- 编辑器右下提供持续可见的打开、发布、完成快捷操作；
- 授权码成为可分类、可统计、可追溯但不泄露原文的课程记录。

## 2. 时间线

当前唯一支持的视频为 `BV1WW4y1e7GL`，课程包规范已定义 `video.durationSeconds = 513`。编辑器将这个值作为 `minimumDurationSeconds`。导入字幕后，如果字幕或节点时间超过该值，仍由内容最大时间扩展时间线；否则维持 `08:33`。

时间轴内容区域保留左右安全边距，轴线、起止文案和节点层共用相同的左右 `2%` 边界。最后一个刻度显示 `08:33`，结束文案定位在轴线右端。

## 3. 右下快捷操作

在课程设计视图底部右侧增加粘性操作条：

- `打开视频`：新窗口打开当前固定 B 站视频；
- `发布课程`：调用现有“保存草稿 → 发布”事务，和顶部发布按钮共享忙碌与禁用状态；
- `完成`：保存当前草稿，成功后返回“我的课程”；失败时停留在编辑器并保留内容。

桌面端固定在视口右下；窄屏退化为内容流中的全宽操作条，避免遮挡节点和授权码明细。

## 4. 授权码类型和数据

类型只开放两种：

| 类型 | API 值 | 有效期 |
|---|---|---|
| 短期 | `short_term` | 创建后 7 天 |
| 长期 | `long_term` | 不过期 |

`access_codes` 增加 `code_type` 和可空 `expires_at`。已有数据迁移为长期类型。公开下载在摘要匹配后检查到期时间；已过期与不存在统一返回 `INVALID_ACCESS_CODE`，不向匿名调用者泄露状态差异。

## 5. 授权码 API

创建端点接受可选请求体：

```json
{ "code_type": "short_term" }
```

未传请求体时默认 `long_term`，保持现有调用兼容。响应除一次性原文外返回类型、创建和到期时间。

新增 `GET /api/v1/teacher/courses/{course_id}/access-codes`。它只允许课程所属教师读取，返回总数、分类计数和记录。每条记录只含 ID、类型、末五位提示、创建时间、到期时间和计算出的状态，不返回摘要或原文。

## 6. 编辑器授权区

发布过的课程加载编辑器时即查询授权码列表，不依赖本次会话是否刚创建。授权区包括：

- 总数摘要；
- `全部 / 短期 / 长期` 三个可点击分类及数量；
- 当前分类的记录列表，显示尾号、创建时间、有效期和状态；
- 类型选择和“创建授权码”按钮；
- 本次新建原文与复制按钮。刷新后原文消失是安全约束，不是数据丢失。

创建成功后重新加载统计和明细，并将新记录插入正确分类。

## 7. 验收

1. 无字幕编辑器显示 `08:33`，最后刻度和结束边界一致。
2. 513 秒节点显示在时间轴最右端且仍可选择。
3. 页面滚动后右下仍能打开视频、发布和完成。
4. 完成保存失败不离开；成功返回课程页。
5. 新旧授权码刷新后均计入总数和类型数。
6. 点击类型只显示对应记录及正确创建时间。
7. 短期码 7 天后无法下载；长期码保持可用。
8. 列表、日志和数据库都不保存或暴露授权码原文。
