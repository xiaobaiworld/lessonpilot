## 1. 要解决的问题

教师端已经具备真实数据闭环，但用户可见界面仍沿用原型阶段的语言和结构：

- 标题和品牌副标题直接写“原型”；
- 登录页暴露开发账号、本地 API 和测试环境说明；
- 密码明文预填在页面源码中，且无法显示或隐藏；
- 课程首页以价值解释和未来能力说明为主，不像日常工作平台；
- 编辑页使用营销式大标题、假播放器和操作说明占据主要空间；
- 保存、发布、登录等异步操作缺少稳定的进行中状态，容易重复提交。

本轮不增加新的业务能力，而是让已经存在的能力以真实、安静、可重复使用的教师工具形态出现。

## 2. 产品命名

统一使用：

```text
品牌：KnownMap
产品类别：互动课程工具
完整名称：KnownMap 互动课程工具
```

页面标题、顶栏、登录入口和课程页使用这一名称。`Studio` 不再作为教师应用的主名称，但历史文档和内部兼容标识不做机械替换。

## 3. 页面结构

### 3.1 登录页

目标是只回答三个问题：正在登录什么、输入什么、如何继续。

- 顶栏只显示 KnownMap Logo 和“互动课程工具”；
- 登录面板标题为“登录互动课程工具”；
- 字段为“用户名”和“密码”；
- 账号保留 `teacher-test-01` 预填，密码为空；
- 本地预建测试账号的 seed 密码固定为 `password`，页面不预填密码；
- 密码字段右侧提供“显示/隐藏”控制，并同步 `aria-label` 和 `aria-pressed`；
- 登录按钮提交期间显示“正在登录…”并禁止重复提交；
- 用户名或密码错误时统一显示“用户名或密码错误”；
- 其它登录失败只显示通用重试提示，不暴露后端实现细节。

### 3.2 我的课程

首页从解释产品改为处理当前课程：

```text
我的课程
  -> 课程信息：课程名称、课节名称、B 站视频链接
  -> 课程素材：导入字幕、显示已选文件和解析状态
  -> 主操作：创建或继续课程设计
```

已有课程时，按钮显示“继续设计课程”；没有课程时显示“创建课程并开始设计”。页面不展示 W0 范围、未来学习证据或实现说明。

### 3.3 课程设计

- 页面主标题使用真实课程名称；
- 课节名称和 BVID 作为紧凑上下文；
- 顶部操作固定为打开视频、发布课程、保存草稿；
- 课程概览不再绘制不可操作的假播放器；
- 节点组件区标题为“添加节点”，状态文字只表达当前放置状态；
- 时间线保留必要的空状态和操作反馈，删除长期占位的教程式说明；
- 发布后授权区继续提供创建和复制授权码，文案只描述当前操作。

## 4. 应用状态

前端继续使用现有 API 和页面状态，不新增第二套业务模型。

新增或校正的 UI 状态：

- `auth`: 未登录、登录中、登录失败；
- `service`: 连接中、服务正常、连接异常；
- `course`: 未创建、已创建；
- `subtitle`: 未导入、解析中、已导入、解析失败；
- `draft`: 未保存、保存中、已保存、保存失败；
- `publish`: 发布中、已发布；
- `access code`: 未创建、创建中、已创建、已复制。

异步按钮结束后必须恢复可操作状态；失败不能清空老师当前输入或节点草稿。

## 5. 安全与隐私

- 删除 HTML 中的测试密码默认值；
- 不把密码写入 `localStorage`、`sessionStorage`、日志、错误或 DOM 属性；
- 显示密码只切换当前输入框的 `type`；
- 退出后清空密码输入框并恢复隐藏状态；
- 不修改后端 Argon2、HttpOnly cookie、会话摘要和资源归属检查。

## 6. 响应式与可访问性

- 1440px、900px 和 375px 均不得产生页面级横向溢出；
- 密码切换控制必须可键盘聚焦；
- 小屏登录页不隐藏主要字段或提交按钮；
- 顶栏在未登录时不显示课程导航和退出按钮；
- 按钮禁用状态要有可见反馈；
- 状态更新继续通过现有 `aria-live` 错误区和 toast 呈现。

## 7. 非目标

- 多课程列表；
- 多课节切换；
- 教师注册和找回密码；
- 修改后端认证、数据库或 API；
- 修改插件授权码下载流程；
- 自动保存、撤销/重做或 AI 生成节点；
- 重做销售页和历史示例页。

## 8. 完成定义

1. 页面不再把教师应用称为原型、Studio、W0 或本地 API 工具。
2. 密码源码中无默认值，并可显示和隐藏。
3. 未登录顶栏不出现课程导航和退出操作。
4. 首页呈现真实课程准备和继续设计任务，不出现未来功能解释。
5. 编辑页以真实课程标题和操作状态为主，不显示假播放器。
6. 登录、保存、发布和创建授权码都有防重复提交状态。
7. 现有登录、课程、字幕、节点、草稿、发布和授权码流程保持可用。
8. 自动化测试、桌面与移动浏览器验收通过。

## 9. 实施结果

- 教师应用统一命名为“KnownMap 互动课程工具”。
- 登录页不再预填密码，支持显示或隐藏，并在登录成功和退出时清空凭据。
- “我的课程”只呈现课程、课节、视频和字幕任务；新课程为空表单，已有课程读取真实数据。
- 课程设计页删除假播放器和原型说明，保留真实节点、草稿、发布和授权流程。
- 无字幕时不显示示例字幕。这里曾把固定视频时长误写成 `3:42`；2026-08-20 已由 `doc/teacher-editor-completion-design.md` 更正为课程规范定义的完整 `08:33`。
- 节点支持键盘选择、时间位置调整和放置；字幕选择按钮可键盘聚焦。
- 发布期间锁定保存、节点组件和时间轴，避免发布版本与界面内容竞态。
- 退出时清空课程、字幕、发布版本、授权码和路由状态，避免跨账号残留。
