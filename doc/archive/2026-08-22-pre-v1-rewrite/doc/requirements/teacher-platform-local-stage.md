## 1. 阶段目标

本阶段完成教师生产发布和学生插件领取闭环：

```text
预建教师测试账号
→ 教师登录
→ 创建一门课程和一个课节
→ 编辑四种初始互动节点
→ 发布课程
→ 创建课程授权码
→ 学生在 B 站页面通过我们提供的解压版 Chrome 插件输入授权码
→ 插件从 FastAPI 服务下载已发布课程配置
→ 插件在对应 B 站视频页面运行课程
```

本阶段的成功标准是：教师能够在生产工作台发布一门真实可运行的测试课程，学生能够使用
正式分发的插件从正确环境取得对应课程配置，并在匹配的 B 站页面完成一次互动。

- 已完成：生产教师登录、课程与多个有序课节、四种节点编辑、草稿、v2 课程包发布、

- 未完成：节点 8 的完整真实 Chrome 边界验收；插件课程 API 的生产/本地环境切换；学生插件 ZIP 的生产发布验证；节点 9 从生产教师端到学生插件的完整闭环；

## 2. 当前产品形态

### 2.1 教师端

- 教师应用统一命名为“KnownMap 互动课程工具”；KnownMap 是品牌，“互动课程工具”是产品类别。
- 沿用现有课程、时间轴和节点编辑能力，当前重点是让真实后端能力以正式工作平台形态出现，不重新设计销售页。
- 教师使用手工预建的测试账号登录。
- 不开放教师注册。
- 站点索引和管理员持久化底座已经存在；教师账号管理 API、管理员登录闭环和完整管理页面
  仍按独立设计验收，不混入本阶段教师编辑闭环。
- 当前教师编辑界面仍以一个活动课节为主要操作对象。
- 一个课节必须归属于一门课程。
- 后端数据模型、教师课程 API 和发布服务支持一门课程包含多个有序课节。
- 正常教师界面不得显示“原型”“W0”“开发测试账号”“本地 API”等内部实施说明。
- 登录密码不得在页面源码中预填；密码输入必须支持显示和隐藏。
- 登录、保存、发布和创建授权码等异步操作必须避免重复提交，并保留失败前的教师输入。

### 2.2 学生端

- 学生不使用独立公网网页。
- 学生使用 KnownMap 直接提供的解压版 Chrome 插件。
- 插件运行在 B 站原页面。
- 点击 Chrome 工具栏中的 KnownMap 图标必须打开插件自己的业务面板，而不是只能依赖 B 站页面里的悬浮书包。面板默认显示学生授权码入口、当前已安装课程，以及进入既有教师登录页的教师入口。
- 当前阶段不实现学生账号。学生面板必须明确说明“使用授权码，无需注册”，不能展示无法完成的假登录表单；教师入口打开现有教师登录页，为后续角色扩展保留清晰边界。
- 插件向后端提交授权码，取得授权范围内的一门或多门已发布课程配置。
- 插件只使用 `studentCourseStore` 保存多门课程；以 `courseId` 为课程索引，并以
  `courseId + lessonId` 隔离学习状态。
- 插件首次读取课程库时自动加入一门只读示例课程。示例课程使用独立固定 UUID，不覆盖
  教师授权课程；若两者匹配同一 BVID，运行时优先使用授权课程。
- 授权码可以重复提交，并取得课程最新已发布版本。
- 领取成功后，“课程”区域按课程和课节新增或更新记录；必须显示课程名称和课节名称，
  同时提供经过校验的标准 B 站课程链接和“打开课程视频”操作，不能把内部 ID 当作主显示名称。
- 工具栏面板与 B 站页面书包读取同一份 `studentCourseStore`，并显示其中全部课程。
- 插件后台未响应、扩展刚更新但尚未重新加载或消息返回空值时，授权码表单必须在有限时间内恢复可操作状态并显示“重新加载插件和页面”的提示，不能永久停在“正在下载并校验课程”。
- 每个课节包含自己的 `videoRef` 和互动节点，不包含结构化字幕句；上一句、下一句、
  一次复听、三次复听和持续循环仍是已接受设计，尚未进入当前 `CoursePackage` v2。
- 每个课节的学习状态只保存节点完成/重试状态、尝试次数和最后回答；有效学习次数、复听
  次数和待复习清单尚未实现。已有学习状态只保存在本机，不上传后端。
- 插件不通过 Chrome Web Store 分发。

### 2.3 课程和节点

- 当前课程层级为 `Course -> Lesson -> Published Script -> Nodes`。
- 一门课程可以包含多个有序课节，每个课节使用独立 UUID，并绑定一个 B 站视频。
- 学生课程库可以同时保存多门课程，每门课程和每个课节都拥有独立 UUID。
- 当前初始节点类型为：
  - 重点内容；
  - 选择题；
  - 填空题；
  - 问答题。
- 节点类型必须按可扩展的类型注册方式组织，但本阶段不实现更多类型。
- 问答题只保存学生原始回答和教师预设反馈；学生学习数据本阶段不上传。

### 2.4 教师可视化节点编辑器

- `teacher-web/forsales.html` 中的“节点组件栏 + 横向时间轴 + 节点摘要 + 字幕上下文”是当前教师编辑器的视觉和交互参照。
- 正式教师编辑器不能继续以“字幕列表 + 右侧普通表单”作为主要编辑模型。
- 四种节点必须作为可注册的编辑器组件存在。组件注册项至少包含类型标识、显示名称、图标、默认值、字段定义、节点创建规则、摘要规则和校验入口。
- 老师添加节点时同时支持两种入口：
  - 点击组件，再点击时间轴位置；
  - 将组件拖放到时间轴位置。
- 两种入口必须调用同一个节点创建动作，产生一致的默认值、时间、字幕关联、编辑弹窗和校验结果。
- 时间轴位置根据当前课节时长和节点 `trigger.timeSeconds` 计算，不允许使用销售页中的固定百分比或固定节点数据。
- 当前固定视频 `BV1WW4y1e7GL` 的时长真源为课程包规范中的 `513` 秒；即使本次浏览器没有导入字幕，编辑器也必须显示完整 `08:33`，时间线结束点必须对应视频结束位置。
- 当前固定测试视频已有一份经完整 SRT 验证的 177 条匹配字幕；打开该测试课程时编辑器默认加载这份字幕并在右栏展示节点上下文，老师手工导入合法 SRT/VTT 后可以覆盖默认字幕。默认字幕不得应用到其它视频。
- 正式时间线的开始/结束边界、节点摘要连线、节点 marker 和四种 SVG 小图标必须与 `teacher-web/forsales.html` 及官网“完整课程示例”保持同一种视觉语言；结束边界显示“结束”，`08:33` 作为独立时长/刻度文本显示。
- 有字幕时，新建或移动节点关联距离目标时间最近的字幕，并保存合法 `captionId`；字幕只在浏览器中解析，不上传后端。
- 老师可以单击选中节点、双击或按 Enter 打开编辑、拖动节点调整触发时间、删除节点。
- 同一字幕或同一时间附近允许存在多个节点；界面需要通过轨道或摘要布局避免节点互相遮挡。
- 节点编辑弹窗按节点类型显示不同字段；取消存在未保存修改时必须明确确认。
- 保存草稿后，页面必须使用后端返回的标准节点重新渲染；保存失败时保留当前未保存状态。
- 发布、授权码和现有 FastAPI 接口保持在同一教师闭环中，不为可视化编辑器另建第二套草稿格式。
- 开发/测试环境记录组件选择、放置、拖动、弹窗打开和校验失败等 `debug` 诊断日志；正常运行默认只记录保存、发布、失败等 `info` 及以上事件。日志不得记录节点正文、字幕正文、密码、cookie 或授权码原文。

## 3. 当前授权码语义

授权码是一个课程范围下载凭证：

```text
授权码 → AccessGrant[] → 已发布课程/课节/节点范围 → CoursePackage v2[]
```

本阶段要求：

- 教师可以创建短期或长期授权码；短期授权码创建后 7 天失效，长期授权码不过期；
- 每个授权码可以通过多条 `AccessGrant` 覆盖一门或多门课程，并可继续收窄到课节、节点
  和现实有效时间；
- `AccessCode.course_id` 只作为教师端管理锚点，实际下载范围以 `AccessGrant[]` 为准；
- 只有已发布课程可以被授权码下载；
- 插件提交授权码后，后端返回当前有效授权范围内各课程的最新已发布配置；
- 同一授权码可以重复下载，不记录一次性消费状态；
- 教师编辑器必须显示当前课程已创建的授权码总数，并按短期、长期分类统计；点击分类可查看尾号提示、创建时间、到期时间和当前状态；
- 授权码原文仍只在创建响应中出现一次，历史记录不得恢复或显示完整原文；
- 当前不提供停用、人数限制或领取记录页面；
- 授权码不创建学生账号；
- 授权码不产生 Learning Identity；
- 授权码不记录学生身份、领取记录或学习数据；
- 授权码不负责远程删除插件本地已有配置。

插件本地可以同时保存多门课程。领取新授权码时按 `courseId` 合并，不覆盖其他课程；
同一课程取得新版本时，保留仍由稳定 `lessonId` 和节点 ID 引用的本地状态。

授权码原文不得长期明文落库。服务端只保存可检索的安全摘要，创建成功时将原文返回给教师端用于复制给学生。

## 5. 与 v0.2 的关系

`doc/AI_Learning_Companion_Product_Function_Spec_v0.2.md` 仍然是产品方向和长期边界的主要依据。本文件是当前本地开发阶段的范围裁剪：

## 6. 阶段验收

### 6.1 教师端

1. 使用预建测试账号可以登录和退出。
2. 登录页可以显示和隐藏密码，页面源码不包含测试密码默认值。
3. 未登录状态不显示课程导航和退出操作。
4. 未登录请求不能访问教师课程 API。
5. 教师可以创建课程和一个课节。
6. 教师可以通过点击组件后点击时间轴创建四种节点。
7. 教师可以通过拖放组件到时间轴创建四种节点。
8. 教师可以在时间轴上选择、编辑、移动和删除节点。
9. 点击添加和拖放添加产生相同的后端节点结构。
10. 教师可以保存包含四种节点的结构化脚本。
11. 刷新后从后端草稿恢复的节点位置、类型和内容一致。
12. 草稿不会被学生下载。
13. 发布后可以读取已发布课程配置。
14. 当前教师只能访问自己的课程。
15. 编辑器时间线在无字幕时仍显示固定视频真实时长 `08:33`，且结束标记与时间轴终点一致。
16. 编辑器右下方持续提供“打开视频”“发布课程”“完成”快捷操作；“完成”成功保存草稿后返回“我的课程”。
17. 固定测试课程进入编辑器后自动加载匹配字幕，选择节点时右栏显示并高亮对应字幕上下文。
18. 时间线开始/结束边界位于轴线两端，节点摘要线连续连接对应节点，组件栏与 marker 使用官网同款四种 SVG 小图标。

### 6.2 授权码和插件

1. 教师可以创建绑定课程的授权码。
2. 教师可以选择短期（7 天）或长期（不过期）授权码，并查看当前课程按类型统计的历史记录。
3. 未发布课程不能创建可下载授权结果。
4. 插件提交有效且未过期的授权码后得到对应已发布课程配置。
5. 无效、已过期授权码、未发布课程和课程不存在时默认拒绝。
6. 后端响应不包含教师密码、授权码摘要或内部数据库字段。
7. 插件将课程保存到本地后，可以在匹配的 B 站视频页面运行。
8. 插件不通过独立学生网页获取课程。

### 6.3 工程验收

1. FastAPI OpenAPI 文档可以单独调试当前端点。
2. SQLite 数据库可以通过初始化和迁移命令重建。
3. 核心业务逻辑有单元测试和数据库集成测试。
4. 登录、课程发布、授权码下载有端到端 API 流程测试。
5. 后端日志包含 request ID、模块、动作、成功或失败和耗时。
6. 测试密钥、密码和授权码原文不进入源码、数据库或日志。

### 6.4 多课程数据底座增量门禁

1. 一门课程可以保存多个有序课节，每个课程和课节使用后台生成的独立 UUID。
2. `CourseDetail` 返回 `lessons[]`，不再返回单数 `lesson`。
3. v2 课程包使用后台 UUID `courseId`、UUID `lessonId` 和非空 `lessons[]`。
4. 插件只接受 v2 `{ "courses": [...] }` 响应并只读写 `studentCourseStore`；旧单课程响应、
   `installedCourse` 和 `learningState` 必须拒绝，不提供迁移路径。
5. 授权码通过 `AccessGrant[]` 表达多课程、多课节、多节点和现实时间范围，公开下载只返回
   当前有效范围。
6. 插件首次读取时加入独立 UUID 的只读示例课程；授权课程不得被示例课程覆盖。
7. 工具栏和 B 站书包显示课程名称与课节名称，不能用课程编号代替主显示名称。
8. 学习状态按 `courseId + lessonId` 隔离；同一课程更新时只迁移仍然有效的节点状态。
