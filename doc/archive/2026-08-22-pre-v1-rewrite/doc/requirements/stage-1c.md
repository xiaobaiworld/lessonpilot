# Stage 1C B 站学习运行时与端到端需求

版本：1.0

更新时间：2026-08-15

状态：已确认，等待 1A、1B 完成后实施。

## 1. 本阶段目标

插件读取 1B 保存的一门课程，只在匹配 BVID 的 B 站原页面启动，并让四种节点完成到点暂停、互动、反馈、跳过和继续播放。

本阶段完成的是老师亲手制作课程后的真实预览，不是固定视频、固定 35 秒弹窗或静态效果演示。

## 2. 课程识别与生命周期

### RUNTIME-01 课程匹配

- 插件读取唯一 `currentCourse`；
- 只有当前页面 BVID 与 `videoRef.videoId` 精确一致时启动课程；
- 其它 B 站视频不得显示课程窗口、记录节点状态或报告不匹配错误；
- 配置 schema 损坏或版本不支持时失败关闭，并提供可诊断错误。

### RUNTIME-02 B 站 SPA 生命周期

- 进入匹配课程时只挂载一个运行时；
- 离开或切换到不匹配视频时卸载学习窗口、播放器监听、计时器、观察器、字幕遮挡和其它注入 UI；
- 返回匹配视频时可以重新挂载，但不得重复绑定；
- content script 或运行时重复初始化不得造成重复节点触发。

### RUNTIME-03 播放器可用性

- 播放器选择器集中在播放器适配模块，不进入节点逻辑；
- 找不到播放器时显示可恢复的“课程暂时无法启动”；
- 允许有限次数、有限时间的重试；
- 不得无限创建观察器、持续高频查询 DOM 或伪造启动成功。

## 3. 节点调度

### RUNTIME-04 状态机

```text
pending -> active -> completed | skipped
```

- 到达触发时间时暂停视频并打开唯一学习窗口；
- 一个节点只能从 pending 进入 active；
- active 节点只能以 completed 或 skipped 结束；
- 同一预览会话中 completed/skipped 节点不重复触发；
- 刷新页面创建新预览会话后允许重新触发。

### RUNTIME-05 队列与 seek

- 同时最多一个 active 节点；
- seek 跨过多个 pending 节点时先触发时间最早的一个；
- 同一时间的多个节点按稳定节点 ID 依次处理；
- 完成或跳过当前节点后继续处理已跨过的 pending 队列；
- 队列清空后恢复播放；
- 暂停或继续失败时显示错误，不伪造节点完成状态。

## 4. 唯一学习窗口

### WINDOW-01 通用行为

- 四种节点使用同一个一级学习窗口；
- 窗口内完整呈现节点内容，不依赖画面高亮才能理解；
- 提供明确完成/提交和跳过操作；
- 完成或跳过后关闭当前窗口并按调度规则继续；
- 动态内容使用安全 DOM API，不执行课程提供的 HTML、CSS 或 JavaScript；
- 卸载运行时时移除窗口、焦点处理和全部事件监听。

### WINDOW-02 重点标注

- 完整显示标题、正文和可选重点内容；
- 打开时视频已经暂停；
- 学生确认时记录 completed，跳过时记录 skipped；
- B 站画面高亮属于可选增强，失败不影响完成。

### WINDOW-03 选择题

- 学生一次选择一个选项；
- 提交后按老师配置显示确定性的正确/错误状态和解释；
- 允许重试、跳过和继续；
- 只有学生结束该节点后才恢复调度。

### WINDOW-04 填空题

- 学生输入非空文本；
- 判断时执行 `trim` 和英文 `casefold`；
- 提交后显示确定性的正确/错误状态和老师解释；
- 允许重试、跳过和继续。

### WINDOW-05 问答题

- 学生输入非空自由回答；
- 插件保存原始回答；
- 提交后显示老师预设参考反馈；
- 不显示正确/错误，不调用 AI，不生成个性化评价或追问；
- 允许修改、跳过和继续。

## 5. 本地预览会话

### SESSION-01 会话边界

- 会话绑定 `courseId` 和课程 `updatedAt`；
- 每个节点记录 pending/active/completed/skipped、尝试次数和必要答案；
- 重点标注答案保持 null；选择题和填空题保存字符串；问答题保存原始文本；
- 刷新 B 站页面创建新会话；
- 换课清除旧 active session；
- 第一阶段不上传会话、不生成老师报告、不建立会话历史。

### SESSION-02 隐私与日志

- 原始问答答案只保存在本机插件存储；
- 通用日志不得包含字幕全文、题目正文或学生答案；
- 不记录与当前课程无关的 B 站访问历史；
- 日志可以记录 courseId、节点 ID、状态迁移、结果和错误码。

## 6. 插件交付

- 老师使用 PC Chrome 开发者模式加载仓库 `src/` 的已解压插件；
- 首次安装和更新允许人工协助；
- 工作台保存新课程后无需重新安装或重新加载插件；
- Chrome 应用商店发布不是本阶段门禁；
- 现有固定 BVID、固定节点、吉祥物按钮和 35 秒弹窗不能继续作为课程事实源。

## 7. 错误处理

运行时必须明确处理：

- 当前课程配置损坏或协议版本不支持；
- BVID 解析失败或当前视频不是课程视频；
- 播放器暂时不存在或 B 站 DOM 变化；
- 暂停、seek 或恢复播放失败；
- 预览会话不存在、课程不匹配或存储失败；
- SPA 切换导致的重复挂载风险；
- 动态内容过长或窗口无法完整显示主要操作。

非课程视频保持安静，不把“没有匹配课程”当作用户错误弹窗。

## 8. 本阶段非目标

- 正式学生分发、账号和 Chrome 商店安装；
- 老师报告、多学生汇总和远程遥测；
- AI 反馈、语音、发音评价和其它节点；
- 手机端或其它视频平台；
- 第一阶段总览中的全部共同非目标。

## 9. 1C 完成定义

1. 插件只在保存课程对应的 BVID 页面启动；
2. 四种节点均能到点暂停并在唯一学习窗口正确呈现；
3. 重点标注可确认，选择和填空可确定性判断，问答只显示老师反馈；
4. 四种节点都能完成或跳过并返回播放；
5. 同一会话不会重复触发已完成或跳过节点；
6. seek 跨节点和同时间节点按规定队列处理；
7. 刷新创建新会话，SPA 离开后没有残留 UI、监听器、计时器或观察器；
8. 非课程 B 站视频没有课程 UI 或无关行为记录；
9. 播放器缺失和控制失败不会伪造成功或无限重试；
10. 学生答案只保存在本机，通用日志不包含原始回答；
11. 自动化测试覆盖匹配、状态机、队列、四种窗口和会话行为；
12. 从公网工作台制作课程到真实 B 站页面完成四种节点的人工端到端验收；
13. 销售页展示能力与真实结果一致，相关文档和 changelog 已同步；
14. 下一步转为邀请第一位真实老师验证，而不是继续扩大产品范围。
