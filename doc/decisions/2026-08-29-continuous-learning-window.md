# D-V1-024：互动学习窗口采用连续尺寸与位置配置

日期：2026-08-29  
状态：已接受，已实现，待浏览器人工验收
关联设计：[`连续可调互动学习窗口设计`](../../docs/superpowers/specs/2026-08-29-continuous-learning-window-design.md)

## 要解决的问题

当前互动节点窗口使用小/中/大和左下/右下/居中等离散预设，教师无法细致调整窗口大小和位置；缺少配置的旧节点还会回退到右下角小卡片。

## 已确认事实与约束

- 展示形式是互动节点的一部分，与节点内容一起保存和发布；
- 教师端已有学生端实时预览；
- 学生插件通过已安装课程和发布版本读取节点，不支持窗口配置实时推送；
- 窗口必须继续支持离线运行和不可变课程发布快照；
- 配置不能携带任意 CSS 或脚本。

## 决策

采用“预览窗口拖动 + 宽高连续滑块”的节点级展示配置：

- 宽度、高度分别保存为 10%–66% 的数值；
- 位置保存为窗口中心点的 `xPercent`、`yPercent`；
- 内容可以在基础尺寸上增长，但不超过视口上限，超出后内部滚动；
- 默认宽度 40%、高度 30%、位置 50%/50%、文档样式；
- 教师编辑时预览立即更新，但不为每次拖动请求后端；
- 保存草稿、发布课程和插件升级是学生端生效链路；
- 后端提供节点展示配置局部更新接口，但不新增独立窗口配置表。

## 未采用方案

- 只改 CSS：不能按节点保存，也无法支持连续配置；
- 只使用 X/Y 滑块：可行但不如直接拖动预览直观；
- 保存像素值：不适应不同屏幕、全屏和窄屏；
- 独立配置表或实时推送：扩大离线和发布快照边界，当前没有必要。

## 影响与复查条件

- 课程包展示配置结构需要版本化并支持旧值兼容；
- 教师预览和插件运行时必须共享范围、默认值和兼容解析；
- 需要新增拖动边界、内容超限、全屏、窄屏和 revision 冲突测试；
- 如果未来要求教师修改后学生当前窗口立即变化，必须重新讨论实时通道和发布快照边界。
