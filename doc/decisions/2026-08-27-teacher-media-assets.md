# D-V1-016 教师端媒体资源输入与课程引用

状态：已接受

日期：2026-08-27

## 决策

教师编辑互动节点时，图片、音频和视频允许通过文件上传或 URL 导入。服务器负责校验类型、保存二进制并生成稳定的 `assetId`；草稿、发布快照和课程包只保存 `assetId` 及资源元数据，不保存外链作为运行时真源，也不把二进制写入 SQLite。

教师端编辑器可以用服务器资源地址预览；编辑器的临时 HTML 表示可以使用 `asset://<assetId>` 占位，转换保存后的 `RichPageDocument` 只保留结构化 `assetId`。URL 只作为一次导入来源，导入后的资源归属于当前教师，并通过同源资源接口提供给预览和后续学生交付流程。

教师节点预览同时消费节点级 `presentationHints`，由共享 `resolvePresentationHints` 解析大小、位置和样式；`assetUrlForId` 生成的地址只用于教师预览和编辑器回显，不写入课程包，也不替代 `assetId`。预览中的节点视频同样属于互动内容资源，不得与课节的 B 站播放引用混同。

## 边界

- v1 只接受图片、音频、视频；服务器拒绝未知 MIME 类型和超出大小限制的文件。
- URL 导入仅接受 HTTP(S)，服务器不接受本机、内网、回环或保留地址，避免把导入能力变成 SSRF 通道。
- `v1_script_drafts`、`v1_course_releases` 和 `v1_release_lesson_snapshots` 的 JSON 结构继续保存节点与资源清单；资源二进制在服务器文件存储，不新增资源业务表。
- 资源未被节点引用时不影响草稿正确性；后续可增加独立清理策略，本次不删除资源。

## 验收

1. 教师可上传图片、音频或视频，接口返回稳定 `assetId` 与元数据。
2. 教师可输入 URL，服务器导入后返回同样的资源记录；不能直接把任意外链写入节点内容。
3. 编辑器插入媒体后，草稿 JSON 的媒体块只出现 `assetId`，保存和发布快照结构不出现服务器文件路径或原始 URL。
4. 无效 MIME、超大文件、越权资源和内网 URL 均被明确拒绝，原草稿不被覆盖。
