# v1 插件分发与更新方式决策

- 日期：2026-08-21
- 状态：已接受
- 决策编号：D-V1-004

## 决定

v1 使用固定 ZIP 作为学生插件交付物。发布包来自已推送的精确提交，提供 SHA-256 校验；学生手动下载、替换解压目录，并在 Chrome 扩展管理页手动刷新。

v1 不提供 Chrome Web Store、企业策略分发、`.crx` 签名安装、后台自动升级、自动下架或远程强制卸载。

## 责任与边界

- 发布方负责包内容、版本标识、哈希、下载入口和回滚记录；
- 学生负责本机安装、替换和刷新；
- 授权终止只停止后续领取、重新下载和更新，不远程删除已安装内容；
- 未来需要自动升级、商店分发或企业部署时，另行重开分发方案和安全验收。
