# v1 产品成功门槛决策

- 日期：2026-08-22
- 状态：已接受
- 决策编号：D-V1-005

## 决定

v1 采用两层成功判断：

### 产品闭环门槛

发布 v1 前必须证明：

- 至少一位真实老师使用真实课程完成建立、互动设计、保存和发布；
- 至少一位真实学生成功领取、运行并完成互动；
- 同一流程在另一门课程或另一位老师上重复成功；
- 本机重启恢复、授权更新、失败恢复和回滚通过；
- 全过程不需要开发者修改代码或直接改生产数据。

### 市场价值观察

暂不冻结样本量、观察周期、完成率、再次使用率或支持成本的固定数字。先记录真实老师交付意愿、学生实际互动、老师再次使用意愿和人工支持成本；取得真实数据后再决定是否需要数值门槛。
