# D-V1-027：试用申请改为 KnownMap 本地表单

日期：2026-09-01

状态：已接受

替代：[`D-V1-001`](2026-08-21-v1-public-trial-intake.md) 中“继续使用飞书公开表单并由飞书保存申请正文”的具体实现边界；D-V1-001 关于公开试用属于 v1 P0、人工跟进和受控创建教师账号的业务结果继续有效。

## 决定

KnownMap v1 的公开试用申请改为销售页链接到的独立本地表单页面。申请正文由 KnownMap FastAPI 接收并保存到 SQLite，申请人无需登录；管理员仍必须通过管理员会话查看和跟进申请。

本阶段是开发期，没有需要迁移的飞书历史数据。飞书不再作为新申请的运行依赖，也不接入飞书 API、邮件或其它通知服务。

表单字段为：

- 必填：称呼、联系方式、课程类别、视频当前状态、最想解决的教学问题、字幕情况；
- 选填：B 站课程链接、产品验证问题。

B 站课程链接只做轻量格式校验：填写时接受 B 站网页域名或 `b23.tv` 短链接；不验证视频存在性，不抓取视频信息；未填写时允许提交。课程类别先使用必填文本，不在本阶段冻结分类枚举。

提交成功后只向申请人显示明确成功结果，不发送邮件或其它通知。跟进状态固定为“待联系”“已联系”“已关闭”。

公开提交接口采用限流和轻量防刷（例如隐藏字段），不引入验证码服务。提交申请不会创建教师账号、会话、工作空间、课程或授权；人工确认后仍由管理员单独创建教师账号。

## 理由

- 当前仍处于开发阶段，没有历史申请数据迁移成本；
- 本地表单可以让申请、跟进和管理员后台形成同一套可测试闭环；
- 不接入通知服务和验证码可以控制第一版复杂度，同时保留基本的公开接口保护；
- 申请与教师身份继续分离，避免把获客入口直接扩张为开放注册。

## 影响

- 新增 `TrialApplication` 申请正文对象；`TrialFollowup` 改为引用本地申请，而不是依赖 `feishu_record_ref`；
- 新增无需登录的公开提交 HTTP 接口和管理员受保护的申请查询/状态更新接口；
- 销售页由外链入口改为本地表单和成功状态；管理员 Web 增加申请列表/详情和三档跟进状态；
- 需求和设计中的新申请数据权威从飞书改为 FastAPI + SQLite；
- `D-V1-001` 保留为历史决策，原始飞书验收记录只作为历史证据，不再指导新实现；
- 申请数据仍按 `D-V1-006` 从最后一次跟进起保留 90 天，之后删除或匿名化。

## 待验证事实

- 公开接口的具体限流窗口和阈值在实现前按部署环境确定，不在本决策中虚构数值；
- 管理员申请详情页的具体布局由交互设计和实现验收确定；
- 本阶段不迁移飞书历史数据；若未来恢复历史导入，必须另立迁移决策。
