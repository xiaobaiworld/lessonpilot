# D-V1-014：课节字幕持久化到教师侧,不进入课程包与插件

- 日期：2026-08-26
- 状态：已接受
- 决策编号：D-V1-014

## 背景

`doc/design/v1/10-lesson-subtitle-persistence-design.md` 提出让教师主动导入的 SRT/VTT 字幕原文脱离
“只在教师浏览器临时处理”的旧约束,随课节草稿持久化。审查过程中确认该设计原稿的范围过大:它要求字幕
原文一路进入课程包（升级到 v4）和插件本机存储,但学生端运行互动课程实际只需要节点已经携带的
`anchor.timeSeconds`,不需要字幕原文本身。

## 决策

1. 字幕原文（文件名、格式、文本内容）随保存草稿动作进入服务端 `ScriptDraft`,并随发布动作原样复制进
   `ReleaseLessonSnapshot`。这是字幕原文在服务端持久化的终点。
2. 字幕原文不进入课程包（`CoursePackage`/`TERM-030`）、不进入插件本机存储
   （`InstalledLesson`）。课程包 JSON Schema 版本保持 `v3`,不需要升级到 v4。
3. 发布时不新增“课节必须有字幕才能发布”的校验。教师端创建互动节点的唯一入口已经要求先导入字幕
   （无字幕时时间轴不渲染,见 `doc/lessons.md` 对应记录）,所以草稿一旦存在节点,字幕字段必然已经存在；
   发布只需原样复制草稿里已有的字幕字段,不新增 `RELEASE_SUBTITLE_MISSING` 一类错误码。
4. 教师课程导入导出文件（`TeacherCourseFile`,`FR-PORT-*`/`DATA-PORT-*`）包含字幕原文,方便教师更换设备
   或备份工作区；这份文件仍只在教师之间流转,不发给学生插件。

## 依据

- 学生端运行互动课程的时间定位只依赖节点自身的 `anchor.timeSeconds`
  （已在 `v1/backend/app/modules/authoring_release/application_service.py` 发布时从草稿节点取值写入
  快照）,不需要字幕原文本身参与运行时逻辑。
- 课程包（`TERM-030`）的既有定义和边界（不含完整字幕）继续有效,不需要修改；只有教师侧的持久化边界
  发生变化。
- 教师端创建/编辑互动节点强制要求先导入字幕（`v1/web/teacher/src/pages/LessonPage.tsx`
  的 `Timeline` 组件在无字幕时不渲染,`SubtitlePicker` 是当前唯一的建节点入口）,因此发布前置校验没有
  必要单独实现。

## 影响

替代以下已接受条款的部分内容（保留原编号,标记“已替代”并说明替代方向,详见对应文件的修订）：

- `FR-AUTHOR-002`：字幕全文默认只在教师本机用于制作；
- `DATA-CONTENT-003`：字幕是教师本机临时制作数据；
- `INT-FILE-001`：字幕文件仅在教师浏览器内解析；
- `FR-PORT-002`：课程文件只包含可携带的课程配置（去掉字幕原文排除）；
- `DATA-PORT-001`：教师课程文件具有自描述边界（去掉字幕原文排除）。

不改变以下条款：

- `TERM-030`（课程包定义与边界不变）；
- 课程包禁止字段清单（`doc/design/v1/06-interface-contracts.md` 第 5.2 节,课程包仍不含完整字幕文件）。

同时确认一个与本决策相关但独立的既存偏差：`FR-AUTHOR-001` 描述的“无字幕时使用已确认的视频时间创建
节点”分支在代码中从未实现,一并在需求文本中修订为匹配当前实际行为，详见该条款修订说明。
