# D-V1-001：公开销售页与飞书试用申请属于 v1 P0

日期：2026-08-21

状态：已接受

## 决定

v1 P0 包含现有公开销售页和无需登录的飞书试用申请表。最小业务闭环为：

```text
目标老师查看真实产品承诺
  -> 打开公开飞书表单
  -> 提交最小必要试用信息
  -> 授权运营人员取得线索并人工跟进
  -> 平台管理员确认后创建教师账号
```

## 当前边界

- 销售页和表单是正式业务入口，必须进入 v1 发布验收；
- 当前继续使用飞书公开表单，但需求描述业务结果和安全边界，不把具体表单 ID 写成永久产品规则；
- 不建设 CRM、自动营销、自动创建教师账号、开放注册、批量线索导入或复杂线索评分；
- 表单只收集试用接入所需信息，并明确第三方表单处理、用途、必填项和可选项；
- 提交失败不能显示假成功；外部入口失效时提供明确的人工联系恢复方式；
- 申请记录、教师账号、试用跟进、课程和学生数据是不同对象，不因提交申请自动产生账号或业务权限。

## 理由

用户确认现有公开销售页和飞书试用申请表属于 v1。该入口把真实老师意愿转化为可跟进申请，是当前测试原型业务闭环的一部分；同时保持人工接入，避免提前扩展到完整销售系统。

## 影响

同步更新产品范围、用户场景、功能、数据、接口、隐私、部署运维和验收追踪需求。旧 1B 页面布局与具体实现仍作为设计和迁移证据，不自动成为 v1 需求。
