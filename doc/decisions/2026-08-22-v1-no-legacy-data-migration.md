# D-V1-012：v1 不迁移无价值旧业务数据与学生本机数据

日期：2026-08-22

状态：已接受

## 决策

1. 当前服务端没有具有保留价值的正式业务数据，也没有正式发布的课程版本。v1 不迁移现有服务端账号、工作空间、
   课程、草稿、发布或授权到新的 v1 业务真源；v1 从新的初始化数据开始。
2. 当前没有需要保留的学生本机课程或学习数据。v1 不建立旧学生本机数据迁移路径，新的 v1 插件从新的本机存储开始。
3. 为了避免误删和保留可追溯性，旧数据库、旧插件产物和旧本机存储说明在切换前只作为只读历史证据保留，不被 v1 运行时
   读取或当作兼容数据；它们的物理删除仍按既有保留策略另行执行。

## 影响

- 不需要建设服务端业务对象的旧新身份映射、旧授权码继续有效转换或旧 `PublishedScript` 到 `CourseRelease` 的生产迁移。
- 不需要承诺 `v0.9.1` 学生学习状态、旧课程包或旧存储键的无感升级。
- v1 首次运行需要创建新的管理员/教师基础数据；教师从新课程、草稿、发布和授权开始。
- v1 插件使用新的存储 Schema 和课程包契约；发现旧存储时不读取、不覆盖、不伪造迁移结果。
- 迁移测试仍保留旧数据/旧包的拒绝、隔离和不破坏测试，以证明旧证据不会误进入 v1。

## 重开条件

只有在发现以下情况时，才重新审核本决策：

- 现有服务端数据被确认包含仍需保留的真实教师、课程、授权或审计责任；
- 已有学生本机数据被确认具有必须保留的业务或合同价值；
- v1 交付范围改为要求旧用户无感升级；
- 法律、运营或安全责任要求旧数据继续在线可访问。
