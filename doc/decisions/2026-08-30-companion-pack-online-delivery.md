# D-V1-026：后续学习伙伴采用网站目录与按需资源下载

- 日期：2026-08-30
- 状态：已接受；当前仅记录方向，尚未实现远程角色包
- 决策编号：`D-V1-026`
- 替代关系：仅具体化并替代 `D-V1-023` 第 7 条的“后续再评估”部分；`D-V1-023` 的第一版小猫、六种状态、声音语义、自定义头像边界和奖励鱼干结论继续有效。

## 要解决的问题与边界

第一版小猫资源可以随插件发布，便于首次使用和离线学习。但后续可能出现不同猫种、其它伙伴和更多声音；把全部资源随每个插件版本发布会持续增大下载量，也会使单个角色的更新绑定到插件代码发布。

本决定只确定后续角色包的交付方向，不实现网站目录、账号、下载、缓存淘汰、远程包更新或跨设备同步。

## 已确认事实、约束与未知项

1. 当前插件是 Manifest V3；插件代码、权限和行为必须包含在正式插件包中，不能由网站下发可执行脚本或 WASM。
2. Chrome 允许扩展请求远程数据、图片和音频；资源二进制可存入扩展的 IndexedDB、Cache Storage 或 OPFS，而不是容量有限的 `chrome.storage` 设置值。
3. 当前生产插件已经只允许 KnownMap 与 B 站所需的 host permission；后续资源地址必须继续收敛到 KnownMap 的固定 HTTPS 域名。
4. 当前仅有一个内置 `cat-v1` 包；其压缩与 popup 设置体验是本次小功能的交付范围。
5. 网站账号、资源授权、角色包体积、缓存上限与失效策略尚未确认，不能作为当前实现假设。

## 考虑过的方案

| 方案 | 收益 | 成本与风险 | 结论 |
| --- | --- | --- | --- |
| 所有角色包永久随插件发布 | 离线最简单、无需网络服务 | 每次插件下载持续膨胀；新增或修订一个角色也要发布整个插件 | 不采用为长期方案 |
| 网站目录 + 按需下载图片、音频和 JSON 清单 | 仅下载学生选择的角色；角色内容可独立上新；默认包仍可离线 | 需要下载、校验、缓存、离线和账号策略 | 采用为后续方向 |
| 网站远程更新插件功能代码 | 看似更新快 | Manifest V3 与商店审核不允许远程执行代码；安全和可审计性不足 | 明确不采用 |

## 最终选择与理由

1. 插件基础包继续内置一个已压缩的默认猫咪包，保证首次使用和离线时有完整学习伙伴。
2. 未来由 KnownMap 网站提供角色包目录，展示介绍、状态图预览、声音试听、版本、文件大小和校验信息。
3. 学生在插件设置或网站选择角色后，插件只从 KnownMap 固定 HTTPS 域名下载该包的 JSON 清单、图片和音频；未选择的角色不下载。
4. 扩展代码、权限、课程触发逻辑和可执行内容仍只通过正式插件版本更新。角色包只允许 JSON、图片与音频，不得包含 HTML、脚本、WASM 或其它可执行内容。
5. 未来实际下载时，必须校验包 ID、版本、大小、MIME、音频时长和 SHA-256；二进制进入 IndexedDB、Cache Storage 或 OPFS，不写入 `chrome.storage`。

这个选择保留首版离线可用性，同时把角色内容增量与插件代码发布分开，并遵守 Manifest V3 的远程代码边界。

## 假设、风险与重新讨论条件

- 假设：KnownMap 将提供稳定 HTTPS 静态资源或资源 API；在实现前必须验证实际域名、鉴权和缓存头。
- 风险：下载中断、缓存损坏、资源版权、空间不足及跨设备选择不同步；上线阶段要为这些情况给出稳定错误、保留当前可用包，并进行安全输入校验。
- 重新讨论：批准第一个远程角色包、账户绑定角色选择、付费/授权资源、浏览器存储权限调整或需要角色包自动更新时，必须新建对应实施设计并复核本决定。

## 影响与后续行动

- 当前小功能只压缩并发布 `cat-v1`，不新增任何远程请求、存储或权限。
- `docs/superpowers/specs/2026-08-30-student-companion-package-settings-design.md` 是当前 popup 与压缩实现设计。
- 后续资源交付实现应在开始前建立单独的包清单、校验、缓存原子提交、离线回退、人工验收与安全测试计划。
