# LessonPilot 界面设计与颜色系统

> 文档状态（2026-08-15）：当前视觉参考。页面职责和第一阶段功能已经更新，以 `doc/requirements.md` 为准；本文旧页面命名和 AI 产品描述不得扩大当前范围。

更新时间：2026-08-14
状态：颜色系统仍用于教师/学生页；教师工作台示例页外形以 `doc/teacher-course-workspace-design.md` 为准；节点展示内容以 `doc/node-content-standard.md` 为准

## 1. 整体方向

LessonPilot 不是视频编辑器、通用 AI SaaS，也不是儿童游戏界面。它是由 AI 先分析、老师最终决定的互动课程创作工作台。视觉需要同时表达：

- 老师可信、课程专业；
- 学习过程有人在场、有温度；
- 时间线和事件可以快速识别；
- AI 是持续工作的课堂设计副驾驶，但老师始终拥有最终决定权。

因此采用暖纸白、墨色文字和深墨绿主色。避免大面积蓝紫渐变、霓虹色和高饱和彩色看板。

## 2. 核心颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面纸色 | `#F5F1E7` | 页面背景，提供温暖的教学材料感 |
| 明亮纸色 | `#FFFDF8` | 字幕画布、表单和主要操作面 |
| 主文字 | `#16251F` | 标题、正文、主要边框 |
| 次文字 | `#4F6259` | 描述、状态说明、辅助信息 |
| 品牌墨绿 | `#1D5C43` | 主操作、时间、课程身份、选中状态 |
| 深墨绿 | `#123B2C` | 视频预览、主按钮、Logo |

品牌主色只承担课程与操作层级，不用它为所有组件涂背景。

## 3. 节点组件颜色

| 节点组件 | 实色 | 浅色背景 | 设计含义 |
|---|---|---|---|
| 重点标注 | `#927008` | `#F4EBC9` | 短暂提醒、视觉聚焦 |
| 老师补充 | `#3E8060` | `#DFEDE5` | 老师在场、补充讲解 |
| 选择题 | `#A9654E` | `#F1DFD8` | 识别、判断和即时解释 |
| 填空题 | `#8D6F61` | `#EBE3DF` | 回忆与补全关键表达 |
| 问答题 | `#5D766E` | `#E2EBE8` | 迁移到个人情境并按标准评价 |

AI 不使用紫色。即使 AI 在信息架构中成为主动建议者，也继续使用品牌深绿与灰青，不用高饱和色制造独立的“魔法功能区”。

## 4. 状态与交互

- 本地演示、扩展待连接使用独立琥珀色 `#E5B93F`；
- 键盘焦点使用半透明品牌绿，不再占用注意力黄色；
- 选中字幕使用浅绿底、绿色边框与内侧强调线；
- 主操作使用深墨绿实底；次操作使用纸白底加墨色边框；
- 错误状态保留砖红色，仅在校验失败时出现。

## 5. 页面层级

```text
暖纸白页面
  -> 浅灰绿课程概览
  -> 明亮纸色课堂时间线（字幕 / 知识点 / 易错点 / AI 建议）
  -> 深墨绿 AI Copilot 建议
  -> 略暖的课堂设计区
  -> 五种低饱和节点标记
```

颜色用于说明结构与状态，不用于装饰。删除颜色后仍应能依靠文字、边框和布局理解页面；颜色只加速识别。

## 6. 双页面信息架构

两个页面服务不同角色和不同任务，不能因为共用同一课程而做成同一种界面。

- **教师端：课堂设计工作台。** 首页围绕一个主任务展开：沿字幕决定学生在哪一段需要重点提醒、补充、练习或追问。固定 B 站链接确认和字幕导入只是开始设计的紧凑输入；学生预览不占首页主位，仍在编辑阶段支持设计判断。首页底部只用一小段说明连接到学生学习过程和未来学习证据，不制造报告看板或平台愿景。时间线是具体课堂设计的工作面，W0 不提供本地视频导入。
- **学生端：单节课程交付。** W0 在视频上方先呈现课程标题与学习目标，把来源视频作为最大内容区域；视频下方只展示课程设计的学习结果与“在 B 站打开原课”回退。定时练习与反馈在可控播放器路径确认后再加入，不展示播放器适配、本地文件或来源验证等实现信息。
- **测试边界：** W0 不在学生页提供测试者工具或本地视频替换；跨源播放器能力通过独立的 B 站原页面插件 spike 验证，不能成为学生开始学习时必须理解或选择的路径。
- **跨端一致性：** 两端都保持暖纸白、墨绿和低饱和状态色，但教师端信息密度较高、学生端更安静且一次只推进一个学习动作。

### 6.1 Creator Studio 信息架构

销售时单独打开的页面正式称为「教师工作台示例页」，以 `doc/teacher-course-workspace-design.md` 为准，实现文件是 `teacher-web/index.html`、`sample.css`、`sample.js`。它使用预置课程、节点和持续标注的示例数据，不是营销落地页。真实教师工作台保留在 `teacher-web/editor.html`；两者入口和数据状态分开，信息架构、节点组件、学生效果和视觉系统保持一致。

线上第一次接触老师使用独立 `teacher-web/forsales.html`，以 `doc/teacher-sales-page-design.md` 为准。该页允许使用售前首屏、前后变化、价值翻译和行动收口；这些营销结构不得进入教师工作台示例页或真实教师工作台。

- 视频右侧“整体介绍”只总结当前视频内容，不承担产品说明；
- 视频下方是一体化时间线编辑平台：五个紧凑组件按钮、视频选择、15 分钟分段翻页、交互节点和轴线上下的节点简介；时间线头部不重复播放器的当前/总时长，也不提供缩放减号、加号；
- 组件栏标题只写“交互节点”，不显示“拖入节点”或额外拖拽操作提示；
- 时间线头部显示课程名称；课程内视频下拉按“第一节、第二节……”命名，不使用“视频 1、视频 2……”；
- 播放器与时间线共享当前播放时刻，进度和选中节点必须一致；时间线不绘制独立的播放游标竖线；
- 节点简介分布在时间轴上下两侧，使用与图标一致的浅色底，并以同类型颜色的细线连接对应节点；
- 时间轴两端使用小型胶囊边界标识；单段为“开始 / 结束”，分页时按所在分段切换为“上一段 / 下一段”；
- 当前编辑节点使用完整行浅色底、细描边和“正在编辑”标签，不使用单侧竖线；
- 参数面板的“保存节点”使用水平居中的紧凑主按钮，不横向占满整栏；按钮下方放默认勾选的小型“自动保存”复选框，用来控制字段修改是否自动保存。

- 功能原型首页主叙事：导入授权字幕 → 设计课堂动作；
- 首页将「设计课堂」作为最大、最直接的命令。课程和字幕输入服务于这个命令；学生过程与结果只用一段轻量说明呈现，不使用虚构的数据、报告卡片或并列的大模块；
- 时间线是课程时间线，不只是字幕列表；字幕只是定位教学意图的基础材料；
- AI Copilot 固定在课堂设计侧，解释“为什么建议互动”，并提供采纳、修改、忽略；
- “添加动作”统一改称“课堂设计”，老师输入自然语言教学意图，AI 再生成具体事件；
- “预览学生视角”升级为“模拟学生课堂”，后续用典型学生回答验证课堂设计；
- 当前页面只是高保真交互原型，不声称已接入真实课程分析或学生模拟模型。

## 7. 可读性验证

当前教师端主要组合对比度：

- 次文字 / 页面纸色：约 `5.78:1`；
- 品牌绿 / 页面纸色：约 `6.99:1`；
- 五种节点文字 / 对应浅色背景：发布前需要按最终字号重新核验，普通文本目标不低于 `4.5:1`。

均高于普通文本 `4.5:1` 的目标线。后续更换字体、字号或透明度后需要重新检查。
