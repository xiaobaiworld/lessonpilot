# LessonPilot 界面设计与颜色系统

更新时间：2026-08-12
状态：教师工作台与学生课程页已采用；两者共用颜色系统，但不共用信息架构

## 1. 整体方向

LessonPilot 不是视频编辑器、通用 AI SaaS，也不是儿童游戏界面。它是由 AI 先分析、老师最终决定的互动课程创作工作台。视觉需要同时表达：

- 老师可信、课程专业；
- 学习过程有人在场、有温度；
- 时间线和事件可以快速识别；
- AI 是持续工作的课堂设计副驾驶，但老师始终拥有最终决定权。

因此采用暖纸白、墨色文字和深墨绿主色。避免大面积蓝紫渐变、霓虹色和高饱和彩色看板。

## 2. 核心颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面纸色 | `#F5F1E7` | 页面背景，提供温暖的教学材料感 |
| 明亮纸色 | `#FFFDF8` | 字幕画布、表单和主要操作面 |
| 主文字 | `#16251F` | 标题、正文、主要边框 |
| 次文字 | `#4F6259` | 描述、状态说明、辅助信息 |
| 品牌墨绿 | `#1D5C43` | 主操作、时间、课程身份、选中状态 |
| 深墨绿 | `#123B2C` | 视频预览、主按钮、Logo |

品牌主色只承担课程与操作层级，不用它为所有组件涂背景。

## 3. 课堂事件颜色

| 事件 | 实色 | 浅色背景 | 设计含义 |
|---|---|---|---|
| 注意力爆发 | `#D9A51E` | `#F5E7B0` | 短暂提醒、视觉聚焦 |
| 老师语音 | `#3E8060` | `#D9E9DF` | 老师在场、语音补充 |
| 互动练习 | `#A9654E` | `#EFDDD5` | 动手、作答和行动 |
| AI 教学模板 | `#5D766E` | `#E1E9E4` | 受控辅助，不抢主视觉 |

AI 不使用紫色。即使 AI 在信息架构中成为主动建议者，也继续使用品牌深绿与灰青，不用高饱和色制造独立的“魔法功能区”。

## 4. 状态与交互

- 本地演示、扩展待连接使用独立琥珀色 `#E5B93F`；
- 键盘焦点使用半透明品牌绿，不再占用注意力黄色；
- 选中字幕使用浅绿底、绿色边框与内侧强调线；
- 主操作使用深墨绿实底；次操作使用纸白底加墨色边框；
- 错误状态保留砖红色，仅在校验失败时出现。

## 5. 页面层级

```text
暖纸白页面
  -> 浅灰绿课程概览
  -> 明亮纸色课堂时间线（字幕 / 知识点 / 易错点 / AI 建议）
  -> 深墨绿 AI Copilot 建议
  -> 略暖的课堂设计区
  -> 四种低饱和事件标记
```

颜色用于说明结构与状态，不用于装饰。删除颜色后仍应能依靠文字、边框和布局理解页面；颜色只加速识别。

## 6. 双页面信息架构

两个页面服务不同角色和不同任务，不能因为共用同一课程而做成同一种界面。

- **教师端：操作工作台。** 首页先展示当前课程、待决定事项、课程健康度和下一步；W0 的次级工作项只指向固定 B 站原课、首个教学节点和课堂设计，不提供本地视频导入。时间线是进入具体课堂设计后的工作面。老师看到的是可继续完成的工作，不是平台愿景或学校采购式首页。
- **学生端：单节课程交付。** W0 在视频上方先呈现课程标题与学习目标，把来源视频作为最大内容区域；视频下方只展示课程设计的学习结果与“在 B 站打开原课”回退。定时练习与反馈在可控播放器路径确认后再加入，不展示播放器适配、本地文件或来源验证等实现信息。
- **测试边界：** W0 不在学生页提供测试者工具或本地视频替换；跨源播放器能力通过独立的 B 站原页面插件 spike 验证，不能成为学生开始学习时必须理解或选择的路径。
- **跨端一致性：** 两端都保持暖纸白、墨绿和低饱和状态色，但教师端信息密度较高、学生端更安静且一次只推进一个学习动作。

### 6.1 Creator Studio 信息架构

- 首页主叙事：上传课程 → AI 分析 → 设计课堂 → 模拟学生 → 发布课程；
- 时间线是课程时间线，不只是字幕列表；字幕只是定位教学意图的基础材料；
- AI Copilot 固定在课堂设计侧，解释“为什么建议互动”，并提供采纳、修改、忽略；
- “添加动作”统一改称“课堂设计”，老师输入自然语言教学意图，AI 再生成具体事件；
- “预览学生视角”升级为“模拟学生课堂”，后续用典型学生回答验证课堂设计；
- 当前页面只是高保真交互原型，不声称已接入真实课程分析或学生模拟模型。

## 7. 可读性验证

当前教师端主要组合对比度：

- 次文字 / 页面纸色：约 `5.78:1`；
- 品牌绿 / 页面纸色：约 `6.99:1`；
- 四种事件文字 / 对应浅色背景：约 `5.87:1`–`6.56:1`。

均高于普通文本 `4.5:1` 的目标线。后续更换字体、字号或透明度后需要重新检查。
