# 教师平台本地开发阶段需求

版本：0.1

更新时间：2026-08-18

状态：当前阶段需求；来源为 `doc/AI_Learning_Companion_Product_Function_Spec_v0.2.md` 及 2026-08-18 对话确认

## 1. 阶段目标

本阶段实现一个可以在本地运行、以后可以部署到公网的教师发布闭环：

```text
预建教师测试账号
→ 教师登录
→ 创建一门课程和一个课节
→ 编辑四种初始互动节点
→ 发布课程
→ 创建课程授权码
→ 学生在 B 站页面通过我们提供的解压版 Chrome 插件输入授权码
→ 插件从 FastAPI 服务下载已发布课程配置
→ 插件在对应 B 站视频页面运行课程
```

本阶段的成功标准是：教师能够发布一门真实可运行的测试课程，学生能够使用授权码通过插件取得对应课程配置。当前先在本地完成，不执行公网部署。

## 2. 当前产品形态

### 2.1 教师端

- 沿用现有教师界面和产品形态，当前重点是接入真实后端能力，不重新设计销售页。
- 教师使用手工预建的测试账号登录。
- 不开放教师注册。
- 不开发平台管理员账号管理页面。
- 当前界面只展示和操作一个课节。
- 一个课节必须归属于一门课程。
- 数据模型保留课程下多个课节的扩展能力。

### 2.2 学生端

- 学生不使用独立公网网页。
- 学生使用 KnownMap 直接提供的解压版 Chrome 插件。
- 插件运行在 B 站原页面。
- 插件向后端提交授权码，取得授权码对应的已发布课程配置。
- 插件不通过 Chrome Web Store 分发。

### 2.3 课程和节点

- 当前课程层级为 `Course -> Lesson -> Published Script -> Nodes`。
- 当前第一版只需要一门课程和一个课节的教师操作路径。
- 当前初始节点类型为：
  - 重点内容；
  - 选择题；
  - 填空题；
  - 问答题。
- 节点类型必须按可扩展的类型注册方式组织，但本阶段不实现更多类型。
- 问答题只保存学生原始回答和教师预设反馈；学生学习数据本阶段不上传。

### 2.4 教师可视化节点编辑器

- `teacher-web/forsales.html` 中的“节点组件栏 + 横向时间轴 + 节点摘要 + 字幕上下文”是当前教师编辑器的视觉和交互参照。
- 正式教师编辑器不能继续以“字幕列表 + 右侧普通表单”作为主要编辑模型。
- 四种节点必须作为可注册的编辑器组件存在。组件注册项至少包含类型标识、显示名称、图标、默认值、字段定义、节点创建规则、摘要规则和校验入口。
- 老师添加节点时同时支持两种入口：
  - 点击组件，再点击时间轴位置；
  - 将组件拖放到时间轴位置。
- 两种入口必须调用同一个节点创建动作，产生一致的默认值、时间、字幕关联、编辑弹窗和校验结果。
- 时间轴位置根据当前课节时长和节点 `trigger.timeSeconds` 计算，不允许使用销售页中的固定百分比或固定节点数据。
- 有字幕时，新建或移动节点关联距离目标时间最近的字幕，并保存合法 `captionId`；字幕只在浏览器中解析，不上传后端。
- 老师可以单击选中节点、双击或按 Enter 打开编辑、拖动节点调整触发时间、删除节点。
- 同一字幕或同一时间附近允许存在多个节点；界面需要通过轨道或摘要布局避免节点互相遮挡。
- 节点编辑弹窗按节点类型显示不同字段；取消存在未保存修改时必须明确确认。
- 保存草稿后，页面必须使用后端返回的标准节点重新渲染；保存失败时保留当前未保存状态。
- 发布、授权码和现有 FastAPI 接口保持在同一教师闭环中，不为可视化编辑器另建第二套草稿格式。
- 开发/测试环境记录组件选择、放置、拖动、弹窗打开和校验失败等 `debug` 诊断日志；正常运行默认只记录保存、发布、失败等 `info` 及以上事件。日志不得记录节点正文、字幕正文、密码、cookie 或授权码原文。

## 3. 当前授权码语义

授权码是一个课程配置下载凭证：

```text
授权码 → 已发布课程 → PluginCourseConfig
```

本阶段要求：

- 教师可以创建授权码；
- 每个授权码绑定一门课程；
- 只有已发布课程可以被授权码下载；
- 插件提交授权码后，后端返回对应课程的最新已发布配置；
- 授权码不需要教师列表、复制、停用、过期、人数限制或领取记录页面；
- 授权码不创建学生账号；
- 授权码不产生 Learning Identity；
- 授权码不记录学生身份、领取记录或学习数据；
- 授权码不负责远程删除插件本地已有配置。

授权码原文不得长期明文落库。服务端只保存可检索的安全摘要，创建成功时将原文返回给教师端用于复制给学生。

## 4. 当前阶段不做

- 平台管理员登录和管理界面；
- 教师自主注册；
- Google 登录；
- 教师助手和工作空间成员；
- 多工作空间切换；
- 多课节教师管理界面；
- 学生账号和学生列表；
- 授权领取记录；
- 多授权码并集计算；
- 授权码停用、过期、人数限制和定向账号授权；
- 学习事件上传；
- 学习进度、作答结果和教师数据报表；
- CSV 学习数据导出；
- 独立学生网页；
- Chrome Web Store 发布；
- 公网服务器、域名、HTTPS、生产部署和监控平台配置；
- B 站视频文件下载；
- AI 评分、AI 追问和 AI 自动生成并发布内容。

## 5. 与 v0.2 的关系

`doc/AI_Learning_Companion_Product_Function_Spec_v0.2.md` 仍然是产品方向和长期边界的主要依据。本文件是当前本地开发阶段的范围裁剪：

- v0.2 的教师账号、课程、课节和四种节点作为当前实现基础；
- v0.2 的完整学生身份、授权记录、更新资格和学习数据后置；
- 本阶段不把后置能力伪装成已实现；
- 本阶段的数据和 API 应保留后续扩展空间，但不提前创建没有当前验收价值的复杂状态。

## 6. 阶段验收

### 6.1 教师端

1. 使用预建测试账号可以登录和退出。
2. 未登录请求不能访问教师课程 API。
3. 教师可以创建课程和一个课节。
4. 教师可以通过点击组件后点击时间轴创建四种节点。
5. 教师可以通过拖放组件到时间轴创建四种节点。
6. 教师可以在时间轴上选择、编辑、移动和删除节点。
7. 点击添加和拖放添加产生相同的后端节点结构。
8. 教师可以保存包含四种节点的结构化脚本。
9. 刷新后从后端草稿恢复的节点位置、类型和内容一致。
10. 草稿不会被学生下载。
11. 发布后可以读取已发布课程配置。
12. 当前教师只能访问自己的课程。

### 6.2 授权码和插件

1. 教师可以创建绑定课程的授权码。
2. 未发布课程不能创建可下载授权结果。
3. 插件提交有效授权码后得到对应已发布课程配置。
4. 无效授权码、未发布课程和课程不存在时默认拒绝。
5. 后端响应不包含教师密码、授权码摘要或内部数据库字段。
6. 插件将课程保存到本地后，可以在匹配的 B 站视频页面运行。
7. 插件不通过独立学生网页获取课程。

### 6.3 工程验收

1. FastAPI OpenAPI 文档可以单独调试当前端点。
2. SQLite 数据库可以通过初始化和迁移命令重建。
3. 核心业务逻辑有单元测试和数据库集成测试。
4. 登录、课程发布、授权码下载有端到端 API 流程测试。
5. 后端日志包含 request ID、模块、动作、成功或失败和耗时。
6. 测试密钥、密码和授权码原文不进入源码、数据库或日志。
