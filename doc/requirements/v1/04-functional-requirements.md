## 1. 功能分解与编号骨架

功能需求回答“系统必须提供什么可观察行为”，不规定数据库、API、组件、框架或部署方式。追踪链固定为：

```text
GOAL / SUCCESS
  -> SCOPE
  -> SCN
  -> FR
  -> 设计
  -> 代码
  -> 自动化测试与人工验收证据
```

每条正式功能需求必须包含：稳定编号、状态、优先级、来源场景、前置条件、行为规则、异常结果、
可观察验收条件，以及涉及的数据、安全、接口或非功能需求引用。缺少异常结果或验收条件的条目只能是笔记，
不能标记为已接受需求。

### 1.2 单条需求模板

```markdown
#### FR-<DOMAIN>-<NNN>：<可观察行为标题>

- 状态：待审核 / 已接受 / 需修改 / 已否决 / 已替代
- 优先级：P0 / P1 / P2
- 来源：SCOPE-*；SCN-*
- 主要角色：明确角色
- 前置条件：动作发生前必须为真的事实
- 触发：由谁在什么情况下发起
- 系统行为：必须发生的业务行为和状态变化
- 异常结果：拒绝、失败、超时、冲突和重试时的结果
- 验收条件：用户或测试能够观察和检查的结果
- 关联要求：DATA-* / INT-* / NFR-* / SEC-* / OPS-* / MIG-*
```

优先级含义：

- `P0`：没有它就无法形成已接受的 v1 核心闭环，或会造成安全、数据完整性、权限、迁移和恢复风险；
- `P1`：v1 应交付的重要行为，但不直接阻断最小核心闭环；
- `P2`：体验增强、运营效率或可以在闭环成立后补充的能力。

优先级不是实现顺序。实现顺序由依赖、风险和验证成本决定，并在开发计划中记录。

### 1.3 补充场景与需求变更规则

1. 整理某个功能域时，如果发现 `03-user-scenarios.md` 没有承接其角色目标、异常分支或恢复路径，
   必须先新增或修订 `SCN-*`，再创建对应 `FR-*`。
2. 一条 `FR-*` 可以服务多个场景，一个场景也可以拆成多条功能需求；不得为了追求一一对应而复制需求。
3. 相同业务行为只保留一个权威 `FR-*`，其它场景通过引用复用；界面差异不能制造多个事实源。
4. 已接受需求发生语义变化时新增替代记录，不覆盖原结论或复用编号。
5. 需求被拆分时，原编号标记“已替代”，并列出全部新编号；合并时同样保留来源编号。
6. 功能要求不能把开放问题伪装成默认答案。受 `OPEN-*` 影响的条目标记阻塞或保留方案分支。
7. 每完成一个功能域，都要检查正常、边界、异常、重复操作、并发、恢复和权限隔离场景。

### 1.4 建议审核顺序

按业务依赖先审核身份与工作空间，再审核课程制作、发布、授权、学生运行、本机学习状态和运营恢复：

```text
FR-AUTH
  -> FR-WS
  -> FR-COURSE
  -> FR-AUTHOR
  -> FR-PUBLISH
  -> FR-GRANT
  -> FR-LIB
  -> FR-RUNTIME
  -> FR-LEARN
  -> FR-ADMIN
  -> FR-PORT
```

`FR-REPORT` 已按 `D-026` 移到后续阶段，不进入当前审核序列。该顺序只控制需求审核，不代表最终模块依赖
或代码目录结构。

## 2. 身份认证与会话（`FR-AUTH-*`）

本功能域按角色职责组织：先说明每个角色为了完成当前工作必须具备什么能力，再列出系统必须共同保证的
隔离和失败边界。密码算法、会话载体、Cookie 属性和限流数值留给后续安全、接口与设计文档。

### 2.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 登录管理入口；创建教师用户名和密码；重置教师密码；停用或恢复教师登录资格 | 不代替教师编辑课程；不查询教师现有密码；不因管理身份默认读取课程正文 |
| 教师 | 使用用户名和密码登录；进入自己的工作空间；退出；重新登录后继续使用已保存课程 | 不自行注册；不管理其他教师账号；不因会话结束丢失课程数据 |
| 学生 | 在当前机器建立本机学习标识；保存课程和学习状态；换机后重新下载课程 | 不注册或登录；不上传个人学习数据；不跨设备恢复或合并学习状态 |

### 2.2 平台管理员职责

#### FR-AUTH-001：管理员登录和退出管理入口

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-ADM-04`、`SCN-ERR-01`
- **主要角色**：平台管理员
- **前置条件**：管理员账号已经通过受控方式建立且允许登录。
- **触发**：管理员进入管理入口、恢复已有会话或主动退出。
- **系统行为**：正确验证管理员用户名和密码后建立或恢复管理员会话；退出后立即结束当前管理员会话。
- **异常结果**：用户名或密码错误、账号不可用、会话过期时不得进入管理能力，也不得泄露账号是否存在。
- **验收条件**：有效管理员可以登录和恢复会话；退出、过期或撤销后，同一会话不能继续执行管理操作。
- **关联要求**：`SEC-AUTH-*`、`SEC-ACCESS-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-002：管理员创建教师用户名和密码

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-01`
- **主要角色**：平台管理员
- **前置条件**：管理员已经登录，并确认需要接入的教师及其登录名。
- **触发**：管理员创建教师账号。
- **系统行为**：系统创建唯一教师用户名和可直接使用的密码，同时建立教师进入业务所需的基本归属；当前阶段不开放教师自行注册。
- **异常结果**：用户名重复、输入无效或创建失败时，不留下无法登录或没有业务归属的半成品教师账号。
- **验收条件**：教师可以直接使用管理员交付的用户名和密码登录；不要求首次登录后再次修改密码；未受邀请者不能自行注册教师账号。
- **关联要求**：`FR-ADMIN-*`、`FR-WS-*`、`DATA-ACCOUNT-*`、`SEC-AUTH-*`（待建立）

#### FR-AUTH-003：管理员重置或停止教师登录资格

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-02`、`SCN-ADM-05`
- **主要角色**：平台管理员
- **前置条件**：目标教师账号存在，管理员有权操作该账号。
- **触发**：教师遗失密码，或管理员决定重置密码、停用或恢复教师账号。
- **系统行为**：重置后新密码可直接登录，旧密码和该教师全部旧会话失效；停用后拒绝新登录和旧会话；恢复后允许教师用当前有效密码重新登录。
- **异常结果**：目标不存在、操作失败或并发冲突时，不显示假成功；重置停用账号不会自动恢复账号状态。
- **验收条件**：密码重置后只有新密码可用；停用后新旧会话均不可用；恢复后必须重新登录；所有操作都不删除教师已保存的课程等业务数据。
- **关联要求**：`FR-ADMIN-*`、`DATA-LIFE-*`、`SEC-AUTH-*`、`SEC-LOG-*`（待建立）

### 2.3 教师职责

#### FR-AUTH-004：教师使用用户名和密码登录

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：教师
- **前置条件**：管理员已经创建教师账号，账号当前允许登录。
- **触发**：教师提交自己的用户名和密码。
- **系统行为**：验证成功后建立教师会话，并把教师带到自己有权使用的工作入口。
- **异常结果**：用户名或密码错误、账号停用或服务不可用时不建立会话，不泄露账号是否存在或停用。
- **验收条件**：有效教师可以登录；错误、未知或停用账号不能登录；教师登录不会获得管理员身份。
- **关联要求**：`FR-WS-*`、`SEC-AUTH-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-005：教师恢复会话和主动退出

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`；`SCN-TCH-01`
- **主要角色**：教师
- **前置条件**：教师可能持有一个已有会话。
- **触发**：教师重新打开工作台、访问受保护功能或主动退出。
- **系统行为**：仍有效的会话可以恢复；退出、过期、撤销或账号停用后的会话不能继续访问教师功能。
- **异常结果**：会话失效时要求重新登录，不清空已经确认保存的课程，也不把当前无法访问显示为数据已删除。
- **验收条件**：有效会话刷新后仍可使用；退出后同一会话立即不可用；重新登录会建立新的有效会话。
- **关联要求**：`NFR-REL-*`、`SEC-AUTH-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-006：教师会话结束后保留业务数据

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-TCH-02`
- **主要角色**：教师
- **前置条件**：教师已经确认保存课程、课节、草稿、发布版本或授权等业务数据。
- **触发**：教师退出、会话过期、密码被重置、账号被停用或之后重新登录。
- **系统行为**：认证状态只决定当前能否访问，不承担业务数据存储；会话变化不得删除、覆盖或重新创建已保存业务数据。
- **异常结果**：暂时无法重新认证时继续保留业务数据；未确认保存的页面临时输入不得伪装为服务端已保存。
- **验收条件**：保存课程后退出再登录，课程及其稳定标识保持不变；密码重置、会话过期或账号停用同样不删除课程。
- **关联要求**：`FR-WS-*`、`DATA-LIFE-*`、`NFR-REL-*`（待建立）

### 2.4 学生职责

#### FR-AUTH-007：学生在当前机器使用本机学习标识

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-06`；`SCN-STU-01`、`SCN-STU-03`；`D-026`
- **主要角色**：学生
- **前置条件**：学生首次或再次在当前机器使用受支持的 KnownMap 运行时。
- **触发**：学生领取课程或重新打开已有课程。
- **系统行为**：运行时在当前机器建立或恢复本机学习标识，用它关联本机课程、领取结果和学习状态；不要求学生注册、登录或提供真实身份信息。
- **异常结果**：本机标识损坏或本地存储不可用时，不把其它机器或其它本地上下文的数据自动归入当前标识。
- **验收条件**：同一机器和同一受支持存储上下文能够恢复相同标识及本地数据；本机标识不能进入管理员或教师权限。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`DATA-IDENTITY-*`（待建立）

#### FR-AUTH-008：学生在本机保存并恢复课程数据

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-01`、`SCN-STU-03`
- **主要角色**：学生
- **前置条件**：课程已经成功下载到当前机器。
- **触发**：学生关闭并重新打开浏览器或运行时，或在暂时断网时继续学习。
- **系统行为**：当前机器保存课程包和学习状态；重新打开后按本机学习标识恢复；不依赖教师或管理员登录会话保存学生数据。
- **异常结果**：本地保存失败或数据损坏时显示真实错误并保留最后一个可确认状态，不声称数据已经上传或能够云端恢复。
- **验收条件**：同一机器重新打开后课程和已保存学习状态仍存在；教师或管理员退出不影响学生本机课程。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`DATA-LOCAL-*`、`NFR-REL-*`（待建立）

#### FR-AUTH-009：学生换机后重新下载课程

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-STU-01`、`SCN-STU-04`；`D-026`
- **主要角色**：学生
- **前置条件**：学生换用另一台机器，且仍持有可用于重新领取的有效授权。
- **触发**：学生在新机器输入授权码并下载课程。
- **系统行为**：新机器建立新的本机学习标识并保存独立课程副本；当前阶段不查找、恢复或合并原机器学习状态。
- **异常结果**：授权已经失效时拒绝重新下载，不声称服务端保存了原机器数据，也不伪造跨设备连续性。
- **验收条件**：有效授权可在规则允许时重新下载课程；新机器从新的本机状态开始；界面不承诺云同步、换机恢复或账号找回。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`MIG-IDENTITY-*`（待建立）

### 2.5 系统共同边界

#### FR-AUTH-010：三类角色和身份相互隔离

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-06`、`SCOPE-08`；`SCN-ADM-04`、`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师、学生
- **前置条件**：请求可能携带管理员会话、教师会话、本机学习标识或没有任何身份信息。
- **触发**：任一角色访问需要身份或权限的能力。
- **系统行为**：管理员会话只用于管理能力，教师会话只用于教师能力，本机学习标识只关联学生本机数据；任何一种都不能自动换取另一种权限。
- **异常结果**：身份缺失、类型错误、过期或权限不足时拒绝操作，不降级为其它角色，也不返回越权数据。
- **验收条件**：教师会话不能执行管理操作；本机学习标识不能访问教师或管理入口；管理员登录不会同时建立教师会话。
- **关联要求**：`FR-WS-*`、`SEC-ACCESS-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-011：认证失败安全且可以恢复

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-04`、`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师
- **前置条件**：管理员或教师认证入口可访问。
- **触发**：凭证错误、重复尝试、会话失效或认证服务失败。
- **系统行为**：返回一致且可理解的失败结果；限制短时间内的重复认证尝试；允许合法用户在限制解除或服务恢复后重试。
- **异常结果**：错误信息不得泄露账号是否存在，不记录密码、会话原文或完整认证请求，也不得因认证失败删除业务数据。
- **验收条件**：错误账号和错误密码得到不便于枚举账号的结果；超过后续安全要求规定的阈值会受限；恢复后合法账号可以再次登录。
- **关联要求**：`SEC-AUTH-*`、`SEC-LOG-*`、`NFR-AVAIL-*`、`OPS-MON-*`（待建立）

### 2.6 本功能域完成条件

1. 管理员能够登录，并完成教师用户名和密码的创建、重置、停用与恢复；
2. 教师能够使用用户名和密码登录、退出，并在重新登录后继续使用已保存课程；
3. 学生无需账号，只使用本机学习标识保存当前机器上的课程和学习状态；
4. 换机后重新下载课程，不恢复原机器数据；
5. 三类角色不能互相替代或越权；认证失败不删除课程等业务数据；
6. 学习数据上传、教师学习证据和跨设备同步不进入当前阶段。

本功能域通过后，下一段进入 `FR-WS-*` 工作空间与权限边界，不提前展开课程功能。

## 3. 工作空间与权限边界（`FR-WS-*`）

工作空间是教师业务数据的归属与隔离边界，不是一个页面、登录会话或本地文件夹。本功能域只确定谁拥有、
谁能进入、系统如何判断归属，以及越权时必须发生什么；课程内部如何创建和编辑留给 `FR-COURSE-*`。

### 3.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 创建教师时建立其工作空间；维护教师账号与工作空间的有效关联；在授权支持时处理恢复 | 不代替教师编辑课程；不因管理员身份默认读取课程正文；不直接改库绕过归属规则 |
| 教师 | 登录后进入自己的唯一工作空间；管理该空间内有权操作的业务对象 | 不切换或加入其他工作空间；不查看、修改或引用其他教师的数据 |
| 学生 | 通过有效授权取得允许的课程包，并在本机使用 | 不加入教师工作空间；不访问教师工作台；授权码不产生工作空间成员资格 |

### 3.2 平台管理员职责

#### FR-WS-001：创建教师时建立唯一工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-ADM-01`
- **主要角色**：平台管理员
- **前置条件**：管理员正在通过受控流程创建一名教师。
- **触发**：教师账号创建成功。
- **系统行为**：系统同时为教师建立一个独立工作空间，并把该教师设为当前唯一所有者；账号与工作空间必须作为一个完整接入结果交付。
- **异常结果**：工作空间建立失败时，教师接入不得显示为完整成功，也不得留下可以登录但没有业务归属的半成品状态；重复请求不得创建第二个当前工作空间。
- **验收条件**：新教师首次登录即可进入自己的工作空间；同一教师重复初始化仍只有一个当前工作空间；其他教师拥有不同的工作空间标识。
- **关联要求**：`FR-AUTH-002`、`FR-ADMIN-*`、`DATA-WS-*`、`NFR-REL-*`（待建立）

#### FR-WS-002：管理员维护归属但不默认读取业务正文

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-02`、`SCN-ADM-03`
- **主要角色**：平台管理员、支持人员
- **前置条件**：教师及其工作空间已经存在。
- **触发**：管理员停用或恢复教师，查看必要运营状态，或处理明确的支持与恢复请求。
- **系统行为**：系统允许管理员查看完成账号管理所需的最小摘要，并维护教师与工作空间的有效关联；读取课程正文或执行恢复操作必须经过额外的明确授权和审计路径。
- **异常结果**：普通账号管理不得顺带返回课程正文、脚本内容、学生本机数据或密码；没有明确支持授权时拒绝扩大读取范围。
- **验收条件**：管理员可以确认教师、工作空间和必要状态是否存在；普通列表和状态操作不返回课程正文；受控恢复能够留下操作者、对象、时间和结果。
- **关联要求**：`FR-ADMIN-*`、`SEC-ACCESS-*`、`SEC-LOG-*`、`DATA-CLASS-*`（待建立）

### 3.3 教师职责

#### FR-WS-003：教师登录后进入自己的唯一工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`
- **主要角色**：教师
- **前置条件**：教师已经登录，账号与工作空间关联有效。
- **触发**：教师打开工作台或重新登录。
- **系统行为**：系统自动进入该教师当前唯一工作空间，恢复其有权看到的工作上下文；当前阶段不显示工作空间选择、创建、加入或切换入口。
- **异常结果**：关联缺失、重复或损坏时停止进入业务功能，保留已有数据并给出可追踪的支持错误；不得临时创建第二个空间掩盖问题。
- **验收条件**：教师每次登录进入同一工作空间；刷新或重新登录后工作空间标识不变；界面没有不可用的多工作空间入口。
- **关联要求**：`FR-AUTH-004`、`FR-AUTH-006`、`NFR-REL-*`、`OPS-SUPPORT-*`（待建立）

#### FR-WS-004：教师只管理自己工作空间内的对象

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：教师
- **前置条件**：教师已进入自己的工作空间。
- **触发**：教师查看列表、打开对象，或发起创建、修改、发布、归档、授权和导出等操作。
- **系统行为**：只返回和修改归属于当前工作空间的业务对象；新对象自动归入当前工作空间，不能由教师在请求中指定为其他空间。
- **异常结果**：对象属于其他空间、不存在或归属无法确认时拒绝操作，不返回正文，不改变任何对象，也不通过差异化错误泄露对象是否存在。
- **验收条件**：教师列表中只出现自己空间的数据；使用其他教师的对象标识执行读写均失败；失败后双方数据保持不变。
- **关联要求**：`FR-COURSE-*`、`FR-AUTHOR-*`、`FR-PUBLISH-*`、`FR-GRANT-*`、`FR-PORT-*`、`SEC-ACCESS-*`（待建立）

#### FR-WS-005：教师账号停用不删除工作空间数据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-ADM-02`、`SCN-TCH-06`
- **主要角色**：平台管理员、教师
- **前置条件**：工作空间内已经有课程、发布版本、授权或操作记录。
- **触发**：教师账号被停用、恢复，或工作空间暂时不可访问。
- **系统行为**：停止新的教师受保护操作，但继续按数据生命周期规则保留工作空间及其业务对象；恢复登录资格后重新显示原工作空间和已保存数据。
- **异常结果**：账号状态变化不得被解释为课程归档、授权终止或数据删除；恢复账号也不得自动恢复已经单独终止的授权来源。
- **验收条件**：停用前后的工作空间标识和已保存课程标识一致；停用期间教师操作被拒绝；恢复后原数据仍在且独立业务状态没有被重写。
- **关联要求**：`FR-AUTH-003`、`FR-AUTH-006`、`FR-GRANT-*`、`DATA-LIFE-*`（待建立）

### 3.4 学生职责

#### FR-WS-006：学生授权不产生工作空间成员资格

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-STU-01`、`SCN-ERR-01`
- **主要角色**：学生
- **前置条件**：学生持有课程授权码并在当前机器领取课程。
- **触发**：学生下载、更新或打开课程包。
- **系统行为**：系统只按有效授权返回允许的已发布课程内容；本机学习标识和授权码都不成为工作空间账号或成员关系。
- **异常结果**：授权无效、范围不足或课程不属于对应授权来源时拒绝课程动作，不开放教师工作台、草稿、其它课程或工作空间摘要。
- **验收条件**：学生只能取得授权范围内的课程包；不能使用授权码或本机学习标识访问教师接口；一个工作空间的授权不能读取另一个工作空间的内容。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`SEC-ACCESS-*`、`DATA-GRANT-*`（待建立）

### 3.5 系统共同边界

#### FR-WS-007：服务端从可信身份推导工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师
- **前置条件**：请求涉及某个工作空间或其业务对象。
- **触发**：系统执行权限判断。
- **系统行为**：教师操作的工作空间必须从已验证教师会话及服务端归属关系推导；客户端提交的教师标识、工作空间标识、所有者或角色字段不能单独构成授权依据。
- **异常结果**：可信归属不存在、不唯一或与目标对象不一致时默认拒绝，不使用客户端字段修补服务端归属。
- **验收条件**：篡改请求中的教师、工作空间或角色字段不能扩大权限；省略这些非必要客户端字段仍能按服务端关系完成合法操作。
- **关联要求**：`FR-AUTH-010`、`INT-API-*`、`SEC-ACCESS-*`、`DATA-WS-*`（待建立）

#### FR-WS-008：业务对象归属稳定且越权失败不产生副作用

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`、`SCOPE-09`；`SCN-ERR-01`、`SCN-ERR-02`
- **主要角色**：平台管理员、教师、支持人员
- **前置条件**：业务对象已经归属于一个工作空间，或系统正准备创建新对象。
- **触发**：对象被创建、读取、修改、导入、导出、恢复或迁移。
- **系统行为**：每个需要隔离的业务对象都必须能追溯到唯一工作空间；普通编辑不能改变归属；确需迁移时使用后续迁移需求规定的受控流程并留下记录。
- **异常结果**：归属缺失、重复、跨空间引用、迁移中断或权限不足时停止整个操作，不留下部分写入，不覆盖来源或目标空间的有效数据。
- **验收条件**：课程、课节、脚本、发布版本和授权均能追溯到一个工作空间；跨空间读写与引用被拒绝；失败前后两个空间的数据一致。
- **关联要求**：`DATA-WS-*`、`SEC-ACCESS-*`、`MIG-WS-*`、`NFR-REL-*`（待建立）

### 3.6 本功能域完成条件

1. 当前阶段每名教师只有一个工作空间，教师是唯一 Owner，不提供成员、助手或空间切换；
2. 管理员能够建立和维护教师与工作空间的关联，但普通管理操作不读取课程正文；
3. 教师只能查看和修改自己工作空间的数据，权限由服务端可信身份推导；
4. 学生不加入工作空间，只能通过有效授权取得允许的已发布课程包；
5. 登录、停用和恢复不会删除或重写工作空间业务数据；
6. 越权、归属损坏和跨空间引用失败时不泄露正文、不产生部分写入。

本功能域通过后，下一段进入 `FR-COURSE-*` 课程、课节与视频引用，不提前展开脚本制作。

## 4. 课程、课节与视频引用（`FR-COURSE-*`）

本功能域定义教师如何建立课程结构，以及学生最终能够识别什么课程和课节。互动节点、草稿和发布版本分别
留给 `FR-AUTHOR-*` 与 `FR-PUBLISH-*`；本节不把“保存课程结构”和“发布给学生”混成同一动作。

### 4.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 在受控支持时确认课程归属和状态是否正常 | 不代替教师创建、编辑、排序或归档课程与课节；不默认读取课程正文 |
| 教师 | 管理多门课程；管理每门课程的有序课节；为课节绑定准确视频引用；确认归档影响 | 不使用标题或视频标识代替课程、课节身份；不直接修改已发布历史版本 |
| 学生 | 在课程包中看到可理解的课程、课节名称和正确顺序；只在匹配视频中进入相应课节 | 不编辑教师课程结构；不使用内部 UUID 作为主要显示名称 |

### 4.2 教师职责：课程

#### FR-COURSE-001：教师管理多门独立课程

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`
- **主要角色**：教师
- **前置条件**：教师已进入自己的工作空间。
- **触发**：教师查看课程列表或创建新课程。
- **系统行为**：系统列出当前工作空间内的全部非归档课程，并允许创建多门课程；课程标题和描述作为可编辑信息，课程身份由系统独立建立。
- **异常结果**：标题为空、超过允许长度、保存失败或重复提交时，不产生无标题、重复写入或部分保存的课程；同名课程不得因名称相同而互相覆盖。
- **验收条件**：教师可以连续创建并看到多门课程；两门课程允许同名但拥有不同稳定标识；列表不包含其他工作空间课程。
- **关联要求**：`FR-WS-004`、`DATA-COURSE-*`、`INT-API-*`、`NFR-REL-*`（待建立）

#### FR-COURSE-002：教师编辑课程信息但不改变课程身份

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：目标课程属于教师当前工作空间且未归档。
- **触发**：教师修改课程标题、描述或其它已允许的课程级信息并保存。
- **系统行为**：系统保存合法修改并保留原课程标识、课节归属、草稿和发布历史；课程标题不作为唯一键或目录主键。
- **异常结果**：输入无效、并发冲突或保存失败时保留最后一个已确认版本，明确显示未保存或冲突状态，不静默覆盖较新的合法修改。
- **验收条件**：修改标题或描述后课程标识不变；原有课节仍属于该课程；刷新后只显示服务端已确认内容。
- **关联要求**：`DATA-COURSE-*`、`NFR-CONC-*`、`INT-API-*`（待建立）

#### FR-COURSE-003：教师归档课程并保留历史

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-04`；`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：目标课程属于教师工作空间，且影响范围可确认。
- **触发**：教师确认归档课程。
- **系统行为**：系统把课程标记为归档，使其退出正常课程列表，并停止该课程新的领取、重新下载和更新；课程结构、发布历史、授权历史和操作记录继续保留。
- **异常结果**：归档失败或请求重复时显示真实当前状态，不删除课程，不把归档伪装成授权码终止，也不承诺删除学生本机已有课程。
- **验收条件**：归档课程不再出现在正常课程列表；历史记录仍可追溯；新领取和更新被拒绝；学生机器上的已有副本不被远程删除。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`DATA-LIFE-*`、`SEC-LOG-*`（待建立）

### 4.3 教师职责：课节

#### FR-COURSE-004：教师建立和维护有序课节

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：课程属于教师当前工作空间且未归档。
- **触发**：教师新增、修改、排序或归档课节。
- **系统行为**：一门课程可以包含多个课节；每个课节具有标题、顺序、状态和视频引用；新增和排序后形成明确且无歧义的课程内顺序。
- **异常结果**：目标课程或课节越权、顺序冲突、输入无效或保存失败时，不留下重复顺序、孤立课节或部分重排结果。
- **验收条件**：教师可以建立多个课节并得到确定顺序；刷新后顺序一致；归档课节不进入新的课程交付，但历史引用继续保留。
- **关联要求**：`FR-WS-004`、`DATA-LESSON-*`、`NFR-CONC-*`（待建立）

#### FR-COURSE-005：课程交付前至少有一个有效课节

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-03`；`SCN-TCH-02`、`SCN-TCH-04`
- **主要角色**：教师
- **前置条件**：教师正在准备预览、发布或创建课程授权。
- **触发**：课程从可编辑结构进入交付前校验。
- **系统行为**：允许教师在创建过程暂时保存没有课节的课程草稿，但真实预览、发布和授权前必须至少存在一个未归档且视频引用有效的课节。
- **异常结果**：课程没有有效课节时拒绝进入交付流程，保留已有课程草稿，并指出需要补充或恢复的课节。
- **验收条件**：空课程可以作为未完成草稿存在；空课程或全部课节已归档的课程不能发布或创建有效授权；补充合法课节后可以重新校验。
- **关联要求**：`FR-PUBLISH-*`、`FR-GRANT-*`、`DATA-LESSON-*`（待建立）

#### FR-COURSE-006：课节身份不随标题、顺序或视频变化

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-STU-04`
- **主要角色**：教师、学生
- **前置条件**：课节已经建立并取得系统标识。
- **触发**：教师修改标题、调整顺序或在允许时更换视频引用。
- **系统行为**：系统保留原课节标识和课程归属；学生本机状态是否还能沿用，必须由稳定课节和节点标识及后续版本兼容规则共同判断，不能仅按顺序或视频标识猜测。
- **异常结果**：任何普通编辑都不得删除后重建课节来伪装更新；无法安全对应历史状态时必须明确标记不兼容，不静默挂到另一课节。
- **验收条件**：标题、顺序或视频引用改变后课节标识不变；课程标识也不变；历史发布记录仍指向原课节身份。
- **关联要求**：`FR-PUBLISH-*`、`FR-LIB-*`、`FR-LEARN-*`、`MIG-COURSE-*`（待建立）

### 4.4 教师职责：视频引用

#### FR-COURSE-007：每个课节绑定一个可精确匹配的视频引用

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-05`；`SCN-TCH-02`、`SCN-STU-02`
- **主要角色**：教师、学生
- **前置条件**：教师正在新增课节或更换课节视频。
- **触发**：教师提交视频链接或结构化视频引用。
- **系统行为**：系统只接受当前支持的视频来源，解析并回显足以精确匹配目标视频的结构化引用；当前阶段正式支持 B 站视频，视频引用不充当课程或课节标识。
- **异常结果**：链接无效、来源不支持、标识缺失、目标无法精确区分或解析失败时，不保存新绑定，也不覆盖原有效引用。
- **验收条件**：合法 B 站视频得到可复现的结构化引用；重新进入后引用一致；修改视频不会改变课程或课节标识；学生运行时可用同一引用判断是否匹配。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`DATA-VIDEO-*`、`NFR-COMPAT-*`（待建立）

#### FR-COURSE-008：视频重复规则以课程为边界

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`；`D-023`、`D-024`
- **主要角色**：教师
- **前置条件**：教师为课节建立或更换视频引用。
- **触发**：目标视频已经被某个课节引用。
- **系统行为**：同一课程内任意两个课节不得绑定同一 BVID；不同课程可以引用同一视频，并继续保持独立课程、课节、脚本和学习状态。
- **异常结果**：同一课程内发生重复时拒绝保存并保留原绑定；不得用全局唯一限制阻止另一个课程合法引用同一视频。
- **验收条件**：同一课程第二次绑定同一 BVID 失败；两个不同课程绑定同一 BVID 成功且标识不同；失败不会覆盖任一现有课节。
- **关联要求**：`DATA-VIDEO-*`、`FR-RUNTIME-*`、`SEC-ACCESS-*`（待建立）

### 4.5 学生职责与系统共同边界

#### FR-COURSE-009：课程包保留可理解的层级和顺序

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-04`；`SCN-STU-01`、`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：教师已经发布课程，学生正在领取或更新课程包。
- **触发**：系统生成并展示学生可用课程结构。
- **系统行为**：课程包保留课程、课节、视频引用和明确顺序；界面显示教师确认的课程与课节名称，同时内部继续使用稳定课程和课节标识关联数据。
- **异常结果**：结构缺少标识、课节顺序不确定、视频引用无效或范围裁剪后没有可交付课节时，拒绝安装新包并保留最后一个有效本机版本。
- **验收条件**：学生看到课程名称和有序课节，不以 UUID 作为主要名称；更新前后稳定课节能够正确对应；无效新包不覆盖现有课程。
- **关联要求**：`FR-PUBLISH-*`、`FR-GRANT-*`、`FR-LIB-*`、`DATA-PACKAGE-*`（待建立）

#### FR-COURSE-010：外部视频状态变化不删除课程结构

- **状态**：待审核
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-05`；`SCN-TCH-02`、`SCN-ERR-02`
- **主要角色**：教师、学生、支持人员
- **前置条件**：课节已经绑定外部视频。
- **触发**：视频被下架、改为不可访问、平台暂时故障或宿主标识规则变化。
- **系统行为**：系统区分“课程结构仍存在”和“外部视频当前不可用”，保留课程、课节、脚本和历史版本，并给出检查或更换视频引用的恢复路径。
- **异常结果**：外部视频失败不得触发课程、课节或学习状态删除；未验证的新视频引用不得静默替换原绑定。
- **验收条件**：视频不可用时教师仍能识别受影响课程和课节；学生得到视频不可用而非课程不存在的结果；恢复或受控更换后仍沿用原课程、课节标识。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`NFR-REL-*`、`OPS-SUPPORT-*`（待建立）

### 4.6 本功能域完成条件

1. 教师能够管理多门独立课程，每门课程能够管理多个有序课节；
2. 课程和课节身份由系统建立，不因标题、顺序或视频引用变化而改变；
3. 课程草稿可以暂时为空，但发布和授权前至少有一个有效课节；
4. 每个课节绑定一个可精确匹配的受支持视频引用；当前阶段正式支持 B 站；
5. 同一课程内不允许重复 BVID，不同课程可以合法复用同一视频；
6. 课程归档、视频不可用和外部平台故障都不删除历史结构或学生本机已有版本；
7. 学生课程包保留可理解的课程、课节名称和确定顺序，不使用内部 UUID 代替名称。

本功能域通过后，下一段进入 `FR-AUTHOR-*` 字幕与互动脚本制作。

## 5. 字幕与互动脚本制作（`FR-AUTHOR-*`）

本功能域只回答教师如何准备时间依据、制作节点并可靠保存脚本草稿。真实运行预览、发布版本生成和学生端执行
分别由后续 `FR-PUBLISH-*` 与 `FR-RUNTIME-*` 定义；保存草稿不等于预览成功或发布成功。

### 5.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 维护教师制作资格和必要的支持边界；在不读取正文时查看故障所需的状态与标识 | 不代替教师编写脚本；不因管理身份默认读取字幕、题目、答案或反馈正文 |
| 教师 | 为自己的课节准备可靠时间依据；创建、编辑、移动、复制、删除节点；检查校验结果；明确保存草稿 | 不编辑其他教师内容；不把页面临时状态当作已保存草稿；不以保存草稿代替真实预览和发布 |
| 学生 | 本功能域没有制作职责；后续只执行教师已发布且自己有权取得的版本 | 不读取脚本草稿、教师制作素材或未发布修改；不参与教师端字幕导入 |
| 系统 | 隔离工作空间和课节；校验字幕、触发和节点结构；保留最近一次已确认草稿；明确反馈保存状态 | 不静默修正教学语义；不把无效或未保存内容伪装成已确认草稿；不自动发布 |

### 5.2 教师职责：准备时间依据

#### FR-AUTHOR-001：教师为指定课节导入或选择可靠时间依据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师有权编辑目标课节；课节已经绑定有效视频引用；教师拥有合法可用的字幕、已确认时间点或等价依据。
- **触发**：教师打开目标课节并开始安排互动触发位置。
- **系统行为**：系统允许教师导入带时间信息的 SRT、VTT 字幕，或在没有字幕时使用已确认的视频时间；导入成功后按字幕句展示时间和文本，并始终标明当前依据属于哪个课节和视频。
- **异常结果**：文件格式错误、编码无法读取、没有有效字幕句、时间顺序非法或素材与目标视频无法确认时，不替换当前有效时间依据，并指出失败原因。
- **验收条件**：合法 SRT、VTT 均能形成可定位的字幕句；无字幕时仍可按合法视频时间创建节点；错误导入后原时间依据和已有草稿保持不变。
- **关联要求**：`DATA-SUBTITLE-*`、`INT-FILE-*`、`SEC-CONTENT-*`、`NFR-USABILITY-*`（待建立）

#### FR-AUTHOR-002：字幕全文默认只在教师本机用于制作

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-017`、`TERM-018`
- **主要角色**：教师、平台管理员
- **前置条件**：教师选择或导入了字幕文档。
- **触发**：系统解析、展示、引用或记录该字幕文档。
- **系统行为**：系统默认在教师本机解析和使用字幕全文；服务端草稿只保存教师明确写入节点的内容及必要引用，不因导入动作自动上传完整字幕文档，也不把字幕正文写入普通操作日志。
- **异常结果**：本机解析失败、页面刷新或教师移除本机字幕后，不得从服务端伪造“字幕仍已导入”的状态；未来若需要上传字幕，必须先形成独立、明确的需求和用户动作。
- **验收条件**：仅导入字幕而不编辑节点时，服务端草稿和普通日志中不存在字幕全文；教师能够辨认字幕是本机制作依据，而不是已发布课程内容。
- **关联要求**：`DATA-SUBTITLE-*`、`SEC-PRIVACY-*`、`SEC-LOG-*`、`INT-FILE-*`（待建立）

### 5.3 教师职责：建立和编辑互动节点

#### FR-AUTHOR-003：每个课节维护独立的当前脚本草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-019`、`TERM-020`
- **主要角色**：教师
- **前置条件**：教师有权编辑目标课节。
- **触发**：教师首次开始制作、重新进入课节或保存修改。
- **系统行为**：系统为每个课节维护一个可继续编辑的当前脚本草稿；草稿只能归属于该课节和其所在工作空间，重新进入时恢复最近一次服务端确认保存的内容。
- **异常结果**：课节不存在、已经归档、教师无权访问或草稿数据损坏时，拒绝加载为可编辑有效草稿，不得加载其它课节或其它工作空间内容顶替。
- **验收条件**：两个课节的草稿互不覆盖；退出后重新进入可以恢复已确认草稿；草稿状态与已发布版本明确区分。
- **关联要求**：`FR-WS-*`、`FR-PUBLISH-*`、`DATA-SCRIPT-*`、`SEC-ACCESS-*`（待建立）

#### FR-AUTHOR-004：教师能够完整管理节点生命周期

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-022`
- **主要角色**：教师
- **前置条件**：目标课节草稿已经可编辑。
- **触发**：教师添加、编辑、移动、复制或删除互动节点。
- **系统行为**：系统允许教师修改节点的触发位置、展示内容、学生动作、反馈和完成行为；移动保留节点身份，复制建立新节点身份，删除只影响被明确选择的节点；同一时间或同一字幕句允许存在多个不同节点。
- **异常结果**：操作目标已经不存在、修改结果无效或发生保存冲突时，不产生部分修改，也不把复制结果与原节点共用同一身份。
- **验收条件**：五类操作均有确定结果；移动前后节点标识不变；复制后标识不同；删除一个节点不影响同位置其它节点；重新加载后结果与已保存草稿一致。
- **关联要求**：`DATA-NODE-*`、`NFR-USABILITY-*`、`NFR-REL-*`（待建立）

#### FR-AUTHOR-005：提供四种基线节点及明确教学行为

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-023`
- **主要角色**：教师、学生
- **前置条件**：教师正在为课节添加或修改节点。
- **触发**：教师选择重点内容、选择题、填空题或问答题。
- **系统行为**：重点内容用于展示教师确认的信息且不要求作答；选择题要求教师提供可区分选项、正确答案和反馈；填空题要求教师提供可接受答案及反馈；问答题接收学生自由表达并展示教师预先编写的参考反馈，当前阶段不自动判定开放回答对错。这四种是 v1 基线，不构成永久封闭清单。
- **异常结果**：节点缺少该类型完成教学行为所需的题干、选项、答案或反馈时，不得标记为合法可发布节点；系统不得用默认文案静默补齐教师尚未确认的教学内容。
- **验收条件**：四种类型能够分别建立、保存和重新加载；每种类型只要求与自身行为有关的字段；问答题不产生虚假的自动对错结论。
- **关联要求**：`FR-RUNTIME-*`、`DATA-NODE-*`、`NFR-ACCESSIBILITY-*`（待建立）

#### FR-AUTHOR-006：节点具有稳定身份、合法触发和确定顺序

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-03`；`TERM-022`、`TERM-024`
- **主要角色**：教师、学生
- **前置条件**：教师创建节点或修改节点触发位置。
- **触发**：系统校验、保存、预览、发布或执行节点。
- **系统行为**：每个节点在所属课节内具有唯一稳定标识；当前核心触发依据为有限、非负且不超过目标视频有效时长的视频时间；节点按触发时间和稳定的次序规则排列，引用字幕句时同时保存可验证的字幕局部标识。
- **异常结果**：标识缺失或重复、时间非数字、为负、越过已知视频范围或字幕引用无效时，拒绝确认该修改，不把越界值自动吸附为另一个时间。
- **验收条件**：普通内容编辑和移动不会更换节点标识；相同时间的多个节点顺序可重复得到；无效触发无法保存为有效草稿或进入后续发布。
- **关联要求**：`FR-LEARN-*`、`FR-RUNTIME-*`、`DATA-NODE-*`、`INT-BILIBILI-*`（待建立）

#### FR-AUTHOR-007：节点校验不静默改变教学语义

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师编辑了一个或多个节点。
- **触发**：教师确认字段、保存草稿或进入后续预览与发布校验。
- **系统行为**：系统按节点类型校验必填内容、选项唯一性、答案与选项关系、可接受答案、反馈和完成行为，并把问题定位到具体节点和字段；校验只判断是否合法，不自行改写题目、答案或反馈。
- **异常结果**：任一节点结构无效时，不把不完整结果冒充已确认保存；不得通过删除未知字段、截断正文、替换答案或改变节点类型来使校验通过。
- **验收条件**：教师能够看到具体错误位置并修正后重试；错误内容不覆盖最近一次有效草稿；相同输入的校验结果一致。
- **关联要求**：`DATA-NODE-*`、`SEC-INPUT-*`、`NFR-USABILITY-*`（待建立）

### 5.4 系统共同职责：可靠保存与内容边界

#### FR-AUTHOR-008：明确区分页面修改、保存中和已确认草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师已经打开可编辑草稿。
- **触发**：教师修改内容、发起保存、离开页面或重新加载。
- **系统行为**：系统持续标明当前内容是未保存、保存中、已保存还是保存失败；只有服务端完整确认后才更新“已保存”状态，重新进入时恢复该最近确认版本。
- **异常结果**：网络失败、服务端拒绝、响应中断或页面存在未保存修改时，不得显示为已保存；教师离开可能丢失页面修改前必须得到明确提醒。
- **验收条件**：断网保存不会覆盖或丢失服务端最近有效草稿；恢复网络后可以重试；刷新后出现的是最近确认版本而非半次保存结果。
- **关联要求**：`DATA-SCRIPT-*`、`NFR-REL-*`、`NFR-USABILITY-*`（待建立）

#### FR-AUTHOR-009：并发修改不得静默互相覆盖

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：同一课节草稿可能在两个页面、两个会话或一次延迟重试中被修改。
- **触发**：系统收到基于旧草稿状态发起的保存。
- **系统行为**：系统识别该保存是否仍基于当前已确认草稿；发生冲突时保留服务端当前版本和待提交修改，向教师明确展示冲突并提供重新加载或受控重试路径。
- **异常结果**：旧页面、重复请求或延迟响应不得静默覆盖较新的已确认草稿；冲突处理不得自动拼接题目、答案或节点顺序。
- **验收条件**：两个页面依次修改同一草稿时，后到的过期保存得到冲突结果；教师能够恢复服务端版本并保留足够信息重新处理自己的修改。
- **关联要求**：`DATA-SCRIPT-*`、`INT-WEB-*`、`NFR-CONCURRENCY-*`、`NFR-REL-*`（待建立）

#### FR-AUTHOR-010：制作内容按数据处理且不能自动成为发布内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`OPEN-06`、`OPEN-07`
- **主要角色**：教师、平台管理员、学生
- **前置条件**：教师输入、粘贴、导入或由任何辅助能力生成节点内容。
- **触发**：系统保存、展示、记录或准备交付制作内容。
- **系统行为**：系统把字幕、题目、选项、答案和反馈作为内容数据处理，不执行其中夹带的脚本或可执行标记；所有内容都必须经过教师明确确认、保存和后续显式发布，任何导入或辅助生成动作都不能自动发布。
- **异常结果**：内容包含不可接受的可执行结构、教师无内容权利或无法确认来源时，拒绝进入可发布状态并保留安全的原草稿；管理员和学生不得因此获得草稿读取权限。
- **验收条件**：恶意标记只作为安全文本显示或被明确拒绝，不执行；未发布修改不出现在学生端；无论 `OPEN-06` 最终是否纳入 AI 辅助，人工制作和教师确认链路都能独立成立。
- **关联要求**：`FR-PUBLISH-*`、`DATA-CONTENT-*`、`SEC-CONTENT-*`、`SEC-ACCESS-*`（待建立）

#### FR-AUTHOR-011：所有节点类型遵守统一管理契约

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-022`、`TERM-023`
- **主要角色**：教师、学生、平台管理员
- **前置条件**：系统提供四种基线节点，或后续增加新的节点类型。
- **触发**：节点类型被启用、停用、创建、编辑、保存、预览、发布、执行、导入或导出。
- **系统行为**：所有节点类型共同遵守节点身份、工作空间权限、草稿与发布隔离、结构校验、版本追踪和内容安全规则；每种类型另外声明自身的内容结构、学生动作、反馈、完成规则及兼容范围。新增类型必须接入同一管理入口和生命周期，不能形成绕过公共规则的独立旁路。
- **异常结果**：类型未知、定义缺失、版本不兼容或未完成公共能力接入时，系统不得把它误当成其它类型、静默丢弃其数据或允许其进入发布；已有草稿和发布版本保持可识别、可恢复。
- **验收条件**：四种基线类型通过同一组公共生命周期检查；增加一个测试类型时无需复制账号、权限、草稿、发布和安全流程；不支持该类型的运行环境给出明确不兼容结果而不是错误执行。
- **关联要求**：`FR-PUBLISH-*`、`FR-RUNTIME-*`、`FR-PORT-*`、`DATA-NODE-*`、`MIG-NODE-*`（待建立）

### 5.5 本功能域完成条件

1. 教师能够为指定课节使用合法 SRT、VTT 或已确认视频时间作为制作依据，错误导入不覆盖现有内容；
2. 字幕全文默认在教师本机处理，不因导入自动进入服务端草稿、课程包或普通日志；
3. 每个课节具有独立当前草稿，教师能够添加、编辑、移动、复制和删除具有稳定身份的节点；
4. 重点内容、选择题、填空题和问答题具有不同且可验收的教学行为，四种基线类型及后续新增类型遵守统一管理契约；
5. 节点触发、结构、答案和反馈得到明确校验，系统不静默修正教学语义；
6. 页面修改、保存中、保存失败和服务端已确认草稿可以区分，失败与并发冲突不覆盖最近有效版本；
7. 制作内容不会被执行为代码，也不会因导入、辅助生成或保存草稿而自动发布给学生。

本功能域通过后，下一段进入 `FR-PUBLISH-*` 真实预览、发布与版本。

## 6. 真实预览、发布与版本（`FR-PUBLISH-*`）

本功能域把页面内静态示意、教师真实预览、保存草稿和正式发布分成四种不同结果。发布对象是整门课程在某一
时刻的可交付快照；课节、脚本和课程包内部如何存储留给设计文档，但任何实现都不能让学生取得半次发布结果。

### 6.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 维护教师发布资格；查看不含课程正文的发布状态、操作者、时间和失败标识 | 不代替教师预览或发布；不因管理身份默认读取草稿、发布正文或学生预览回答 |
| 教师 | 选择自己的已保存草稿；通过学生真实路径检查变化；确认发布影响；识别当前草稿、预览对象和最新发布版本 | 不发布其他工作空间课程；不把静态示意当真实预览；不把保存成功当发布成功 |
| 学生 | 只领取有权取得的正式发布版本；继续保留本机已安装版本，直到合法更新成功 | 不读取教师草稿、预览数据或发布中的临时状态；不接收部分发布版本 |
| 系统 | 锁定预览对象；隔离预览数据；发布前完整校验；原子生成不可混淆版本；保留历史版本和审计事实 | 不从页面未保存状态发布；不静默覆盖历史版本；不把发布失败显示为成功 |

### 6.2 教师职责：真实预览

#### FR-PUBLISH-001：真实预览使用学生正式交付路径

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-TCH-04`；`TERM-026`、`TERM-027`
- **主要角色**：教师
- **前置条件**：目标课节已保存合法草稿；受支持的学生运行环境可用；目标视频引用仍有效。
- **触发**：教师对指定课节和草稿发起真实预览。
- **系统行为**：系统把指定的已保存草稿送入与学生正式交付相同的课程包解释、视频匹配、触发、暂停、作答、反馈和继续学习路径，并持续标明当前处于教师预览。
- **异常结果**：只能展示静态界面、运行环境缺失、视频不匹配、草稿不兼容或真实触发失败时，不得显示为预览通过，也不得降级为静态示意后继续冒用“真实预览”名称。
- **验收条件**：教师在受支持视频原页面看到节点按真实时间触发并完整作答；预览与学生运行使用同一节点内容和行为规则；静态示意具有不同名称和状态。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`INT-EXTENSION-*`、`NFR-COMPAT-*`（待建立）

#### FR-PUBLISH-002：每次预览锁定可识别的已保存草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`、`SCN-TCH-04`
- **主要角色**：教师
- **前置条件**：教师页面可能同时存在已保存草稿和未保存修改。
- **触发**：教师启动预览或在预览期间继续修改草稿。
- **系统行为**：系统为每次预览建立唯一预览会话，并记录课程、课节、草稿修订和开始时间；该会话始终运行启动时锁定的已保存内容，之后的页面修改只在重新保存并重启预览后生效。
- **异常结果**：草稿已经改变、预览会话过期或运行端收到另一课程内容时，明确标记预览已过期或不匹配，不把混合状态继续作为有效预览。
- **验收条件**：预览启动后修改页面不会改变正在运行的预览；教师能识别预览对应哪次已保存内容；重新保存并预览会建立新会话。
- **关联要求**：`DATA-PREVIEW-*`、`INT-BRIDGE-*`、`NFR-CONCURRENCY-*`（待建立）

#### FR-PUBLISH-003：预览活动与学生真实学习状态隔离

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-04`
- **主要角色**：教师、学生
- **前置条件**：教师正在运行、重复或结束真实预览。
- **触发**：预览中产生节点打开、回答、完成、跳过、关闭或错误状态。
- **系统行为**：系统把全部预览活动标记为教师预览数据，只供本次预览检查；每次新预览从独立初始状态开始，不写入学生本机学习状态、领取结果或未来教师真实学习证据。
- **异常结果**：无法确认会话类型、课程身份或草稿修订时，停止记录和执行，不得把未知活动归入学生数据。
- **验收条件**：教师可在预览中多次作答且不改变任何学生状态；开始新预览时节点恢复初始状态；未来报表和课程完成情况不包含预览活动。
- **关联要求**：`FR-LEARN-*`、`FR-REPORT-*`、`DATA-PREVIEW-*`、`SEC-PRIVACY-*`（待建立）

#### FR-PUBLISH-004：预览失败提供可恢复且不过度泄露的结果

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-TCH-04`、`SCN-ERR-02`
- **主要角色**：教师、支持人员
- **前置条件**：预览依赖教师页面、扩展、宿主视频和已保存草稿共同工作。
- **触发**：任一环节缺失、版本不兼容、响应超时或宿主页面变化。
- **系统行为**：系统区分未安装或未连接、版本不兼容、课程不匹配、视频不可用、草稿无效和运行时失败，并提供重新保存、重新连接、更新运行环境或检查视频的对应恢复动作和支持标识。
- **异常结果**：不得无限等待、反复自动打开页面、清空草稿或暴露凭证、课程正文、字幕全文和学生回答到普通日志。
- **验收条件**：每类故障都有稳定错误类别和可执行下一步；恢复条件满足后能够重新启动新预览；原草稿和最近发布版本不变。
- **关联要求**：`INT-BRIDGE-*`、`NFR-REL-*`、`NFR-OBS-*`、`SEC-LOG-*`（待建立）

### 6.3 教师职责：正式发布

#### FR-PUBLISH-005：发布前校验整门课程的交付完整性

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-03`；`SCN-TCH-04`；`FR-COURSE-005`
- **主要角色**：教师
- **前置条件**：教师准备发布自己的课程。
- **触发**：教师进入发布检查或提交发布。
- **系统行为**：系统使用服务端最近确认的课程、课节和脚本草稿进行完整校验；课程必须至少有一个未归档课节，所有未归档课节都必须具备有效视频引用、非空合法脚本和对该脚本的最近一次成功真实预览。
- **异常结果**：存在空课程、未完成课节、无效视频、空脚本、无效节点、过期预览或不兼容数据时，整体拒绝发布，列出受影响课节且不改变既有发布版本。
- **验收条件**：任一未归档课节不合格都会阻止整门课程发布；教师完成或归档该课节并对最终草稿重新预览后可以再次校验；页面未保存修改不进入发布内容。
- **关联要求**：`FR-COURSE-*`、`FR-AUTHOR-*`、`DATA-PACKAGE-*`、`NFR-COMPAT-*`（待建立）

#### FR-PUBLISH-006：教师通过显式确认发布整门课程

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-04`、`SCN-TCH-06`；`TERM-028`
- **主要角色**：教师
- **前置条件**：发布前校验已经针对当前服务端草稿通过；教师有权发布该课程。
- **触发**：教师查看将发布的课程、课节和草稿修订后明确确认发布。
- **系统行为**：系统在一个不可分割的发布动作中锁定全部未归档课节，生成整门课程的发布快照，并在全部写入成功后才把新版本标记为可交付。
- **异常结果**：教师取消、权限改变、草稿在确认后发生变化、重复提交或任一步骤失败时，不产生半发布课程，不改变学生当前可取得的最新成功版本。
- **验收条件**：成功结果包含课程和新发布版本；所有纳入课节来自同一次快照；故障注入到任一课节时没有课节单独进入新版本。
- **关联要求**：`FR-WS-*`、`DATA-PUBLISH-*`、`NFR-TRANSACTION-*`、`SEC-ACCESS-*`（待建立）

#### FR-PUBLISH-007：发布版本唯一、不可变且可以追溯

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-04`、`SCN-TCH-06`；`TERM-029`
- **主要角色**：教师、学生、支持人员
- **前置条件**：一次课程发布成功。
- **触发**：系统保存、展示、下载、更新或追查该发布结果。
- **系统行为**：系统为课程快照分配在该课程内唯一且单调前进的发布版本，并记录课程、纳入课节、脚本修订、课程包 Schema 版本、发布者和发布时间；成功版本形成后不可原地修改。
- **异常结果**：版本号冲突、快照引用缺失或历史内容损坏时，不得复用版本号、回填猜测内容或把损坏版本设为最新可交付版本。
- **验收条件**：连续两次成功发布得到两个不同版本；旧版本内容保持不变；任一已安装课程和未来学习证据都能指回当时使用的确切课程发布版本。
- **关联要求**：`DATA-PUBLISH-*`、`DATA-PACKAGE-*`、`MIG-VERSION-*`、`NFR-REL-*`（待建立）

#### FR-PUBLISH-008：草稿修改不改变任何已发布版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-04`；`SCN-TCH-03`、`SCN-TCH-06`
- **主要角色**：教师、学生
- **前置条件**：课程至少已经成功发布一次。
- **触发**：教师继续修改、保存或预览课程草稿。
- **系统行为**：系统把后续草稿与最新发布版本分开维护；只有再次显式发布成功后，新的发布版本才可供有更新资格的学生取得，已经安装的旧版本继续保持原内容。
- **异常结果**：草稿保存失败、预览失败或新发布失败时，不得修改、撤回或重新标记此前成功版本，也不得向学生下发部分草稿。
- **验收条件**：发布 v1 后修改草稿，学生仍只能取得 v1；发布 v2 成功后符合资格的学生可取得 v2；设备上的 v1 只在合法更新完成后被替换。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`DATA-PUBLISH-*`、`MIG-VERSION-*`（待建立）

#### FR-PUBLISH-009：重复和并发发布不会制造重复或倒退版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-04`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：相同课程可能收到双击、网络重试、两个页面或延迟响应产生的多个发布请求。
- **触发**：系统处理相同发布意图或基于不同草稿修订的并发请求。
- **系统行为**：同一发布意图的重复请求返回同一最终结果，不重复创建版本；不同草稿修订的并发发布按明确次序处理，过期请求得到冲突结果并要求教师重新确认最新草稿。
- **异常结果**：不得出现相同版本号对应不同内容、一次确认跳增多个版本、较旧草稿晚到后成为最新版本或页面把旧响应显示成新成功。
- **验收条件**：重复提交只生成一个版本；两个页面发布不同修订时最多一个按原确认成功，另一个明确冲突；版本序列不重复、不倒退。
- **关联要求**：`DATA-PUBLISH-*`、`INT-WEB-*`、`NFR-CONCURRENCY-*`、`NFR-REL-*`（待建立）

### 6.4 系统共同职责：课程包与发布记录

#### FR-PUBLISH-010：发布快照生成完整且最小的课程包

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-04`；`SCN-TCH-04`、`SCN-STU-01`；`TERM-030`、`TERM-031`
- **主要角色**：教师、学生
- **前置条件**：整门课程发布事务准备生成可交付快照。
- **触发**：系统构建并校验课程发布版本。
- **系统行为**：课程包包含可解释其结构的 Schema 版本、课程发布版本、稳定课程和课节标识、有序课节、视频引用、节点及运行所需规则；不包含第三方视频文件、完整字幕文档、密码、会话、授权码原文、教师页面状态或预览记录。
- **异常结果**：必需字段缺失、标识冲突、顺序不确定、Schema 不受支持或出现禁止数据时，整体拒绝发布，不把无法解释的包标记为可下载。
- **验收条件**：合法课程包能够独立通过契约校验并由受支持运行时解释；相同发布版本对应不变内容；对包进行字段检查不出现禁止数据。
- **关联要求**：`FR-GRANT-*`、`FR-RUNTIME-*`、`DATA-PACKAGE-*`、`INT-PACKAGE-*`、`SEC-DATA-*`（待建立）

#### FR-PUBLISH-011：发布结果与高风险操作可审计

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-TCH-04`、`SCN-ERR-01`
- **主要角色**：教师、平台管理员、支持人员
- **前置条件**：教师发起发布，或发布校验、事务和交付状态发生变化。
- **触发**：发布成功、失败、冲突或被拒绝。
- **系统行为**：系统向教师显示明确结果，并记录最小审计事实，包括操作者、课程、目标草稿修订、结果、发布版本或稳定错误类别及发生时间。
- **异常结果**：审计写入失败时按后续安全与运维要求决定是否阻止高风险动作；无论何种结果，日志不得包含密码、会话、授权码原文、完整字幕、节点正文或学生回答。
- **验收条件**：教师能区分成功、失败和冲突；支持人员能用不含正文的标识定位一次发布；成功记录能对应唯一发布版本，失败记录不伪造版本。
- **关联要求**：`FR-ADMIN-*`、`DATA-AUDIT-*`、`SEC-AUDIT-*`、`SEC-LOG-*`、`OPS-SUPPORT-*`（待建立）

### 6.5 本功能域完成条件

1. 教师可以对已保存草稿启动走学生正式交付路径的真实预览，静态示意不能冒充真实预览；
2. 每次预览锁定唯一草稿修订，之后的页面修改不会混入当前预览；
3. 预览活动与学生学习状态、领取结果及未来教师报表完全隔离；
4. 所有未归档课节的最终草稿都通过真实预览和完整校验后，教师才能显式发布整门课程；
5. 一次发布要么生成完整课程快照，要么完全失败，不产生部分发布课节；
6. 每个课程发布版本唯一、不可变、可追溯，草稿修改不改变已有版本；
7. 重复或并发发布不产生重复、倒退或内容混淆的版本；
8. 课程包包含运行所需的最小版本化数据，不包含视频文件、完整字幕、凭证、预览记录或页面临时状态；
9. 发布成功、失败和冲突都可由最小审计事实定位，同时不记录课程正文和敏感数据。
