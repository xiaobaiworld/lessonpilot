## 1. 功能分解与编号骨架

功能需求回答“系统必须提供什么可观察行为”，不规定数据库、API、组件、框架或部署方式。追踪链固定为：

```text
GOAL / SUCCESS
  -> SCOPE
  -> SCN
  -> FR
  -> 设计
  -> 代码
  -> 自动化测试与人工验收证据
```

每条正式功能需求必须包含：稳定编号、状态、优先级、来源场景、前置条件、行为规则、异常结果、
可观察验收条件，以及涉及的数据、安全、接口或非功能需求引用。缺少异常结果或验收条件的条目只能是笔记，
不能标记为已接受需求。

### 1.2 单条需求模板

```markdown
#### FR-<DOMAIN>-<NNN>：<可观察行为标题>

- 状态：待审核 / 已接受 / 需修改 / 已否决 / 已替代
- 优先级：P0 / P1 / P2
- 来源：SCOPE-*；SCN-*
- 主要角色：明确角色
- 前置条件：动作发生前必须为真的事实
- 触发：由谁在什么情况下发起
- 系统行为：必须发生的业务行为和状态变化
- 异常结果：拒绝、失败、超时、冲突和重试时的结果
- 验收条件：用户或测试能够观察和检查的结果
- 关联要求：DATA-* / INT-* / NFR-* / SEC-* / OPS-* / MIG-*
```

优先级含义：

- `P0`：没有它就无法形成已接受的 v1 核心闭环，或会造成安全、数据完整性、权限、迁移和恢复风险；
- `P1`：v1 应交付的重要行为，但不直接阻断最小核心闭环；
- `P2`：体验增强、运营效率或可以在闭环成立后补充的能力。

优先级不是实现顺序。实现顺序由依赖、风险和验证成本决定，并在开发计划中记录。

### 1.3 补充场景与需求变更规则

1. 整理某个功能域时，如果发现 `03-user-scenarios.md` 没有承接其角色目标、异常分支或恢复路径，
   必须先新增或修订 `SCN-*`，再创建对应 `FR-*`。
2. 一条 `FR-*` 可以服务多个场景，一个场景也可以拆成多条功能需求；不得为了追求一一对应而复制需求。
3. 相同业务行为只保留一个权威 `FR-*`，其它场景通过引用复用；界面差异不能制造多个事实源。
4. 已接受需求发生语义变化时新增替代记录，不覆盖原结论或复用编号。
5. 需求被拆分时，原编号标记“已替代”，并列出全部新编号；合并时同样保留来源编号。
6. 功能要求不能把开放问题伪装成默认答案。受 `OPEN-*` 影响的条目标记阻塞或保留方案分支。
7. 每完成一个功能域，都要检查正常、边界、异常、重复操作、并发、恢复和权限隔离场景。

### 1.4 建议审核顺序

按业务依赖先审核身份与工作空间，再审核课程制作、发布、授权、学生运行、本机学习状态和运营恢复：

```text
FR-AUTH
  -> FR-WS
  -> FR-COURSE
  -> FR-AUTHOR
  -> FR-PUBLISH
  -> FR-GRANT
  -> FR-LIB
  -> FR-RUNTIME
  -> FR-LEARN
  -> FR-ADMIN
  -> FR-PORT
```

`FR-REPORT` 已按 `D-026` 移到后续阶段，不进入当前审核序列。该顺序只控制需求审核，不代表最终模块依赖
或代码目录结构。

## 2. 身份认证与会话（`FR-AUTH-*`）

本功能域按角色职责组织：先说明每个角色为了完成当前工作必须具备什么能力，再列出系统必须共同保证的
隔离和失败边界。密码算法、会话载体、Cookie 属性和限流数值留给后续安全、接口与设计文档。

### 2.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 登录管理入口；创建教师用户名和密码；重置教师密码；停用或恢复教师登录资格 | 不代替教师编辑课程；不查询教师现有密码；不因管理身份默认读取课程正文 |
| 教师 | 使用用户名和密码登录；进入自己的工作空间；退出；重新登录后继续使用已保存课程 | 不自行注册；不管理其他教师账号；不因会话结束丢失课程数据 |
| 学生 | 在当前机器建立本机学习标识；保存课程和学习状态；换机后重新下载课程 | 不注册或登录；不上传个人学习数据；不跨设备恢复或合并学习状态 |

### 2.2 平台管理员职责

#### FR-AUTH-001：管理员登录和退出管理入口

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-ADM-04`、`SCN-ERR-01`
- **主要角色**：平台管理员
- **前置条件**：管理员账号已经通过受控方式建立且允许登录。
- **触发**：管理员进入管理入口、恢复已有会话或主动退出。
- **系统行为**：正确验证管理员用户名和密码后建立或恢复管理员会话；退出后立即结束当前管理员会话。
- **异常结果**：用户名或密码错误、账号不可用、会话过期时不得进入管理能力，也不得泄露账号是否存在。
- **验收条件**：有效管理员可以登录和恢复会话；退出、过期或撤销后，同一会话不能继续执行管理操作。
- **关联要求**：`SEC-AUTH-*`、`SEC-ACCESS-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-002：管理员创建教师用户名和密码

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-01`
- **主要角色**：平台管理员
- **前置条件**：管理员已经登录，并确认需要接入的教师及其登录名。
- **触发**：管理员创建教师账号。
- **系统行为**：系统创建唯一教师用户名和可直接使用的密码，同时建立教师进入业务所需的基本归属；当前阶段不开放教师自行注册。
- **异常结果**：用户名重复、输入无效或创建失败时，不留下无法登录或没有业务归属的半成品教师账号。
- **验收条件**：教师可以直接使用管理员交付的用户名和密码登录；不要求首次登录后再次修改密码；未受邀请者不能自行注册教师账号。
- **关联要求**：`FR-ADMIN-*`、`FR-WS-*`、`DATA-ACCOUNT-*`、`SEC-AUTH-*`（待建立）

#### FR-AUTH-003：管理员重置或停止教师登录资格

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-02`、`SCN-ADM-05`
- **主要角色**：平台管理员
- **前置条件**：目标教师账号存在，管理员有权操作该账号。
- **触发**：教师遗失密码，或管理员决定重置密码、停用或恢复教师账号。
- **系统行为**：重置后新密码可直接登录，旧密码和该教师全部旧会话失效；停用后拒绝新登录和旧会话；恢复后允许教师用当前有效密码重新登录。
- **异常结果**：目标不存在、操作失败或并发冲突时，不显示假成功；重置停用账号不会自动恢复账号状态。
- **验收条件**：密码重置后只有新密码可用；停用后新旧会话均不可用；恢复后必须重新登录；所有操作都不删除教师已保存的课程等业务数据。
- **关联要求**：`FR-ADMIN-*`、`DATA-LIFE-*`、`SEC-AUTH-*`、`SEC-LOG-*`（待建立）

### 2.3 教师职责

#### FR-AUTH-004：教师使用用户名和密码登录

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：教师
- **前置条件**：管理员已经创建教师账号，账号当前允许登录。
- **触发**：教师提交自己的用户名和密码。
- **系统行为**：验证成功后建立教师会话，并把教师带到自己有权使用的工作入口。
- **异常结果**：用户名或密码错误、账号停用或服务不可用时不建立会话，不泄露账号是否存在或停用。
- **验收条件**：有效教师可以登录；错误、未知或停用账号不能登录；教师登录不会获得管理员身份。
- **关联要求**：`FR-WS-*`、`SEC-AUTH-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-005：教师恢复会话和主动退出

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`；`SCN-TCH-01`
- **主要角色**：教师
- **前置条件**：教师可能持有一个已有会话。
- **触发**：教师重新打开工作台、访问受保护功能或主动退出。
- **系统行为**：仍有效的会话可以恢复；退出、过期、撤销或账号停用后的会话不能继续访问教师功能。
- **异常结果**：会话失效时要求重新登录，不清空已经确认保存的课程，也不把当前无法访问显示为数据已删除。
- **验收条件**：有效会话刷新后仍可使用；退出后同一会话立即不可用；重新登录会建立新的有效会话。
- **关联要求**：`NFR-REL-*`、`SEC-AUTH-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-006：教师会话结束后保留业务数据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-TCH-02`
- **主要角色**：教师
- **前置条件**：教师已经确认保存课程、课节、草稿、发布版本或授权等业务数据。
- **触发**：教师退出、会话过期、密码被重置、账号被停用或之后重新登录。
- **系统行为**：认证状态只决定当前能否访问，不承担业务数据存储；会话变化不得删除、覆盖或重新创建已保存业务数据。
- **异常结果**：暂时无法重新认证时继续保留业务数据；未确认保存的页面临时输入不得伪装为服务端已保存。
- **验收条件**：保存课程后退出再登录，课程及其稳定标识保持不变；密码重置、会话过期或账号停用同样不删除课程。
- **关联要求**：`FR-WS-*`、`DATA-LIFE-*`、`NFR-REL-*`（待建立）

### 2.4 学生职责

#### FR-AUTH-007：学生在当前机器使用本机学习标识

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-06`；`SCN-STU-01`、`SCN-STU-03`；`D-026`
- **主要角色**：学生
- **前置条件**：学生首次或再次在当前机器使用受支持的 KnownMap 运行时。
- **触发**：学生领取课程或重新打开已有课程。
- **系统行为**：运行时在当前机器建立或恢复本机学习标识，用它关联本机课程、领取结果和学习状态；不要求学生注册、登录或提供真实身份信息。
- **异常结果**：本机标识损坏或本地存储不可用时，不把其它机器或其它本地上下文的数据自动归入当前标识。
- **验收条件**：同一机器和同一受支持存储上下文能够恢复相同标识及本地数据；本机标识不能进入管理员或教师权限。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`DATA-IDENTITY-*`（待建立）

#### FR-AUTH-008：学生在本机保存并恢复课程数据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-01`、`SCN-STU-03`
- **主要角色**：学生
- **前置条件**：课程已经成功下载到当前机器。
- **触发**：学生关闭并重新打开浏览器或运行时，或在暂时断网时继续学习。
- **系统行为**：当前机器保存课程包和学习状态；重新打开后按本机学习标识恢复；不依赖教师或管理员登录会话保存学生数据。
- **异常结果**：本地保存失败或数据损坏时显示真实错误并保留最后一个可确认状态，不声称数据已经上传或能够云端恢复。
- **验收条件**：同一机器重新打开后课程和已保存学习状态仍存在；教师或管理员退出不影响学生本机课程。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`DATA-LOCAL-*`、`NFR-REL-*`（待建立）

#### FR-AUTH-009：学生换机后重新下载课程

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-STU-01`、`SCN-STU-04`；`D-026`
- **主要角色**：学生
- **前置条件**：学生换用另一台机器，且仍持有可用于重新领取的有效授权。
- **触发**：学生在新机器输入授权码并下载课程。
- **系统行为**：新机器建立新的本机学习标识并保存独立课程副本；当前阶段不查找、恢复或合并原机器学习状态。
- **异常结果**：授权已经失效时拒绝重新下载，不声称服务端保存了原机器数据，也不伪造跨设备连续性。
- **验收条件**：有效授权可在规则允许时重新下载课程；新机器从新的本机状态开始；界面不承诺云同步、换机恢复或账号找回。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`MIG-IDENTITY-*`（待建立）

### 2.5 系统共同边界

#### FR-AUTH-010：三类角色和身份相互隔离

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-06`、`SCOPE-08`；`SCN-ADM-04`、`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师、学生
- **前置条件**：请求可能携带管理员会话、教师会话、本机学习标识或没有任何身份信息。
- **触发**：任一角色访问需要身份或权限的能力。
- **系统行为**：管理员会话只用于管理能力，教师会话只用于教师能力，本机学习标识只关联学生本机数据；任何一种都不能自动换取另一种权限。
- **异常结果**：身份缺失、类型错误、过期或权限不足时拒绝操作，不降级为其它角色，也不返回越权数据。
- **验收条件**：教师会话不能执行管理操作；本机学习标识不能访问教师或管理入口；管理员登录不会同时建立教师会话。
- **关联要求**：`FR-WS-*`、`SEC-ACCESS-*`、`INT-WEB-*`（待建立）

#### FR-AUTH-011：认证失败安全且可以恢复

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-04`、`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师
- **前置条件**：管理员或教师认证入口可访问。
- **触发**：凭证错误、重复尝试、会话失效或认证服务失败。
- **系统行为**：返回一致且可理解的失败结果；限制短时间内的重复认证尝试；允许合法用户在限制解除或服务恢复后重试。
- **异常结果**：错误信息不得泄露账号是否存在，不记录密码、会话原文或完整认证请求，也不得因认证失败删除业务数据。
- **验收条件**：错误账号和错误密码得到不便于枚举账号的结果；超过后续安全要求规定的阈值会受限；恢复后合法账号可以再次登录。
- **关联要求**：`SEC-AUTH-*`、`SEC-LOG-*`、`NFR-AVAIL-*`、`OPS-MON-*`（待建立）

### 2.6 本功能域完成条件

1. 管理员能够登录，并完成教师用户名和密码的创建、重置、停用与恢复；
2. 教师能够使用用户名和密码登录、退出，并在重新登录后继续使用已保存课程；
3. 学生无需账号，只使用本机学习标识保存当前机器上的课程和学习状态；
4. 换机后重新下载课程，不恢复原机器数据；
5. 三类角色不能互相替代或越权；认证失败不删除课程等业务数据；
6. 学习数据上传、教师学习证据和跨设备同步不进入当前阶段。

本功能域通过后，下一段进入 `FR-WS-*` 工作空间与权限边界，不提前展开课程功能。

## 3. 工作空间与权限边界（`FR-WS-*`）

工作空间是教师业务数据的归属与隔离边界，不是一个页面、登录会话或本地文件夹。本功能域只确定谁拥有、
谁能进入、系统如何判断归属，以及越权时必须发生什么；课程内部如何创建和编辑留给 `FR-COURSE-*`。

### 3.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 创建教师时建立其工作空间；维护教师账号与工作空间的有效关联；在授权支持时处理恢复 | 不代替教师编辑课程；不因管理员身份默认读取课程正文；不直接改库绕过归属规则 |
| 教师 | 登录后进入自己的唯一工作空间；管理该空间内有权操作的业务对象 | 不切换或加入其他工作空间；不查看、修改或引用其他教师的数据 |
| 学生 | 通过有效授权取得允许的课程包，并在本机使用 | 不加入教师工作空间；不访问教师工作台；授权码不产生工作空间成员资格 |

### 3.2 平台管理员职责

#### FR-WS-001：创建教师时建立唯一工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-ADM-01`
- **主要角色**：平台管理员
- **前置条件**：管理员正在通过受控流程创建一名教师。
- **触发**：教师账号创建成功。
- **系统行为**：系统同时为教师建立一个独立工作空间，并把该教师设为当前唯一所有者；账号与工作空间必须作为一个完整接入结果交付。
- **异常结果**：工作空间建立失败时，教师接入不得显示为完整成功，也不得留下可以登录但没有业务归属的半成品状态；重复请求不得创建第二个当前工作空间。
- **验收条件**：新教师首次登录即可进入自己的工作空间；同一教师重复初始化仍只有一个当前工作空间；其他教师拥有不同的工作空间标识。
- **关联要求**：`FR-AUTH-002`、`FR-ADMIN-*`、`DATA-WS-*`、`NFR-REL-*`（待建立）

#### FR-WS-002：管理员维护归属但不默认读取业务正文

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-08`；`SCN-ADM-02`、`SCN-ADM-03`
- **主要角色**：平台管理员、支持人员
- **前置条件**：教师及其工作空间已经存在。
- **触发**：管理员停用或恢复教师，查看必要运营状态，或处理明确的支持与恢复请求。
- **系统行为**：系统允许管理员查看完成账号管理所需的最小摘要，并维护教师与工作空间的有效关联；读取课程正文或执行恢复操作必须经过额外的明确授权和审计路径。
- **异常结果**：普通账号管理不得顺带返回课程正文、脚本内容、学生本机数据或密码；没有明确支持授权时拒绝扩大读取范围。
- **验收条件**：管理员可以确认教师、工作空间和必要状态是否存在；普通列表和状态操作不返回课程正文；受控恢复能够留下操作者、对象、时间和结果。
- **关联要求**：`FR-ADMIN-*`、`SEC-ACCESS-*`、`SEC-LOG-*`、`DATA-CLASS-*`（待建立）

### 3.3 教师职责

#### FR-WS-003：教师登录后进入自己的唯一工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`
- **主要角色**：教师
- **前置条件**：教师已经登录，账号与工作空间关联有效。
- **触发**：教师打开工作台或重新登录。
- **系统行为**：系统自动进入该教师当前唯一工作空间，恢复其有权看到的工作上下文；当前阶段不显示工作空间选择、创建、加入或切换入口。
- **异常结果**：关联缺失、重复或损坏时停止进入业务功能，保留已有数据并给出可追踪的支持错误；不得临时创建第二个空间掩盖问题。
- **验收条件**：教师每次登录进入同一工作空间；刷新或重新登录后工作空间标识不变；界面没有不可用的多工作空间入口。
- **关联要求**：`FR-AUTH-004`、`FR-AUTH-006`、`NFR-REL-*`、`OPS-SUPPORT-*`（待建立）

#### FR-WS-004：教师只管理自己工作空间内的对象

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：教师
- **前置条件**：教师已进入自己的工作空间。
- **触发**：教师查看列表、打开对象，或发起创建、修改、发布、归档、授权和导出等操作。
- **系统行为**：只返回和修改归属于当前工作空间的业务对象；新对象自动归入当前工作空间，不能由教师在请求中指定为其他空间。
- **异常结果**：对象属于其他空间、不存在或归属无法确认时拒绝操作，不返回正文，不改变任何对象，也不通过差异化错误泄露对象是否存在。
- **验收条件**：教师列表中只出现自己空间的数据；使用其他教师的对象标识执行读写均失败；失败后双方数据保持不变。
- **关联要求**：`FR-COURSE-*`、`FR-AUTHOR-*`、`FR-PUBLISH-*`、`FR-GRANT-*`、`FR-PORT-*`、`SEC-ACCESS-*`（待建立）

#### FR-WS-005：教师账号停用不删除工作空间数据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-ADM-02`、`SCN-TCH-06`
- **主要角色**：平台管理员、教师
- **前置条件**：工作空间内已经有课程、发布版本、授权或操作记录。
- **触发**：教师账号被停用、恢复，或工作空间暂时不可访问。
- **系统行为**：停止新的教师受保护操作，但继续按数据生命周期规则保留工作空间及其业务对象；恢复登录资格后重新显示原工作空间和已保存数据。
- **异常结果**：账号状态变化不得被解释为课程归档、授权终止或数据删除；恢复账号也不得自动恢复已经单独终止的授权来源。
- **验收条件**：停用前后的工作空间标识和已保存课程标识一致；停用期间教师操作被拒绝；恢复后原数据仍在且独立业务状态没有被重写。
- **关联要求**：`FR-AUTH-003`、`FR-AUTH-006`、`FR-GRANT-*`、`DATA-LIFE-*`（待建立）

### 3.4 学生职责

#### FR-WS-006：学生授权不产生工作空间成员资格

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-STU-01`、`SCN-ERR-01`
- **主要角色**：学生
- **前置条件**：学生持有课程授权码并在当前机器领取课程。
- **触发**：学生下载、更新或打开课程包。
- **系统行为**：系统只按有效授权返回允许的已发布课程内容；本机学习标识和授权码都不成为工作空间账号或成员关系。
- **异常结果**：授权无效、范围不足或课程不属于对应授权来源时拒绝课程动作，不开放教师工作台、草稿、其它课程或工作空间摘要。
- **验收条件**：学生只能取得授权范围内的课程包；不能使用授权码或本机学习标识访问教师接口；一个工作空间的授权不能读取另一个工作空间的内容。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`SEC-ACCESS-*`、`DATA-GRANT-*`（待建立）

### 3.5 系统共同边界

#### FR-WS-007：服务端从可信身份推导工作空间

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`；`SCN-TCH-01`、`SCN-ERR-01`
- **主要角色**：平台管理员、教师
- **前置条件**：请求涉及某个工作空间或其业务对象。
- **触发**：系统执行权限判断。
- **系统行为**：教师操作的工作空间必须从已验证教师会话及服务端归属关系推导；客户端提交的教师标识、工作空间标识、所有者或角色字段不能单独构成授权依据。
- **异常结果**：可信归属不存在、不唯一或与目标对象不一致时默认拒绝，不使用客户端字段修补服务端归属。
- **验收条件**：篡改请求中的教师、工作空间或角色字段不能扩大权限；省略这些非必要客户端字段仍能按服务端关系完成合法操作。
- **关联要求**：`FR-AUTH-010`、`INT-API-*`、`SEC-ACCESS-*`、`DATA-WS-*`（待建立）

#### FR-WS-008：业务对象归属稳定且越权失败不产生副作用

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-01`、`SCOPE-02`、`SCOPE-09`；`SCN-ERR-01`、`SCN-ERR-02`
- **主要角色**：平台管理员、教师、支持人员
- **前置条件**：业务对象已经归属于一个工作空间，或系统正准备创建新对象。
- **触发**：对象被创建、读取、修改、导入、导出、恢复或迁移。
- **系统行为**：每个需要隔离的业务对象都必须能追溯到唯一工作空间；普通编辑不能改变归属；确需迁移时使用后续迁移需求规定的受控流程并留下记录。
- **异常结果**：归属缺失、重复、跨空间引用、迁移中断或权限不足时停止整个操作，不留下部分写入，不覆盖来源或目标空间的有效数据。
- **验收条件**：课程、课节、脚本、发布版本和授权均能追溯到一个工作空间；跨空间读写与引用被拒绝；失败前后两个空间的数据一致。
- **关联要求**：`DATA-WS-*`、`SEC-ACCESS-*`、`MIG-WS-*`、`NFR-REL-*`（待建立）

### 3.6 本功能域完成条件

1. 当前阶段每名教师只有一个工作空间，教师是唯一 Owner，不提供成员、助手或空间切换；
2. 管理员能够建立和维护教师与工作空间的关联，但普通管理操作不读取课程正文；
3. 教师只能查看和修改自己工作空间的数据，权限由服务端可信身份推导；
4. 学生不加入工作空间，只能通过有效授权取得允许的已发布课程包；
5. 登录、停用和恢复不会删除或重写工作空间业务数据；
6. 越权、归属损坏和跨空间引用失败时不泄露正文、不产生部分写入。

本功能域通过后，下一段进入 `FR-COURSE-*` 课程、课节与视频引用，不提前展开脚本制作。

## 4. 课程、课节与视频引用（`FR-COURSE-*`）

本功能域定义教师如何建立课程结构，以及学生最终能够识别什么课程和课节。互动节点、草稿和发布版本分别
留给 `FR-AUTHOR-*` 与 `FR-PUBLISH-*`；本节不把“保存课程结构”和“发布给学生”混成同一动作。

### 4.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 在受控支持时确认课程归属和状态是否正常 | 不代替教师创建、编辑、排序或归档课程与课节；不默认读取课程正文 |
| 教师 | 管理多门课程；管理每门课程的有序课节；为课节绑定准确视频引用；确认归档影响 | 不使用标题或视频标识代替课程、课节身份；不直接修改已发布历史版本 |
| 学生 | 在课程包中看到可理解的课程、课节名称和正确顺序；只在匹配视频中进入相应课节 | 不编辑教师课程结构；不使用内部 UUID 作为主要显示名称 |

### 4.2 教师职责：课程

#### FR-COURSE-001：教师管理多门独立课程

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`
- **主要角色**：教师
- **前置条件**：教师已进入自己的工作空间。
- **触发**：教师查看课程列表或创建新课程。
- **系统行为**：系统列出当前工作空间内的全部非归档课程，并允许创建多门课程；课程标题和描述作为可编辑信息，课程身份由系统独立建立。
- **异常结果**：标题为空、超过允许长度、保存失败或重复提交时，不产生无标题、重复写入或部分保存的课程；同名课程不得因名称相同而互相覆盖。
- **验收条件**：教师可以连续创建并看到多门课程；两门课程允许同名但拥有不同稳定标识；列表不包含其他工作空间课程。
- **关联要求**：`FR-WS-004`、`DATA-COURSE-*`、`INT-API-*`、`NFR-REL-*`（待建立）

#### FR-COURSE-002：教师编辑课程信息但不改变课程身份

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：目标课程属于教师当前工作空间且未归档。
- **触发**：教师修改课程标题、描述或其它已允许的课程级信息并保存。
- **系统行为**：系统保存合法修改并保留原课程标识、课节归属、草稿和发布历史；课程标题不作为唯一键或目录主键。
- **异常结果**：输入无效、并发冲突或保存失败时保留最后一个已确认版本，明确显示未保存或冲突状态，不静默覆盖较新的合法修改。
- **验收条件**：修改标题或描述后课程标识不变；原有课节仍属于该课程；刷新后只显示服务端已确认内容。
- **关联要求**：`DATA-COURSE-*`、`NFR-CONC-*`、`INT-API-*`（待建立）

#### FR-COURSE-003：教师归档课程并保留历史

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-04`；`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：目标课程属于教师工作空间，且影响范围可确认。
- **触发**：教师确认归档课程。
- **系统行为**：系统把课程标记为归档，使其退出正常课程列表，并停止该课程新的领取、重新下载和更新；课程结构、发布历史、授权历史和操作记录继续保留。
- **异常结果**：归档失败或请求重复时显示真实当前状态，不删除课程，不把归档伪装成授权码终止，也不承诺删除学生本机已有课程。
- **验收条件**：归档课程不再出现在正常课程列表；历史记录仍可追溯；新领取和更新被拒绝；学生机器上的已有副本不被远程删除。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`DATA-LIFE-*`、`SEC-LOG-*`（待建立）

### 4.3 教师职责：课节

#### FR-COURSE-004：教师建立和维护有序课节

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：课程属于教师当前工作空间且未归档。
- **触发**：教师新增、修改、排序或归档课节。
- **系统行为**：一门课程可以包含多个课节；每个课节具有标题、顺序、状态和视频引用；新增和排序后形成明确且无歧义的课程内顺序。
- **异常结果**：目标课程或课节越权、顺序冲突、输入无效或保存失败时，不留下重复顺序、孤立课节或部分重排结果。
- **验收条件**：教师可以建立多个课节并得到确定顺序；刷新后顺序一致；归档课节不进入新的课程交付，但历史引用继续保留。
- **关联要求**：`FR-WS-004`、`DATA-LESSON-*`、`NFR-CONC-*`（待建立）

#### FR-COURSE-005：课程交付前至少有一个有效课节

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-03`；`SCN-TCH-02`、`SCN-TCH-04`
- **主要角色**：教师
- **前置条件**：教师正在准备预览、发布或创建课程授权。
- **触发**：课程从可编辑结构进入交付前校验。
- **系统行为**：允许教师在创建过程暂时保存没有课节的课程草稿，但真实预览、发布和授权前必须至少存在一个未归档且视频引用有效的课节。
- **异常结果**：课程没有有效课节时拒绝进入交付流程，保留已有课程草稿，并指出需要补充或恢复的课节。
- **验收条件**：空课程可以作为未完成草稿存在；空课程或全部课节已归档的课程不能发布或创建有效授权；补充合法课节后可以重新校验。
- **关联要求**：`FR-PUBLISH-*`、`FR-GRANT-*`、`DATA-LESSON-*`（待建立）

#### FR-COURSE-006：课节身份不随标题、顺序或视频变化

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`、`SCN-STU-04`
- **主要角色**：教师、学生
- **前置条件**：课节已经建立并取得系统标识。
- **触发**：教师修改标题、调整顺序或在允许时更换视频引用。
- **系统行为**：系统保留原课节标识和课程归属；学生本机状态是否还能沿用，必须由稳定课节和节点标识及后续版本兼容规则共同判断，不能仅按顺序或视频标识猜测。
- **异常结果**：任何普通编辑都不得删除后重建课节来伪装更新；无法安全对应历史状态时必须明确标记不兼容，不静默挂到另一课节。
- **验收条件**：标题、顺序或视频引用改变后课节标识不变；课程标识也不变；历史发布记录仍指向原课节身份。
- **关联要求**：`FR-PUBLISH-*`、`FR-LIB-*`、`FR-LEARN-*`、`MIG-COURSE-*`（待建立）

### 4.4 教师职责：视频引用

#### FR-COURSE-007：每个课节绑定一个可精确匹配的视频引用

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-05`；`SCN-TCH-02`、`SCN-STU-02`
- **主要角色**：教师、学生
- **前置条件**：教师正在新增课节或更换课节视频。
- **触发**：教师提交视频链接或结构化视频引用。
- **系统行为**：系统只接受当前支持的视频来源，解析并回显足以精确匹配目标视频的结构化引用；当前阶段正式支持 B 站视频，视频引用不充当课程或课节标识。
- **异常结果**：链接无效、来源不支持、标识缺失、目标无法精确区分或解析失败时，不保存新绑定，也不覆盖原有效引用。
- **验收条件**：合法 B 站视频得到可复现的结构化引用；重新进入后引用一致；修改视频不会改变课程或课节标识；学生运行时可用同一引用判断是否匹配。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`DATA-VIDEO-*`、`NFR-COMPAT-*`（待建立）

#### FR-COURSE-008：视频重复规则以课程为边界

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`；`SCN-TCH-02`；`D-023`、`D-024`
- **主要角色**：教师
- **前置条件**：教师为课节建立或更换视频引用。
- **触发**：目标视频已经被某个课节引用。
- **系统行为**：同一课程内任意两个课节不得绑定同一 BVID；不同课程可以引用同一视频，并继续保持独立课程、课节、脚本和学习状态。
- **异常结果**：同一课程内发生重复时拒绝保存并保留原绑定；不得用全局唯一限制阻止另一个课程合法引用同一视频。
- **验收条件**：同一课程第二次绑定同一 BVID 失败；两个不同课程绑定同一 BVID 成功且标识不同；失败不会覆盖任一现有课节。
- **关联要求**：`DATA-VIDEO-*`、`FR-RUNTIME-*`、`SEC-ACCESS-*`（待建立）

### 4.5 学生职责与系统共同边界

#### FR-COURSE-009：课程包保留可理解的层级和顺序

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-04`；`SCN-STU-01`、`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：教师已经发布课程，学生正在领取或更新课程包。
- **触发**：系统生成并展示学生可用课程结构。
- **系统行为**：课程包保留课程、课节、视频引用和明确顺序；界面显示教师确认的课程与课节名称，同时内部继续使用稳定课程和课节标识关联数据。
- **异常结果**：结构缺少标识、课节顺序不确定、视频引用无效或范围裁剪后没有可交付课节时，拒绝安装新包并保留最后一个有效本机版本。
- **验收条件**：学生看到课程名称和有序课节，不以 UUID 作为主要名称；更新前后稳定课节能够正确对应；无效新包不覆盖现有课程。
- **关联要求**：`FR-PUBLISH-*`、`FR-GRANT-*`、`FR-LIB-*`、`DATA-PACKAGE-*`（待建立）

#### FR-COURSE-010：外部视频状态变化不删除课程结构

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-05`；`SCN-TCH-02`、`SCN-ERR-02`
- **主要角色**：教师、学生、支持人员
- **前置条件**：课节已经绑定外部视频。
- **触发**：视频被下架、改为不可访问、平台暂时故障或宿主标识规则变化。
- **系统行为**：系统区分“课程结构仍存在”和“外部视频当前不可用”，保留课程、课节、脚本和历史版本，并给出检查或更换视频引用的恢复路径。
- **异常结果**：外部视频失败不得触发课程、课节或学习状态删除；未验证的新视频引用不得静默替换原绑定。
- **验收条件**：视频不可用时教师仍能识别受影响课程和课节；学生得到视频不可用而非课程不存在的结果；恢复或受控更换后仍沿用原课程、课节标识。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`NFR-REL-*`、`OPS-SUPPORT-*`（待建立）

### 4.6 本功能域完成条件

1. 教师能够管理多门独立课程，每门课程能够管理多个有序课节；
2. 课程和课节身份由系统建立，不因标题、顺序或视频引用变化而改变；
3. 课程草稿可以暂时为空，但发布和授权前至少有一个有效课节；
4. 每个课节绑定一个可精确匹配的受支持视频引用；当前阶段正式支持 B 站；
5. 同一课程内不允许重复 BVID，不同课程可以合法复用同一视频；
6. 课程归档、视频不可用和外部平台故障都不删除历史结构或学生本机已有版本；
7. 学生课程包保留可理解的课程、课节名称和确定顺序，不使用内部 UUID 代替名称。

本功能域通过后，下一段进入 `FR-AUTHOR-*` 字幕与互动脚本制作。

## 5. 字幕与互动脚本制作（`FR-AUTHOR-*`）

本功能域只回答教师如何准备时间依据、制作节点并可靠保存脚本草稿。真实运行预览、发布版本生成和学生端执行
分别由后续 `FR-PUBLISH-*` 与 `FR-RUNTIME-*` 定义；保存草稿不等于预览成功或发布成功。

### 5.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 维护教师制作资格和必要的支持边界；在不读取正文时查看故障所需的状态与标识 | 不代替教师编写脚本；不因管理身份默认读取字幕、题目、答案或反馈正文 |
| 教师 | 为自己的课节准备可靠时间依据；创建、编辑、移动、复制、删除节点；检查校验结果；明确保存草稿 | 不编辑其他教师内容；不把页面临时状态当作已保存草稿；不以保存草稿代替真实预览和发布 |
| 学生 | 本功能域没有制作职责；后续只执行教师已发布且自己有权取得的版本 | 不读取脚本草稿、教师制作素材或未发布修改；不参与教师端字幕导入 |
| 系统 | 隔离工作空间和课节；校验字幕、触发和节点结构；保留最近一次已确认草稿；明确反馈保存状态 | 不静默修正教学语义；不把无效或未保存内容伪装成已确认草稿；不自动发布 |

### 5.2 教师职责：准备时间依据

#### FR-AUTHOR-001：教师为指定课节导入或选择可靠时间依据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师有权编辑目标课节；课节已经绑定有效视频引用；教师拥有合法可用的字幕、已确认时间点或等价依据。
- **触发**：教师打开目标课节并开始安排互动触发位置。
- **系统行为**：系统允许教师导入带时间信息的 SRT、VTT 字幕，或在没有字幕时使用已确认的视频时间；导入成功后按字幕句展示时间和文本，并始终标明当前依据属于哪个课节和视频。
- **异常结果**：文件格式错误、编码无法读取、没有有效字幕句、时间顺序非法或素材与目标视频无法确认时，不替换当前有效时间依据，并指出失败原因。
- **验收条件**：合法 SRT、VTT 均能形成可定位的字幕句；无字幕时仍可按合法视频时间创建节点；错误导入后原时间依据和已有草稿保持不变。
- **关联要求**：`DATA-SUBTITLE-*`、`INT-FILE-*`、`SEC-CONTENT-*`、`NFR-USABILITY-*`（待建立）

#### FR-AUTHOR-002：字幕全文默认只在教师本机用于制作

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-017`、`TERM-018`
- **主要角色**：教师、平台管理员
- **前置条件**：教师选择或导入了字幕文档。
- **触发**：系统解析、展示、引用或记录该字幕文档。
- **系统行为**：系统默认在教师本机解析和使用字幕全文；服务端草稿只保存教师明确写入节点的内容及必要引用，不因导入动作自动上传完整字幕文档，也不把字幕正文写入普通操作日志。
- **异常结果**：本机解析失败、页面刷新或教师移除本机字幕后，不得从服务端伪造“字幕仍已导入”的状态；未来若需要上传字幕，必须先形成独立、明确的需求和用户动作。
- **验收条件**：仅导入字幕而不编辑节点时，服务端草稿和普通日志中不存在字幕全文；教师能够辨认字幕是本机制作依据，而不是已发布课程内容。
- **关联要求**：`DATA-SUBTITLE-*`、`SEC-PRIVACY-*`、`SEC-LOG-*`、`INT-FILE-*`（待建立）

### 5.3 教师职责：建立和编辑互动节点

#### FR-AUTHOR-003：每个课节维护独立的当前脚本草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-019`、`TERM-020`
- **主要角色**：教师
- **前置条件**：教师有权编辑目标课节。
- **触发**：教师首次开始制作、重新进入课节或保存修改。
- **系统行为**：系统为每个课节维护一个可继续编辑的当前脚本草稿；草稿只能归属于该课节和其所在工作空间，重新进入时恢复最近一次服务端确认保存的内容。
- **异常结果**：课节不存在、已经归档、教师无权访问或草稿数据损坏时，拒绝加载为可编辑有效草稿，不得加载其它课节或其它工作空间内容顶替。
- **验收条件**：两个课节的草稿互不覆盖；退出后重新进入可以恢复已确认草稿；草稿状态与已发布版本明确区分。
- **关联要求**：`FR-WS-*`、`FR-PUBLISH-*`、`DATA-SCRIPT-*`、`SEC-ACCESS-*`（待建立）

#### FR-AUTHOR-004：教师能够完整管理节点生命周期

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-022`
- **主要角色**：教师
- **前置条件**：目标课节草稿已经可编辑。
- **触发**：教师添加、编辑、移动、复制或删除互动节点。
- **系统行为**：系统允许教师修改节点的触发位置、展示内容、学生动作、反馈和完成行为；移动保留节点身份，复制建立新节点身份，删除只影响被明确选择的节点；同一时间或同一字幕句允许存在多个不同节点。
- **异常结果**：操作目标已经不存在、修改结果无效或发生保存冲突时，不产生部分修改，也不把复制结果与原节点共用同一身份。
- **验收条件**：五类操作均有确定结果；移动前后节点标识不变；复制后标识不同；删除一个节点不影响同位置其它节点；重新加载后结果与已保存草稿一致。
- **关联要求**：`DATA-NODE-*`、`NFR-USABILITY-*`、`NFR-REL-*`（待建立）

#### FR-AUTHOR-005：提供四种基线节点及明确教学行为

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-023`
- **主要角色**：教师、学生
- **前置条件**：教师正在为课节添加或修改节点。
- **触发**：教师选择重点内容、选择题、填空题或问答题。
- **系统行为**：重点内容用于展示教师确认的信息且不要求作答；选择题要求教师提供可区分选项、正确答案和反馈；填空题要求教师提供可接受答案及反馈；问答题接收学生自由表达并展示教师预先编写的参考反馈，当前阶段不自动判定开放回答对错。这四种是 v1 基线，不构成永久封闭清单。
- **异常结果**：节点缺少该类型完成教学行为所需的题干、选项、答案或反馈时，不得标记为合法可发布节点；系统不得用默认文案静默补齐教师尚未确认的教学内容。
- **验收条件**：四种类型能够分别建立、保存和重新加载；每种类型只要求与自身行为有关的字段；问答题不产生虚假的自动对错结论。
- **关联要求**：`FR-RUNTIME-*`、`DATA-NODE-*`、`NFR-ACCESSIBILITY-*`（待建立）

#### FR-AUTHOR-006：节点具有稳定身份、合法触发和确定顺序

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-03`；`TERM-022`、`TERM-024`
- **主要角色**：教师、学生
- **前置条件**：教师创建节点或修改节点触发位置。
- **触发**：系统校验、保存、预览、发布或执行节点。
- **系统行为**：每个节点在所属课节内具有唯一稳定标识；当前核心触发依据为有限、非负且不超过目标视频有效时长的视频时间；节点按触发时间和稳定的次序规则排列，引用字幕句时同时保存可验证的字幕局部标识。
- **异常结果**：标识缺失或重复、时间非数字、为负、越过已知视频范围或字幕引用无效时，拒绝确认该修改，不把越界值自动吸附为另一个时间。
- **验收条件**：普通内容编辑和移动不会更换节点标识；相同时间的多个节点顺序可重复得到；无效触发无法保存为有效草稿或进入后续发布。
- **关联要求**：`FR-LEARN-*`、`FR-RUNTIME-*`、`DATA-NODE-*`、`INT-BILIBILI-*`（待建立）

#### FR-AUTHOR-007：节点校验不静默改变教学语义

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师编辑了一个或多个节点。
- **触发**：教师确认字段、保存草稿或进入后续预览与发布校验。
- **系统行为**：系统按节点类型校验必填内容、选项唯一性、答案与选项关系、可接受答案、反馈和完成行为，并把问题定位到具体节点和字段；校验只判断是否合法，不自行改写题目、答案或反馈。
- **异常结果**：任一节点结构无效时，不把不完整结果冒充已确认保存；不得通过删除未知字段、截断正文、替换答案或改变节点类型来使校验通过。
- **验收条件**：教师能够看到具体错误位置并修正后重试；错误内容不覆盖最近一次有效草稿；相同输入的校验结果一致。
- **关联要求**：`DATA-NODE-*`、`SEC-INPUT-*`、`NFR-USABILITY-*`（待建立）

### 5.4 系统共同职责：可靠保存与内容边界

#### FR-AUTHOR-008：明确区分页面修改、保存中和已确认草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`
- **主要角色**：教师
- **前置条件**：教师已经打开可编辑草稿。
- **触发**：教师修改内容、发起保存、离开页面或重新加载。
- **系统行为**：系统持续标明当前内容是未保存、保存中、已保存还是保存失败；只有服务端完整确认后才更新“已保存”状态，重新进入时恢复该最近确认版本。
- **异常结果**：网络失败、服务端拒绝、响应中断或页面存在未保存修改时，不得显示为已保存；教师离开可能丢失页面修改前必须得到明确提醒。
- **验收条件**：断网保存不会覆盖或丢失服务端最近有效草稿；恢复网络后可以重试；刷新后出现的是最近确认版本而非半次保存结果。
- **关联要求**：`DATA-SCRIPT-*`、`NFR-REL-*`、`NFR-USABILITY-*`（待建立）

#### FR-AUTHOR-009：并发修改不得静默互相覆盖

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：同一课节草稿可能在两个页面、两个会话或一次延迟重试中被修改。
- **触发**：系统收到基于旧草稿状态发起的保存。
- **系统行为**：系统识别该保存是否仍基于当前已确认草稿；发生冲突时保留服务端当前版本和待提交修改，向教师明确展示冲突并提供重新加载或受控重试路径。
- **异常结果**：旧页面、重复请求或延迟响应不得静默覆盖较新的已确认草稿；冲突处理不得自动拼接题目、答案或节点顺序。
- **验收条件**：两个页面依次修改同一草稿时，后到的过期保存得到冲突结果；教师能够恢复服务端版本并保留足够信息重新处理自己的修改。
- **关联要求**：`DATA-SCRIPT-*`、`INT-WEB-*`、`NFR-CONCURRENCY-*`、`NFR-REL-*`（待建立）

#### FR-AUTHOR-010：制作内容按数据处理且不能自动成为发布内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`D-V1-002`、`D-V1-008`
- **主要角色**：教师、平台管理员、学生
- **前置条件**：教师输入、粘贴或导入节点内容；v1 不提供 AI 辅助制作。
- **触发**：系统保存、展示、记录或准备交付制作内容。
- **系统行为**：系统把字幕、题目、选项、答案和反馈作为内容数据处理，不执行其中夹带的脚本或可执行标记；所有内容都必须经过教师明确确认、保存和后续显式发布，任何导入或辅助生成动作都不能自动发布。
- **异常结果**：内容包含不可接受的可执行结构、教师无内容权利或无法确认来源时，拒绝进入可发布状态并保留安全的原草稿；管理员和学生不得因此获得草稿读取权限。
- **验收条件**：恶意标记只作为安全文本显示或被明确拒绝，不执行；未发布修改不出现在学生端；人工制作和教师确认链路独立成立，v1 不出现 AI 生成入口。
- **关联要求**：`FR-PUBLISH-*`、`DATA-CONTENT-*`、`SEC-CONTENT-*`、`SEC-ACCESS-*`（待建立）

#### FR-AUTHOR-011：所有节点类型遵守统一管理契约

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`；`TERM-022`、`TERM-023`
- **主要角色**：教师、学生、平台管理员
- **前置条件**：系统提供四种基线节点，或后续增加新的节点类型。
- **触发**：节点类型被启用、停用、创建、编辑、保存、预览、发布、执行、导入或导出。
- **系统行为**：所有节点类型共同遵守节点身份、工作空间权限、草稿与发布隔离、结构校验、版本追踪和内容安全规则；每种类型另外声明自身的内容结构、学生动作、反馈、完成规则及兼容范围。新增类型必须接入同一管理入口和生命周期，不能形成绕过公共规则的独立旁路。
- **异常结果**：类型未知、定义缺失、版本不兼容或未完成公共能力接入时，系统不得把它误当成其它类型、静默丢弃其数据或允许其进入发布；已有草稿和发布版本保持可识别、可恢复。
- **验收条件**：四种基线类型通过同一组公共生命周期检查；增加一个测试类型时无需复制账号、权限、草稿、发布和安全流程；不支持该类型的运行环境给出明确不兼容结果而不是错误执行。
- **关联要求**：`FR-PUBLISH-*`、`FR-RUNTIME-*`、`FR-PORT-*`、`DATA-NODE-*`、`MIG-NODE-*`（待建立）

### 5.5 本功能域完成条件

1. 教师能够为指定课节使用合法 SRT、VTT 或已确认视频时间作为制作依据，错误导入不覆盖现有内容；
2. 字幕全文默认在教师本机处理，不因导入自动进入服务端草稿、课程包或普通日志；
3. 每个课节具有独立当前草稿，教师能够添加、编辑、移动、复制和删除具有稳定身份的节点；
4. 重点内容、选择题、填空题和问答题具有不同且可验收的教学行为，四种基线类型及后续新增类型遵守统一管理契约；
5. 节点触发、结构、答案和反馈得到明确校验，系统不静默修正教学语义；
6. 页面修改、保存中、保存失败和服务端已确认草稿可以区分，失败与并发冲突不覆盖最近有效版本；
7. 制作内容不会被执行为代码，也不会因导入、辅助生成或保存草稿而自动发布给学生。

本功能域通过后，下一段进入 `FR-PUBLISH-*` 真实预览、发布与版本。

## 6. 真实预览、发布与版本（`FR-PUBLISH-*`）

本功能域把页面内静态示意、教师真实预览、保存草稿和正式发布分成四种不同结果。发布对象是整门课程在某一
时刻的可交付快照；课节、脚本和课程包内部如何存储留给设计文档，但任何实现都不能让学生取得半次发布结果。

### 6.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 维护教师发布资格；查看不含课程正文的发布状态、操作者、时间和失败标识 | 不代替教师预览或发布；不因管理身份默认读取草稿、发布正文或学生预览回答 |
| 教师 | 选择自己的已保存草稿；通过学生真实路径检查变化；确认发布影响；识别当前草稿、预览对象和最新发布版本 | 不发布其他工作空间课程；不把静态示意当真实预览；不把保存成功当发布成功 |
| 学生 | 只领取有权取得的正式发布版本；继续保留本机已安装版本，直到合法更新成功 | 不读取教师草稿、预览数据或发布中的临时状态；不接收部分发布版本 |
| 系统 | 锁定预览对象；隔离预览数据；发布前完整校验；原子生成不可混淆版本；保留历史版本和审计事实 | 不从页面未保存状态发布；不静默覆盖历史版本；不把发布失败显示为成功 |

### 6.2 教师职责：真实预览

#### FR-PUBLISH-001：真实预览使用学生正式交付路径

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-TCH-04`；`TERM-026`、`TERM-027`
- **主要角色**：教师
- **前置条件**：目标课节已保存合法草稿；受支持的学生运行环境可用；目标视频引用仍有效。
- **触发**：教师对指定课节和草稿发起真实预览。
- **系统行为**：系统把指定的已保存草稿送入与学生正式交付相同的课程包解释、视频匹配、触发、暂停、作答、反馈和继续学习路径，并持续标明当前处于教师预览。
- **异常结果**：只能展示静态界面、运行环境缺失、视频不匹配、草稿不兼容或真实触发失败时，不得显示为预览通过，也不得降级为静态示意后继续冒用“真实预览”名称。
- **验收条件**：教师在受支持视频原页面看到节点按真实时间触发并完整作答；预览与学生运行使用同一节点内容和行为规则；静态示意具有不同名称和状态。
- **关联要求**：`FR-RUNTIME-*`、`INT-BILIBILI-*`、`INT-EXTENSION-*`、`NFR-COMPAT-*`（待建立）

#### FR-PUBLISH-002：每次预览锁定可识别的已保存草稿

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-03`、`SCN-TCH-04`
- **主要角色**：教师
- **前置条件**：教师页面可能同时存在已保存草稿和未保存修改。
- **触发**：教师启动预览或在预览期间继续修改草稿。
- **系统行为**：系统为每次预览建立唯一预览会话，并记录课程、课节、草稿修订和开始时间；该会话始终运行启动时锁定的已保存内容，之后的页面修改只在重新保存并重启预览后生效。
- **异常结果**：草稿已经改变、预览会话过期或运行端收到另一课程内容时，明确标记预览已过期或不匹配，不把混合状态继续作为有效预览。
- **验收条件**：预览启动后修改页面不会改变正在运行的预览；教师能识别预览对应哪次已保存内容；重新保存并预览会建立新会话。
- **关联要求**：`DATA-PREVIEW-*`、`INT-BRIDGE-*`、`NFR-CONCURRENCY-*`（待建立）

#### FR-PUBLISH-003：预览活动与学生真实学习状态隔离

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-04`
- **主要角色**：教师、学生
- **前置条件**：教师正在运行、重复或结束真实预览。
- **触发**：预览中产生节点打开、回答、完成、跳过、关闭或错误状态。
- **系统行为**：系统把全部预览活动标记为教师预览数据，只供本次预览检查；每次新预览从独立初始状态开始，不写入学生本机学习状态、领取结果或未来教师真实学习证据。
- **异常结果**：无法确认会话类型、课程身份或草稿修订时，停止记录和执行，不得把未知活动归入学生数据。
- **验收条件**：教师可在预览中多次作答且不改变任何学生状态；开始新预览时节点恢复初始状态；未来报表和课程完成情况不包含预览活动。
- **关联要求**：`FR-LEARN-*`、`FR-REPORT-*`、`DATA-PREVIEW-*`、`SEC-PRIVACY-*`（待建立）

#### FR-PUBLISH-004：预览失败提供可恢复且不过度泄露的结果

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-TCH-04`、`SCN-ERR-02`
- **主要角色**：教师、支持人员
- **前置条件**：预览依赖教师页面、扩展、宿主视频和已保存草稿共同工作。
- **触发**：任一环节缺失、版本不兼容、响应超时或宿主页面变化。
- **系统行为**：系统区分未安装或未连接、版本不兼容、课程不匹配、视频不可用、草稿无效和运行时失败，并提供重新保存、重新连接、更新运行环境或检查视频的对应恢复动作和支持标识。
- **异常结果**：不得无限等待、反复自动打开页面、清空草稿或暴露凭证、课程正文、字幕全文和学生回答到普通日志。
- **验收条件**：每类故障都有稳定错误类别和可执行下一步；恢复条件满足后能够重新启动新预览；原草稿和最近发布版本不变。
- **关联要求**：`INT-BRIDGE-*`、`NFR-REL-*`、`NFR-OBS-*`、`SEC-LOG-*`（待建立）

### 6.3 教师职责：正式发布

#### FR-PUBLISH-005：发布前校验整门课程的交付完整性

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-03`；`SCN-TCH-04`；`FR-COURSE-005`
- **主要角色**：教师
- **前置条件**：教师准备发布自己的课程。
- **触发**：教师进入发布检查或提交发布。
- **系统行为**：系统使用服务端最近确认的课程、课节和脚本草稿进行完整校验；课程必须至少有一个未归档课节，所有未归档课节都必须具备有效视频引用、非空合法脚本和对该脚本的最近一次成功真实预览。
- **异常结果**：存在空课程、未完成课节、无效视频、空脚本、无效节点、过期预览或不兼容数据时，整体拒绝发布，列出受影响课节且不改变既有发布版本。
- **验收条件**：任一未归档课节不合格都会阻止整门课程发布；教师完成或归档该课节并对最终草稿重新预览后可以再次校验；页面未保存修改不进入发布内容。
- **关联要求**：`FR-COURSE-*`、`FR-AUTHOR-*`、`DATA-PACKAGE-*`、`NFR-COMPAT-*`（待建立）

#### FR-PUBLISH-006：教师通过显式确认发布整门课程

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-04`、`SCN-TCH-06`；`TERM-028`
- **主要角色**：教师
- **前置条件**：发布前校验已经针对当前服务端草稿通过；教师有权发布该课程。
- **触发**：教师查看将发布的课程、课节和草稿修订后明确确认发布。
- **系统行为**：系统在一个不可分割的发布动作中锁定全部未归档课节，生成整门课程的发布快照，并在全部写入成功后才把新版本标记为可交付。
- **异常结果**：教师取消、权限改变、草稿在确认后发生变化、重复提交或任一步骤失败时，不产生半发布课程，不改变学生当前可取得的最新成功版本。
- **验收条件**：成功结果包含课程和新发布版本；所有纳入课节来自同一次快照；故障注入到任一课节时没有课节单独进入新版本。
- **关联要求**：`FR-WS-*`、`DATA-PUBLISH-*`、`NFR-TRANSACTION-*`、`SEC-ACCESS-*`（待建立）

#### FR-PUBLISH-007：发布版本唯一、不可变且可以追溯

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-06`；`SCN-TCH-04`、`SCN-TCH-06`；`TERM-029`
- **主要角色**：教师、学生、支持人员
- **前置条件**：一次课程发布成功。
- **触发**：系统保存、展示、下载、更新或追查该发布结果。
- **系统行为**：系统为课程快照分配在该课程内唯一且单调前进的发布版本，并记录课程、纳入课节、脚本修订、课程包 Schema 版本、发布者和发布时间；成功版本形成后不可原地修改。
- **异常结果**：版本号冲突、快照引用缺失或历史内容损坏时，不得复用版本号、回填猜测内容或把损坏版本设为最新可交付版本。
- **验收条件**：连续两次成功发布得到两个不同版本；旧版本内容保持不变；任一已安装课程和未来学习证据都能指回当时使用的确切课程发布版本。
- **关联要求**：`DATA-PUBLISH-*`、`DATA-PACKAGE-*`、`MIG-VERSION-*`、`NFR-REL-*`（待建立）

#### FR-PUBLISH-008：草稿修改不改变任何已发布版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-04`；`SCN-TCH-03`、`SCN-TCH-06`
- **主要角色**：教师、学生
- **前置条件**：课程至少已经成功发布一次。
- **触发**：教师继续修改、保存或预览课程草稿。
- **系统行为**：系统把后续草稿与最新发布版本分开维护；只有再次显式发布成功后，新的发布版本才可供有更新资格的学生取得，已经安装的旧版本继续保持原内容。
- **异常结果**：草稿保存失败、预览失败或新发布失败时，不得修改、撤回或重新标记此前成功版本，也不得向学生下发部分草稿。
- **验收条件**：发布 v1 后修改草稿，学生仍只能取得 v1；发布 v2 成功后符合资格的学生可取得 v2；设备上的 v1 只在合法更新完成后被替换。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`DATA-PUBLISH-*`、`MIG-VERSION-*`（待建立）

#### FR-PUBLISH-009：重复和并发发布不会制造重复或倒退版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`；`SCN-TCH-04`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：相同课程可能收到双击、网络重试、两个页面或延迟响应产生的多个发布请求。
- **触发**：系统处理相同发布意图或基于不同草稿修订的并发请求。
- **系统行为**：同一发布意图的重复请求返回同一最终结果，不重复创建版本；不同草稿修订的并发发布按明确次序处理，过期请求得到冲突结果并要求教师重新确认最新草稿。
- **异常结果**：不得出现相同版本号对应不同内容、一次确认跳增多个版本、较旧草稿晚到后成为最新版本或页面把旧响应显示成新成功。
- **验收条件**：重复提交只生成一个版本；两个页面发布不同修订时最多一个按原确认成功，另一个明确冲突；版本序列不重复、不倒退。
- **关联要求**：`DATA-PUBLISH-*`、`INT-WEB-*`、`NFR-CONCURRENCY-*`、`NFR-REL-*`（待建立）

### 6.4 系统共同职责：课程包与发布记录

#### FR-PUBLISH-010：发布快照生成完整且最小的课程包

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-04`；`SCN-TCH-04`、`SCN-STU-01`；`TERM-030`、`TERM-031`
- **主要角色**：教师、学生
- **前置条件**：整门课程发布事务准备生成可交付快照。
- **触发**：系统构建并校验课程发布版本。
- **系统行为**：课程包包含可解释其结构的 Schema 版本、课程发布版本、稳定课程和课节标识、有序课节、视频引用、节点及运行所需规则；不包含第三方视频文件、完整字幕文档、密码、会话、授权码原文、教师页面状态或预览记录。
- **异常结果**：必需字段缺失、标识冲突、顺序不确定、Schema 不受支持或出现禁止数据时，整体拒绝发布，不把无法解释的包标记为可下载。
- **验收条件**：合法课程包能够独立通过契约校验并由受支持运行时解释；相同发布版本对应不变内容；对包进行字段检查不出现禁止数据。
- **关联要求**：`FR-GRANT-*`、`FR-RUNTIME-*`、`DATA-PACKAGE-*`、`INT-PACKAGE-*`、`SEC-DATA-*`（待建立）

#### FR-PUBLISH-011：发布结果与高风险操作可审计

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-TCH-04`、`SCN-ERR-01`
- **主要角色**：教师、平台管理员、支持人员
- **前置条件**：教师发起发布，或发布校验、事务和交付状态发生变化。
- **触发**：发布成功、失败、冲突或被拒绝。
- **系统行为**：系统向教师显示明确结果，并记录最小审计事实，包括操作者、课程、目标草稿修订、结果、发布版本或稳定错误类别及发生时间。
- **异常结果**：审计写入失败时按后续安全与运维要求决定是否阻止高风险动作；无论何种结果，日志不得包含密码、会话、授权码原文、完整字幕、节点正文或学生回答。
- **验收条件**：教师能区分成功、失败和冲突；支持人员能用不含正文的标识定位一次发布；成功记录能对应唯一发布版本，失败记录不伪造版本。
- **关联要求**：`FR-ADMIN-*`、`DATA-AUDIT-*`、`SEC-AUDIT-*`、`SEC-LOG-*`、`OPS-SUPPORT-*`（待建立）

### 6.5 本功能域完成条件

1. 教师可以对已保存草稿启动走学生正式交付路径的真实预览，静态示意不能冒充真实预览；
2. 每次预览锁定唯一草稿修订，之后的页面修改不会混入当前预览；
3. 预览活动与学生学习状态、领取结果及未来教师报表完全隔离；
4. 所有未归档课节的最终草稿都通过真实预览和完整校验后，教师才能显式发布整门课程；
5. 一次发布要么生成完整课程快照，要么完全失败，不产生部分发布课节；
6. 每个课程发布版本唯一、不可变、可追溯，草稿修改不改变已有版本；
7. 重复或并发发布不产生重复、倒退或内容混淆的版本；
8. 课程包包含运行所需的最小版本化数据，不包含视频文件、完整字幕、凭证、预览记录或页面临时状态；
9. 发布成功、失败和冲突都可由最小审计事实定位，同时不记录课程正文和敏感数据。

本功能域通过后，下一段进入 `FR-GRANT-*` 授权、领取与有效资格。

## 7. 授权、领取与有效资格（`FR-GRANT-*`）

本功能域把授权码、授权项、领取记录、授权来源、有效资格和本机已安装课程分开。授权码只证明一次领取请求
持有有效秘密；学生最终能否首次领取、重新下载或更新，由本机学习标识的全部授权来源、授权范围、现实时间、
课程状态和发布状态共同决定。

### 7.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 查看不含授权码原文的授权状态和审计事实；在明确支持流程中处理异常状态 | 不代替教师创建课程授权；不查询或恢复授权码原文；不把授权码当学生账号 |
| 教师 | 选择自己已发布内容的授权范围和时间；创建并安全交付授权码；查看范围与状态；终止不再允许继续分发的授权来源 | 不授权其他工作空间内容；不查看学生本机学习状态；不承诺远程删除已安装课程 |
| 学生 | 使用授权码在当前机器建立授权来源；确认并安装允许的课程；在仍有资格时重新下载或更新 | 不注册或登录；不选择服务端课程 ID 绕过授权范围；不因输入新码丢失已有其它来源 |
| 系统 | 安全校验凭证；记录领取关系；合并全部有效来源；裁剪课程包；隔离工作空间；处理到期、终止、重复和失败 | 不保存授权码原文；不以最后一次领取覆盖全部资格；不把在线失效伪装成本机内容已删除 |

### 7.2 教师职责：定义并交付授权

#### FR-GRANT-001：教师为已发布内容建立分层授权范围

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-TCH-05`；`D-025`
- **主要角色**：教师
- **前置条件**：教师有权管理目标工作空间；目标课程及授权范围内的课节、节点已经进入成功发布版本。
- **触发**：教师选择一门或多门课程、特定课节或特定节点作为授权范围。
- **系统行为**：系统用稳定课程、课节和节点标识保存一组授权项；课程级范围覆盖该课程当前及授权有效期间后续发布的内容，课节级范围只跟随该稳定课节的后续发布，节点级范围只跟随指定课节中的稳定节点，不使用视频时间代替节点身份。
- **异常结果**：范围为空、跨越其他工作空间、课节不属于课程、节点不属于课节、对象未发布或标识失效时，整体拒绝创建，不保存部分授权项。
- **验收条件**：一个授权来源可以覆盖多门自有课程、多个课节或节点；层级归属可验证；课程新增课节后课程级范围可以取得其新发布内容，课节或节点级范围不会自行扩大到同级其它对象。
- **关联要求**：`FR-PUBLISH-*`、`DATA-GRANT-*`、`SEC-ACCESS-*`（待建立）

#### FR-GRANT-002：授权码领取窗口与授权项有效时间相互独立

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-TCH-05`、`SCN-STU-01`；`TERM-035`、`TERM-036`、`TERM-043`
- **主要角色**：教师、学生
- **前置条件**：教师正在建立授权码及其授权项。
- **触发**：教师设置允许首次领取的期限，或为授权项设置生效和到期时间。
- **系统行为**：系统分别记录授权码可用于建立新授权来源的领取窗口，以及每项授权对重新下载和更新资格的现实时间窗口；时间包含明确时区，生效时刻包含在范围内，到期时刻不再包含。
- **异常结果**：结束时间不晚于开始时间、时区不明确或授权码窗口与授权项规则无法解释时，拒绝创建并指出具体字段；不得把视频触发时间误作现实授权时间。
- **验收条件**：短期码到期后不能在新机器建立新来源；已在本机确认的来源是否继续贡献重新下载或更新资格只由其授权项、终止状态和课程状态决定；没有到期时间的长期授权不会被推测出隐藏期限。
- **关联要求**：`DATA-GRANT-*`、`INT-TIME-*`、`NFR-TIME-*`（待建立）

#### FR-GRANT-003：授权码原文只在创建结果中显示一次

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-08`；`SCN-TCH-05`
- **主要角色**：教师、平台管理员
- **前置条件**：合法授权范围已经通过校验。
- **触发**：教师确认创建授权码。
- **系统行为**：系统生成不可预测且可人工转交的授权码，只在本次成功创建结果中向教师显示原文；持久化时只保存不可反推的校验值、非敏感尾号提示、领取窗口、授权范围、创建者和状态。
- **异常结果**：生成、持久化或审计任一步骤失败时，不显示不可用授权码，也不留下范围不完整的授权来源；离开结果页面后系统不提供找回原文能力。
- **验收条件**：教师可在创建成功当次复制完整码；刷新或重新进入后只看到尾号等安全提示；数据库、普通日志和列表响应中不存在授权码原文。
- **关联要求**：`DATA-CREDENTIAL-*`、`SEC-SECRET-*`、`SEC-LOG-*`（待建立）

#### FR-GRANT-004：教师查看授权范围、领取窗口和当前状态

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-TCH-05`、`SCN-TCH-06`
- **主要角色**：教师
- **前置条件**：教师已为自己的课程创建一个或多个授权来源。
- **触发**：教师查看课程授权记录或准备终止分发。
- **系统行为**：系统展示可识别的授权记录、码尾号、创建时间、领取窗口、授权层级和范围、各项生效时间以及有效、未生效、已到期或已终止状态，不返回原文或校验摘要。
- **异常结果**：记录跨工作空间、范围数据损坏或状态无法确定时，不显示为有效；只展示教师可管理的最小信息并提供支持标识。
- **验收条件**：教师能在不持有原文的情况下辨认授权记录及影响范围；状态由服务端时间和真实记录得出；其他教师不能查看该记录。
- **关联要求**：`DATA-GRANT-*`、`SEC-ACCESS-*`、`NFR-USABILITY-*`（待建立）

#### FR-GRANT-005：教师永久终止一个授权来源的未来在线资格

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-TCH-06`；`TERM-041`、`TERM-042`
- **主要角色**：教师、学生
- **前置条件**：教师有权管理目标授权来源，并已查看终止影响。
- **触发**：教师明确确认终止该授权来源。
- **系统行为**：系统把该来源标记为已终止并永久停止它建立新领取、贡献重新下载和更新资格；保留授权项、既有领取记录、终止操作者和时间用于追溯。
- **异常结果**：重复终止返回同一最终状态；权限不足、对象不存在或并发状态改变时不影响其它授权来源；终止后不得通过普通恢复操作重新激活原来源。
- **验收条件**：终止后新机器不能用该码领取，同一机器也不能再依赖该来源重新下载或更新；其它仍有效来源继续贡献资格；学生已经安装的本机课程不被删除或改写。
- **关联要求**：`DATA-GRANT-*`、`SEC-AUDIT-*`、`NFR-CONCURRENCY-*`（待建立）

### 7.3 学生职责：领取并保留多个授权来源

#### FR-GRANT-006：学生用本机学习标识完成一次可追溯领取

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-STU-01`；`TERM-038`、`TERM-039`
- **主要角色**：学生
- **前置条件**：受支持运行环境已在当前机器建立本机学习标识；学生持有仍可领取的授权码。
- **触发**：学生输入授权码并提交领取。
- **系统行为**：系统验证凭证、领取窗口、授权状态、授权项和可交付发布版本后，把该授权来源与当前本机学习标识建立领取记录，并返回允许取得的课程名称、范围和版本供学生确认。
- **异常结果**：凭证无效、未生效、到期、已终止、没有可交付内容或本机标识无效时，不建立领取记录，也不泄露码是否存在、关联教师或具体失败范围。
- **验收条件**：有效码可以在不注册登录的情况下建立当前机器的领取记录；记录能回溯到本机学习标识、授权来源、实际范围、时间和结果；授权码本身不充当学习标识。
- **关联要求**：`FR-AUTH-007`、`DATA-REDEMPTION-*`、`SEC-PRIVACY-*`、`SEC-ABUSE-*`（待建立）

#### FR-GRANT-007：重复领取同一来源不制造重复关系

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-STU-01`、`SCN-ERR-01`
- **主要角色**：学生
- **前置条件**：当前本机学习标识已经成功领取某个授权来源，或同一领取请求正在重试。
- **触发**：学生重复提交相同授权码、页面重复发送或网络重试。
- **系统行为**：系统识别同一本机学习标识和授权来源的既有成功领取，返回同一业务关系及当前有效结果，不重复建立来源或覆盖该机器的其它领取。
- **异常结果**：并发请求、延迟响应或一次成功后响应丢失时，不产生多条逻辑重复关系，也不把较旧结果显示为新的范围扩张。
- **验收条件**：连续或并发提交同一码只形成一条有效领取关系；重复操作可以安全恢复结果；领取历史仍能区分失败尝试和唯一成功关系。
- **关联要求**：`DATA-REDEMPTION-*`、`INT-PUBLIC-*`、`NFR-IDEMPOTENCY-*`（待建立）

#### FR-GRANT-008：多个授权来源按有效范围求并集

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-STU-01`、`SCN-STU-04`；`TERM-040`、`TERM-041`
- **主要角色**：学生
- **前置条件**：同一本机学习标识已经领取一个或多个授权来源。
- **触发**：学生新增领取、重新下载、检查更新，或某个来源生效、到期、终止。
- **系统行为**：系统按当前时刻计算全部仍有效授权项的范围并集；课程级范围包含其下已发布内容，课节级和节点级范围只贡献对应稳定对象，重叠范围去重后形成该机器的最终在线资格。
- **异常结果**：某个来源失效、损坏或暂时无法计算时，不得清空其它独立来源，也不得用最后输入的授权码替换此前资格；无法安全确定的范围不纳入本次在线结果。
- **验收条件**：先后领取两个不同范围后同时具备两者并集；终止其中一个后只移除该来源独有的在线范围；被多个来源共同覆盖的内容继续有效。
- **关联要求**：`DATA-ELIGIBILITY-*`、`NFR-REL-*`、`NFR-TIME-*`（待建立）

#### FR-GRANT-009：授权范围裁剪只返回允许的最新发布内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-STU-01`、`SCN-STU-04`；`D-025`
- **主要角色**：学生
- **前置条件**：系统已经计算当前机器的有效资格，并存在对应成功发布版本。
- **触发**：学生领取、重新下载或取得更新。
- **系统行为**：系统从每门课程最新可交付发布版本中按资格裁剪课程、课节和节点，保留必要的课程层级、稳定标识、顺序、视频引用和版本；同一对象被多个授权项覆盖时只返回一次。
- **异常结果**：裁剪后课程为空、发布版本损坏、授权对象在新版本中不存在或结果无法通过课程包契约校验时，不返回该无效课程，也不扩大到相邻课节或相同时间节点。
- **验收条件**：课程级授权取得完整课程；课节级授权只取得指定课节；节点级授权只取得指定稳定节点及运行所需父级结构；多个课程范围得到多个相互独立的课程包。
- **关联要求**：`FR-PUBLISH-*`、`FR-LIB-*`、`DATA-PACKAGE-*`、`SEC-ACCESS-*`（待建立）

#### FR-GRANT-010：仍具资格时可以重新下载和取得更新

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-STU-04`；`TERM-044`、`TERM-045`
- **主要角色**：学生
- **前置条件**：当前本机学习标识已有成功领取记录，且至少一个来源仍对目标范围有效。
- **触发**：本机课程缺失、学生主动重新下载或课程存在较新发布版本。
- **系统行为**：系统不要求学生再次提供原授权码，依据本机学习标识的有效资格返回允许范围内的最新版本；在安装前显示课程、版本和范围变化，实际本机替换由 `FR-LIB-*` 负责。
- **异常结果**：没有有效来源、课程已归档、没有可交付发布版本或服务暂时不可用时，不返回新包，也不把失败解释为本机课程已失效。
- **验收条件**：删除本机课程后仍有资格可以重新下载；发布新版本后仍有资格可以取得更新；授权码领取窗口结束但已领取授权项仍有效时，同一机器仍可使用既有来源资格。
- **关联要求**：`FR-LIB-*`、`DATA-ELIGIBILITY-*`、`INT-PUBLIC-*`、`NFR-REL-*`（待建立）

#### FR-GRANT-011：在线资格失效不删除本机已安装内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-06`；`SCN-TCH-06`、`SCN-STU-03`、`SCN-STU-04`
- **主要角色**：教师、学生
- **前置条件**：学生当前机器已经安装某个课程版本。
- **触发**：授权码领取窗口结束、授权项未生效或到期、授权来源被终止、课程归档、教师账号停用或在线服务不可用。
- **系统行为**：系统只据此重新计算未来领取、重新下载和更新资格；不发送或执行远程删除，不修改已经安装的课程包和本机学习状态，也不承诺离线设备立即感知在线变化。
- **异常结果**：在线检查失败或状态暂时未知时，不把已安装内容标记为已删除；不得用清空本地数据作为权限恢复或错误处理手段。
- **验收条件**：资格失效前已安装的课程仍保留在本机；学生看到“当前不能重新下载或更新”而不是“课程已被收回”；其它本机课程和学习状态不受影响。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`SEC-PRIVACY-*`、`NFR-OFFLINE-*`（待建立）

### 7.4 系统共同职责：安全失败与审计

#### FR-GRANT-012：授权和领取失败保持原状态且限制信息泄露

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-08`；`SCN-STU-01`、`SCN-ERR-01`、`SCN-ERR-02`
- **主要角色**：教师、学生、支持人员
- **前置条件**：系统正在创建、领取、终止、重新下载或计算有效资格。
- **触发**：输入错误、权限拒绝、重复请求、限流、网络中断、存储失败或服务端事务失败。
- **系统行为**：系统在最接近真源的边界拒绝并保留此前有效授权、领取和本机课程；对公开领取统一返回不过度区分码不存在、已过期或已终止的安全错误，对已授权教师提供可操作且不泄露其它工作空间的结果。
- **异常结果**：不得写入部分授权项、部分领取关系或半个课程包；不得把授权码原文、校验摘要、本机学习标识、课程正文、节点内容或学生回答写入普通日志。
- **验收条件**：所有失败路径均可安全重试或明确停止；原有授权来源和课程库保持不变；审计记录只含操作者类型、对象标识、动作、时间、结果和稳定错误类别。
- **关联要求**：`DATA-AUDIT-*`、`SEC-ABUSE-*`、`SEC-LOG-*`、`NFR-REL-*`、`OPS-SUPPORT-*`（待建立）

### 7.5 本功能域完成条件

1. 教师能够对自己已发布的课程、课节或节点建立一组有明确现实时间范围的授权项；
2. 课程级授权可跟随后续发布扩展，课节和节点级授权不会静默扩大到其它对象；
3. 授权码领取窗口、授权项有效时间和本机已安装课程是相互独立的状态；
4. 授权码原文只在创建成功当次显示，之后只保留安全提示、范围和状态；
5. 教师可以永久终止一个来源的未来在线资格，但不能远程删除学生已经安装的内容；
6. 学生无需注册登录即可用本机学习标识建立幂等、可追溯的领取记录；
7. 同一机器的多个有效授权来源按范围求并集，一个来源失效不覆盖其它来源；
8. 领取、重新下载和更新只返回有效资格允许的最新发布内容，并按课程、课节和稳定节点正确裁剪；
9. 同一机器已领取且授权项仍有效时，无需再次提供原授权码即可重新下载或更新；
10. 资格失效、服务故障和授权操作失败都不删除或破坏本机已有课程和学习状态；
11. 公开错误和审计记录不泄露授权码、本机学习标识、课程正文或学生回答。

本功能域通过后，下一段进入 `FR-LIB-*` 学生课程库与更新。

## 8. 学生课程库与更新（`FR-LIB-*`）

本功能域管理课程包已经到达学生机器之后的本机生命周期。在线授权服务只决定当前能否领取、重新下载或更新；
学生课程库负责校验、确认、原子安装、版本替换、本地学习状态迁移和删除，不把在线状态变化直接翻译成本机删除。

### 8.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 通过不含课程正文和学习状态的诊断标识协助定位安装、更新或存储故障 | 不查看或远程修改学生课程库；不替学生删除本机课程；不把示例课程计作真实领取 |
| 教师 | 发布具有稳定身份和兼容信息的课程版本；理解学生可能继续保留旧版本 | 不直接写入学生设备；不强制更新或远程删除；不读取学生本机学习状态 |
| 学生 | 查看并打开多门已安装课程；确认新增和更新影响；选择更新或删除；理解数据只在当前机器 | 不手工修改内部标识或课程包绕过校验；不期待换机自动恢复本机课程和进度 |
| 系统 | 维护本机课程库；校验课程包与版本；隔离各课程状态；原子安装和更新；在失败时保留最近有效数据 | 不因登录退出、网络中断或资格失效清空课程；不把同名课程或相同视频错误合并 |

### 8.2 学生职责：查看和管理本机课程

#### FR-LIB-001：当前机器维护独立且可恢复的学生课程库

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-01`、`SCN-STU-03`；`TERM-032`
- **主要角色**：学生
- **前置条件**：受支持运行环境首次启动或重新打开。
- **触发**：系统创建、读取或恢复当前机器的课程库。
- **系统行为**：系统以本机学习标识为边界保存已安装课程、课程版本、取得来源类型、安装时间和对应本地学习状态；浏览器或运行时重新打开后恢复最近一次确认写入的课程库。
- **异常结果**：教师或管理员退出、会话过期、网络不可用或某门课程在线资格变化时，不得初始化空库覆盖现有数据；换机时不得声称已恢复原机器内容。
- **验收条件**：同一机器重启运行环境后课程与状态仍存在；教师账号退出不影响学生库；新机器建立独立空库并通过有效资格重新下载课程。

#### FR-LIB-002：课程库展示多门课程、课节和当前版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-01`、`SCN-STU-04`；`TERM-033`
- **主要角色**：学生
- **前置条件**：课程库中已有零门、一门或多门课程。
- **触发**：学生打开课程库或安装、更新、删除完成。
- **系统行为**：系统按稳定课程标识列出全部已安装课程，并展示可理解的课程名称、有序课节、当前课程发布版本、来源类型和本机安装或更新时间；内部 UUID 不作为主要名称。
- **异常结果**：同名课程、相同 BVID 或来自不同授权来源时，不得合并成一个课程；名称缺失或记录损坏时显示安全占位和诊断状态，不展示原始内部对象冒充正常课程。
- **验收条件**：多门课程可同时查看；同名但标识不同的课程分别出现；学生能判断当前版本和可打开课节；空库有明确领取入口而非错误状态。
- **关联要求**：`FR-COURSE-*`、`DATA-LOCAL-*`、`NFR-USABILITY-*`（待建立）

#### FR-LIB-003：学生在写入前确认将安装的课程内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`；`SCN-STU-01`
- **主要角色**：学生
- **前置条件**：领取或重新下载已经返回一个或多个合法课程包。
- **触发**：系统准备首次写入当前机器。
- **系统行为**：系统在写入前展示课程名称、课节范围、发布版本、来源类型及本机存储影响，由学生明确确认后安装。
- **异常结果**：学生取消、确认期间资格响应被替换、课程包改变或展示信息与待写入内容不一致时，不写入任何课程。
- **验收条件**：学生可以在确认前辨认要取得的课程和范围；取消后课程库完全不变；确认对象与最终写入包具有相同课程、范围和版本身份。
- **关联要求**：`FR-GRANT-*`、`DATA-PACKAGE-*`、`NFR-USABILITY-*`（待建立）

#### FR-LIB-004：学生可以明确删除一门本机课程及其学习状态

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-06`、`SCOPE-09`；`SCN-STU-03`、`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：目标课程已经安装在当前机器。
- **触发**：学生选择删除该课程并确认影响。
- **系统行为**：系统在确认前说明将删除该课程包及其本机学习状态、当前阶段无法从服务端恢复进度；确认后只删除所选稳定课程标识对应的数据，不终止服务端授权来源和领取记录。
- **异常结果**：学生取消、目标身份不匹配、删除写入失败或并发更新正在进行时，不产生半删除，也不影响其它课程、授权来源或示例课程。
- **验收条件**：删除后目标课程和其本机进度均不可用，其它课程不变；仍具重新下载资格时可再次取得课程，但被明确删除的进度不会恢复。
- **关联要求**：`FR-GRANT-*`、`FR-LEARN-*`、`DATA-DELETION-*`、`NFR-REL-*`（待建立）

### 8.3 系统职责：校验和原子安装

#### FR-LIB-005：课程包通过完整契约校验后才能进入本机课程库

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-05`；`SCN-STU-01`、`SCN-ERR-02`
- **主要角色**：学生
- **前置条件**：系统收到待安装或更新的课程包。
- **触发**：任何课程包准备进入持久化课程库。
- **系统行为**：系统校验响应边界、大小、课程包 Schema 版本、课程发布版本、稳定标识、层级归属、课节顺序、视频引用、节点类型和禁止字段；全部通过后才允许进入确认和写入流程。
- **异常结果**：响应过大、格式无法解释、版本不受支持、课程重复、标识冲突、内容越权或包含禁止数据时，拒绝整批结果且不修改课程库。
- **验收条件**：合法包可以安装；逐类破坏必需字段都会被拒绝；一批多课程中任一包无效时没有课程被部分写入。
- **关联要求**：`FR-PUBLISH-*`、`INT-PACKAGE-*`、`SEC-INPUT-*`、`NFR-COMPAT-*`（待建立）

#### FR-LIB-006：新增课程原子合并且不覆盖其它课程

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-05`；`SCN-STU-01`
- **主要角色**：学生
- **前置条件**：一个或多个新课程包已经校验并由学生确认。
- **触发**：系统把新课程写入已有课程库。
- **系统行为**：系统按稳定课程标识合并新课程；不同课程分别保存，同一批写入作为一个不可分割结果提交，课程包与其初始本地状态共同成功后才显示为已安装。
- **异常结果**：空间不足、并发写入、持久化失败或写后校验失败时，回到写入前的完整课程库，不留下只有课程没有状态或只有部分课程的结果。
- **验收条件**：新增一门课程不改变已有课程；一批多课程全部成功或全部不生效；相同名称和相同视频不会造成错误覆盖。
- **关联要求**：`DATA-LOCAL-*`、`NFR-TRANSACTION-*`、`NFR-CONCURRENCY-*`（待建立）

### 8.4 学生职责与系统共同边界：课程更新

#### FR-LIB-007：同一课程只保留一个当前已安装版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-05`；`SCN-STU-04`；`TERM-029`、`TERM-033`
- **主要角色**：学生
- **前置条件**：课程库已有某个稳定课程标识的已安装版本。
- **触发**：系统收到同一课程的课程包。
- **系统行为**：系统比较课程发布版本和内容身份；更高且兼容的版本进入更新流程，相同版本且内容一致返回“已是当前版本”，较低版本不得替换当前版本。
- **异常结果**：相同版本对应不同内容、版本无法比较、课程标识相同但来源边界冲突或新包要求不受支持的迁移时，拒绝更新并保留现有版本。
- **验收条件**：重复下载同一版本不新增副本；v2 可以受控替换 v1；v1 不能覆盖 v2；同版本内容被篡改时得到错误而不是“已更新”。
- **关联要求**：`FR-PUBLISH-*`、`DATA-VERSION-*`、`MIG-PACKAGE-*`、`NFR-COMPAT-*`（待建立）

#### FR-LIB-008：更新前展示版本、范围和本机数据影响

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-04`、`SCOPE-05`；`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：较新课程版本已通过校验并可根据当前资格取得。
- **触发**：系统准备替换本机当前版本。
- **系统行为**：系统展示当前版本和目标版本，并说明新增、修改、删除或因授权范围变化而不再包含的课节与节点，以及可保留、需重置或将移除的本机学习状态；学生明确确认后才更新。
- **异常结果**：影响无法计算、资格响应在确认期间改变、学生取消或确认对象已过期时，不更新，也不把范围缩小作为后台静默删除。
- **验收条件**：普通更新和范围缩小都能在写入前看到影响；取消后旧课程完整可用；最终写入内容与已确认版本和范围一致。
- **关联要求**：`FR-GRANT-*`、`FR-LEARN-*`、`MIG-PACKAGE-*`、`NFR-USABILITY-*`（待建立）

#### FR-LIB-009：更新只迁移能够安全对应的本机学习状态

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：本机已有课程和学习状态，目标版本包含明确的稳定标识与兼容信息。
- **触发**：学生确认课程更新。
- **系统行为**：系统按稳定课程、课节和节点标识迁移本机状态；身份未变且完成语义兼容的状态可以保留，新增对象从初始状态开始，已删除、越出授权范围或语义不兼容的状态按更新影响处理，不挂到其它对象。
- **异常结果**：兼容关系缺失、同一标识语义冲突、状态损坏或迁移无法完整完成时，拒绝更新或按教师已发布的明确不兼容规则重置受影响项，不无条件清空整门课程进度。
- **验收条件**：未变化节点保留合法完成状态；新增节点没有伪造完成；删除节点状态不迁到相邻节点；单个不兼容节点不会清空其它可安全对应课节和节点的状态。
- **关联要求**：`FR-LEARN-*`、`DATA-LEARNING-*`、`MIG-LEARNING-*`、`NFR-REL-*`（待建立）

#### FR-LIB-010：课程包和迁移状态作为一个原子更新写入

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-04`、`SCN-ERR-02`
- **主要角色**：学生
- **前置条件**：学生已经确认目标版本和迁移影响。
- **触发**：系统执行本机课程更新。
- **系统行为**：系统把新课程包和迁移后的本地学习状态作为同一个不可分割结果写入，并在写后复验成功才切换当前版本；更新过程中旧版本继续作为恢复点。
- **异常结果**：下载中断、存储不足、写入失败、运行环境退出或写后复验失败时，保留并恢复旧课程包及其原学习状态，不显示更新成功。
- **验收条件**：故障发生在任一写入步骤都只能看到完整旧版本或完整新版本；不存在新课程配旧状态或旧课程配新状态；重试不会重复迁移。
- **关联要求**：`DATA-LOCAL-*`、`MIG-LEARNING-*`、`NFR-TRANSACTION-*`、`NFR-REL-*`（待建立）

### 8.5 系统共同职责：离线、示例与存储恢复

#### FR-LIB-011：已安装课程在离线时保持可发现和可打开

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-03`、`SCN-STU-04`
- **主要角色**：学生
- **前置条件**：课程包已成功安装且所引用的宿主视频仍可访问或已由宿主缓存。
- **触发**：网络、KnownMap 服务或授权检查暂时不可用。
- **系统行为**：系统继续从本机课程库列出并打开已安装课程，使用本机包和学习状态运行不依赖在线服务的能力；在线领取、重新下载和更新明确显示为暂不可用。
- **异常结果**：宿主视频本身不可访问时，显示视频不可用而不是删除课程；不得因为无法检查最新版本而把当前课程标为损坏或未授权。
- **验收条件**：断开 KnownMap 服务后课程仍出现在课程库；本机互动和状态保存按本地能力继续；联网恢复后可重新检查更新。
- **关联要求**：`FR-RUNTIME-*`、`FR-LEARN-*`、`NFR-OFFLINE-*`、`NFR-REL-*`（待建立）

#### FR-LIB-012：示例课程与真实授权课程明确隔离

- **状态**：已接受
- **优先级**：P1
- **来源**：`SCOPE-03`、`SCOPE-04`；`SCN-STU-01`；`TERM-034`
- **主要角色**：学生、教师、平台管理员
- **前置条件**：产品随运行环境提供一个或多个示例课程。
- **触发**：课程库初始化、显示、匹配视频、更新、删除或统计课程。
- **系统行为**：系统把示例课程标记为只读示例来源，与授权课程的标识、领取、版本、学习状态和统计分开；同一视频同时匹配示例与真实授权课程时，优先让学生使用真实授权课程。
- **异常结果**：示例损坏、缺失或与授权课程冲突时，不覆盖、降级或阻止真实课程；不得把示例使用记录计作真实领取、完成情况或产品成功证据。
- **验收条件**：学生能识别示例和真实课程；授权课程安装后与示例并存；同视频冲突时打开真实课程；删除真实课程不会把示例伪装成该课程的旧版本。
- **关联要求**：`FR-RUNTIME-*`、`DATA-EXAMPLE-*`、`NFR-USABILITY-*`（待建立）

#### FR-LIB-013：并发操作和存储损坏不破坏最近有效课程库

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-03`、`SCN-ERR-02`
- **主要角色**：学生、支持人员
- **前置条件**：多个领取、更新、删除或学习状态写入可能同时发生，或本机存储记录无法通过校验。
- **触发**：系统开始课程库读改写或检测到损坏、空间不足和版本不兼容。
- **系统行为**：系统串行化或等效协调同一课程库的写操作，写入前基于最新确认状态重新计算；检测异常后停止破坏性写入，隔离受影响记录，并保留可验证的其它课程和支持诊断信息。
- **异常结果**：不得由后到旧响应覆盖新结果，不得为修复一门损坏课程清空整个课程库，也不得把课程正文、学习答案或本机学习标识写入普通日志。
- **验收条件**：同时安装两门课程后两者都存在；更新与学习写入并发时无状态丢失；单门损坏时其它课程仍可读取；无法恢复时明确告知哪些本机数据可能受影响。
- **关联要求**：`DATA-LOCAL-*`、`SEC-LOG-*`、`NFR-CONCURRENCY-*`、`NFR-RECOVERY-*`（待建立）

### 8.6 后续本地文件边界

当前阶段的“保存到本机”只表示课程包和学习状态进入当前浏览器运行环境的持久化存储，不等于已经生成用户可见、
可复制的下载文件。后续 `FR-PORT-*` 将按 `SCN-STU-05` 定义把课程、课节和互动节点配置导出为版本化本地文件；
是否允许重新导入、文件如何校验和迁移，以及是否单独选择导出学生回答与学习进度，必须在该功能域另行审核。

### 8.7 本功能域完成条件

1. 当前机器能够恢复包含多门课程、课节、版本和本地学习状态的学生课程库；
2. 课程库使用可理解名称展示课程和课节，不按标题或视频标识错误合并独立课程；
3. 新课程在校验和学生确认后原子安装，不覆盖其它课程，也不产生部分多课程结果；
4. 同一课程只保留一个当前安装版本，拒绝降级、同版本异内容和不兼容更新；
5. 更新前明确展示版本、授权范围、课节、节点及本机状态变化，并由学生确认；
6. 更新只迁移稳定身份和完成语义都兼容的状态，不无条件清空课程进度；
7. 新课程包和迁移状态共同原子写入，失败时完整保留旧版本；
8. 已安装课程在 KnownMap 服务离线时仍可发现和使用本地能力；
9. 学生可以明确删除一门本机课程及其状态，且删除不终止服务端授权来源；
10. 示例课程与真实授权课程明确隔离，不进入真实领取和完成证据；
11. 并发、空间不足、记录损坏或不兼容不会清空整个课程库，也不会在日志泄露本机内容。

本功能域通过后，下一段进入 `FR-RUNTIME-*` 视频运行时与互动执行。

## 9. 视频运行时与互动执行（`FR-RUNTIME-*`）

本功能域回答学生打开宿主视频后，系统如何选择已安装课程、锁定学习上下文、读取真实播放位置、顺序触发节点、
执行四种基线互动并安全退出。节点产生哪些本机学习记录和如何计算完成情况，由下一段 `FR-LEARN-*` 定义。

### 9.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 通过不含课程正文和学生回答的兼容、宿主和运行错误标识协助排障 | 不远程控制学生播放器；不查看学生本机互动；不代替学生选择课程 |
| 教师 | 通过真实预览验证自己发布的节点在同一运行路径中可执行；对节点内容和完成行为负责 | 不在学生学习中实时修改已锁定版本；不监看学生页面；不把草稿推入运行时 |
| 学生 | 在匹配视频中选择要学习的课程；完成或明确退出互动；在运行故障时得到可执行恢复路径 | 不处理内部课程标识和节点协议；不因普通浏览被强制加入课程；不依赖联网完成已安装内容 |
| 系统 | 精确匹配视频和课节；锁定课程版本；读取可信时间；控制单一互动窗口；校验回答；安全记录结果；在页面变化时清理 | 不猜选歧义课程；不执行课程正文中的代码；不在未匹配页面干预播放；不把失败记成完成 |

### 9.2 系统职责：课程匹配与学习上下文

#### FR-RUNTIME-001：只在受支持环境加载已安装且有效的课程包

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-02`、`SCN-STU-03`
- **主要角色**：学生
- **前置条件**：学生使用受支持的桌面 Chrome 和 B 站原页面；当前机器课程库可读取。
- **触发**：运行时启动、页面刷新或进入新宿主页面。
- **系统行为**：系统只从当前机器已确认课程库读取通过契约校验的课程包和本地学习状态，不依赖教师登录会话，也不在学习开始时把草稿或在线未确认内容混入。
- **异常结果**：运行环境不受支持、课程库不可读、课程包损坏或 Schema 不兼容时，不启动该课程互动，保留宿主页面正常使用并提供课程级错误和恢复入口。
- **验收条件**：合法已安装课程可在离线于 KnownMap 服务时加载；教师退出不影响运行；无效包不会产生节点窗口或播放控制。
- **关联要求**：`FR-LIB-*`、`INT-EXTENSION-*`、`NFR-COMPAT-*`、`NFR-OFFLINE-*`（待建立）

#### FR-RUNTIME-002：使用完整视频引用精确匹配一个课节

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-02`、`SCOPE-05`；`SCN-STU-02`；`FR-COURSE-007`
- **主要角色**：学生
- **前置条件**：当前页面存在可识别的宿主视频，课程库中存在零个或多个课节。
- **触发**：进入视频页、B 站单页导航、分 P 切换或视频身份变化。
- **系统行为**：系统使用当前宿主页面的真实视频身份与课节完整结构化视频引用逐项匹配；仅 BVID 不足以区分目标分段时，必须同时匹配引用中的分 P、CID 或等价定位信息。
- **异常结果**：没有匹配、身份尚未稳定、引用信息不足或视频发生切换时，不挂载课程互动，也不暂停、跳转或修改播放器；课程库入口仍可由学生主动打开。
- **验收条件**：目标视频及分段只匹配正确课节；相邻视频、其它分 P 和普通页面无自动干预；页面身份稳定后可重新匹配。
- **关联要求**：`DATA-VIDEO-*`、`INT-BILIBILI-*`、`NFR-COMPAT-*`（待建立）

#### FR-RUNTIME-003：多个课程匹配同一视频时由学生明确选择

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`；`FR-COURSE-008`
- **主要角色**：学生
- **前置条件**：两个或更多已安装课程中的课节精确匹配当前视频。
- **触发**：系统准备建立当前学习上下文。

- **异常结果**：学生未选择、选择对象已更新或删除、候选身份仍有歧义时，不自动按安装时间、标题、教师、授权来源或示例顺序猜选，也不启动节点时间线。
- **验收条件**：两个不同课程复用同一 BVID 时出现选择；选择其中一门只运行其节点和状态；重新建立会话时仍可选择另一门。
- **关联要求**：`FR-LIB-*`、`DATA-SESSION-*`、`NFR-USABILITY-*`（待建立）

#### FR-RUNTIME-004：一次学习会话锁定课程、课节和发布版本

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-02`、`SCN-STU-04`；`TERM-046`
- **主要角色**：学生
- **前置条件**：系统已经唯一确定或由学生选择一个匹配课节。
- **触发**：学生开始本次课节学习。
- **系统行为**：系统建立可识别学习会话，锁定本机学习标识、课程、课节、课程发布版本和开始时间；课程库随后安装新版本时，当前会话继续使用已锁定内容，直到明确结束并建立新会话。
- **异常结果**：锁定版本从本机消失、上下文身份改变或课程更新无法与当前会话隔离时，安全结束当前互动并提示重新进入，不在会话中热切换节点和答案规则。
- **验收条件**：学习过程中完成课程更新不会改变已打开节点；刷新或明确重新开始后按规则建立新会话；所有节点结果能指回本次锁定版本。
- **关联要求**：`FR-LIB-*`、`FR-LEARN-*`、`DATA-SESSION-*`、`MIG-VERSION-*`（待建立）

### 9.3 系统职责：播放器与时间触发

#### FR-RUNTIME-005：从可信主播放器读取状态并执行最小控制

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`、`SCN-ERR-02`
- **主要角色**：学生
- **前置条件**：当前课节已经匹配，宿主页面可能存在一个或多个媒体元素。
- **触发**：运行时绑定、播放器重建、全屏变化或播放状态变化。
- **系统行为**：系统识别当前可见主播放器，从其真实状态读取播放时间、播放、暂停和结束；只为执行已发布节点使用暂停、继续及明确需要的定位能力，不改变倍速、清晰度、音量或宿主其它设置。
- **异常结果**：主播放器缺失、多个候选无法区分、时间非有限值、控制失败或宿主结构变化时，暂停新的自动触发并进入可恢复错误状态，不用墙上时钟、DOM 进度条像素或推测值伪造播放位置。
- **验收条件**：播放器重建后只绑定一个主实例；读取时间与用户可见播放位置一致；无法可信读取时没有错误时间触发；恢复后可继续监听。
- **关联要求**：`INT-BILIBILI-*`、`NFR-COMPAT-*`、`NFR-REL-*`（待建立）

#### FR-RUNTIME-006：节点只在合法时间穿越时自动触发

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-STU-02`；`TERM-024`
- **主要角色**：学生
- **前置条件**：学习会话已锁定，播放器时间可信，课节包含尚未完成的有效节点。
- **触发**：播放从节点触发时间之前到达或越过该时间。
- **系统行为**：系统按节点触发时间和稳定次序选择最早合法节点，每个节点在一次会话的同一完成状态下只自动触发一次；正常连续播放中到期的后续节点按确定顺序等待当前互动结束。
- **异常结果**：时间抖动、重复事件、暂停期间重复报告或播放器重新绑定时，不重复打开同一节点；时间值越界或节点无效时停止该节点并记录运行错误。
- **验收条件**：正常播放跨过节点时间只出现一次；同一时间的多个节点次序可重复得到且不互相覆盖；完成节点不会因时间事件重复弹出。
- **关联要求**：`FR-LEARN-*`、`DATA-NODE-*`、`NFR-IDEMPOTENCY-*`（待建立）

#### FR-RUNTIME-007：前后跳转和跨越多个节点具有确定行为

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`
- **主要角色**：学生
- **前置条件**：学生拖动进度、点击时间点、切换分段或宿主主动改变播放位置。
- **触发**：播放时间发生明显向前或向后跳变。
- **系统行为**：向前一次跨过多个未完成节点时只触发其中时间最早的一个，其余保持未完成而不连续补弹；向后跳转后，已完成节点不自动重做，未完成节点只有在再次从其触发点之前正常穿越时才可触发。
- **异常结果**：跳转发生在作答中时不替换当前窗口；课程或视频身份同时改变时先按页面切换结束当前上下文，不把旧课节节点带到新视频。
- **验收条件**：从开头跳到片尾不会连续弹出全部节点；回看已完成段落不重复完成；向后越过未完成节点并再次播放到点时可以触发。
- **关联要求**：`FR-LEARN-*`、`DATA-SESSION-*`、`NFR-USABILITY-*`（待建立）

#### FR-RUNTIME-008：同一时刻只执行一个一级互动

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`
- **主要角色**：学生
- **前置条件**：一个节点正在展示，另一个节点到期或学生发起其它课程内动作。
- **触发**：多个互动竞争同一显示和播放器控制权。
- **系统行为**：系统保持单一互动窗口，不中断学生正在填写的回答；正常连续播放产生的到期节点按稳定顺序排队，当前节点按发布规则完成或明确退出后才处理下一个，并在队列处理结束后恢复播放。
- **异常结果**：页面离开、课程身份改变或排队节点已不再属于当前时间语境时，安全取消相应排队项，不把取消记为学生完成或跳过。
- **验收条件**：相邻节点不会同时显示；作答内容不会被后续节点覆盖；队列顺序确定；离开页面后没有旧节点继续弹出。
- **关联要求**：`FR-LEARN-*`、`DATA-SESSION-*`、`NFR-CONCURRENCY-*`（待建立）

### 9.4 学生职责与系统共同边界：完成互动

#### FR-RUNTIME-009：节点窗口完整呈现内容且不执行课程代码

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-STU-02`；`FR-AUTHOR-010`
- **主要角色**：学生
- **前置条件**：合法节点已经触发或由学生按允许路径打开。
- **触发**：系统渲染节点标题、内容、输入、反馈和操作。
- **系统行为**：系统使用统一受控窗口和宿主界面文案，把节点字段作为数据安全渲染；窗口内包含完成该节点所需的题目、选项、答案输入和反馈信息，并适配页面内播放、全屏和可用停靠位置。
- **异常结果**：课程内容中的 HTML、脚本、事件处理器、外部资源或样式不能获得执行权；窗口无法安全挂载、会遮挡关键宿主控件或进入画中画等不可覆盖状态时，使用明确安全布局或停止展示。
- **验收条件**：恶意内容只显示为文本或被拒绝；全屏切换、窗口缩放和页面滚动后窗口仍可操作；节点内容不修改宿主页面样式和其它节点数据。
- **关联要求**：`SEC-CONTENT-*`、`SEC-INPUT-*`、`NFR-ACCESSIBILITY-*`、`NFR-USABILITY-*`（待建立）

#### FR-RUNTIME-010：四种基线节点按已发布规则执行

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-STU-02`；`FR-AUTHOR-005`
- **主要角色**：学生
- **前置条件**：运行时识别节点类型且字段合法。
- **触发**：重点内容、选择题、填空题或问答题进入活动状态。

- **验收条件**：四种类型的输入、提交、反馈和继续行为与教师真实预览一致；同一确定性回答重复计算结果一致；问答题不显示伪造分数或正确率。

#### FR-RUNTIME-011：节点完成前暂停并在明确结果后恢复播放

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`
- **主要角色**：学生
- **前置条件**：当前受支持的 B 站播放器可控，节点要求暂停完成互动。
- **触发**：节点自动触发、学生提交回答、重试、确认继续或明确退出。
- **系统行为**：节点触发时系统先暂停播放器再展示互动；提交后先完成确定性校验并展示反馈，错误答案按已发布规则允许重试或明确继续；只有节点结果成功写入本机或学生明确选择不完成后，才关闭当前互动并恢复或保持用户原有播放意图。
- **异常结果**：暂停失败、回答无效、结果保存失败或恢复播放被浏览器拒绝时，不显示假成功；保留当前输入和反馈，提供重试或由学生手动恢复的路径。
- **验收条件**：节点到点时视频停止；提交后先看到反馈再继续；保存失败不会把节点记成完成并自动放走；学生原本处于暂停状态时不被无条件强制播放。
- **关联要求**：`FR-LEARN-*`、`INT-BILIBILI-*`、`NFR-REL-*`、`NFR-USABILITY-*`（待建立）

#### FR-RUNTIME-012：未知节点类型和不支持能力显式降级

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-03`、`SCOPE-05`；`SCN-ERR-02`；`FR-AUTHOR-011`
- **主要角色**：学生、教师
- **前置条件**：课程使用了当前运行时未知的节点类型、较新协议或宿主暂不支持的非核心效果。
- **触发**：运行时解释或执行节点。
- **系统行为**：未知类型显示“需要更新运行环境”的明确不支持状态，并允许学生安全继续；不支持的非核心视觉或媒体增强可以省略，但节点核心内容和回答路径必须自足，且记录哪些效果未执行。
- **异常结果**：不得白屏、崩溃、静默跳过、误当其它类型或记成学生完成；当前核心定时触发、暂停或安全输入能力缺失时，不得把手动列表冒充正式学生运行路径。
- **验收条件**：测试未知类型得到不支持提示和可退出路径；不支持增强不改变题目语义；缺少核心能力时该节点不产生完成结果。
- **关联要求**：`FR-AUTHOR-*`、`FR-LEARN-*`、`INT-PACKAGE-*`、`NFR-COMPAT-*`（待建立）

### 9.5 系统共同职责：页面生命周期与安全恢复

#### FR-RUNTIME-013：刷新、单页导航和播放器重建不会留下重复运行时

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`；`SCN-STU-02`、`SCN-ERR-02`
- **主要角色**：学生
- **前置条件**：B 站会通过刷新、历史导航、分 P 切换、单页路由或 DOM 重建改变页面。
- **触发**：URL、视频身份、播放器元素、全屏容器或页面可见性变化。
- **系统行为**：系统重新确认页面和视频身份；离开当前课节时及时卸载窗口、时间监听、播放监听、排队节点和临时播放器控制；重新进入时只建立一套运行实例，并从已确认本机状态恢复。
- **异常结果**：旧异步响应、旧计时器和旧播放器事件不得在新页面挂载窗口、覆盖新状态或控制新视频；清理失败时停止新互动并给出恢复动作。
- **验收条件**：在两个视频间多次往返始终最多存在一套课程 UI 和监听；旧视频节点不出现在新页面；刷新后完成节点不重复自动完成。
- **关联要求**：`FR-LEARN-*`、`INT-BILIBILI-*`、`NFR-CONCURRENCY-*`、`NFR-REL-*`（待建立）

#### FR-RUNTIME-014：运行故障不干扰普通视频浏览或泄露本机内容

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-02`、`SCN-STU-03`、`SCN-ERR-02`
- **主要角色**：学生、支持人员
- **前置条件**：插件后台、课程库、宿主播放器或运行组件可能暂时失败。
- **触发**：启动超时、消息无响应、存储失败、组件异常、断网或运行时被重新加载。
- **系统行为**：系统在有限时间内恢复页面可操作状态，停止自身监听和播放器控制，保留宿主原生功能及最近确认的课程和学习状态，并给出重新加载页面、运行环境或课程的明确动作。
- **异常结果**：不得无限加载、循环弹窗、反复暂停、阻止导航或清空本机数据；普通日志不得包含课程正文、节点内容、学生输入、学习状态或本机学习标识。
- **验收条件**：模拟各类组件失败后 B 站原生播放和导航仍可使用；运行环境恢复后可重新进入课程；失败前确认的数据保持不变。
- **关联要求**：`SEC-LOG-*`、`NFR-REL-*`、`NFR-OBS-*`、`OPS-SUPPORT-*`（待建立）

### 9.6 本功能域完成条件

1. 运行时只从本机有效课程库加载内容，并用完整视频引用精确匹配课节；
2. 未匹配页面不受播放干预；多个课程匹配同一视频时由学生明确选择，不由系统猜选；
3. 一次学习会话锁定课程、课节和发布版本，中途更新不热切换节点；
4. 系统从可信主播放器读取时间和状态，无法可信读取时停止自动触发而不伪造时间；
5. 正常播放、前后跳转、相邻节点和同时间节点都具有确定且不重复的触发与排队行为；
6. 同一时刻只执行一个一级互动，不用后续节点覆盖正在填写的回答；
7. 四种基线节点按照已发布内容确定性执行，问答题当前不自动判断开放回答对错；
8. 节点先暂停再展示，结果成功保存或学生明确退出后才按原播放意图恢复；
9. 未知节点和不支持效果显式降级，不白屏、不猜测、不伪造完成；
10. 全屏、刷新、单页导航、分 P 切换和播放器重建不会留下重复 UI、监听或旧课程控制；
11. 运行故障在有限时间内释放宿主页面，不破坏课程库、学习状态或普通视频浏览。

本功能域通过后，下一段进入 `FR-LEARN-*` 本机学习状态。

## 10. 本机学习状态（`FR-LEARN-*`）

本功能域定义学生在当前机器完成互动后必须保存和恢复的事实，包括学习会话、继续位置、节点状态、每次尝试、
课节进度和课程进度。当前阶段这些数据只属于学生本机，不上传服务端，也不构成教师已经看到的学习证据。

### 10.1 角色职责总览

| 角色 | 当前阶段必须完成的职责 | 当前阶段不承担的职责 |
| --- | --- | --- |
| 平台管理员 | 只通过不含学生内容的存储版本和错误类别协助排障 | 不读取、修改或汇总学生本机学习状态；不把本机数据冒充服务端统计 |
| 教师 | 在课程中定义节点行为并理解后续版本可能影响状态兼容 | 当前阶段不查看学生回答、尝试、进度或完成情况；不远程重置学生状态 |
| 学生 | 在本机继续学习；查看当前安装范围内的进度；明确重置或删除自己的本机状态 | 不注册或上传学习数据；不把本机进度理解为跨设备记录或教师已收到反馈 |
| 系统 | 按稳定身份保存会话、位置、节点尝试和完成状态；计算本机范围进度；原子写入；处理重复、并发、损坏和更新迁移 | 不用视频播放百分比猜测课程完成；不覆盖其它课程状态；不在日志或网络请求泄露回答 |

### 10.2 系统职责：状态身份与学习会话

- **优先级**：P0

- **验收条件**：每种节点都有可重复验证的完成条件；错误选择和填空不会完成；问答题完成不带虚假正确率；跳过与完成分别显示。

### 10.4 学生职责与系统共同边界：进度和完成情况

#### FR-LEARN-008：课节进度只按当前安装范围内的节点计算

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-02`、`SCN-STU-04`；`TERM-054`、`TERM-055`
- **主要角色**：学生
- **前置条件**：当前安装课节包含至少一个授权范围内的有效节点。
- **触发**：节点状态改变、课程更新或学生查看课节进度。
- **系统行为**：系统以当前安装发布版本和授权范围内的全部节点为分母，以已完成节点为完成数；全部节点已完成时课节完成，已跳过、已关闭未完成、进行中和不支持节点均不计完成。
- **异常结果**：不得使用视频播放百分比、播放到结尾、打开次数或提交任意一个节点推导课节完成；分母变化时按新版本迁移结果重新计算并说明范围。
- **验收条件**：学生能看到完成数、总数和课节状态；存在任一未完成节点时课节不完成；仅看完视频不改变节点完成数。
- **关联要求**：`FR-LIB-*`、`DATA-PROGRESS-*`、`MIG-LEARNING-*`（待建立）

#### FR-LEARN-009：课程进度只表示当前机器的当前安装范围

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-03`、`SCN-STU-04`；`TERM-054`
- **主要角色**：学生
- **前置条件**：本机课程包含一个或多个已安装课节。
- **触发**：课节完成状态改变、课程范围或版本更新、学生查看课程进度。
- **系统行为**：系统按当前安装范围内各课节的节点总数和完成数汇总课程进度；全部当前范围课节完成时显示“当前安装范围已完成”，并同时标明课程发布版本和本机范围。
- **异常结果**：部分课节或节点授权不得被描述为教师原始整门课程全部完成；进度不得解释为学习效果、掌握程度、成绩或教师已收到结果。
- **验收条件**：部分范围完成时文案明确限定当前安装范围；新增合法课节或节点后进度重新计算；同一课程不同机器可有不同本机进度且不尝试合并。
- **关联要求**：`FR-GRANT-*`、`FR-LIB-*`、`DATA-PROGRESS-*`、`NFR-USABILITY-*`（待建立）

#### FR-LEARN-010：学生可以明确重置课节或课程本机进度

- **状态**：已接受
- **优先级**：P1
- **来源**：`SCOPE-06`；`SCN-STU-03`
- **主要角色**：学生
- **前置条件**：目标课节或课程已有本机学习状态。
- **触发**：学生选择重新学习并确认重置范围。
- **系统行为**：系统说明将清除的继续位置、输入草稿、节点尝试和完成状态；确认后只重置所选课节或课程的本机学习状态，不删除课程包、授权来源或领取记录。
- **异常结果**：学生取消、身份不匹配、并发学习仍在写入或持久化失败时，不产生部分重置，也不影响其它课程。
- **验收条件**：重置课节只清除该课节；重置课程清除其全部课节进度但课程仍可打开；失败后原状态完整保留。
- **关联要求**：`FR-LIB-*`、`DATA-DELETION-*`、`NFR-TRANSACTION-*`（待建立）

### 10.5 系统共同职责：本机边界与恢复

#### FR-LEARN-011：学习状态只在当前机器保存且不自动上传

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-06`；`SCN-STU-03`；`D-026`
- **主要角色**：学生、教师、平台管理员
- **前置条件**：运行时产生继续位置、输入草稿、回答、反馈、尝试或完成状态。
- **触发**：系统持久化、读取、展示、诊断或准备网络请求。
- **系统行为**：系统把学习状态保存到当前机器并只用于本机恢复和计算；当前阶段不向服务端、教师或管理员上传学生回答、尝试、位置、进度和完成情况，也不标记为待同步或已同步。
- **异常结果**：任何在线领取、更新、健康检查、错误上报或普通日志不得夹带这些数据；需要未来上传时必须重新打开 `SCOPE-07` 和相应隐私、安全、保留删除需求。
- **验收条件**：断网仍能保存和查看本机状态；检查网络请求与日志不包含学习内容或本机学习标识；教师端当前没有真实学生报表。
- **关联要求**：`FR-REPORT-*`、`DATA-LEARNING-*`、`SEC-PRIVACY-*`、`SEC-LOG-*`（待建立）

#### FR-LEARN-012：重复、并发和存储故障不制造虚假进度

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-06`；`SCN-STU-02`、`SCN-STU-03`、`SCN-ERR-02`
- **主要角色**：学生、支持人员
- **前置条件**：播放位置、输入草稿、节点尝试、更新迁移或重置可能并发写入同一课程库。
- **触发**：重复事件、旧响应晚到、空间不足、运行环境退出、状态损坏或存储接口失败。
- **系统行为**：系统协调同一课程和课节的写入，基于最近确认状态应用幂等事件；失败时保留最近有效状态，隔离无法解释的局部记录并提供不含学习内容的诊断标识。
- **异常结果**：不得丢失其它节点尝试、重复增加尝试数、把失败写入记为完成、让旧事件回退新状态，或为修复一条记录清空整门课程和其它课程。
- **验收条件**：重复提交只记一次；两个不同节点并发保存后两者都存在；故障后最多丢失未确认变化，已确认进度保持；单节点损坏不影响其它合法状态。
- **关联要求**：`FR-LIB-*`、`DATA-LEARNING-*`、`NFR-CONCURRENCY-*`、`NFR-RECOVERY-*`（待建立）

#### FR-LEARN-013：课程更新只保留可证明兼容的学习状态

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-05`、`SCOPE-06`；`SCN-STU-04`；`FR-LIB-009`
- **主要角色**：学生
- **前置条件**：学生确认安装同一课程的较新发布版本。
- **触发**：课程库迁移继续位置、草稿、尝试和节点完成状态。
- **系统行为**：稳定课节和节点身份、类型、完成语义及发布兼容信息共同证明兼容时才迁移状态；继续位置必须仍在目标视频有效范围，未提交草稿和历史尝试按更严格兼容规则处理。
- **异常结果**：仅标识相同但题目、答案、反馈或完成条件已发生不兼容变化时，不沿用旧完成结果；无法证明时只重置受影响对象并在更新确认中说明。
- **验收条件**：纯文案兼容修改可按发布声明保留状态；答案规则改变的节点不继承完成；一个节点不兼容不会清空其它可证明兼容的课节和节点。
- **关联要求**：`FR-LIB-*`、`DATA-LEARNING-*`、`MIG-LEARNING-*`（待建立）

### 10.6 后续可携带与教师反馈边界

后续本地课程文件、学习数据导出和教师查看完成情况是三个独立能力。`SCN-STU-05` 当前只候选导出课程与互动
配置，不默认包含本段的继续位置、草稿、回答、尝试或完成状态；`SCN-TCH-07` 重新纳入前，本机学习状态也不能
作为教师报表来源。未来若允许学生主动导出或上传学习状态，必须明确选择范围、文件或传输保护、身份关联、撤回、
保留、删除和失败恢复规则。

### 10.7 本功能域完成条件

1. 所有学习状态都绑定本机学习标识、课程、课节、课程发布版本和必要的节点身份；
2. 学习会话、继续位置、节点状态、输入草稿和正式尝试是可区分的对象；
3. 每次正式提交形成幂等、可追溯的本机节点尝试，未提交输入不增加尝试次数；
4. 重点内容、选择题、填空题和问答题分别使用明确且可验证的完成规则；
5. 课节进度只按当前安装范围内节点完成数计算，课程进度明确限定当前机器、范围和发布版本；
6. 播放到结尾、打开课程、提交任意节点、跳过或运行时不支持都不能伪造完成；
7. 学生可以从最近确认位置继续，也可以明确重置课节或课程进度；
8. 当前阶段学习状态只在本机保存，不上传、不跨设备合并、不进入教师报表；
9. 重复、并发、存储失败和局部损坏不制造虚假进度或清空其它合法状态；
10. 课程更新只迁移稳定身份和完成语义均可证明兼容的状态，不兼容只影响对应对象；
11. 后续课程配置导出、学习状态导出和教师反馈分别审核，不从本机保存自动推出。

本功能域通过后，下一段进入 `FR-ADMIN-*` 平台管理、支持与审计。

## 11. 平台管理、支持与审计（`FR-ADMIN-*`）

- **验收条件**：管理员可以区分教师并核对账号状态和已发布课程数量；修改试用跟进状态不会影响教师登录和业务数据；教师不能访问该目录。

#### FR-ADMIN-002：高风险管理动作先确认对象和影响

- **触发**：管理员选择目标动作。
- **系统行为**：系统显示目标教师、当前状态和操作影响，管理员确认后才执行 `FR-AUTH-*` 已定义的账号操作。
- **异常结果**：目标或权限已变化、请求重复或执行失败时，不显示假成功，也不产生部分状态。
- **验收条件**：重置密码或停用账号前能看到影响；操作不会删除课程等业务数据；对错误教师不能执行。
- **关联要求**：`FR-AUTH-003`、`FR-WS-*`、`SEC-ACCESS-*`、`NFR-IDEMPOTENCY-*`（待建立）

### 11.3 审计职责

#### FR-ADMIN-003：高风险业务动作可追溯

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-ADM-01`、`SCN-ADM-02`、`SCN-ADM-03`、`SCN-TCH-04`、`SCN-TCH-05`
- **主要角色**：平台管理员、教师、支持人员
- **前置条件**：系统执行账号管理、课程发布或归档、授权创建或终止、恢复等高风险动作。

- **系统行为**：系统记录操作者、动作、对象、时间和结果；有权人员能够查询这些记录。日志只保存定位所需信息，不保存密码、授权码原文、完整课程内容或学生本机学习数据。
- **异常结果**：审计不可用时不得把高风险动作显示为完整成功；重复请求不能形成互相矛盾的记录。
- **验收条件**：能够追溯教师停用、课程发布和授权终止；失败同样有结果；普通教师和学生不能查看平台审计。

### 11.4 支持与恢复职责

- **系统行为**：系统显示当前生效版本、检查时间和核心业务所需组件的健康结果。
- **异常结果**：版本不明、检查超时或依赖不可用时显示未知、降级或不可用，不沿用旧成功结果。
- **验收条件**：支持人员能够确认当前版本和故障范围；服务部分故障时不显示为完全健康。

#### FR-ADMIN-005：故障结果提供安全的支持标识

- **状态**：已接受

- **前置条件**：核心操作失败、降级或需要人工支持。
- **触发**：系统向教师或学生展示失败结果。

- **验收条件**：支持标识不包含秘密和学习内容；支持人员能区分主要故障范围；无法关联时不捏造结论。
- **关联要求**：`INT-ERROR-*`、`NFR-SUPPORT-*`、`NFR-OBS-*`、`SEC-LOG-*`（待建立）

#### FR-ADMIN-006：支持和恢复遵守最小范围

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-08`；`SCN-ADM-03`
- **主要角色**：支持人员、平台管理员
- **前置条件**：存在明确故障或支持请求，普通诊断不足以解决，且目标恢复步骤已经批准。
- **触发**：支持人员请求受保护信息或执行恢复、回滚、数据恢复。

- **异常结果**：权限、范围、版本或备份无法确认时停止操作；不得用共享账号或直接改库绕过流程，也不得扩大恢复范围。
- **验收条件**：支持人员只能访问批准范围；恢复失败不覆盖最近有效数据；处置结果能够区分已恢复、部分恢复和未恢复。
- **关联要求**：`FR-LEARN-011`、`SEC-ACCESS-*`、`DATA-BACKUP-*`、`OPS-RESTORE-*`（待建立）

### 11.5 本功能域完成条件

1. 管理员能够查看必要的教师运营状态，试用跟进不改变账号和课程状态；
2. 高风险账号操作先确认对象和影响，并复用已经审核的认证规则；
3. 账号、发布、授权和恢复等高风险动作可追溯，审计不保存敏感业务原文；
4. 支持人员能够确认当前版本和核心健康状态；
5. 教师和学生能够取得安全的错误标识，支持人员能够据此定位问题；
6. 支持和恢复只作用于批准范围，不默认读取课程正文，也不能远程读取学生本机回答和进度。

### 12.1 角色职责总览

| 角色 | 当前阶段职责 | 当前阶段边界 |
| --- | --- | --- |
| 教师 | 导出自己课程的已保存配置；检查并导入合法文件 | 不能导出其他工作空间内容；导入不会直接发布或覆盖原课程 |
| 学生 | 无当前阶段操作 | 学生课程文件、回答和进度导出继续作为后续能力 |
| 系统 | 生成带格式版本的文件；导入前校验并原子建立新草稿 | 不包含视频、凭证、学生数据或未保存页面内容 |

### 12.2 教师职责

#### FR-PORT-001：教师导出自己课程的已保存配置

- **状态**：已接受
- **优先级**：P1
- **来源**：`SCOPE-09`；`SCN-TCH-08`
- **主要角色**：教师
- **前置条件**：目标课程属于当前教师工作空间，并存在已保存草稿或发布版本。
- **触发**：教师选择课程和导出版本。
- **系统行为**：系统生成一个带格式版本、课程名称、来源类型和来源版本的本地文件；导出对象是教师明确选择的已保存草稿或发布版本。
- **异常结果**：权限不足、目标不存在、生成失败或下载取消时不显示成功，也不改变课程状态。
- **验收条件**：文件能够辨认课程和来源版本；未保存页面修改不会混入文件；教师不能导出其他工作空间课程。
- **关联要求**：`DATA-EXPORT-*`、`SEC-ACCESS-*`、`INT-FILE-*`（待建立）

#### FR-PORT-002：课程文件只包含可携带的课程配置

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-09`；`SCN-TCH-08`
- **主要角色**：教师
- **前置条件**：系统准备生成课程配置文件。
- **触发**：导出内容被组装和校验。
- **系统行为**：文件包含课程、课节、视频引用、节点配置和还原教学语义所需的版本信息；不包含视频文件、密码、会话、授权码、学生数据，未进入已保存课程配置的字幕原文也不包含在内。
- **异常结果**：发现越权对象、秘密或无法识别的数据时拒绝生成，不以删减后的不完整文件冒充成功导出。
- **验收条件**：检查文件可以还原课程结构和节点行为；敏感内容与视频文件不存在；文件不构成视频下载或授权转移。
- **关联要求**：`DATA-EXPORT-*`、`SEC-PRIVACY-*`、`INT-FILE-*`（待建立）

#### FR-PORT-003：导入课程文件默认建立新的课程草稿

- **状态**：已接受
- **优先级**：P1
- **来源**：`SCOPE-09`；`SCN-TCH-08`
- **主要角色**：教师
- **前置条件**：教师选择了一个通过基础读取的 KnownMap 课程文件。
- **触发**：教师查看导入摘要并确认。
- **系统行为**：系统展示课程、课节、节点数量、来源版本和兼容结果；确认后在当前工作空间建立具有新平台身份的课程草稿，并保留原有教学结构和节点语义。
- **异常结果**：教师取消、目标空间不可用或写入失败时不建立部分课程；导入不覆盖同名课程，不自动发布，也不创建授权。
- **验收条件**：同一文件可以导入为独立新草稿；原课程保持不变；导入结果必须由教师再次预览和发布后才影响学生。
- **关联要求**：`FR-COURSE-*`、`FR-AUTHOR-*`、`FR-PUBLISH-*`、`DATA-IMPORT-*`（待建立）

#### FR-PORT-004：无效或不兼容文件不改变现有数据

- **状态**：已接受
- **优先级**：P0
- **来源**：`SCOPE-09`；`SCN-TCH-08`、`SCN-ERR-02`
- **主要角色**：教师
- **前置条件**：系统正在读取、校验或写入导入文件。
- **触发**：文件损坏、格式版本不支持、结构无效、内容超限或写入失败。
- **系统行为**：系统拒绝导入并说明主要原因；只有完整校验和完整写入都成功后，新课程草稿才可见。
- **异常结果**：不得执行文件中的代码，不得产生半门课程、覆盖现有课程或影响已发布版本和授权。
- **验收条件**：任一失败阶段后现有数据保持不变；修正或更换合法文件后可以重新导入；重复确认不会产生非预期重复结果。
- **关联要求**：`INT-FILE-*`、`SEC-INPUT-*`、`NFR-TRANSACTION-*`、`MIG-FORMAT-*`（待建立）

### 12.3 后续能力边界

`SCN-STU-05` 的学生课程文件不进入当前实现；未来文件是否包含学习状态必须另行审核。平台数据库、发布版本和
配置的备份、恢复及 v0.9.1 迁移分别进入数据、部署运维和迁移兼容需求，不用教师课程文件代替生产备份。

### 12.4 本功能域完成条件

1. 教师可以导出自己课程的已保存草稿或指定发布版本；
2. 文件能够还原课程结构与节点语义，但不包含视频、凭证和学生数据；
3. 导入前显示摘要和兼容结果，确认后只建立新的课程草稿；
4. 导入不覆盖原课程、不自动发布、不创建授权；
5. 无效、不兼容或写入失败的文件不会改变现有数据；
6. 学生课程文件、生产备份和版本迁移继续由各自后续需求审核。

## 13. 公开试用申请与人工接入（`FR-INTAKE-*`）

#### FR-INTAKE-001：公开销售页只承诺当前可交付的试用能力

- **状态**：已接受
- **优先级**：P0
- **来源**：`D-V1-001`、`SCOPE-10`；`SCN-PUB-01`
- **主要角色**：目标老师、平台运营人员
- **前置条件**：公开销售页作为正式获客入口对外提供。
- **触发**：未登录访问者查看产品和试用说明。
- **系统行为**：页面清楚说明目标老师、当前交付环境、试用内容、人工协助边界和申请方式；主要申请入口与人工联系恢复入口可辨认，不把未交付的 AI、报告、自动开户或其它未来能力写成现有事实。
- **异常结果**：正式申请入口不可用或配置无效时隐藏或禁用该入口并显示真实恢复方式，不以占位链接、内部编辑地址或复制话术冒充申请成功。
- **验收条件**：无登录访问者能理解“申请一次真实课程试用”的实际结果；页面承诺与发布版本一致；入口失效时仍能找到明确人工联系方式。
- **关联要求**：`DATA-INTAKE-*`、`INT-TRIAL-*`、`SEC-PRIV-003`、`OPS-HEALTH-002`

#### FR-INTAKE-002：目标老师无需登录即可提交最小试用信息

- **状态**：已接受
- **优先级**：P0
- **来源**：`D-V1-001`、`SCOPE-10`；`SCN-PUB-01`
- **主要角色**：目标老师
- **前置条件**：正式飞书公开表单可访问，且页面已说明用途、第三方处理、必填项和可选项。
- **触发**：目标老师填写并提交申请。
- **系统行为**：必填项只包含称呼、联系方式、视频状态、一个最想解决的教学问题和字幕情况；B 站链接及用于验证个性化教学需求的问题保持可选；提交不要求 KnownMap 教师账号。
- **异常结果**：必填缺失、格式无效、网络失败或外部表单未确认接收时不显示成功，申请者可以修正或通过人工联系入口继续。
- **验收条件**：无登录状态可完成一份最小申请；可选项留空不阻止提交；失败与成功结果可区分；提交页面不显示其他申请者内容。
- **关联要求**：`DATA-INTAKE-001`、`INT-TRIAL-001`、`SEC-PRIV-003`

#### FR-INTAKE-003：授权运营人员能够取得申请并人工跟进

- **状态**：已接受
- **优先级**：P0
- **来源**：`D-V1-001`、`SCOPE-10`；`SCN-PUB-01`
- **主要角色**：平台运营人员
- **前置条件**：表单已确认接收申请；运营人员通过批准的飞书权限访问申请结果。
- **触发**：出现新申请或运营人员检查待跟进申请。
- **系统行为**：授权运营人员能够看到接入所需字段、识别提交时间和来源并记录人工跟进结果；申请内容不自动进入教师工作空间、课程、日志正文或公开页面。
- **异常结果**：无权限、申请缺失、重复、外部服务不可用或字段不完整时明确标记待核对，不猜测信息、不自动创建账号。
- **验收条件**：使用虚构申请完成提交、授权读取和人工跟进；未授权访问被拒绝；运营人员能够区分新申请、已联系和无法联系等真实状态。
- **关联要求**：`DATA-INTAKE-001`、`DATA-INTAKE-002`、`INT-TRIAL-002`、`SEC-PRIV-003`

#### FR-INTAKE-004：试用申请与教师账号创建保持受控分离

- **状态**：已接受
- **优先级**：P0
- **来源**：`D-V1-001`、`SCOPE-01`、`SCOPE-10`；`SCN-PUB-01`、`SCN-ADM-01`
- **主要角色**：平台运营人员、平台管理员、目标老师
- **前置条件**：运营人员已取得申请并完成必要人工确认。
- **触发**：平台决定接受申请者进入教师试用。
- **系统行为**：运营人员把已确认接入结果交给有权管理员；管理员仍按受控教师创建流程建立账号和工作空间；申请记录只保留关联状态或安全引用，不直接成为认证身份。
- **异常结果**：申请提交、跟进或确认失败时不创建半成品账号；重复申请不自动创建多个教师；拒绝或暂不接入不删除必须保留的运营证据，也不授予任何权限。
- **验收条件**：提交申请后不能登录；只有管理员明确创建后才能获得教师身份；申请、教师账号和试用跟进状态可区分并按权限关联。
- **关联要求**：`FR-AUTH-002`、`FR-WS-001`、`DATA-INTAKE-002`、`DATA-OPS-001`、`SEC-ACCESS-001`
