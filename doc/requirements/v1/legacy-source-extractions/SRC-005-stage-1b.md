## 1. 提取结论

该文件把三类内容写在同一阶段：公开销售与试用申请、单课程教师工作台、具体字幕和节点编辑器设计。核对结果如下：

- 课程输入、字幕本机解析、四类节点、草稿保存、真实预览和失败恢复已由 v1 需求覆盖；
- 单课程草稿、固定页面路径、具体字幕列行数、右键/双击弹窗、消息操作和本地存储键属于旧实现或 UI 设计，不进入需求真源；
- 更换 URL 后清除旧课程的规则已被 v1 稳定课程与课节身份要求替代；
- 销售页和飞书试用申请表已由产品负责人确认属于 v1 P0 正式发布范围；
- 该结论已形成 `D-V1-001`，并同步到产品、场景、功能、数据、接口、隐私、运维和验收要求。

## 4. 已决定：公开销售与试用申请进入 v1 P0

### 4.1 已知事实

- 旧 1B 把销售首页的主要动作定义为“申请改造一节真实课程”；
- 次要入口使用无需登录的飞书公开表单，收集称呼、联系方式、视频状态、可选 B 站链接、教学问题和字幕情况；
- 当前 v1 已要求管理员受控创建教师，并管理教师试用跟进状态，但没有定义公开获客页面、外部表单、联系方式收集或线索进入教师账号的流程；
- 把该入口纳入 v1 会新增外部服务依赖、个人联系方式处理、表单失效恢复、线索归属和从申请到教师账号的验收责任；
- 不纳入 v1 不等于删除现有销售页或表单，它们可以作为独立运营入口继续保留，直到另行替换或停止。

### 4.2 已接受方案

产品负责人确认公开销售页和飞书表单属于 v1 P0。正式闭环从目标老师查看真实承诺和提交申请开始，经过授权运营人员人工跟进，再由管理员受控创建教师；申请入口可用性进入发布门禁。

范围保持最小：继续使用飞书公开表单，不建设 CRM、自动营销、自动开户、开放注册或复杂线索评分。具体要求见 [`D-V1-001`](../../../decisions/2026-08-21-v1-public-trial-intake.md)。
