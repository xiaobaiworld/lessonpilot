## 1. 提取结论

该文件是 v0.2 发布前的平台化产品设想，混合当前需求、远期方向、建议数据模型、API、开发任务和验收标准。核对结果如下：

- 工作空间、课程—课节—视频、脚本版本、授权码—领取—授权来源—有效资格、多授权来源合并和审计原则已由 v1 覆盖；
- 长期学生身份、Google 登录、匿名合并、学习事件上传、跨设备同步和教师学生报表已由 `D-026` 推迟，不进入当前阶段；
- seat limit、授权暂停/恢复、教师助手、课程合集、工作空间通行证、外部 API、Webhook、订单关联和支付衔接保留为未来候选；
- 建议表、字段、API 路径和开发任务属于旧设计，不作为 v1 契约或实施计划；
- 未发现需要新增或修改的 v1 需求，也没有人工决策项。

## 3. 已推迟或否决的当前范围

### 3.1 学生身份和学习数据上传

v0.1 要求内部 Learning Identity、设备身份、Google 登录、匿名身份合并、服务端学习事件和教师报表。`D-026` 已决定当前阶段只使用单机本地学习标识，不提供学生登录、个人学习数据上传、跨设备恢复或身份合并。

处理结论：相关数据模型、API、事件、教师学生列表和验收标准不进入当前 v1；它们只作为 `SCOPE-07` 后续阶段候选。当前不得预建服务端学生画像或用本机测试数据冒充教师报表。

### 3.2 授权码扩展能力

以下内容不在当前已接受范围，保留为未来候选：

- 单人、限定人数和不限人数领取及 `seat_limit`；
- 授权码 Draft、Paused、Exhausted、恢复和延长有效期；
- 教师审批、自动加入学生列表、外部订单和来源字段；
- 课程合集、当前全部课程通行证和未来课程通行证。

当前 v1 只保留已接受的范围授权、领取窗口与授权有效期分离、多来源合并、终止未来在线资格及本机内容不被远程删除。候选能力只有出现真实业务证据后才能新增。

### 3.3 组织、外部系统和商业化

教师助手、细粒度权限、班级、外部授权 API、Webhook、API Client、订单关联、支付、退款和分账均不进入当前阶段。数据设计不得为了这些未接受能力提前创建无当前验收价值的复杂状态。

## 4. 设计与历史证据去向

- `User`、`LearningIdentity`、`Grant`、`Entitlement`、`LearningEvent` 等建议实体只保留为概念历史，v1 数据设计以已接受数据需求重新建立；
- 建议 API 路径、Google 认证流程、批量学习事件、学生列表和教师端点不构成 v1 接口承诺；
- `bvid + cid` 或等价稳定组合证明分 P 需要精确引用，具体字段留给视频引用设计；
- 原始学习事件和聚合结果并存的方案属于后续学习证据阶段，当前不采集无关浏览事件；
- Task A–G 和 v0.1 验收标准是被 v0.2 及后续实现替代的历史计划，不能作为当前完成证据；
- AI 动态生成、条件节点、知识点掌握和跨课程复习继续作为远期方向，不因本文件出现而进入 v1。
