## 1. 提取结论

该文件混合了旧阶段需求、2026-08-20 前后的实现状态、具体 UI 设计、测试夹具和生产验收门禁。核对结果如下：

- 教师认证、工作空间隔离、多课程多课节、四类节点、课程发布、范围授权、插件课程库和本机学习状态已由 v1 覆盖；
- `studentCourseStore`、`CoursePackage v2`、`AccessGrant[]`、固定页面、固定视频和具体 API 响应是当前实现及迁移证据，不冻结为 v1 目标契约；
- “测试期无旧数据，因此直接舍弃旧格式”缺少生产与已分发产物盘点证据，不能作为迁移结论；
- 具体编辑器布局、时间线交互、图标和日志级别进入后续设计或测试参考，不作为需求层新增规则；
- 未发现需要新增或修改的 v1 需求，也没有需要立即提交用户判断的产品取舍。

## 4. 被替代或不采纳的旧规则

### 4.1 未盘点就直接丢弃旧数据

源文件以“测试期没有正式旧课程数据”为由，要求拒绝旧单课程响应并直接舍弃 `installedCourse` 和 `learningState`，不提供迁移路径。

处理结论：不把这句话当成已验证事实。`MIG-SOURCE-001` 要求先清点生产数据库、实际分发插件和代表性本机存储；`MIG-LOCAL-001`、`MIG-LOCAL-002` 允许拒绝不可证明兼容的旧结构，但必须先识别、保留用户确认前的原数据，并给出明确结果，不能静默清除。

### 4.2 固定授权期限和缺失授权生命周期

源文件把短期授权固定为 7 天、长期授权设为永不过期，同时不提供停用、领取记录或多个授权来源的服务端资格合并。

处理结论：7 天和永久只是旧实现策略，不进入 v1 需求。`FR-GRANT-002` 将领取窗口与授权有效期分开；`FR-GRANT-005` 至 `FR-GRANT-010` 已要求终止未来资格、记录领取、合并多个有效来源以及在仍具资格时更新。具体默认期限留给后续业务规则或配置设计，不从旧代码反推。

### 4.3 旧阶段非目标已经变化

管理员闭环、教师账号管理、授权领取记录、授权终止、环境配置、生产监控、备份和恢复在该阶段被排除，但 v1 已分别纳入 `FR-ADMIN-*`、`FR-GRANT-*`、`DEV-DEP-002` 和 `OPS-*`。这些旧非目标不再约束 v1。

Chrome Web Store 仍未确定是否作为正式分发渠道，继续由 `OPEN-02` 决定；AI 自动评分、自动追问及未经教师审核自动发布继续保持非目标，教师审核后的辅助制作仍由 `OPEN-06` 决定。

### 4.4 尚未实施的复听和复习能力

源文件称“上一句、下一句、一次复听、三次复听、持续循环”为已接受设计，但同时明确未进入当前课程包；有效学习次数、复听次数和待复习清单也未实现。

处理结论：这些内容不在当前已接受 v1 范围中，也没有真实交付证据。保留为未来候选，不因旧文件使用“已接受设计”字样而新增需求；若后续出现用户证据，需重新进入需求审核。
