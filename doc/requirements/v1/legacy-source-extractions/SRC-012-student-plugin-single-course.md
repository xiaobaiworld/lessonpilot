## 提取结论

旧记录同时描述单课程覆盖、可重复授权码、课程包、字幕句导航、有效学习次数、复听次数和确定性复习清单。v1 已明确多课程、课程包最小化、字幕全文不进入课程包以及学生学习状态保持本机，但尚未明确是否把“字幕句导航”和“有效学习/复习指标”作为当前学生运行闭环。

## 待决定范围

请产品负责人确认以下两项是否进入 v1 P0：

1. 学生插件是否需要课程包内的字幕句文本和上一句/下一句/复听导航；
2. 学生插件是否需要记录“有效学习次数”、复听次数和确定性待复习清单。

建议：**两项均不进入 v1 P0**，先验证授权领取、打开匹配视频、四类互动节点和本机基础状态；字幕全文继续只在教师本机制作，学习指标待真实学习反馈需求出现后再单独定义。
