## 1. 提取结论

该文件定义旧单课程预览运行时的 BVID 匹配、SPA 生命周期、节点调度、学习窗口、本机会话和开发者模式交付。核对结果如下：

- 精确视频匹配、可信播放器、最小控制、SPA 重绑、单一活动窗口、seek 队列和故障降级已由 v1 运行时及接口需求覆盖；
- 四类节点的确定行为、跳过与完成区分、问答不自动评分、本机答案和日志最小化已进入 v1 功能、数据和安全要求；
- 唯一 `currentCourse`、`updatedAt` 会话、固定状态机、答案存储类型和开发者模式加载属于旧实现或测试证据；
- 旧预览“刷新后允许重新触发”不能用于覆盖真实学生学习状态，v1 已将预览与真实学习隔离；
- 未发现新增需求或人工决策项。

## 3. 被替代或需重新设计的内容

| 旧规则 | v1 处理 |
| --- | --- |
| 运行时只读取唯一 `currentCourse` | 由多课程库、明确选择及完整视频引用匹配替代 |
| 会话只绑定 `courseId + updatedAt` | v1 学习状态绑定本机、课程、课节、发布版本和节点稳定身份 |
| 状态只有 pending / active / completed / skipped | v1 还区分进行中、关闭未完成、不支持、尝试及草稿等事实 |
| 刷新一律建立可重新触发的新会话 | 只可用于隔离预览；真实学习按持久状态、时间穿越和重新学习规则决定 |
| 换课清除旧 active session | 多课程状态按课程和课节隔离，不用全局清除替代精确生命周期 |
| 选择/填空答案保存字符串、重点答案固定 null | 属于字段设计，不在需求层固定存储表示 |
| 填空固定英文 `casefold` | 使用已发布的明确判断规则，具体归一化由契约和内容设计决定 |
| 所有课程通过开发者模式加载仓库 `src/` | 只是旧验收环境；正式分发、更新和回退继续由 `OPEN-02` 决定 |

## 4. 设计、迁移与证据去向

- 播放器适配模块、有限重试、观察器清理、稳定节点排序和队列实现进入运行时设计；
- `currentCourse`、旧 preview session 及状态枚举进入 `MIG-LOCAL-002`、`MIG-CONTRACT-001` 对照，不建立长期兼容层；
- 固定 BVID、35 秒弹窗、吉祥物按钮等明确不是课程真源，保留为历史原型证据；
- 1C 的“等待 1A、1B 后实施”和完成清单是 2026-08-15 历史计划，按 `ACC-LINK-002` 对精确代码和真实 Chrome 证据重新判断；
- 销售页展示与真实结果一致的原则现由 `FR-INTAKE-001` 和 v1 发布门禁承接。
