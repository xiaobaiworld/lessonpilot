## 1. 文档范围

本文件只记录 KnownMap 特有的跨边界协作要求，以及一旦理解不同便会改变产品行为的接口约定。
通用的参数校验、身份校验、安全错误、超时、重试、日志、传输加密等工程常识，不在这里重复编号；
它们由全局开发规范以及后续的非功能、安全、开发质量和设计文档统一约束。

本文件覆盖五类边界：

| 编号域 | 边界 |
| --- | --- |
| `INT-WEB-*` | 管理员或教师网页与服务端业务能力之间 |
| `INT-EXT-*` | 插件页面、后台脚本、内容脚本及教师真实预览之间 |
| `INT-BILI-*` | 插件与受支持的哔哩哔哩网页及播放器之间 |
| `INT-PACKAGE-*` | 兑换码、课程发布包、下载和本地安装之间 |
| `INT-FILE-*` | 字幕文件及教师课程导入导出文件之间 |
| `INT-TRIAL-*` | 公开销售页、飞书试用表单与人工运营接入之间 |

### 1.1 单条需求格式

每条需求只保留以下九项，以便后续设计、测试和追踪：

1. 状态；
2. 优先级；
3. 来源；
4. 边界参与方；
5. 输入或前置条件；
6. 成功结果；
7. 失败与恢复；
8. 安全边界；
9. 验收。

需求之间的上下游关系不再写进条目，统一由
[`doc/traceability/v1-requirements.tsv`](../../traceability/v1-requirements.tsv) 单向维护。

## 2. Web 业务边界

#### INT-WEB-001：按角色隔离 Web 业务能力

- 状态：已接受
- 优先级：P0
- 来源：管理员职责、教师职责及工作区需求
- 边界参与方：管理员页面、教师页面、服务端业务层和数据层
- 输入或前置条件：用户已使用用户名和密码建立相应角色的有效会话
- 成功结果：管理员页面只能调用管理员能力，教师页面只能调用教师能力；页面不直接访问数据库，服务端依据当前会话确定角色、教师身份和数据归属
- 失败与恢复：会话失效或角色不匹配时拒绝业务操作，用户重新登录后可继续
- 安全边界：客户端提交的角色、教师标识或数据归属声明不能替代服务端判定
- 验收：分别使用管理员、教师及失效会话调用双方能力，结果符合角色职责且不能跨教师访问数据

## 3. 浏览器插件内部边界

#### INT-EXT-001：由插件后台统一承担联网与本地持久化

- 状态：已接受
- 优先级：P0
- 来源：插件运行边界和单机数据边界
- 边界参与方：插件页面、内容脚本、插件后台、课程服务和插件本地存储
- 输入或前置条件：插件页面或内容脚本需要兑换、读取课程，或保存学习状态
- 成功结果：课程网络请求及课程、学习状态的本地读写统一经插件后台完成；页面和内容脚本只通过插件内部消息提出业务请求
- 失败与恢复：插件后台不可用时不绕过边界直连或直写，恢复插件上下文后重新发起请求
- 安全边界：网页脚本不能直接获得课程服务权限，也不能直接修改插件课程库或学习记录
- 验收：审查所有相关调用路径，并模拟后台失效，确认不存在页面或内容脚本旁路

#### INT-EXT-002：插件内部消息必须可配对并识别失效上下文

- 状态：已接受
- 优先级：P0
- 来源：插件页面、后台和内容脚本之间的异步协作
- 边界参与方：插件页面、内容脚本和插件后台
- 输入或前置条件：任一参与方发起跨插件上下文的业务请求
- 成功结果：消息包含协议版本、操作类型和请求标识，响应能与原请求配对；只处理当前插件上下文产生的有效响应
- 失败与恢复：空响应、非对象响应、未知操作、版本不兼容或旧上下文响应均视为失败；恢复插件上下文后重新建立监听并重试必要操作
- 安全边界：消息接收方只执行其职责范围内的已知操作，不把消息内容作为任意代码或存储指令执行
- 验收：覆盖正常配对、并发请求、未知操作、插件重载和延迟旧响应，旧响应不得改变新上下文状态

#### INT-EXT-003：真实预览使用学生运行时但不产生学生数据

- 状态：已接受
- 优先级：P0
- 来源：教师需要在发布前验证真实交互效果
- 边界参与方：教师工作区、教师预览页、插件和学生侧课程运行时
- 输入或前置条件：教师从自己的课程草稿发起真实预览，且草稿已有可识别的保存版本
- 成功结果：预览入口通过受信任握手绑定教师、课程、草稿版本和本次预览会话；插件复用学生侧运行时呈现该版本
- 失败与恢复：绑定信息缺失、过期或不一致时不进入预览；教师返回工作区重新发起
- 安全边界：预览不能发布课程、生成兑换授权、写入学生课程库或生成学生学习记录
- 验收：对同一草稿完成正常预览，并尝试篡改课程、版本和会话信息；仅正确绑定的会话可运行且本地学生数据保持不变

## 4. 哔哩哔哩页面与播放器边界

#### INT-BILI-001：只在匹配课节的受支持视频页激活

- 状态：已接受
- 优先级：P0
- 来源：B 站视频课运行场景和最小侵入约束
- 边界参与方：内容脚本、当前哔哩哔哩视频页、当前主播放器和本地课程库
- 输入或前置条件：用户在受支持的桌面 Chrome 中打开哔哩哔哩视频页
- 成功结果：插件以完整视频引用匹配本地课节；无匹配时静默，有一个匹配时加载，同一或不同课程中有多个课节匹配时由学生选择；交互只绑定当前可信主播放器
- 失败与恢复：页面不受支持、视频引用不完整或主播放器无法确认时不加载课程；页面稳定后可重新识别
- 安全边界：页面中的仿冒元素、非主播放器或其它 frame 不能取得课程控制权
- 验收：覆盖无匹配、单匹配、同课程多课节匹配、跨课程多课节匹配、分 P 或不同视频引用及页面内仿冒播放器场景

#### INT-BILI-002：课程节点只使用最小播放器控制并随页面生命周期重绑

- 状态：已接受
- 优先级：P0
- 来源：课程节点运行方式和对宿主页面的最小干预原则
- 边界参与方：课程运行时、哔哩哔哩页面和当前主播放器
- 输入或前置条件：已为当前视频加载课程，节点到达触发条件
- 成功结果：节点仅按课程运行需要暂停或恢复当前播放器；页面单页切换、播放器重建或全屏变化后，旧绑定被清理并绑定新实例
- 失败与恢复：播放器状态不可确认时停止本次控制；重新识别当前页面和播放器后再恢复课程运行
- 安全边界：插件不改变倍速、不阻止跳过、不下载 B 站播放视频，也不伪造宿主站点原生功能；节点媒体不属于宿主视频下载路径
- 验收：运行各类节点并触发页面切换、播放器重建和全屏变化，确认无重复节点、残留界面或旧状态控制新页面

## 5. 课程兑换、发布包与安装边界

#### INT-PACKAGE-001：兑换只返回当前授权课程的最新可交付版本

- 状态：已接受
- 优先级：P0
- 来源：兑换码授权、课程整包下载和单机使用方式
- 边界参与方：插件后台、课程兑换服务和课程发布存储
- 输入或前置条件：学生在插件中提交兑换码，插件附带识别本机兑换关系所需的最小本机引用
- 成功结果：服务端完成授权判定，仅返回该兑换关系当前有权获得的、按 `course_id` 自动解析出的最新可交付发布版本及其必要元数据
- 失败与恢复：兑换码无效、已失效或无权获得课程时不返回课程内容；学生修正兑换码或联系教师后重试
- 安全边界：请求不要求学生账号或教师会话，响应不包含其它课程、教师私有数据、凭证或学生数据
- 验收：分别验证有效、无效、失效及不属于该课程的兑换关系，比较响应内容和字段范围；响应中的 `releaseId` 必须是该课程当前最新可交付版本

#### INT-PACKAGE-002：插件独立校验并原子安装课程发布包

- 状态：已接受
- 优先级：P0
- 来源：课程下载、更新和本地课程库可靠性
- 边界参与方：插件后台、课程发布包和插件本地课程库
- 输入或前置条件：插件已收到兑换服务返回的课程发布包或更新包
- 成功结果：插件独立核对包版本、课程身份、必要结构和完整性后，一次性安装或替换对应课程版本
- 失败与恢复：响应无效、校验失败或本地写入失败时保留原课程库，不留下可被选中的半安装版本；之后可重新下载
- 安全边界：网页和内容脚本不能以消息载荷直接写入或替换课程库
- 验收：模拟有效包、损坏包、课程身份不符及写入中断，只有有效且完整写入的版本可被运行

## 6. 文件接口

#### INT-FILE-001：字幕文件仅在教师浏览器内解析

- 状态：已替代（被 `INT-FILE-003` 替代）
- 优先级：P1
- 来源：教师使用字幕辅助课程制作
- 边界参与方：教师浏览器、字幕解析器和课程草稿
- 输入或前置条件：教师主动选择受支持的 SRT 或 VTT 文件
- 成功结果：浏览器在本地解析字幕并供教师选择；课程节点只保存教师确认采用的必要字幕内容
- 失败与恢复：格式不支持或解析失败时不改变草稿，教师可更换文件重试
- 安全边界：原始字幕文件不自动上传，也不把字幕内容当作 HTML 或可执行内容处理
- 验收：导入有效和无效的 SRT、VTT 文件，检查网络请求、草稿变更和最终节点内容

#### INT-FILE-002：教师课程文件可移植但不直接改变线上状态

- 状态：已接受
- 优先级：P1
- 来源：课程及交互信息需要支持教师本地下载和迁移
- 边界参与方：教师工作区、课程文件和课程草稿
- 输入或前置条件：教师导出自己的课程，或选择一个受支持版本的课程文件导入
- 成功结果：导出文件自描述其格式版本并包含重建课程所需内容；导入前提供预览，确认后创建带新标识的新草稿
- 失败与恢复：文件不受支持、内容不完整或导入失败时不改变现有课程；教师修正或更换文件后重试
- 安全边界：文件不包含视频文件、凭证或学生数据；导入内容按数据处理，不能执行代码
- 验收：完成导出后导入，核对新草稿内容和新标识；验证导入不会覆盖、发布课程或生成兑换授权

#### INT-FILE-003：字幕经服务端检查修复后再由保存草稿动作进入服务端，不进入课程包或插件（替代 `INT-FILE-001`）

- 状态：已接受
- 优先级：P1
- 来源：教师使用字幕辅助课程制作；`D-V1-014`、`D-V1-017`
- 边界参与方：教师浏览器、字幕解析器、字幕检查修复接口、课程草稿、发布快照
- 输入或前置条件：教师主动选择受支持的 SRT 或 VTT 文件，上传检查成功，并执行保存草稿动作
- 成功结果：服务端临时检查字幕并对可确定的时间重叠做最小修复，浏览器展示返回的字幕；教师保存草稿时，修复后的字幕文档随草稿整体提交并持久化到服务端；发布时原样复制进发布快照
- 失败与恢复：格式、编码、时间戳、字幕文字或无法安全修复时不替换当前字幕，教师可更换文件重试；仅上传检查不产生服务端持久化副本
- 安全边界：检查接口不写数据库、不记录字幕正文；字幕原文不进入课程包、不进入插件本机存储，也不把字幕内容当作 HTML 或可执行内容处理
- 验收：导入有效、可修复和不可修复的 SRT/VTT 文件，检查网络请求、修复说明、草稿变更和最终节点内容；保存草稿后确认服务端持久化，课程包和插件校验数据中不含字幕原文

## 7. 公开试用表单边界

#### INT-TRIAL-001：销售页只打开已批准的飞书公开表单

- 状态：已接受
- 优先级：P0
- 来源：`D-V1-001`、`SCN-PUB-01`、`FR-INTAKE-001`、`FR-INTAKE-002`
- 边界参与方：公开销售页、目标老师浏览器和飞书公开表单
- 输入或前置条件：销售页配置了当前批准的 HTTPS 飞书或 Lark 公共表单地址，且该地址无需登录即可提交
- 成功结果：目标老师在新页面打开正式表单，看到与销售页一致的用途和字段说明，提交后由飞书给出明确结果
- 失败与恢复：地址缺失、域名或公开表单路径不符合批准规则、页面不可达或提交结果未知时，不显示已申请；销售页提供明确人工联系入口
- 安全边界：不使用内部编辑、预览或管理地址；销售页不读取、缓存或转发表单正文，也不暴露其他申请记录
- 验收：无登录状态打开并提交虚构申请；验证无效配置被隐藏或拒绝、失败不假成功、人工恢复入口可用

#### INT-TRIAL-002：申请结果通过受权飞书入口交给人工运营

- 状态：已接受
- 优先级：P0
- 来源：`D-V1-001`、`SCN-PUB-01`、`FR-INTAKE-003`、`FR-INTAKE-004`
- 边界参与方：飞书申请记录、获准运营人员和 KnownMap 管理员接入流程
- 输入或前置条件：飞书已经确认接收申请，运营人员通过批准身份和权限访问记录
- 成功结果：运营人员取得最小申请内容并记录跟进结果；确认接入后把必要信息交给管理员，由管理员另行创建教师
- 失败与恢复：权限不足、外部服务不可用、记录重复或内容不完整时保留真实状态并人工核对，不自动开户或复制未知数据
- 安全边界：外部表单会话和管理权限不进入公开页面或 KnownMap 教师会话；申请正文不进入普通日志
- 验收：验证授权人员可读取虚构申请、未授权人员被拒绝、申请和账号创建之间不存在自动提权路径

## 8. 已决定事项与设计阶段任务

1. 六类项目特有边界均有明确责任方；
2. 每条需求可独立验收，且不重复功能性需求的业务流程；
3. 通用工程规则没有为了凑数量而重复编号；
4. 开放项均有明确的后续落点；
5. 人工审核已完成并更新需求索引。
