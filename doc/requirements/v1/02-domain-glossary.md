## 1. 使用规则

本文件统一需求、设计、代码、测试、界面和运营文档中的业务语言。它定义“一个词在产品里表示什么”，
不负责决定数据库表名、API 字段名或页面文案；这些实现名称可以不同，但必须回链到本文件中的唯一业务概念。

1. 每个正式术语使用稳定的 `TERM-*` 编号；术语被替代时保留原编号和替代关系。
2. 中文名称是当前需求文档的标准写法；英文或代码名只用于对应已有实现，不反向改变业务含义。
3. 同一个词在不同上下文有不同含义时必须拆开命名，不依赖读者猜测。
4. 状态、权限、身份和版本不得混用；它们必须分别说明对象、时间和真源。
5. 标记为“待确认”的术语不能成为数据库、API 或公开文案的既定事实。
6. 字段级定义由后续数据字典负责，本文件不复制字段清单形成第二个数据真源。

## 2. 角色与组织边界

| 编号 | 标准术语 | 定义 | 不得混同 |
| --- | --- | --- | --- |
| TERM-001 | KnownMap | 产品品牌。当前产品类别是“互动课程工具”。 | 不等同于某个插件、网站、API 或公司主体。 |
| TERM-002 | 平台运营方 | 负责提供、维护和支持 KnownMap 服务的业务主体。 | 不默认拥有老师的课程内容或学生数据。 |
| TERM-003 | 平台管理员 | 代表平台运营方执行受控管理操作的已认证人员。 | 不等同于教师，不因管理员身份自动拥有全部业务正文读取权。 |
| TERM-004 | 教师 | 使用 KnownMap 设计、发布和交付互动课程的自然人。 | 不等同于教师账号、工作空间或课程权利人。 |
| TERM-005 | 教师账号 | 教师用于认证和进入产品的账号主体。 | 账号停用不等于课程归档或授权凭证终止。 |
| TERM-006 | 工作空间 | 课程、课节、授权、学生关系、学习证据和操作记录的业务归属与隔离边界。 | 不等同于登录会话、浏览器窗口或本地文件夹。 |
| TERM-007 | 工作空间所有者 | 对一个工作空间承担主要管理责任的教师角色。 | 不自动表示拥有其中全部内容的法定著作权。 |
| TERM-008 | 课程所有者 | 在 KnownMap 内对某门课程的设计、发布和交付结果负责的业务角色。 | 不等同于课程内容权利人；名称是否改为“课程负责人”见第 8 节。 |
| TERM-009 | 学生 | 通过老师或课程交付方获得互动课程并实际学习的人。 | 不等同于学生账号、设备、授权码或本机学习标识。 |
| TERM-010 | 本机学习标识 | 当前阶段在一台学生机器上生成并保存、用于关联该机器课程领取、版本和本地学习状态的内部标识。 | 不等同于学生账号、真实身份、授权码或可跨设备恢复的用户身份；换机后建立新的本机学习标识。 |
| TERM-011 | 内容权利人 | 对视频、字幕、题目、讲解或其它课程素材拥有相应权利或授权权利的主体。 | 不因其内容可公开访问就推定为课程所有者或教师。 |
| TERM-012 | 支持人员 | 在授权范围内协助接入、排障、恢复或答疑的内部人员。 | 支持职责不构成查看密码、密钥、完整学生回答或无关数据的理由。 |

## 3. 课程与互动内容

| 编号 | 标准术语 | 定义 | 不得混同 |
| --- | --- | --- | --- |
| TERM-013 | 课程 | 由一个工作空间管理、面向一组教学目标交付的顶层内容集合，可以包含多个课节。 | 不等同于一个视频、一个课节或一个课程包文件。 |
| TERM-014 | 课节 | 课程内可独立排序、绑定视频来源、制作互动脚本和记录学习结果的教学单元。 | 不使用 BVID 或视频 URL 充当课节身份。 |
| TERM-015 | 视频来源 | 实际提供和播放原始视频内容的外部平台或受控媒体服务。 | KnownMap 不因引用视频来源而成为视频托管方。 |
| TERM-016 | 视频引用 | 指向受支持视频来源中某个具体视频或分段的结构化定位信息。 | 不等同于课程 ID、课节 ID 或视频文件本身。当前代码对应 `VideoRef`。 |
| TERM-017 | 字幕文档 | 老师提供或确认的、带时间信息的完整字幕输入，例如 SRT 或 VTT。 | 不等同于已发布互动课程，也不默认上传服务端。 |
| TERM-018 | 字幕句 | 字幕文档中具有稳定局部标识、开始时间、结束时间和文本的一条内容单元。 | 不等同于互动节点；节点可以引用字幕句，但两者生命周期不同。 |
| TERM-019 | 互动脚本 | 描述一个课节中全部互动节点及其顺序、触发和反馈规则的结构化教学内容。 | 不等同于视频、字幕文档、页面状态或课程包。 |
| TERM-020 | 脚本草稿 | 老师仍可编辑、尚未成为学生正式交付内容的当前互动脚本。 | 保存草稿不等于发布。当前代码对应 `ScriptDraft`。 |
| TERM-021 | 已发布脚本 | 通过显式发布形成、可进入课程交付的不可混淆脚本版本。 | 不等同于“课程已安装”或“学生正在使用”。当前代码对应 `PublishedScript`。 |
| TERM-022 | 互动节点 | 互动脚本中具有稳定标识、触发规则、展示内容、学生动作、反馈和完成行为的最小教学单元。 | 不等同于字幕句、DOM 元素、数据库行或时间轴图标。 |
| TERM-023 | 节点类型 | 决定互动节点的内容结构、学生动作和反馈规则的业务分类。 | 不等同于视觉主题或实现组件名称。v1 基线为重点内容、选择题、填空题、问答题。 |
| TERM-024 | 触发规则 | 决定互动节点何时进入可执行状态的业务规则。 | 视频内时间与现实授权时间必须分开；当前核心触发使用视频播放时间。 |
| TERM-025 | 反馈 | 学生完成节点动作后由互动课程显示的解释、结果或下一步指导。 | 不默认等于 AI 评分，也不等同于教师之后的人工回复。 |
| TERM-026 | 真实预览 | 使用与学生交付一致的运行路径验证指定草稿或发布版本的课程体验。 | 不等同于静态示意、销售演示或写死数据页面。 |
| TERM-027 | 静态示意 | 只说明视觉或流程、不承诺真实触发和数据写入的展示。 | 不得命名为“真实预览”或作为端到端验收证据。 |

## 4. 发布、课程包与学生课程库

| 编号 | 标准术语 | 定义 | 不得混同 |
| --- | --- | --- | --- |
| TERM-028 | 发布 | 老师把合法草稿显式转换为可交付版本的业务动作。 | 不等同于保存、部署网站或发布软件版本。 |
| TERM-029 | 发布版本 | 某次整门课程原子发布产生的、包含当次全部纳入课节且可唯一识别、不可变、可追溯的内容快照。 | 不等同于内部课节快照、产品版本、Schema 版本、插件版本或部署版本。 |
| TERM-030 | 课程包 | 学生运行互动课程所需的已发布结构化数据集合，包含课程、课节、视频引用、节点和版本信息。 | 不包含第三方视频文件、授权码原文、教师密码或完整字幕文档。当前代码对应 `CoursePackage`。 |
| TERM-031 | 课程包 Schema 版本 | 用于解释和校验课程包数据结构的协议版本。 | 不表示课程内容发布次数，也不表示 KnownMap 产品版本。 |
| TERM-032 | 学生课程库 | 学生设备上保存已取得课程包和对应本地学习状态的逻辑集合。 | 不等同于教师工作空间或服务端课程库。当前实现对应 `studentCourseStore`。 |
| TERM-033 | 已安装课程 | 已经成功写入某个学生设备课程库、可供本地运行的课程包。 | 不代表在线授权仍有效，也不代表一定是最新发布版本。 |
| TERM-034 | 示例课程 | 随产品提供、用于帮助学生理解操作的只读课程包。 | 不属于老师授权课程，不计入真实课程交付和市场验证证据。 |

## 5. 授权与交付

| 编号 | 标准术语 | 定义 | 不得混同 |
| --- | --- | --- | --- |
| TERM-035 | 授权码 | 学生输入的高熵领取凭证，用于证明一次授权领取请求持有有效秘密。 | 不等同于学生身份、课程包、最终资格或持续 DRM。当前代码对应 `AccessCode`。 |
| TERM-036 | 授权范围 | 一项授权允许领取或更新的课程、课节、节点和现实有效时间边界。 | 视频播放时间不属于现实授权时间。 |
| TERM-037 | 授权项 | 服务端记录的一条结构化授权范围，是计算有效资格的输入。 | 不等同于授权码字符串或领取记录。当前代码对应 `AccessGrant`。 |
| TERM-038 | 领取 | 学生使用授权凭证请求建立或返回授权结果的业务动作。 | 不等同于下载完成、安装完成或开始学习。 |
| TERM-039 | 领取记录 | 记录某个本机学习标识通过某个授权来源获得了什么范围、何时发生以及结果如何的业务事实。 | 当前尚未实现；不使用访问日志临时代替。旧文档称 `Redemption`。 |
| TERM-040 | 有效资格 | 根据某个本机学习标识全部仍有效的授权来源计算出的领取、重新下载和更新权利集合。 | 不由最后输入的授权码单独决定，也不等同于本地已有内容。 |
| TERM-041 | 授权来源 | 对有效资格有贡献的一次已确认授权关系及其来源凭证。 | 不等同于课程所有权。终止一个来源不应覆盖其它仍有效来源。 |
| TERM-042 | 终止授权 | 永久停止某个授权来源继续产生新领取、重新下载或更新资格的业务动作。 | 不等同于暂停、课程归档、教师账号停用或删除学生本地课程。 |
| TERM-043 | 授权到期 | 因现实有效时间结束而使授权来源不再贡献在线资格的状态变化。 | 不表示历史记录删除，也不远程删除已安装课程。 |
| TERM-044 | 重新下载资格 | 学生删除或丢失本地课程后，重新取得课程包的在线权利。 | 不等同于本地继续运行权或更新资格。 |
| TERM-045 | 更新资格 | 学生取得授权范围内较新发布版本的在线权利。 | 不保证自动更新，也不等同于课程已经更新。 |

## 6. 学习过程与学习证据

| 编号 | 标准术语 | 定义 | 不得混同 |
| --- | --- | --- | --- |
| TERM-046 | 学习会话 | 学生在一段连续使用过程中学习某门课程或课节的上下文。 | 不等同于登录会话、教师会话或浏览器标签页。 |
| TERM-047 | 学习事件 | 对课程相关、已允许采集的一个离散学习行为或状态变化的结构化记录。 | 不包含无关浏览历史，也不直接等同于汇总进度。 |
| TERM-048 | 节点尝试 | 学生针对某个互动节点进行的一次确认、选择、填写或回答及其结果。 | 不等同于节点本身；重复尝试必须可区分。 |
| TERM-049 | 本地学习状态 | 保存在学生设备、用于恢复当前课程进度和节点状态的数据。 | 不等同于教师已看到的服务端学习证据。 |
| TERM-050 | 待同步记录 | 后续学习数据上传阶段中，已在学生设备产生、尚未被服务端确认接收的课程相关记录。 | 当前阶段不产生该状态；本机学习状态不等同于待同步记录。 |
| TERM-051 | 已同步学习记录 | 后续阶段中，服务端已经幂等接收并归属到学习标识、课程、课节和发布版本的学习数据。 | 当前阶段不上传学生个人学习数据，不得用客户端本地记录冒充已同步记录。 |
| TERM-052 | 学习证据 | 后续阶段中，可追溯到真实课程、课节、发布版本、学习标识和发生时间的已允许学习事实或汇总。 | 当前阶段只保存本地学习状态，不提供教师端真实学习证据。 |
| TERM-053 | 数据新鲜度 | 后续教师报表中，教师所见学习证据相对于学生最近同步状态的时间与完整性说明。 | 当前阶段不显示教师学习证据，不使用零值或演示值代替。 |
| TERM-054 | 学习进度 | 基于明确定义的课程或课节完成规则计算出的当前完成程度。 | 不自动等于视频播放百分比、节点完成率或学习效果。计算规则需另行定义。 |
| TERM-055 | 课节完成 | 学生满足某个课节已审核完成规则的业务状态。 | 不得仅因打开视频、播放到结尾或提交一个节点而默认完成。规则待功能需求定义。 |

## 7. 必须分开的状态与版本

### 7.1 状态对象

| 对象 | 可讨论的状态类别 | 必须避免的错误推导 |
| --- | --- | --- |
| 教师账号 | 可用、停用 | 账号停用不自动删除工作空间或终止全部历史授权。 |
| 课程 | 草稿、已发布、已归档 | 课程归档不等于授权码终止，也不删除历史学习证据。 |
| 课节 | 草稿、已发布、已归档 | 课节状态不应由视频是否可访问单独决定。 |
| 授权码 | 未生效、有效、到期、已终止 | 到期和终止不远程删除已安装课程。具体枚举后续审核。 |
| 授权项 | 当前有效、尚未生效、已失效 | 单条授权项失效不代表学生全部资格失效。 |
| 已安装课程 | 当前版本、可更新、来源失效、不可运行 | 本地存在不代表在线授权有效；视频不可访问也不等于课程包不存在。 |
| 学习记录 | 当前阶段只有本机已保存或本机保存失败；待同步、已同步和同步失败属于后续阶段 | 本机已保存不表示服务端或教师已经取得数据。 |
| 学习过程 | 未开始、进行中、已完成 | 状态必须由明确规则计算，不能由 UI 文案猜测。 |

状态枚举、状态机和允许转换将在功能、数据与设计阶段定义。本表只锁定对象之间不得互相替代。

### 7.2 六种版本

| 标准名称 | 表示什么 | 示例或当前对应 |
| --- | --- | --- |
| 产品版本 | KnownMap 对外发布的产品能力版本 | `v0.9.1`、目标 `v1.0.0` |
| 文档版本 | 某份需求或设计文档的修订状态 | `1.0.0-draft.1` |
| 课程包 Schema 版本 | 课程包数据结构的兼容版本 | 当前 `schemaVersion: 2` |
| 发布版本 | 老师某次整门课程发布产生的内容版本 | 某门课程第 1、2、3 次发布 |
| 插件版本 | 浏览器扩展安装包的软件版本 | 当前 manifest `0.9.1` |
| 部署版本 | 一次可追溯生产部署的 release | release ID + Git commit |

任何文档出现“当前版本”“最新版”或“升级版本”时，必须写出上述哪一种版本以及对应标识。

## 8. 禁止混用与待确认命名

### 8.1 禁止或应避免的模糊说法

| 模糊说法 | 必须改写为 |
| --- | --- |
| 用户 | 教师、学生、平台管理员、支持人员或其它明确角色 |
| 下载课程 | 下载课程包；若指视频必须明确写“视频文件”，而 v1 不提供该能力 |
| 课程配置 | 按语义改为脚本草稿、已发布脚本、课程包或页面临时状态 |
| 学生账号 | 学生、本机学习标识或登录账号；三者不能互换；当前阶段没有学生账号 |
| 授权 | 明确为授权码、授权项、授权范围、领取记录或有效资格 |
| 取消授权 | 明确是终止授权来源、课程归档、教师账号停用，还是其它状态变化 |
| 当前课程 | 明确是教师正在编辑的课程、学生选中的课程、当前视频匹配课程或已安装课程 |
| 当前课节 | 明确是教师正在编辑、学生正在学习或播放器当前匹配的课节 |
| 预览 | 明确是真实预览还是静态示意 |
| 学习数据 | 明确为当前本机学习状态，或后续阶段的待同步记录、已同步记录、学习证据或汇总指标 |
| 版本 | 使用第 7.2 节中的完整版本名称 |
| 删除 | 明确对象、真源、软删除或物理删除、历史与备份是否保留 |

旧名称 `LessonPilot` 只允许出现在历史文件名、兼容键、迁移说明或 Git 历史中。当前产品、需求和新增代码
统一使用 `KnownMap`；不得为了表面统一直接重命名仍承担兼容职责的旧存储键或协议标识。

### 8.2 需求冻结前待确认的界面命名

| 编号 | 待确认问题 | 暂定规则 |
| --- | --- | --- |
| NAME-01 | “课程所有者”是否容易被误解为著作权人？ | 需求层保留该业务角色；公开界面优先评估“课程负责人”。 |
