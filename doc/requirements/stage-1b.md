# Stage 1B 销售首页与教师工作台需求

版本：1.0

更新时间：2026-08-15

状态：已确认，等待 1A 完成后实施。

## 1. 本阶段目标

老师可以从默认销售首页进入真实工作台，输入一条 B 站视频 URL、导入对应字幕、配置四种节点，并经 1A 消息桥把一门有效课程保存到本机插件。

1B 不负责在 B 站实际运行节点；该行为属于 1C。

## 2. 页面职责

### WEB-01 默认销售首页

- `teacher-web/index.html` 是网站默认入口；
- 当前 `teacher-web/forsales.html` 的销售内容迁入该入口；
- 页面保持静态，主要行动是“申请改造一节真实课程”；
- 已准备课程的老师可以通过次要行动进入教师工作台；
- 页面不得把老师语音、AI 评价、正式报告、账号或规模化发布描述为已可用。

### WEB-02 真实教师工作台

- `teacher-web/workspace.html` 是唯一真实工作台；
- 沿用现有工作台示例的主要信息结构和视觉语言；
- 提供课程 URL、字幕导入、真实时间线、节点编辑、保存和预览入口；
- 不新增与当前闭环无关的后台模块。

### WEB-03 兼容与旧原型

- `teacher-web/forsales.html` 迁移后跳转到默认销售首页，并提供无脚本回退；
- `teacher-web/editor.html` 停止扩展；
- 旧编辑器的必要能力迁入 workspace 并回归通过后，才另行决定是否删除。

### WEB-04 响应式边界

- 销售首页和工作台在桌面和 375px 宽度下无关键遮挡或横向溢出；
- 移动宽度只保证页面可阅读，不承诺移动端插件体验；
- 动态状态和长文本不得导致主要控件位移到不可操作区域。

## 3. 课程输入

### COURSE-01 视频 URL

- 只接受当前浏览器可访问的标准 `https://www.bilibili.com/video/BV.../` URL；
- 从 pathname 提取 BVID，拒绝非 B 站来源、非标准视频页和缺少 BVID 的 URL；
- 第一阶段不自动验证课程所有权、付费权限或字幕是否对应视频。

### COURSE-02 字幕导入

- 接受 `.srt` 和 `.vtt`；
- 字幕只在浏览器本地解析，不上传、不发送给插件；
- 拒绝空文件、不支持格式、无法解析时间戳、结束早于开始和非递增时间线；
- 成功后显示文件名、字幕段数和“需要人工确认与视频匹配”；
- 未人工勾选 `subtitlesConfirmed` 时允许继续编辑，但禁止保存到插件。

### COURSE-03 本地草稿

- 使用 `localStorage` 的 `lessonpilot.workspaceDraft.v1` 保存唯一当前草稿；
- 草稿包含 URL、VideoRef、人工确认状态、完整解析字幕、节点和更新时间；
- 每次有效修改后保存，刷新页面能够恢复；
- 数据损坏时显示明确错误，不静默覆盖为新空草稿。

## 4. 时间线与四种节点

### COURSE-04 时间线

- 时间线来自已导入字幕，不读取跨源 B 站 iframe 进度；
- 老师可从字幕段落选择节点触发时间，也可修正为合法非负秒数；
- 节点按触发时间、再按稳定 ID 排序；
- 同一时间允许多个节点；
- 老师可以新增、编辑和删除节点。

### NODE-01 重点标注

- `attention + notice`；
- 标题和正文必填，重点词可选；
- 教师预览完整显示内容；画面高亮只作为增强。

### NODE-02 选择题

- `practice + choice`；
- 题目非空，至少两个非空且 ID 唯一的选项；
- 必须指定一个存在的正确选项，并填写解释反馈。

### NODE-03 填空题

- `practice + blank`；
- 题目非空，至少一个非空可接受答案；
- 比较规则固定为 `trim` 和英文 `casefold`；
- 老师必须填写解释反馈。

### NODE-04 问答题

- `followup + free_text`；
- 提示和老师参考反馈必填；
- 不提供正确答案、AI 评价或 AI 配置字段。

### NODE-05 通用校验

- 每个节点只属于当前课程、当前视频和一个时间点；
- 字段以 `doc/data-spec.md` 为准，不接受其它节点组合；
- 任一节点非法时整体拒绝保存；
- 所有动态课程内容使用安全 DOM API 渲染。

## 5. 单课程切换与保存

### COURSE-05 URL 切换

- 当前课程已有字幕或节点时，更换 URL 必须先确认；
- 取消时不得改变 URL、字幕、节点、草稿或插件课程；
- 确认后先用 `expectedCourseId` 清除插件旧课程；
- 插件清除成功后才清空网页旧草稿并采用新 URL；
- 清除失败时保留全部旧数据并显示可重试错误。

### SAVE-01 插件连接

- 页面初始化执行 `PING`；
- 明确区分插件未安装、协议不兼容和连接成功；
- 连接状态显示在固定状态区域，不阻断用户先编辑本地草稿。

### SAVE-02 保存课程

- 保存前要求 URL、字幕确认状态和全部节点通过校验；
- `WorkspaceDraft` 转换为 `PluginCourseConfig` 时删除 captions、sourceUrl 和 UI 状态；
- 页面通过 `SAVE_CURRENT_COURSE` 完整替换插件课程；
- 保存成功后读取确认，只有回读一致才显示已保存；
- 失败或超时保留草稿，允许手动重试但不自动重复写入。

### SAVE-03 开始预览

- 页面先保存并确认课程，再调用 `START_PREVIEW_SESSION`；
- 创建会话成功后才打开与 VideoRef 对应的 B 站原页面；
- 当前 B 站页面无法访问时显示外部访问错误，但不删除课程草稿。

## 6. 错误与用户状态

工作台必须明确处理：

- 无效或不支持的视频 URL；
- 字幕格式、时间线或人工确认错误；
- 节点字段和 family/interaction 组合错误；
- 本地草稿损坏或 localStorage 写入失败；
- 插件未安装、版本不兼容、消息超时和存储失败；
- 切换课程时插件课程已被其它页面改变；
- 保存回读与发送配置不一致。

错误显示在相关字段或固定状态区，保留用户可以修复的数据，不展示堆栈、内部路径或敏感内容。

## 7. 本阶段非目标

- 自动获取、识别或生成字幕；
- 多课程列表、复制、版本历史和云保存；
- AI 生成节点或反馈；
- 账号和正式发布流程；
- B 站学生运行时和真实题目触发；
- 第一阶段总览中的全部共同非目标。

## 8. 1B 完成定义

1. `/teacher-web/` 是销售首页，主要 CTA 清楚且承诺真实；
2. `/teacher-web/workspace.html` 是唯一真实工作台；
3. 旧 `/teacher-web/forsales.html` 不会直接失效；
4. 标准 B 站 URL 和真实 SRT/VTT 能形成字幕时间线；
5. 四种节点均可新增、编辑、删除和校验；
6. 刷新工作台可恢复当前草稿；
7. 未确认字幕或非法节点不能保存到插件；
8. URL 切换的取消、确认、清除失败行为符合 COURSE-05；
9. 保存失败不假成功且不丢草稿，成功后回读一致；
10. 预览会话成功后才打开对应 B 站页面；
11. 两个页面在桌面和 375px 宽度下无关键遮挡或横向溢出；
12. 自动化和真实浏览器人工验收通过，`next.md` 推进到 1C。
