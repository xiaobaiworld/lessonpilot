# KnownMap 老版新版切换计划

版本：0.1.1
建立日期：2026-08-24  
状态：v1 已切换生产，即时验收与观察期执行中
执行真源：本文件只记录切换步骤、完成状态和证据，不替代已冻结需求、设计、开发计划与测试计划。

## 1. 目标与完成定义

本计划用于把 KnownMap 从当前生产老版安全切换到 v1，并在观察期、真实交付、消费者和恢复责任
全部清零后，通过独立变更删除老版代码。

只有以下结果全部成立，才可把本计划标记为“完成”：

1. v1 Web、API、插件、Schema 和数据库迁移作为同一套兼容组合切换到生产；
2. 生产环境的销售、管理员、教师、学生完整链路通过真实验收；
3. 观察期内至少完成一个真实完整交付周期，健康、错误、备份和恢复无阻塞问题；
4. 老版 API、页面、插件、存储、书签、脚本、文档及人工支持消费者已经清零或有明确拒绝/重定向；
5. 老版不再承担回滚、恢复、追溯或安全处置责任；
6. 老版删除通过独立提交完成，删除前后全部门禁和生产探针通过。

首次 v1 生产切换与老版删除不得位于同一提交、同一发布动作或同一回滚单元。

## 2. 状态与记录规则

状态只使用以下四种：

- `[ ]`：待执行或尚无充分证据；
- `[x]`：已执行并在第 5 节登记可复核证据；
- `阻塞`：存在明确阻塞，必须在执行日志写明原因和解除条件；
- `不适用`：经确认不适用，必须记录批准依据，不可直接删除步骤。

每完成一项，必须同时做三件事：

1. 把对应复选框从 `[ ]` 改为 `[x]`；
2. 在“完成记录”追加时间、执行人、提交或发布版本、证据和结果；
3. 在“执行日志”追加简短说明。历史日志只追加，不覆盖；结论更正时新增一条更正记录。

禁止用“页面能打开”“构建成功”或口头印象代替真实业务、回滚、恢复和生产证据。
