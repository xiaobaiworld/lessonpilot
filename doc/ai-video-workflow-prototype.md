# AI 视频工作流单页原型

日期：2026-09-24；状态：原型需求与设计

## 需求

用户希望用一个小网页体验“选题调研 → 脚本分镜 → 视觉设定 → 素材生成 → 动效合成 → 校对发布”的连续流程，能选择选项，并立即看到选择对视频方案和画面预览的影响。

验收：单个 HTML 文件可直接打开；六步可导航；主题、角度、时长、比例、风格、素材形式和动效选择会更新同一份方案；可以播放示意预览并下载制作单；窄屏和键盘可操作。

边界：这是独立于 KnownMap v1 的交互原型。页面使用本地模板和 CSS 示意画面，不调用 AI、外部 API，不声称已生成真实素材或 MP4，也不发布视频。现有 `D-V1-002` 决策仍适用于 KnownMap v1。

## 设计

采用一个自包含 `prototypes/ai-video-workflow.html`：左侧六步导航，中间当前步骤的控件，右侧共享画面预览和方案摘要。浏览器内存维护状态；用户选择立即刷新相关内容。播放预览循环展示四个叙事段落。最终下载 Markdown 制作单，作为后续人工或 AI 制作的输入。

选择单文件原型，是因为当前目标是验证流程和交互；接入真实模型、素材服务、视频渲染和发布会改变成本、授权和数据边界，待原型方向确认后单独定义。
