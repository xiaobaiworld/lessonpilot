# 教师可视化节点编辑器手工验收

日期：2026-08-18

环境：

- 教师页面：`http://127.0.0.1:4173/teacher-web/editor.html`
- FastAPI：`http://127.0.0.1:8000`
- 浏览器：Playwright Chromium
- 桌面视口：1440 x 1000
- 移动视口：375 x 900

## 验收结果

1. 预建教师测试账号可登录并读取现有课程、课节和草稿。
2. 四种节点组件均显示在组件栏中。
3. 点击组件后点击时间轴可打开类型化编辑弹窗。
4. 拖放组件到时间轴可打开同一个编辑弹窗；未保存前节点数量不变化。
5. 拖放创建的选择题从 02:45 移动到 02:53，保存草稿并刷新后时间和内容均恢复。
6. 键盘 Enter 和右键都可编辑选中节点；Delete 会显示“确定删除这个节点吗？”并只删除当前节点。
7. 02:52 和 02:53 的两个临近节点可同时显示并分别操作。
8. 时间轴缩放从 100% 调整到 125%。
9. 发布成功并生成新版本；授权码创建成功，验收记录未读取或保存授权码原文。
10. 桌面页面宽度等于 1440px，无页面级横向溢出。
11. 375px 页面宽度等于 375px；时间轴在局部容器内横向滚动，页面本身不溢出。
12. 移动弹窗宽 337px，左右边界均位于 375px 视口内。
13. 新页面会话无控制台 error、warning 或页面脚本异常。
14. 结构化日志不记录字幕正文、节点正文、密码、会话凭证或授权码原文。
