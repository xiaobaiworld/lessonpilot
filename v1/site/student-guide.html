学生端 · 安装说明

学生使用步骤

先下载插件，再解压并手动安装到 Chrome。第一次大约需要 3–5 分钟，安装完成后不需要登录 KnownMap。

PC Chrome 固定 ZIP 不需要登录
下载学生插件
!

请在电脑上的 Chrome 中操作。手机和其它浏览器不属于当前支持范围。安装完成后，请保留解压得到的插件文件夹。

01

1. 下载插件

点击下面的按钮，下载 knownmapplugin.zip。如果 Chrome 询问是否保留文件，请确认这是从 KnownMap 下载的插件包后再继续。

下载 knownmapplugin.zip
02

2. 解压插件

在“下载”文件夹里找到 ZIP，双击解压。你会得到一个名为 knownmapplugin 的文件夹。把它放到一个长期保留的位置，后面安装时选择的是这个文件夹，不是 ZIP 文件。

重要：安装完成后不要移动或删除这个文件夹，否则 Chrome 会找不到插件文件。
03

3. 打开扩展程序管理页

新开一个 Chrome 标签页，把下面这行地址复制到地址栏并按回车。普通网页不能替你自动打开这个内部页面，所以需要手动粘贴。

chrome://extensions/
04

4. 开启开发者模式

在扩展程序管理页右上角打开“开发者模式”。打开后，页面左上方会出现加载按钮。

05

5. 加载已解压的扩展程序

点击左上角“加载未打包的扩展程序”（部分 Chrome 版本显示为“加载已解压的扩展程序”），在弹出的窗口中选择第 2 步得到的 knownmapplugin 文件夹。

06

6. 安装完成，打开插件

扩展程序列表出现 KnownMap 后，安装就完成了。点击 Chrome 工具栏右上角的扩展图标，找到 KnownMap；你可以把它固定到工具栏，然后按老师提供的授权码领取课程。

以后收到新版 ZIP 时，先替换原文件夹内容，再回到扩展程序管理页点击“更新”或重新加载。

准备好后，就可以领取课程

如果安装过程中某一步与你看到的画面不一样，把当前画面截图发给老师或 KnownMap 开发者即可定位。
