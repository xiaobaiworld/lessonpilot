## 准备

1. 按 `backend/README.md` 启动本地 FastAPI，并准备一门已发布课程和一个有效授权码。
2. 在 `chrome://extensions` 开启开发者模式，加载仓库 `src/` 目录。
3. 打开课程绑定的 B 站视频页，同时打开扩展 service worker、页面和 FastAPI 日志。

不得把完整授权码、Cookie、节点正文或学生答案粘贴到本文件。
